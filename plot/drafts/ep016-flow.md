# 第16話 構成案(本文ではなく、流れの設計図)

## この作品の前提(評価に必要な最小限)

- VRMMO小説。主人公は大学一年の冬夜、ゲーム内名「ウィン」。職業は暗器使い(隠密・投擲)。固有能力(ソウルクレスト)は「彼は誰」——**自分以外の物を一時的に自分のものにして、形を変えられる**。制約は三つ:**同時に変えられるのは一つだけ／変えるとき、その物が手の届く範囲にあること／意識を切れば元の形に戻る**。**自分の持ち物なら、借りる手間なしに直接変えられる**
- 相棒は茜音(光魔導士・後衛。攻撃の光弾と、光の壁を張る技を持つ)。二人は前話までに、本来なら討伐対象の特別なモンスター「氷牙の白虎」を仲間にしてしまい、**その正体を隠して生活している**。白虎は普段は両手に乗る仔虎の姿で、茜音の紋章の中にしまわれている。名前は「ユキ」。しゃがれた老人の声で喋るが、中身は子供っぽい。ウィンのことは「小僧」と呼ぶ
- 前話(第15話)で、街中でユキが勝手に出てきて人だかりができ、その夜プレイヤー掲示板に目撃スレッドが立って祭りになった。冬夜は待ち合わせ場所を広場から南門へ変えた
- 茜音はネットに疎く掲示板を見ないが、**ユキのスレだけは読むようになった**

## 第16話でやること(章プロットで確定している要素)

1. 待ち合わせは南門 / 2. 茜音が「ユキのスレだけ」読む / 3. 二人の狩り / 4. ウィンの新戦術=**借りた物を「置いてから使う」。一度目は失敗、終盤で決める** / 5. レベルアップと、その日できるようになったことを一つ / 6. **クレストで土を借りて足跡を写し取る**(戦闘外運用の初出) / 7. 引き: 写しの隣に新しい足跡が増える

## この回の芯

**「一つしか保てない」という制約が、失敗の理由になり、二度目の解法を決め、最後の怖さになる。**——同じ一本を三回使う。あわせて**「浅場に狼が出てきている」**という異変の線を、戦闘の読み違いと最後の足跡の両方に繋ぐ。

## 流れ(場面は三つ。配分 450 / 2,500 / 1,300)

### 場面1 南門(朝) — 約450字

- ウィンが南門で待つ。広場を避けたのは掲示板の騒ぎのため
- 茜音が来るなり「スレ、一晩で五百まで伸びてた」。**掲示板を見ないと言っていた本人が読んでいる**
  - ウィン「見ないんじゃなかったんですか」/ 茜音「ユキのだけ。**悪く書かれてないか、気になるでしょ**」——**読む理由を人として渡す**
  - ウィンは言い返せずに飲み込む(温度差の処理は一行)。深刻さの議論はしない
- 依頼は**前日に受注済み**。灰色狼を**あと一頭**(数を単純にし、失敗したらその日が終わらない緊張を作る)。既読なので票は読み上げず、**歩きながら一言**「獣道沿いに出るって書いてありましたよね」で渡す(**これが後で見立てを狂わせる出所**)
- **新戦術に着手する動機を一行置く**: 昨日、足元に使える物がなくて一頭取り逃がしている。**「予告」は書かないが、動機の出所は渡す**

### 場面2 森(狩り) — 約2,300字

**(a) 森に入ってユキを出す — 短く**
- 一口ぶんの可愛さ。**不服を一言**(『わしはいつまで、この大きさでおればよいのじゃ』)
- **狼の気配には何も反応しない**ことを一行で見せておく(平常を先に置く。場面3の反転のため)

**(b) 仕込み — 説明せず、動作で**
- ウィンが黙って獣道に**自分の縄を一本**張り、脇の茂みに入って身を伏せる(隠密行動)
- 茜音の「なにしてるの?」に**答えない**(伏せ台詞は置かない)
- **「置いておく利点」は動作で渡す**: 相手が来てから足元の物を探していては間に合わない。長さも場所も、先に選んでおける。**ただし変える瞬間には手が届いていないといけないので、ウィン自身が縄の脇を離れられない**——この一点を、伏せている姿で読者に見せる

**(c) 一度目=罠は作動する。だが獲れない**
- 灰色狼が二頭。**痩せていて毛が汚れている**(浅場に出てきた個体、という物理の証拠)
- **臨戦の合図はこの回で新しく立てる**: 喉の奥が低く鳴り、肩が盛り上がる。**「耳を伏せる」は第12話で別の意味(逃げる合図)に使っているので採らない**
- 一頭が縄を踏む→**縄が棘だらけの茨に変わって足に巻きつく**(量が跳ねない形。柵ではなく縄のまま)。投擲は入るが**浅い。仕留めきれない**——だから**茨を保ち続けるしかない**(保つ理由が残る)
- **破れる理由が制約そのもの**: 茨を保っている間、ウィンは他の物を変えられず、その場も離れられない。そこへ二頭目が**獣道を通らず、藪を斜めに突っ切って**背後へ回る
- ウィンは**茨を保ったまま受けて、背中に一撃をもらう**(被弾に構図の理由がある)。**痛みで意識が飛び、茨が一瞬ほどけかける**(制約の重さを体で見せる)
- **ユキが出ようとするのは、この瞬間**(動機がある)。茜音が押さえる——ここで**「出せない」理由が効く**(討伐対象/街の騒ぎ)。場面1の掲示板と戦闘が、この一行で繋がる
- 茜音の光弾で凌ぐ。ウィンは茨を切らざるを得ず、**手負いの一頭目も含めて二頭とも退く。今日の獲物はゼロ**
- **茜音が被弾に反応する**——手当ての一拍(相棒の怪我に無反応にしない)。**同時に、茜音は「背後が空いていた」ことを見ている**(後の申し出の根拠になる)
- **発見は一つに絞る**: 保っている間は無防備になる。**背中を取られない形でしかやれない**
- ウィンは理屈を言わない。**縄を回収しながら、沢のほうの細い道を見ている**(動作で引き受ける)

**(d) 二度目=決まる**
- **相手は一度目に退いた手負いの個体**。血の匂いを追って戻ってくる(**逃げた狼と再遭遇する橋を必ず一段架ける**)
- 選ぶのは**倒木と岩壁に挟まれた細い道**(森へ入る場面(a)で一度通過させ、画を先に見せておく)。**細道は行き止まりではなく通り抜けられる**——だから狼は逃げ道として入る
- **茜音の側から申し出させる**: 「反対側、わたしが塞ごうか」。根拠は(c)で背後が空いていたのを見ていること
- **タイミングを噛み合わせる**(この回いちばんの難所。順序を固定する):
  1. ウィンが正面から姿を見せて圧をかける(**弁明の台詞は置かず、狼が下がる結果で示す**)
  2. 狼が退き、逃げ道として細道へ入る
  3. **茜音は狼が入る前から詠唱を始めている**(溜めの制約を踏み倒さない)。入った直後に向こう口へ光の壁
  4. 引き返してきた狼が縄を踏む
  5. **茨が縄ごと立ち上がって狼を岩壁へ押さえ込む**(一度目にない画)。ウィンは岩壁を背にしているので背後を取られない
- **二度目にも負荷を一つ**: 手負いの個体は一度縄を避ける。二度目の踏み込みまで待つあいだ、光の壁が保たない
- 音と絵はここに集中。決定打の直前に一拍。**これで数が足りる**(森の中では「数は足りた」までにし、報告は次話へ)

**(e) 通知と、できるようになったこと**
- 戦闘が完全に終わってからレベルアップ通知
- **発見と成長を一本にする**: 学んだのは「長く保つ」ことではなく**「踏んだ一瞬だけ保てばいい」**。二度目は保った時間が一度目よりずっと短い——**発見(場所を選べ)と地続きにする**
- 茜音の受けは短く一言

### 場面3 帰り道の足跡 — 約1,250字

- 沢沿いのぬかるみに、大きな足跡。灰色狼のものではない
- **動機を先に立てる**(偶発のひらめきにしない): ウィンは**この形を残したい**と思う。だが現物は持ち帰れず、絵に描く手もない。**そこでクレストを使う**——目的が先、手段が後の順序にする
- **絵を一文で言い切る**: 足元の土を借りて、**足跡の凹みへ流し込んで固める**。抜き上げると、**足の形をした塊**になる(凹みの陰刻を、陽刻に起こす)
  - **写して初めて見える理由を物理で置く**: 凹みには沢の水が溜まっていて、覗いても底が読めない。**起こして初めて、爪が片側だけ深いことが分かる**(章の伏線。意味は分からないまま置く)
  - 制約は守る:**意識を切れば土に戻る**。だから**保っているあいだに覚えるしかない**——**この「切れない理由」が、そのまま引きの怖さになる**(切れば手は空くが、形は消える)
- **掲示板の線の回収は、この回では書かない**(場面2の「ユキを出せない」と二重になるため。第17話の材料として送る)
- 茜音は**見えている事実**(足跡の向き、間隔の乱れ、沢を渡っている)を見てから「追ってたのかな。逃げてたのかな」と言う。推測から入らせない
- **ユキ**: 匂いを嗅いだあと、**自分から茜音の紋章へ引っ込む**。狼には何も反応しなかった獣が隠れる、という行動で格を渡す(「耳を寝かせる」は既出の合図なので使わない)
  - 引っ込む前に一言:『……何かは分からん。ただ、ここは嫌じゃ』
- **引き**: ウィンは**爪の跡に見入っていて、横を見ていない**(なぜ気づかなかったかの理由を先に置く)。茜音に呼ばれて顔を上げ、戻したとき——**写した塊のすぐ隣に、同じ形の凹みが一つ増えている**
  - **ここで二択が立つ**: 型を保ち続ければ形は残るが、その間ウィンは他の何も変えられない。切れば手は空くが、足の形は土に戻って消える。**この二択があることだけ一行で見せて閉じる**
  - 「顔を上げても何もいない」とは書かない。**目を離した数秒で増えていた**、だけを書く
  - **沢の水音を場面3の頭で一度鳴らしておく**(大きな獣が無音で近づけた理由を、あらかじめ無料で成立させる)
  - **陽刻(写した塊)と陰刻(新しい凹み)を読者に反転照合させない**。同じ主のものだと一目で分かる書き方にする

### 次話への渡し(構成の申し送り)

- **第17話の冒頭は、動いたまま始める。** この回は緊急状態で幕を閉じるので、次話を休憩や雑談から始めない(第13話→第14話で同じ失敗をしている)
- **第17話が引き受けるもの**: (1)引きの直後——**離脱を選ぶ**(遭遇させない。姿を見せるのは章の後半に取っておく)、(2)ギルドへの討伐報告と報酬、(3)足跡を掲示板で照合したいが、ユキの祭りの最中でそれができないという逡巡
- **緊急事態からの帰還と事務処理を同じ回に詰めないよう、17話の配分を先に決めておく**

## この回で守る制約(自己チェック用)

- クレストの三制約が、失敗の理由・二度目の解法・引きの怖さを兼ねる。**制約を回避せず、制約で書く**
- 仕込むのは縄一本。**量が跳ねる形(柵など)にしない**
- 新しい手は一度目に成功させない。ただし**画は一度見せる**(空振りにしない)。**二度目には一度目にない画を足す**
- 観察していないことを前提にしない。発見は一つに絞る
- 制約や職業選択を、台詞で説明・弁明させない。動作と結果で示す
- 討伐数を通す(あと二頭→一度目に一頭→二度目に一頭→達成)
- NPCや仲間に攻略法を言わせない。茜音が出すのは事実の提供と役割の申し出まで
- ステータスの数値・金額は書かない。通知はレベルアップとスキル習得の二種類だけ
- ユキは戦力にしない。ただし**平常を先に見せ、被弾の瞬間に出ようとし、最後に自分から隠れる**の三段で、装置にしない
- **地の文の呼称**: この回は全編ゲーム内なので**地の文はすべて「ウィン」**。掲示板の話題が出ると「冬夜」へ滑りやすいので注意
- **直前二話(第14・15話)と、締めの型・場面構成の型・情報の渡され方が三連続していないか執筆前に突き合わせる**
