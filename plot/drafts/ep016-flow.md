# 第16話 構成案(本文ではなく、流れの設計図)

## この作品の前提(評価に必要な最小限)

- VRMMO小説。主人公は大学一年の冬夜、ゲーム内名「ウィン」。職業は暗器使い(隠密・投擲)。固有能力(ソウルクレスト)は「彼は誰」——**自分以外の物を一時的に自分のものにして、形を変えられる**。制約は三つ:**同時に変えられるのは一つだけ／変えるとき、その物が手の届く範囲にあること／意識を切れば元の形に戻る**。**自分の持ち物なら、借りる手間なしに直接変えられる**
- 相棒は茜音(光魔導士・後衛)。二人は前話までに、本来なら討伐対象の特別なモンスター「氷牙の白虎」を仲間にしてしまい、**その正体を隠して生活している**。白虎は普段は両手に乗る仔虎の姿で、**茜音の**紋章の中にいる(=茜音がいなければ出せない)。名前は「ユキ」。しゃがれた老人の声で喋るが中身は子供っぽい。ウィンのことは「小僧」と呼ぶ
- 前話(第15話)で、街中でユキが勝手に出てきて人だかりができ、その夜プレイヤー掲示板に目撃スレッドが立って祭りになった。ウィンは待ち合わせ場所を広場から南門へ変え、**今日会う約束をしている**
- 茜音には別に友達がいて、前話で狩りの誘いを断っている

## 第16話でやること(章プロットで確定している要素)

1. 待ち合わせは南門 / 2. ウィンの新戦術=**借りた物を「置いてから使う」。一度目は失敗、終盤で決める** / 3. レベルアップと、その日できるようになったことを一つ / 4. 章の伏線=**踏み込みが片側だけ深い足跡** / 5. 引き: 足跡が一つ増える(**戦闘外のクレスト運用は、必然が立たないためこの回では見送る**)

## この回の芯

**「一つしか保てない」という制約が、失敗の理由になり、二度目の解法を決め、最後の怖さになる。**——同じ一本を三回使う。
**そして今回、ウィンは一人である。** 前話が「二人+ユキ」の賑やかな回だったので、対比として静かな単独回にする。救援がないぶん失敗の代償が実際に痛く、最後の発見も**誰にも見せられないまま**残る。

## 流れ(場面は三つ。配分 700 / 2,200 / 1,100。合計4,000字)

### 場面1 南門(朝) — 約650字

- 約束どおり南門で落ち合う。**ただし茜音は、断りに来た**——昨日誘いを断った友達と、今日は行くことになった
- **なぜメッセージで済ませず来たのかを、行動で示す**: 茜音はユキを出して、門の外の草地で少しだけ走らせる。**友達といる間はユキを出せない**(正体は二人だけの秘密なので)。**出せるのが今しかないから来た**——理由を台詞で説明せず、「今日はもう出せないから」の一言と、走らせている数行で渡す
- ユキの出番はここだけ。数行に留める
- ウィンは一人で行くと言う。**新戦術の動機を一行**: 昨日、足元に使える物がなくて一頭取り逃がしている。「試したいことがあるので、ちょうどいいです」
- **「またなんか分かったら話しましょう」で解散**。掲示板の騒ぎは話題に出るが、深刻さの議論はしない(前話で処理済み)
- 依頼は前日受注済みで、灰色狼を**あと一頭**。**歩きながら一言「獣道沿いに出るって書いてありましたよね」**(後で見立てを狂わせる出所)

### 場面2 森(単独の狩り) — 約2,450字

**(a) 森に入る**
- 一人。ユキも茜音もいない。**第15話との対比を、静けさで一行**
- **細道(倒木と岩壁に挟まれた通り抜けの道)を、ここで一度通過させる**——二度目の舞台を先に画に出しておく(都合よく現れないため)

**(b) 仕込み — 説明せず、動作で**
- ウィンが獣道に**自分の縄を一本**張り、脇の茂みに伏せる(隠密行動)
- **「置いておく利点」を動作で渡す**: 相手が来てから足元の物を探していては間に合わない。長さも場所も先に選べる。**ただし変える瞬間には手が届いていないといけないので、縄の脇を離れられない**——この一点を、伏せている姿で読者に見せる(**地の文一行で本人の認識として担保する。台詞の説明はしない**)

**(c) 一度目=罠は作動する。だが獲れない**
- 灰色狼が二頭。**痩せていて毛が汚れている**(浅場に出てきた個体、という物理の証拠)
- **臨戦の合図はこの回で新しく立てる**: 喉の奥が低く鳴り、肩が盛り上がる。**「耳を伏せる」は第12話で別の意味(逃げる合図)に使っているので採らない**
- 一頭が縄を踏む→**縄が棘だらけの茨に変わって足に絡む**(量が跳ねない形)。投擲は入るが**浅く、仕留めきれない**——だから**茨を保ち続けるしかない**
- **破れる理由が制約そのもの**: 保っている間、ウィンは他の物を変えられず、その場も離れられない。そこへ二頭目が**獣道を通らず、藪を斜めに突っ切って**背後へ回る
- **一人なので救援がない。** 茨を切って離脱するしかなく、**背中に一撃をもらいながら逃げる**。今日の獲物はゼロ、傷薬を一本使う
- **発見は一つに絞る**: 保っている間は無防備になる。**背中を取られない形でしかやれない**
- ウィンは理屈を言わない。**傷薬の空き瓶をしまいながら、来る途中で通った細道のほうを見ている**(動作で引き受ける)

**(d) 二度目=決まる**
- **相手は一度目に退いた手負いの個体**。血の匂いを追って戻ってくる(**逃げた狼と再遭遇する橋を必ず一段架ける**)
- 細道へ移る。**通り抜けられる道なので、狼は逃げ道として入る**
- **タイミングを固定する**:
  1. ウィンが正面から姿を見せて圧をかける(**弁明の台詞は置かず、狼が下がる結果で示す**)
  2. 狼が退き、細道へ入る
  3. ウィンは**岩壁を背にして出口に立つ**——背後を取られない形。これが一度目の発見の実装
  4. 狼が縄を踏む
  5. **茨が縄ごと立ち上がって狼を岩壁へ押さえ込む**(一度目にない画)。音と絵はここに集中。決定打の直前に一拍
- **二度目にも負荷を一つ**: 手負いの個体は一度縄を避ける。踏ませ直すまで、ウィンは岩壁を背にしたまま動けない
- **これで数が足りる**(森の中では「数は足りた」までにし、報告は次話へ)

**(e) 通知と、できるようになったこと**
- 戦闘が完全に終わってからレベルアップ通知
- **発見と成長を一本にする**: 学んだのは「長く保つ」ことではなく**「踏んだ一瞬だけ保てばいい」**。二度目に保った時間は、一度目よりずっと短い

### 場面3 帰り道の足跡 — 約800字

- 沢沿いのぬかるみに、大きな足跡。灰色狼のものではない
- **沢の水音を、場面2の終盤か、この場面の入りで一度鳴らしておく**(後で大きな獣が無音で近づける理由を、あらかじめ無料で成立させる)
- **クレストは使わない。** 屈んで見る、それだけ——**写す必然も、水を掬う必然もない**(無駄な作業描写になる)。**この回のクレストの見せ場は場面2の一本に絞る**
  - 見えるもの: **爪が片側だけ深い**(章の伏線。**意味は分からないまま置く**が、完全に無色にはしない。体重の乗り方が偏っている、という事実までは見えている状態にする)
  - 大きさは**手を並べて覚える**(数行)
- **痩せた狼と、この足跡を、ウィンには繋がせない。** 読者だけが繋げられる状態にする(**気づくのは第18話**)
- **一人であることが効く一行**: 見せる相手がその場にいない
- **引き**: 屈んで爪の跡に見入っていて、横を見ていない(**なぜ気づかなかったかの理由を先に置く**)。顔を上げて、戻したとき——**足跡のすぐ隣、こちら側へ一歩ぶん近い位置に、同じ形の凹みが一つ増えている**
  - **方向を書く**(「増えた」だけでは怖さが渡らない。こちらへ寄っていることが分かる形にする)
  - 「顔を上げても何もいない」とは書かない。**目を離した数秒で増えていた**、だけを書く

### 次話への渡し(構成の申し送り)

- **第17話の冒頭は、動いたまま始める**(第13話→第14話で「急ぐ理由を立てた直後に休憩から始める」失敗をしている)
- **第17話が引き受けるもの**: (1)引きの直後——**離脱を選ぶ**(姿は見せない。遭遇は章の後半に取っておく)。**ただし逃げ切るまでの緊張を一場面として書く**(引きの利子を払う)、(2)ギルドへの討伐報告、(3)見たものを紙に描き起こす
- **第18話の「足跡の写しを並べる」は、現実側で描き起こした紙を並べる形に読み替える**

## この回で守る制約(自己チェック用)

- クレストの三制約が、失敗の理由・二度目の解法・引きの怖さを兼ねる。**制約を回避せず、制約で書く**
- **【確定・第16話】大地そのものは借りられない**(地面は生きているもの扱い)。借りられるのは**地面から切り離された物**(拾った石、落ちている枯れ枝、転がる欠片)。**地形を作り替える運用は一切書かない**
- **クレストを使う場面は、この回では戦闘だけ。** 足跡の場面で使わない——**必然のない作業描写を入れない**(章プロットの「戦闘外のクレスト運用①」は、必然が立つ回まで持ち越す)
- 仕込むのは縄一本。**量が跳ねる形(柵など)にしない**
- 新しい手は一度目に成功させない。ただし**画は一度見せる**(空振りにしない)。**二度目には一度目にない画を足す**
- 観察していないことを前提にしない。発見は一つに絞る
- 制約や職業選択を、台詞で説明・弁明させない。動作と結果で示す
- 討伐数を通す(あと一頭→一度目は獲れず→二度目で達成)
- ステータスの数値・金額は書かない。通知はレベルアップとスキル習得の二種類だけ
- **ユキの出番は場面1の数行だけ。** 前話でたっぷり見せた直後なので、ここは引く
- **地の文の呼称**: 現実パートがないので**全編「ウィン」**。掲示板の話題が出ると「冬夜」へ滑りやすいので注意
- **直前二話(第14・15話)と、締めの型・場面構成の型・情報の渡され方が三連続していないか執筆前に突き合わせる**
