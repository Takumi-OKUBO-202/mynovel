## この章は何の話か

白虎を連れ出したことで森の均衡が崩れ、世間が「囚われていた何かが逃げ出した」と誤読して騒ぎになる。狂った生態系から自然発生した新しい刻紋種に世間の誤読が重なっていく中、二人は自分たちだけが理由を知っている異変と向き合う。討伐は、旅の途中で出会う規格外・ミナトの一撃で終わる——**必死のウィンと、余裕のミナトの対比**がこの章の山。秘密は守られ、騒ぎは誤読のまま閉じるが、最後に「外したはずの石が消えている」ことだけが残る。

**章題の意味**: 誰が袖=持ち主の知れない残り香。噂も、異変も、石も、出所を知る者がいないまま動いていく。

**章扉(確定。全文は`plot/outline.md`「第二章の章扉」)**:

```
第二章　誰が袖(たがそで)


　誰が袖ふれし宿の梅ぞも。袖の主を知らないまま、香りだけが残る。

　森の様子がおかしい、という話が流れ始めた。出どころを言える者は、誰もいない。
```

## 第19話の改訂(2026-09-02・ユーザー指摘)

**旧案(制限線の手前で第18話の三人組を見送り、退却してきた一人が二人の目の前で光になって消える)は、書き上げたうえで破棄した。** 破棄の理由は、書けなかったからではなく、**書くと人物が壊れるから**。

- **ウィンが森の入り口へ行く理由が「三人にもう一度言う」しかなかった。** 昨日二回言って二回笑われた相手に三度目を言いに行くのは固執だし、**人が死んでいる場所へ茜音を連れて行く理由**にならない
- そのために**都合のいい偶然が三つ重なった**——三人が来るのを待ち、入るのを見送り、数十分そこに居続ける
- **ギルドの掲示の場面は「行き場がない」を言うためだけ**にあった
- 第18話の締めが「じゃ、また明日!」で場所も時間も決めていないのに、**合流が書かれていなかった**
- 根本の原因: **アーク表の「見送る」という一語を、そのまま行動の動機にした。** 見送らせるために現場へ行かせた結果、人物のほうが壊れた

**代わりに採った軸: 危機を他人事から二人自身の問題へ移す。**

第15〜18話は、異変がずっと「他の誰かに起きていること」だった。**噂の二段目(「洞窟から出てきたプレイヤーを見た」)を出すと、それが一気に自分たちの話になる**——二人は第14話に本当にあの洞窟から出てきているので、**否定のしようがない**。章題「誰が袖」(誰のものとも言えない)にも、F009(秘密)にも、ミナトの来訪経路にも同時に繋がる。

**ギルドの姿勢(ユーザー指示で確定)**: **討伐依頼は掲示に出て、ランク制限なしで誰でも受けられる。立ち入りは妨げない、判断は各自の責任で。力に自信のない者は近づかないこと。国は並行して夜会へ討伐隊の編成を要請中。** この温度で全部が繋がる——(a)**立入禁止ではない**ので、行く者がいても治安の話にならない (b)**職員が体で止めて押し切られる絵が要らなくなる**(**縄・立て札・職員・帳面はすべて本文から外した**) (c)**「なぜプロが片づけないのか」に答えが出る**(夜会に投げてある)。同時に**「夜会が来る前に獲ったら俺らのもんじゃん」という血気盛んな反応の根拠**にもなる (d)**一般プレイヤーが締め出されない**(ユーザー指摘「一般プレイヤーに回ってこないのはゲームとして面白くない」)。
