## 3. あらすじ / 紹介文

### なろう「あらすじ」欄(そのままコピペ)

```
　何もない空を、駆け上がる者がいる。

　踏み込むたびに足首の紋章が灯り、爪先の先へ光の足場が生まれる。それを蹴って、雲の上の巨影へ。たった一人で、斬りかかる。

　大人気VRMMO『ソウルクレスト・オンライン』。フルダイブした者の魂を読み、世界に一つだけの固有スキル——「魂の紋章」を与えるゲーム。

　何を始めても、数日で飽きてきた。大学一年の冬夜が潜ったのも、「少しだけ、やってみるか」程度の軽い気持ちだった。

　その手の甲に浮かんだ紋章は、何も生み出さない。道端の物を「借りて」、形を変える——それだけの力だった。借りた物は、少し経てば元へ返る。

　このゲームは、何もかもがやたらとリアルだった。頬を撫でる風には温度があり、屋台の肉を炙る匂いに腹が鳴る。「現地人」と呼ばれるNPCたちは、口調も間の取り方も、作り物とは思えないほど人間くさい。そして道端には、枯れ枝や小石が無数に転がっている。

　枯れ枝は刃に、小石は鏃に——世界はまるごと、冬夜の武器の山だった。拾って、借りて、工夫で格上を仕留める。気づけば、生まれて初めて夢中になっていた。

　ギルドの掲示板の前で、気乗りしない冬夜を勢いのまま引き込んだ光魔導士の少女・茜音。彼女と潜った森の奥で二人が見つけたのは、鎖に繋がれた、手負いのモンスターだった。

　誰が。何のために。

　思えば、始まりからおかしかったのだ。「魂を読む」はずの解析は、誰にも話したことのない記憶にまで、平気で触れてきた。

　出来の良すぎるこのゲームの底で、遊びではない何かが蠢いている。

　誰も拾わない違和感を拾って、冬夜はその正体に手をかけていく。
```

**実測667字。** あらすじ欄の機能上限は1000字(コンテスト応募時800字)。**もし入力画面のカウンターが500字制限だった場合の削り順**: ①「誰が。何のために。」の段落 → ②「大学一年の」 → ③「頬を撫でる」 → ④「、平気で」。**冒頭の紋章の機構・「何も生み出さない」・武器の山・茜音の一筆・締めの韻は削らない。**

## 4. タグ / キーワード(なろう)

**設定するのはこの11個:**

```
VRMMO　フルダイブ　ゲーム　男主人公　成長　器用貧乏　青春　現代　謎　掲示板　パーティ
```

| タグ | 理由 |
|---|---|
| `VRMMO` | ジャンルの核。検索流入の主軸 |
| `フルダイブ` | 実勢タグ。没入描写への期待と一致 |
| `ゲーム` | 汎用検索語の補完 |
| `男主人公` | なろうでは定番の必須級 |
| `成長` | `主人公最強`を避けつつ到達点を誠実に示す |
| `器用貧乏` | 実勢タグ。序盤の立ち位置の説明として有効(**タイトルでは語感の被りを理由に不使用だが、タグとしては有効**) |
| `青春` | 現実パート(大学生活)の質感 |
| `現代` | 舞台が現代日本+VR |
| `謎` | 縦軸への期待をネタバレなしで作る |
| `掲示板` | 実勢タグ。SNS・掲示板演出の明示 |
| `パーティ` | **主流のソロ最強型ではないことを事前に明示**し、ミスマッチを減らす |

**付けない**: `主人公最強`(序盤の実態と乖離)、`ソロ`(4人パーティ構成)、`スローライフ`・`生産職`(期待値が乖離)

**保留(後で追加を検討)**: `テイム`(実体が出るのは第14話。初日から付けると13話分が看板倒れ) / `AI`(正体が未確定でネタバレ・誤誘導のリスク)

> **⚠ なろうのキーワード上限15個は「自動入力キーワード」込みの数え方。** 投稿画面で残枠を確認し、溢れたら優先度の低い順(`ゲーム` → `現代` → `青春`)に落とす。

## 5. 投稿スケジュール

### 初日(8/21 金)

**第1〜6話を1〜2時間おきに連投。** 21:00〜23:00がアクセスのピーク帯。

**第6話まで出す理由**: 第6話「借りものの刃」が**クレストの初実戦**で、本作最大の差別化が初めて絵として動く回。離脱が集中する3話前後を在庫の力で押し切る。

### 2日目以降

- **毎日1話、21:00固定**(時刻を動かさない)
- 在庫26話 → **9月16日頃まで毎日更新が回る**
- 節目: 第14話(アーク1完結)=8/29 / 第25話(アーク2完結)=9/9

### 執筆の締切

**9月16日までに第33〜40話の8話を書き上げる。** 3〜4日に1話。間に合わない場合は**週3話(月・水・金)に落とし、頻度変更はアークの節目に合わせて活動報告で予告する。**
