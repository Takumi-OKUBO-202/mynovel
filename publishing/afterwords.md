# 掲載用の後書き(なろう/カクヨムの後書き欄に貼る文言)

**位置づけ**: 章の区切りなど、節目の話だけに置く後書きの管理場所。**毎話は置かない**——後書きが常設されると本文の余韻が毎回切れる。置くのはアークの完結話と、長期の更新間隔が空くときだけ。

**書くときの原則**

- **本文の余韻を上書きしない。** 締めの一行を説明し直さない
- **次の章の中身をばらさない。** 「何が起きるか」ではなく「何が漏れていくか」程度に留める
- **謎の答えを匂わせない。**「いずれ出します」と約束するだけにする
- **短くする(確定)。** 150〜250字まで。**内容そのものにはほとんど触れない**——回の中身を要約すると、読者がいま読み終えた本文をもう一度なぞらされることになる
- **ブックマーク・★評価のお願いは最後に一度だけ。** なろうでは定型なので置いてよいが、本文中や冒頭には出さない
- **記号装飾(太字・罫線)は使わない。** 掲載先で崩れる

## 第14話(第一章 完結)

```
　ここまでお読みいただき、ありがとうございます。
　第十四話をもって、第一章が完結となります。

　第二章「誰が袖」は、二人が「誰にも言わない」と決めたところから始まります。洞窟に残ったあの声の正体も、いずれきちんと出します。

　面白いと思っていただけましたら、ブックマークや★での評価をいただけると励みになります。
　引き続き、お付き合いいただけたら嬉しいです。
```

**さらに短い版**

```
　ここまでお読みいただき、ありがとうございます。第十四話で第一章が完結です。

　第二章「誰が袖」は、二人が「誰にも言わない」と決めたところから始まります。

　面白いと思っていただけましたら、ブックマークや★をいただけると励みになります。引き続きよろしくお願いします。
```

**この後書きで意図的にやっていないこと**

- **回の内容を要約しない。** 本文を読み終えた直後の読者に、同じ話をもう一度させない
- **テイムの規格外さを作者の口から言わない**(第15話以降の掲示板の反応が先回りされて死ぬ)
- **白虎の名前・今後の活躍に触れない**(命名は第29話、ヒナ・ゴウの前での露見は第38話)
- **「何か」「刻紋種を刻んだ存在」といった語を使わない**(本文でまだ一度も出していない)
- **次章の登場人物(ルシアン・夜会)を名前で出さない**
