# 掲載用の後書き・活動報告(なろう/カクヨム)

**位置づけ**: 後書き欄に貼る文言と、なろうの活動報告に投稿する文言の管理場所。**目的は評価ポイントの獲得**——ブックマークと★評価は、そのままランキング掲載順に効く。

## なろうの評価ポイントの仕組み(前提)

- **総合評価ポイント = ブックマーク数 × 2 + 評価ポイント合計**
- 評価は「文章評価」「ストーリー評価」の二軸で各5点、**一人あたり最大10点**
- **ブックマークはログインだけで押せるが、★評価は評価画面へ移動する手間がある。** だから**お願いする順番はブックマークが先、★は後**
- **★は「読み進めた人」しか押さない。** 第1話で★を求めても押されず、お願いだけが残る。**第1話はブックマーク一本に絞る**

## 置き方の方針(確定)

| 置く場所 | お願いする内容 | 理由 |
|---|---|---|
| **第1話** | ブックマークのみ | 読者が「続きを追うかどうか」を決めるのがここ。★は時期尚早 |
| **章の完結話**(第14話・第28話…) | ブックマーク＋★評価 | 一区切り読み終えた直後が、★を押してもらえる唯一のまとまったタイミング |
| **十話ごとの節目**(第10・20話…) | 一行だけ、軽く | 常設しないための間引き。長い依頼文は置かない |
| **最新話**(更新が止まっているあいだ) | ブックマーク＋★ | 続きを待つ読者が最も動いてくれる位置。次の更新で外す |
| 上記以外の話 | **置かない** | 後書きが常設されると本文の余韻が毎回切れる |

## 書くときの原則

- **本文の余韻を上書きしない。** 締めの一行を説明し直さない
- **回の内容を要約しない。** いま読み終えた本文をもう一度なぞらせない
- **次の章の中身をばらさない。謎の答えを匂わせない。**「いずれ出します」と約束するだけにする
- **短くする。** 節目で150〜250字、第1話・十話ごとは80字以内
- **お願いは最後に一度だけ。** 本文中や前書きには絶対に出さない
- **記号装飾(太字・罫線)は使わない。** 掲載先で崩れる
- **カクヨムでは「★」ではなく「応援」「レビュー」と書く。** 用語が違うので後書きを使い回さない

# 後書き

## 第1話(なろう)

```
　お読みいただき、ありがとうございます。

　毎日更新でお届けします。続きが気になっていただけましたら、ブックマークに入れていただけると嬉しいです。
```

## 第1話(カクヨム)

```
　お読みいただき、ありがとうございます。

　毎日更新でお届けします。続きが気になっていただけましたら、フォローしていただけると嬉しいです。
```

## 十話ごとの節目(第10・20話…)

```
　ここまでお読みいただき、ありがとうございます。ブックマークや評価をいただけると、更新の励みになります。
```

## 第14話(第一章 完結・なろう)

```
　ここまでお読みいただき、ありがとうございます。
　第十四話をもって、第一章が完結となります。

　第二章「誰が袖」は、二人が「誰にも言わない」と決めたところから始まります。洞窟に残ったあの声の正体も、いずれきちんと出します。

　一章分お付き合いいただけたということで、もしよろしければ、ブックマークと★での評価をいただけると本当に励みになります。★は下の評価欄から、文章とストーリーの二つを選ぶだけで入ります。

　引き続き、お付き合いいただけたら嬉しいです。
```

## 第14話(第一章 完結・カクヨム)

```
　ここまでお読みいただき、ありがとうございます。
　第十四話をもって、第一章が完結となります。

　第二章「誰が袖」は、二人が「誰にも言わない」と決めたところから始まります。洞窟に残ったあの声の正体も、いずれきちんと出します。

　もしよろしければ、フォローと応援(★)をいただけると本当に励みになります。レビューをいただけたら、飛び上がって喜びます。

　引き続き、お付き合いいただけたら嬉しいです。
```

## 第28話(第二章 完結・雛形。中身は執筆後に埋める)

```
　ここまでお読みいただき、ありがとうございます。
　第二十八話をもって、第二章「誰が袖」が完結となります。

　(次章の入口を一行だけ。何が起きるかではなく、何が漏れていくか)

　二章分お付き合いいただけたということで、もしよろしければ、ブックマークと★での評価をいただけると本当に励みになります。

　引き続き、お付き合いいただけたら嬉しいです。
```

## 最新話に置く固定文(更新が空くとき)

```
　ここまでお読みいただき、ありがとうございます。
　次話は(　　)に更新予定です。

　続きを待っていただけるようでしたら、ブックマークをお願いします。ここまで面白いと思っていただけましたら、★での評価もいただけると嬉しいです。
```

# 活動報告(なろう)

**位置づけ**: 活動報告はフォロワーの新着に流れるので、**すでに読んでいる人へ届く唯一の窓口**。後書きより踏み込んだお願いをしてよい。ただし**本文の宣伝だけの報告を連投しない**——読者の新着欄を埋めると逆効果になる。

**投稿するタイミング(確定)**
- 章の完結時
- ブックマーク数・ポイントの節目(100・500・1000…)
- 更新ペースを変えるとき、更新を落とすとき

## 章の完結時

```
第一章が完結しました

　いつもお読みいただき、ありがとうございます。
　『ソウルクレスト・オンライン』第一章が、第十四話で完結しました。

　明日からは第二章「誰が袖」に入ります。引き続き毎日更新の予定です。

　この作品はランキングにも広告にも頼れないので、読んでくださっている方のブックマークと評価が、そのまま新しい読者に届くかどうかになります。

　ここまで面白いと思っていただけましたら、
　・作品ページのブックマーク
　・★での評価(文章とストーリーの二つを選ぶだけです)
　のどちらかだけでも、いただけると本当に助かります。

　感想もお待ちしています。短い一言でも、書いてもらえるとかなり嬉しいです。

　引き続き、よろしくお願いします。
```

## ブックマーク数の節目

```
ブックマーク(　　)件を超えました

　いつもお読みいただき、ありがとうございます。
　おかげさまで、ブックマークが(　　)件を超えました。

　押してくださった方、読んでくださっている方、ありがとうございます。

　もしまだでしたら、★での評価もいただけると嬉しいです。ブックマークが二点、★が最大十点で、合計が作品のポイントになります。数字が伸びるほど、同じ趣味の人の目に留まりやすくなります。

　引き続き、よろしくお願いします。
```

## 更新ペースを変えるとき

```
更新について

　いつもお読みいただき、ありがとうございます。
　(　　)から、更新を(　　)に変更します。

　理由は(　　)です。話の質を落とさずに続けるための調整なので、止めるつもりはありません。

　次話は(　　)に上げます。待っていただけるようでしたら、ブックマークをしておいていただけると、更新がお手元に届きます。

　引き続き、よろしくお願いします。
```

# この後書きで意図的にやっていないこと

- **回の内容を要約しない。** 本文を読み終えた直後の読者に、同じ話をもう一度させない
- **白虎のテイムの規格外さを作者の口から言わない**(掲示板の反応が先回りされて死ぬ)
- **白虎の名前(ユキ)・今後の活躍に触れない**
- **「何か」「刻紋種を刻んだ存在」といった語を使わない**(本文でまだ一度も出していない)
- **第二章の登場人物(ミナト)を名前で出さない**
