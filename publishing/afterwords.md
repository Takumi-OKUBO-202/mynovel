# 掲載用の後書き(なろう/カクヨムの後書き欄に貼る文言)

**位置づけ**: 章の区切りなど、節目の話だけに置く後書きの管理場所。**毎話は置かない**——後書きが常設されると本文の余韻が毎回切れる。置くのはアークの完結話と、長期の更新間隔が空くときだけ。

**書くときの原則**

- **本文の余韻を上書きしない。** 締めの一行を説明し直さない
- **次の章の中身をばらさない。** 「何が起きるか」ではなく「何が漏れていくか」程度に留める
- **謎の答えを匂わせない。**「いずれ出します」と約束するだけにする
- **自分語りを長くしない。** 400〜500字まで
- **ブックマーク・★評価のお願いは最後に一度だけ。** なろうでは定型なので置いてよいが、本文中や冒頭には出さない
- **記号装飾(太字・罫線)は使わない。** 掲載先で崩れる

## 第14話(第一章 完結)

```
　ここまでお読みいただき、ありがとうございます。
　第十四話をもって、第一章が完結となります。

　ゲームを始めてまだ数日の器用貧乏が、洞窟の奥で、自分の手には余るものを見てしまう——ここまでが、この章で書きたかったことでした。

　冬夜は、この回でも一番強い人ではありません。虎を助けたのは茜音で、彼にできたのは、跳ね回る鎖を床に縫い止めることだけでした。それでも、あの場で動けたことは、この先ずっと効いてきます。一撃で終わらせる力がない代わりに、終わらせるまでの手数が無限にある——そういう主人公として、最後まで書いていくつもりです。

　第二章では、二人が「誰にも言わない」と決めたものが、少しずつ形を変えて外へ漏れていきます。掲示板の目撃談、広がる噂、そしてそれを聞きつけた人たち。秘密を抱えたまま、冬夜と茜音がどう動くのかを書いていきます。

　洞窟に残ったあの声については、まだ何も説明しません。いずれ、きちんと正体を出します。

　面白いと思っていただけましたら、ブックマークや★での評価をいただけると、本当に励みになります。感想もお待ちしています。

　引き続き、お付き合いいただけたら嬉しいです。
```

**短縮版**(後書きを長く感じさせたくない場合。こちらでも可)

```
　ここまでお読みいただき、ありがとうございます。第十四話をもって第一章が完結です。

　虎を助けたのは茜音で、冬夜にできたのは鎖を止めることだけでした。それでも、この人はそういう形で強くなっていきます。一撃で終わらせる力はない代わりに、終わらせるまでの手数が無限にある——そういう物語です。

　第二章では、二人が「誰にも言わない」と決めたものが、少しずつ外へ漏れていきます。洞窟に残ったあの声の正体も、いずれきちんと出します。

　面白いと思っていただけましたら、ブックマークや★での評価をいただけると励みになります。引き続きお付き合いいただけたら嬉しいです。
```

**この後書きで意図的にやっていないこと**

- **テイムの規格外さを作者の口から言わない**(「実はとんでもない力です」と説明すると、第15話以降の掲示板の反応が先回りされて死ぬ)
- **白虎の名前・今後の活躍に触れない**(命名は第29話、ヒナ・ゴウの前での露見は第38話。後書きで先出ししない)
- **「何か」「刻紋種を刻んだ存在」といった語を使わない**(本文でまだ一度も出していない)
- **次章の登場人物(ルシアン・夜会)を名前で出さない**
