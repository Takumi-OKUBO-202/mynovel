# 掲載用の後書き・活動報告(なろう/カクヨム)

**位置づけ**: 後書き欄に貼る文言と、なろうの活動報告に投稿する文言の管理場所。**目的は評価ポイントの獲得**——ブックマークと★評価は、そのままランキング掲載順に効く。

## なろうの評価ポイントの仕組み(前提)

- **総合評価ポイント = ブックマーク数 × 2 + 評価ポイント合計**
- 評価は「文章評価」「ストーリー評価」の二軸で各5点、**一人あたり最大10点**
- **ブックマークはログインだけで押せるが、★評価は評価画面へ移動する手間がある。** だから**お願いする順番はブックマークが先、★は後**
- **★は「読み進めた人」しか押さない。** 第1話で★を求めても押されず、お願いだけが残る。**第1話はブックマーク一本に絞る**

## 置き方の方針(確定)

| 置く場所 | お願いする内容 | 理由 |
|---|---|---|
| **第1話** | ブックマークのみ | 読者が「続きを追うかどうか」を決めるのがここ。★は時期尚早 |
| **章の完結話**(第14話・第28話…) | ブックマーク＋★評価 | 一区切り読み終えた直後が、★を押してもらえる唯一のまとまったタイミング |
| **十話ごとの節目**(第10・20話…) | 一行だけ、軽く | 常設しないための間引き。長い依頼文は置かない |
| **最新話**(更新が止まっているあいだ) | ブックマーク＋★ | 続きを待つ読者が最も動いてくれる位置。次の更新で外す |
| 上記以外の話 | **置かない** | 後書きが常設されると本文の余韻が毎回切れる |

## 書くときの原則

- **本文の余韻を上書きしない。** 締めの一行を説明し直さない
- **回の内容を要約しない。** いま読み終えた本文をもう一度なぞらせない
- **次の章の中身をばらさない。謎の答えを匂わせない。**「いずれ出します」と約束するだけにする
- **短くする。** 節目で150〜250字、第1話・十話ごとは80字以内
- **お願いは最後に一度だけ。** 本文中や前書きには絶対に出さない
- **【確定・重要】卑屈にしない。同情を誘わない。** 「ランキングにも広告にも頼れないので」「どちらかだけでも」「本当に助かります」「飛び上がって喜びます」——**この型は媚びて見える。** 本文が抑制の効いた文体なので、後書きだけ腰が低いと落差で嘘くさくなる
  - **お願いは一文で済ませ、理由を並べない。** 「面白ければブックマークを、★も押してもらえると助かります」で足りる
  - **強調語を重ねない**(「本当に」「かなり」「ぜひ」は使わない)。感謝も一度だけ
- **記号装飾(太字・罫線)は使わない。** 掲載先で崩れる
- **カクヨムでは「★」ではなく「応援」「レビュー」と書く。** 用語が違うので後書きを使い回さない

# 後書き

## 第1話(なろう)

```
　お読みいただき、ありがとうございました。

　毎日更新です。続きが気になったら、ブックマークに入れておいてください。
```

## 第1話(カクヨム)

```
　お読みいただき、ありがとうございました。

　毎日更新です。続きが気になったら、フォローしておいてください。
```

## 十話ごとの節目(第10・20話…)

```
　ここまでありがとうございました。面白ければ、ブックマークや★を押していただけると助かります。
```

```
　一章分読めたな、と思っていただけたら、ブックマークと★を押していただけると助かります。

　明日から第二章です。
```

## 第14話(第一章 完結・カクヨム)

```
　第十四話をもって、第一章が完結です。ここまでありがとうございました。

　第二章「誰が袖」は、二人が「誰にも言わない」と決めたところから始まります。洞窟に残ったあの声も、いずれ出します。

```

## 第28話(第二章 完結・雛形。中身は執筆後に埋める)

```
　第二十八話をもって、第二章「誰が袖」が完結です。ここまでありがとうございました。

　(次章の入口を一行だけ。何が起きるかではなく、何が漏れていくか)

　二章分読めたな、と思っていただけたら、ブックマークと★を押していただけると助かります。

　明日から第三章です。
```

## 最新話に置く固定文(更新が空くとき)

```
　次話は(　　)に更新予定です。

　続きを待つ気になったらブックマークを、ここまで面白ければ★も押していただけると助かります。
```

# 活動報告(なろう)

**位置づけ**: 活動報告はフォロワーの新着に流れるので、**すでに読んでいる人へ届く唯一の窓口**。後書きより踏み込んだお願いをしてよい。ただし**本文の宣伝だけの報告を連投しない**——読者の新着欄を埋めると逆効果になる。

**投稿するタイミング(確定)**
- 章の完結時
- **章に入って数話進んだところ**(新章の手応えが出た頃。完結時とは別に、一章分読んだ人へ★を頼み直せる)
- ブックマーク数・ポイントの節目(100・500・1000…)
- 更新ペースを変えるとき、更新を落とすとき

## 章の完結時

```
第一章が完結しました

　『ソウルクレスト・オンライン』第一章が、第十四話で完結しました。ここまでありがとうございました。

　明日から第二章「誰が袖」です。二人が「誰にも言わない」と決めたところから始まります。毎日更新は続けます。

　一章分読めたな、と思っていただけたら、ブックマークと★を押していただけると助かります。感想もお待ちしています。
```

## 第二章の開始(第16話公開時点・なろう)

```
第二章に入りました

　第十六話まで公開しました。第二章「誰が袖」です。

　灰狼の森の浅いところに、いるはずのない獣が出はじめています。入り口から十分で全滅したパーティが出て、掲示板は運営のイベントだろうと言っています。ギルドの受付は、今日はもう森へ戻るなと言いました。

　どちらが正しいかは、そのうち分かります。

　毎日更新は続けます。一章分読めたな、と思っていただけたら、ブックマークと★を押していただけると助かります。
```

## 第二章の開始(第16話公開時点・カクヨムの近況ノート)

```
第二章に入りました

　第十六話まで公開しました。第二章「誰が袖」です。

　灰狼の森の浅いところに、いるはずのない獣が出はじめています。入り口から十分で全滅したパーティが出て、掲示板は運営のイベントだろうと言っています。ギルドの受付は、今日はもう森へ戻るなと言いました。

　どちらが正しいかは、そのうち分かります。

　毎日更新は続けます。一章分読めたな、と思っていただけたら、フォローと応援(★)を押していただけると助かります。
```

**この活動報告で意図的にやっていないこと**
- **白虎(ユキ)・テイム・刻紋種に一切触れない。** 第一章の山場そのものなので、途中から見た人の入口を潰さない
- **森で何が起きているかを言わない。**「森の様子が動く」まで。第16話の引き(足跡・掲示板)を先回りしない
- **第二章の登場人物(ミナト)を名前で出さない**
- **話数の予告をしない**(全14話などの内訳を出すと、読者が残りを数え始める)

## ブックマーク数の節目

```
ブックマーク(　　)件を超えました

　ブックマークが(　　)件を超えました。押してくださった方、ありがとうございます。

　まだの方は、★のほうも押していただけると助かります。ブックマークが二点、★が最大十点で、合計が作品のポイントになります。

　更新は変わらず毎日です。
```

## 更新ペースを変えるとき

```
更新について

　(　　)から、更新を(　　)に変更します。理由は(　　)です。

　止めるつもりはありません。次話は(　　)に上げます。

　ブックマークを入れておくと更新が通知されるので、待つ方は入れておいてください。
```

# この後書きで意図的にやっていないこと

- **回の内容を要約しない。** 本文を読み終えた直後の読者に、同じ話をもう一度させない
- **白虎のテイムの規格外さを作者の口から言わない**(掲示板の反応が先回りされて死ぬ)
- **白虎の名前(ユキ)・今後の活躍に触れない**
- **「何か」「刻紋種を刻んだ存在」といった語を使わない**(本文でまだ一度も出していない)
- **第二章の登場人物(ミナト)を名前で出さない**
