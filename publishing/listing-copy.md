## 1. タイトル案(なろう用)

### 現行の問題(再掲)

現行『ソウルクレスト・オンライン 〜器用貧乏、最強になる〜』は、①先頭が意味不明な造語、②「器用貧乏」が他ジャンル人気作(『勇者パーティを追い出された器用貧乏〜』)と語感が被る、の2点が弱点(`marketing-strategy.md`§7、`research/trends/2026-08-06.md`4節)。

### 案一覧(7案)

**① 何でも借りて、何にでも変える 〜器用貧乏の紋章持ちが、ソウルクレスト・オンラインで最強と渡り合う〜【推奨】**
- 訴求: 本作最大の差別化(必殺技を持たず、他人の物・その辺の物を「借りて」形を変える)を、造語ゼロの平易な動詞だけで冒頭に出す。検索結果で表示されるタイトル冒頭十数文字に、最も強い・最も他作品にない情報を置く配置
- 刺さる読者: 「またソロ最強系か」と食傷している層、機転・工夫の描写が好きな層
- 弱点: 動詞2つ("借りて""変える")の抽象度がやや高く、絵が浮かぶまでに一呼吸要る。副題を読んで初めて「ゲームものだ」とわかる

**② 器用貧乏、借りて最強になる 〜ソウルクレスト・オンライン〜**
- 訴求: 現行タイトルのリズムをほぼ維持しつつ、「借りて」を足して絵を一つ追加する最小改修案
- 刺さる読者: 現行タイトルの言い回し(ギャップ型)に慣れた層。改稿コストを抑えたい場合の代替
- 弱点: 「器用貧乏」を冒頭付近に残すため、他ジャンル人気作との語感の被りが解消されない

**③ 必殺技はない。借りて、変えて、勝つ。**
- 訴求: 造語を完全に排除した比較用の案。動作だけで絵を伝える最短ルート
- 刺さる読者: 情報量よりリズムの良さで目に留めてほしい層。X等の短文シェアと相性が良い
- 弱点: 固有名詞・ジャンルワードが一切なく、なろうの検索流入(作品名・ジャンル名での検索)に弱い。単体では情報不足なので副題が実質必須

**④ 俺の得物は、借り物でできている 〜器用貧乏の紋章持ちが、いつか最強と渡り合う〜**
- 訴求: 一人称「俺」を出し、冬夜の口調の温度をタイトルの時点で伝える。第9話「己の得物」との呼応も作れる
- 刺さる読者: キャラクターの人となりから入りたい層
- 弱点: 「得物」は武器を指す語としてやや硬く、初見の読者(特にライト層)には伝わりにくい可能性

**⑤ 器用貧乏と呼ばれた紋章持ち、他人の得物を借りて最強に至る 〜ソウルクレスト・オンライン〜**
- 訴求: なろうで定着している「〜と呼ばれた…、〜に至る」型のロングタイトル。情報量・検索性は最大
- 刺さる読者: テンプレ型のタイトルで安心して選ぶ層(なろうでは依然として一定数いる)
- 弱点: **型そのものが最も見慣れている**。差別化1(借りて戦う絵)を出していても、外形がテンプレに寄るぶん埋もれやすい

**⑥ このゲーム、何かがおかしい。器用貧乏の俺は、借り物の力で成り上がる**
- 訴求: 縦軸(ゲームの正体)の気配をタイトルの時点で仄めかす。ミステリー要素に反応する読者を拾う
- 刺さる読者: VRMMO×謎解き・技術ミステリーを好む層
- 弱点: 一文の情報量が多すぎて焦点がぼやける。VRMMO読者の主戦場は「ゲーム内でどう強くなるか」であり、そこへの言及が後回しになる

**⑦ 借りものの刃で、最強と渡り合う 〜ソウルクレスト・オンライン、器用貧乏の逆転記〜**
- 訴求: 第6話タイトル「借りものの刃」を丸ごと格上げする案。本文で既に機能しているフレーズなので齟齬が出ない
- 刺さる読者: 「刃」「戦う」という直接的な絵を求める層
- 弱点: 「刃」だけだと投擲(石の鏃)・調合(毒の調合)・生産(素材集め)まで含む「その辺の物を何でも」という広さが伝わらず、差別化1をやや狭く見せてしまう

**①' 枯れ枝も石ころも、武器に変える 〜器用貧乏の紋章持ちが、ソウルクレスト・オンラインで最強と渡り合う〜【対案】**
- ①の副題をそのままに、**冒頭だけを具体名詞に差し替えた案**。①の弱点として自認されている「動詞2つの抽象度が高く、絵が浮かぶまでに一呼吸要る」を潰す
- 根拠: **あらすじ本番用が、まさにこの具体像で書かれている**(「枯れ枝を刃に変え、石を鏃に変える」)。第6話の実際の描写(道端の枯れ枝を借りて変える/足元の小石を鏃状に変えて投擲)そのままなので、本文との齟齬がない
- 一覧で視線が留まるのは名詞であり、**「枯れ枝」「石ころ」という最も価値の低い物が武器になる**という落差が、そのままギャップ型の訴求になる
- 弱点: ①より約2字長い。また「借りる」という語がメインタイトルから消えるため、**返却・時間制限といった制約の存在は副題以降に委ねられる**

### 推奨: ① または ①'

**理由**: 「造語を捨てず、後ろに回して両立させる」という方針(`marketing-strategy.md`§7)に最も忠実で、かつ冒頭に置く情報が本作固有(類似作品との重なりが最も強いのは土台のクレスト概念そのものだが、"借りて変える"という戦い方の絵は`research/trends/2026-08-06.md`でも近い競合が確認できなかった差別化)。副題に「器用貧乏」(実勢タグとの整合)・「ソウルクレスト・オンライン」(固有名詞検索性)・「最強と渡り合う」(`plot/outline.md`の結末が"作中最強、または最強と互角"と未確定であることに対して、言い切りすぎない誠実な表現)を過不足なく収めている。

## 2. タイトル案(カクヨム向けの出し分け)

- **基本方針: 同一タイトルを使う。** コンテスト応募(カクヨムコン・ネット小説大賞)や書籍化打診時に作品名が割れると管理コストが増えるため、①をそのまま採用する
- カクヨムはタイトルとは別に**キャッチコピー欄(目安140字)**があり、ここで詩的な言い回しを使う余地がある(→3節のカクヨム用キャッチコピー参照)。**タイトル自体を短くする必要はない**
- 活動報告・近況ノート・X運用など、略称が要る場面では**『何でも借りて、何にでも変える』(メインタイトルのみ)**を通称として使う

## 3. あらすじ

### 方針の再確認

- 入れる要素: (a) 器用貧乏と侮られる立場、(b) 借りて戦うという絵、(c) ゲームの正体という縦軸の気配
- 「数字ではなく機転で勝つ」と言い切り、ステータス非公開という執筆方針そのものには触れない
- 「何か」の正体・氷牙の白虎・茜音の秘密には触れない。「このゲームには何かある」という気配まで
- 4人パーティ構成であることは、茜音の名前を出すことで**さりげなく仄めかす**に留め、「ソロ最強」を期待させる書き方はしない

### なろう掲載用(本番用)

**なろうの「あらすじ」欄の文字数上限は500字**(検索エンジンのスニペット経由での確認。一次資料の直接取得ができない環境上の制約があり、`research/trends/2026-08-06.md`と同じ限界を持つ。**投稿直前に実際の入力画面のカウンターで必ず再確認すること**)。長編作品では400〜500字程度が目安とされる。

以下は実測**374字**で、上限500字に収まっている。

> 必殺技は、持っていない。器用貧乏と侮られたクレストで、冬夜は他人の得物やその辺の物を「借りて」、思い通りの形に「変える」——それだけの地味な力を武器に戦う。
>
> けれど、枯れ枝を刃に変え、石を鏃に変えるだけで、格上の相手にも食らいついていけることが分かってくる。
>
> ギルドの掲示板で出会った光魔導士の少女・茜音とパーティを組み、冬夜は最初の大きな試練——「第一段階の試練」に巻き込まれる。それは、ただの新イベントではなかった。
>
> 現実では、温厚だった人が突然豹変する事件が、原因不明のまま相次いでいる。ゲームの中と外が、少しずつ繋がりはじめていた。
>
> 大人気VRMMO「ソウルクレスト・オンライン」——このゲームには、何かがある。
>
> 器用貧乏と侮られた紋章持ちが、数字ではなく機転で切り抜けながら、仲間との絆を力に変えて、いつか最強と渡り合うところまで駆け上がっていく。

**冒頭2行(検索結果に表示される部分)が「必殺技は、持っていない。器用貧乏と侮られたクレストで、冬夜は他人の得物やその辺の物を『借りて』、思い通りの形に『変える』」までで、(a)(b)が両方入る配置にしてある。**

### 短縮版(200字程度)

実測**133字**。

> 必殺技は、持っていない。器用貧乏と呼ばれたクレストで、冬夜は他人の得物やその辺の物を「借りて」形を変え、数字ではなく機転で戦う。光魔導士の少女・茜音と出会い、二人は正体不明の「試練」に巻き込まれていく。地味な力を積み重ねた先で、冬夜はいつか最強と渡り合う領域へ届く。

### キャッチ(X等・1〜2行)

> 必殺技はない。借りて、変えて、機転で勝つ。

または(固有名詞を含む2行版)

> 器用貧乏のクレストは、他人の得物もその辺の石ころも「借りて」武器に変える。
> 数字じゃない、機転で勝つVRMMO——『ソウルクレスト・オンライン』。

## 5. タグ/ジャンル

### ジャンル

**「VRゲーム〔SF〕」で確定**(`marketing-strategy.md`§4)。変更提案なし。母数が薄く上位が狙いやすいというリサーチの裏取り(`research/trends/2026-08-06.md`2節)とも矛盾しない。

### 確定タグ(11個)

**なろうのキーワード上限は15個。ただし「選択済みキーワード」と『自動入力キーワード』を合わせて15個以内**という数え方なので、実際に自由に使える枠は11個より狭い可能性がある([キーワード | ヘルプセンター | 小説家になろう](https://syosetu.com/helpcenter/helppage/helppageid/58))。**投稿画面で残枠を確認し、溢れる場合は下の優先度の低いものから落とす。**


| タグ | 付ける理由 |
|---|---|
| `VRMMO` | ジャンルの核。実勢タグ(リサーチ4節)にも合致し、検索流入の主軸になる |
| `フルダイブ` | 実勢タグに合致。VRゲーム〔SF〕読者が期待する没入描写(第2話のヘッドギア描写等)と一致する |
| `ゲーム` | フルダイブ・VRMMOだけでは拾えない汎用検索語を補う |
| `男主人公` | 主人公の性別を明示し、読者のマッチング精度を上げる(なろうでは定番の必須級タグ) |
| `成長` | `主人公最強`を避けつつ、到達点(作中最強、または最強と互角のレベル)を誠実に示す代替語 |
| `器用貧乏` | 実勢タグに合致し、序盤の立ち位置(単一の必殺技を持たない汎用型)を的確に説明する。**タイトルでは語感の被りを理由に避けたが、タグとしては実勢に沿うため有効** |
| `青春` | 現実パート(大学生活の手触り)の質感を示し、差別化3(現実世界への侵食)への入口になる |
| `現代` | 舞台が現代日本+VRという構成であることを明示する |
| `謎/ミステリー` | 縦軸(「何か」の正体)の気配を示す。ネタバレせずに縦軸への期待を作れる |
| `掲示板` | 実勢タグに合致し、演出上の特徴(SNS投稿・掲示板形式)を明示する。**ただし現状は明確な「攻略掲示板」の形にはまだ発展しきっていないため、扱いは次項「保留」も参照** |
| `パーティ` | `research/trends/2026-08-06.md`が指摘した懸念(VRMMOの主流はソロ最強型で、本作の4人パーティ構成とは相性が良くない)への対策。**タグの時点で「ソロではない」ことを明示し、ソロ無双を期待する読者との事前のミスマッチを減らす** |

### 付けない(確定)

- **`主人公最強`は付けない。** 序盤の冬夜は最強ではなく、期待値の乖離は低評価に直結する(`marketing-strategy.md`§4)。**`research/trends/2026-08-06.md`4節の通り、この判断を裏付ける定量データは今回の調査でも見つかっていない。**それでも論理的な妥当性(タグと実態の乖離が離脱・低評価の一般論として語られている)から方針は維持する
- `ソロ` — 4人パーティ構成の本作には合わない。むしろ逆に`パーティ`を立てることで期待値を合わせる

### 保留(理由付き)

- **`テイム`** — 実勢タグではあるが、テイムの実体(氷牙の白虎)が登場するのは第14話。**公開初日にこのタグを付けると、13話分は看板倒れになる。** 第14話公開のタイミングで追加を検討する
- **`AI`** — 「何か」の正体は本文でまだ明かしておらず、単純な"管理AI"ではない可能性がある(`plot/outline.md`「踏み込まない線」参照)。タグとして付けると、正体についての誤った期待(または軽いネタバレ)を作るリスクがある。**`謎/ミステリー`で縦軸への期待は代替できるため、当面は保留**とし、正体が本文で明確になった段階で再検討する
- **`スローライフ` `生産職`** — 実勢タグとして根強い人気があるが(リサーチ3節)、本作は成長・戦闘・縦軸の謎解きが主軸で、スローライフ・生産職が主題化する構成ではない(薬草採取や毒の調合はあくまで戦闘力の一部としての描写)。**期待値が乖離するため付けない**

## 6. 申し送り事項

### 【重要】作成後に見つかった事実誤認(修正済み)

初稿のあらすじに、本文と食い違う記述が2箇所あった。**いずれも修正済みだが、同種の誤りが再発しないよう記録を残す。**

1. **「剣士の少女・茜音」→ 誤り。** 茜音の職業は**光魔導士**(`bible/characters/akane.md`、第12話で名称判明)。杖を持つ後衛の魔法職で、剣は使わない。**あらすじは作品ページで最も目に触れるテキストであり、ここで職業を間違えると初回から信頼を落とす**
2. **「上位ランカーの放つ光の一撃にも、機転一つで食らいつける」→ 誤り。** 「上位ランカー」が本文に出るのは**第1話のPV/動画コメントだけ**で、冬夜が上位ランカーと戦う場面は第32話までに存在しない。加えて「光の一撃」は茜音(光魔導士)の属性と紛らわしい。**格上の相手にも食らいついていける**という、本文に裏付けのある表現に差し替えた

**教訓: あらすじを作る際は、書いた要素一つひとつについて「第32話までの本文に実在するか」を確認すること。** 特に**キャラクターの職業・戦った相手の格**は、`bible/characters/`と本文で裏を取る。

### その他

- **字数はすべてスクリプトで実測し直した**(本番用374字/短縮版133字/カクヨムキャッチ93字/タイトル①49字・①'50字)。初稿の自己申告値は384字・170字とずれていた。`CLAUDE.md`が繰り返し警告しているとおり、**エージェントの自己申告する字数を鵜呑みにしないこと**
- なろう・カクヨムいずれの文字数上限・キーワード上限も、**このセッションではWebFetchが使えず、検索エンジンのスニペット経由でしか確認できていない**(`research/trends/2026-08-06.md`と同じ制約)。投稿直前に実際の入力画面で必ず再確認すること
- `テイム` `AI` タグの追加タイミングは、`publishing/metrics.md`の週次記録と合わせて`marketing-strategy.md`側にも反映すること
- タイトル・あらすじ・タグの最終決定後は、`publishing/marketing-strategy.md`§7「公開前に直すもの」のチェック項目を本文書へのリンクで更新するとよい(本文書自体は`marketing-strategy.md`を上書きしない)
