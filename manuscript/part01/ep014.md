# 第十四話　誰そ彼刻

　乱れた息が収まるまで、ウィンたちはしばらくその場を動かなかった。

　脇腹の痛みはだいぶ引いていたが、まだ足に力が入りきらない。傷薬を使ったばかりだというのに、これほど消耗したのは初めてだった。

「ねえ、座ろっか。わたしも膝ガクガクだよ」

　魔法の連発で消耗した茜音が、近くの石段に腰を下ろす。ウィンもその隣に座り込み、ようやくひと心地がついた。

　落ち着いたところで、ステータス画面を開いた。二段階分がまとめて反映されている。

　この数日で、動きは目に見えて軽くなった。手元の細かい作業も、初日とは比べ物にならない。

　ただ、殴られたときの効き方だけが、何も変わっていない。さっきの一撃も、上着がなければ終わっていた。

　少し考えて、思い当たった。避けてばかりいたから、避けるのが上手くなった。殴られていないから、頑丈にならない。

　そういう理屈で配られているのなら、筋は通っている。

```
ウィン
Lv8
職業:暗器使い
ソウルクレスト:彼は誰(かはたれ)

スキル:投擲、隠密行動、生成(暗器)、調合(毒)、急所看破、会心の一撃、精密投擲
```

「茜音さんのほうは、どうでした」

「わたしなんて一つしか上がってないよ。後半はほとんど杖振ってただけだし、しょうがないよね」

　茜音はさして気にした様子もなく、あっさりとそう言った。それから、ふとウィンの脇腹に目を留める。

「そこ、まだ痛むでしょ。もう一回、治しとくね」

　止める間もなく、茜音は膝をついて手をかざした。淡い光がじんわりと染み込み、鈍く残っていた痛みが嘘のように引いていく。

　ウィンは素直に「助かりました」とだけ返した。

　どちらからともなく立ち上がり、二人は洞窟の中へ足を踏み入れる。

　入り口の暗さに反して、奥へ進むほど壁や天井の苔が光を増していく。まるで見せるためのように、道筋だけがぼんやりと浮かび上がっていた。

　崩れかけた石段が奥まで続き、ところどころに倒れた柱が転がっている。踏み荒らされた土も、置き去りにされた道具の類も見当たらない。

「なんか……静かだね」

　声を潜め合いながら石段を上りきると、天井の高い円形の広間に出た。



　中央に横たわる白い影に、二人は足を止めた。

　全身を真っ白な毛で覆われた、巨大な虎だった。体高だけなら大熊に匹敵する巨躯でありながら、毛並みのそこかしこに深い傷が刻まれ、力なく地に伏せている。

　よく見ると、脚が鎖に繋がれていた。

　視界の隅に、見慣れない表示が浮かぶ。

```
刻紋種
氷牙の白虎(ひょうがのびゃっこ)
```

　ウィンは息を呑む。紋章を刻まれた、通常個体とは一線を画す特殊な存在——ゲームを始める前に読んだガイドで、名前だけは知っていた。

　だが、実物はまるで違った。勝てるか負けるかという物差しそのものが意味を成さない。伏せているだけの体から、そんな圧力が伝わってくる。

　武器を借りる、変える。そういう算段よりも先に、体が竦んで動かなかった。

「……あの子の声だったんだ」

　茜音が、ウィンより先に足を踏み出していた。

「え、危ないですよ!」

　制止も聞かないまま、茜音は武器の一つも持たず、ゆっくりと、それでいてまっすぐに虎へ近づいていく。

　強引にでも止めるべきか、ウィンは一瞬迷った。だが横顔を見て思い直す。そこにあったのは、いつもの物怖じしない明るさとはまた違う、真剣な、けれど少しも怖がっていない表情だった。

　虎もまた唸り声一つ上げない。伏せたまま、ただ弱々しく茜音を見つめている。

　ウィンは警戒だけは解かずについていく。

　茜音は虎のそばに膝をつき、傷だらけの体にそっと手をかざした。手のひらから、ウィンの傷を治したのと同じ淡い光がこぼれる。

　だが、傷は塞がらなかった。わずかに滲んでいた血が止まった程度で、目に見える変化はそれ以上進まない。

「わたしのレベルじゃ、この傷は治せないのかな……」

　困惑した表情には、いつもの余裕がなかった。

　じっと耳を澄ますような間があって、茜音がハッと顔を上げる。

「違うんだって。傷のせいじゃない……喉のところ」

「喉、ですか」

　言われて目を凝らすと、虎の喉元の毛に埋もれるようにして、小さな宝石のようなものが覗いていた。場違いなほど人工的な輝きだ。表面には、細かな紋様のようなものが刻まれている。

「これが、苦しめてる原因……らしい」

　茜音の声は確信めいていた。誰かに教えられたように、けれど誰の姿も見えないまま。

　両手を宝石にかざし、目を閉じる。先ほどより深く、集中するような様子だった。

　手のひらの光が一段と強くなり、虎を包み込んでいく。しばらくして、かちり、と硬い音を立てて宝石が毛の間から浮き上がり、地面に転がり落ちた。

　虎が長く息を吐く。伏せていた体がわずかに緩み、鼻先を茜音の手に擦り寄せる。

　直後、光が二人と虎を包むように膨れ上がる。眩しさにウィンは思わず目を細めた。

```
ソウルクレスト──『誰そ彼刻(たそがれどき)』の開放条件を達成しました。
```

「誰そ彼刻……!」

　光の中心で、茜音が叫ぶように声を上げた。意識してのことではないらしい、驚いたように自分の口元を押さえている。たそがれどき、と読むのだと、ウィンはその響きだけで理解した。

　視界にもう一つ、通知が浮かぶ。

```
『使役に成功しました』
```

「わ、わたしの紋章、色が変わってる……!」

　茜音が慌てて自分の右手を見る。手の甲に浮かぶ、星の意匠を持つ紋章——以前見せてもらった時は、灰色の星が三つ並んでいるだけだった。

　そのうちの一つが今、淡い蒼白い光を帯びて色づいている。

　光が収まると、虎の巨躯もまた縮んでいった。見上げるほどだった体は、両手に抱えられるくらいの、ぬいぐるみのように愛らしい姿に変わっている。深い傷はどこにも見当たらず、そのタイミングで脚の枷も外れたようだ。

　声にならない声のようなものが、ウィンの頭の中にも直接響いた。

『そばにいる。戦う時は、力を貸そう』

　茜音がしゃがみ込んで、恐る恐る手を伸ばす。丸い目がそれを見上げ、鼻先を掌に押しつけた。

　ウィンは、まだ広間の入り口から動けずにいた。

　ついさっきまで、そこには勝てるか負けるかを考えることさえ許さない何かが横たわっていた。それが今、腕に抱えられるほどの大きさで喉を鳴らしている。

　全部この目で見ていたのに、意味のほうが追いつかない。

「……ウィンくん、来ないの?」

　振り向いた茜音の顔は、笑っているのに少し泣きそうだった。

　ウィンは歩み寄って、白い頭にそっと手を置く。ひやりと冷たい毛の下で、確かに息が動いていた。

「必要な時だけ呼べばいいみたい……普段は見えないところにいてくれるって」

　茜音がぽつりと呟く。誰に教わったわけでもないのに、そう分かるらしかった。



　ウィンはふと、地面に転がったままの鎖に目をやった。今しがたまで虎の脚を繋いでいた、太く無骨な鎖だ。

「あの鎖……誰が繋いだんでしょうね」

　茜音の表情から、わずかに笑みが引いた。

「刻紋種が囚われてるって、どういうことでしょう。モンスターなのに、誰かに閉じ込められてたってことですよね」

「うん……傷も、鎖でつけられたものかもしれない。ただの縄張り争いとか、そういうのとは違う気がする」

「これも、調べてみる価値、ありそうです」

　答えはすぐには出ない。それでも、頭の片隅に留めておくことだけは、二人の間で静かに一致した。

「……誰そ彼刻」

　ウィンは今しがた耳にした名を、もう一度小さく呟いた。国語の授業でうろ覚えに聞いた、あの古い言葉と同じ響きだった。

「誰そ彼——たしか、黄昏時に薄闇で相手の顔がよく見えなくて、『誰そ、彼』……あの人は誰だ、って問いかける言葉だったと思います」

「へえ、そんな意味が」

「俺のクレストの名前、『彼は誰』って言うんです。似た意味の言葉ですけど、こっちは明け方の薄闇の方で」

　言ってから、ウィンは自分の言葉にはっとした。誰そ彼と、彼は誰。夕暮れと、夜明け。

　同じ問いを、互いに逆の時間から発している。

「……対になってる、ってこと?」

「偶然にしては、できすぎてる気がしますね」

　二人はしばらく黙り込んだ。

　先に口を開いたのは、茜音のほうだった。

「これ、ちょっと……知られたらまずいやつだったりする?」

　声から、いつもの軽さが引いている。

「はい。回復のクレストだと思っていたら、刻紋種を無傷で仲間にできる。広まったら、悪目立ちどころじゃ済まないと思います」

「じゃあさ、掲示板で似たような話がないか調べてみない?」

「聞き方には気をつけてください。『刻紋種をテイムした人いますか』なんて書き込んだら、それだけで手の内を明かすことになります」

「うっ……それは、そう、かも」

「まずは、もう出回っている情報をこっそり漁るところからです。自分から発信せず、受け取る側に回れば、目立たずに済みます」

「なるほど……。それなら、わたしも探してみる。使役系の知り合いがいないか、それとなく聞くとか」

「その一言で一発アウトですよ」

「わかってるって。もう、子供扱いしないでよ」

　軽口が戻ってくる。決めたことは、結局ひとつきりだった。

「まずは二人だけの秘密、ってことで」

　茜音は頷き、小さくなった虎をそっと抱き上げる。腕の中に収まったそれは、心地よさそうに目を細めていた。

　だが、真っ白な虎を抱いた冒険者が大通りを歩けば、否応なく人目を引く。

「街に戻る前に、一回しまっておいた方がいいかもしれません」

「しまう、って……できるのかな」

　茜音が半信半疑のまま手をかざすと、虎の体はふわりと光の粒子に変わり、手の甲の紋章へ吸い込まれるように消えた。試しに念じてみれば、また姿を現して足元に大人しく収まる。

「便利ですけど……呼ぶ場所は選んだ方が良さそうですね」

「うん、約束。街中では絶対呼ばない」


　　　　◇


　セイレスへ戻る頃には、日はだいぶ傾いていた。討伐の報告と素材の売却を済ませ、二人で割ってなお、今日はいい実入りだった。

「今日はほんと、色々あったね」

　茜音が伸びをしながら言う。門番の大熊、初めての刻紋種、そして誰にも言えない秘密。

「あ、そうだ。依頼はこれで終わりだし、パーティ、いったん解散しとく? ずっと組みっぱなしだと、他の子と組みたいときに困るだろうし」

「そうですね。……でも、調べ物は一緒にやるんですよね。だったら、フレンド登録くらいはしておきませんか」

「あ、それいいね! ……じゃあもしかして、ウィンくんの初フレンドまでも奪っちゃう感じだ?」

「……そうなりますね」

　顔を見合わせ、どちらからともなく小さく笑う。

```
『フレンドを登録しました』
```

　茜音は続けてパーティ解散の手続きを済ませた。視界の端に小さく表示されていた体力ゲージが、静かに消える。

「じゃ、また今度。調べ物、頑張ろうね」

「はい。……気になることが、一日で増えすぎました」

　ウィンはギルドの前で茜音と別れ、すぐにログアウトした。


　　　　◇


　二人が立ち去った後、洞窟の奥にはただ静けさだけが残っていた。

　崩れた石段の隙間で、外れたままの鎖の切れ端だけが、誰にも拾われないままひっそりと転がっている。

　誰のものとも知れない声が、暗がりの中でひとりごちる。

「暴れてもらうつもりでした。手懐けられるとは、思っていません」

　平坦な声だった。抑揚がどこにもないのに、言葉の輪郭だけがはっきりしている。

「北のあれも、夜会に持っていかれました。……縁がないのかもしれませんね」

「それにしても、こういう形でクレストが開くとは。あの方は、どんな魂の形をしているのでしょう」

「……それに」

　声はそこで一度、言葉を切った。愉快でたまらないというように、含み笑いの気配だけが濃くなる。

「私のお気に入りのほうも、面白いクレストの使い方をしていました」

　声はしばらくそこに留まったまま、何かを確かめるように暗がりを漂っていた。冷えた空気だけが、じわりと洞窟の奥まで満ちていく。

　やがて笑いの気配が薄れ、囁きだけが小さくなっていく。それきり、声は闇に溶けて消えていった。
