# 第十四話　誰そ彼刻

「……声、さっきより大きくなってる」

　茜音はもう歩き出していた。膝が震えているのが後ろからでも分かるのに、足のほうは止まらない。

　ウィンの耳に届くのは、奥のほうで水が落ちる音だけだ。声が聞こえるのは茜音だけで、ウィンに分かるのは、彼女の手の甲で明滅している紋章の間隔だけだった。

　土に落ちたままの短剣を拾い上げ、鞘へ戻す。傷は治してもらっても、疲れまでは抜けていない。踏み出す足が、いまさらのように重い。

　二人は洞窟の中へ足を踏み入れた。

　奥へ進むほど、壁と天井の苔が光を増していく。足元の道筋だけが、青白く浮かんで見えた。

　崩れかけた石段が奥まで続き、ところどころに倒れた柱が転がっている。土は柔らかいままで、足跡は自分たちのものしかない。

「なんか……静かだね」

　茜音の手の甲で、紋章の明滅が速くなっている。

　足音を殺しながら石段を上りきると、天井の高い円形の広間に出た。



　息が、白かった。

　外は夏の盛りだ。それがこの広間だけ、冬の朝のように冷えている。床の石にはうっすらと霜が降りている。

　冷気の中心に、白い山があった。

　巨大な虎だった。横たわっていてなお、ウィンの背丈より高い。投げ出された前脚は、大熊の頭ほどもある。

　毛並みのそこかしこが裂けて、乾いた血で固まっていた。呼吸のたびに白い息が漏れ、床の霜を巻き上げる。

　その後ろ脚に、鎖が巻かれていた。腕ほどの太さの鎖が、床へ打ち込まれた杭まで一直線に伸びている。

　視界の隅に、見慣れない表示が浮かぶ。

```
刻紋種
氷牙の白虎(ひょうがのびゃっこ)
```

　刻紋種。紋章を刻まれた、通常個体とは一線を画す特殊な存在——ゲームを始める前に読んだガイドで、名前だけは知っていた。

　床の石には、深い抉れが何本も走っている。爪の跡だ。杭を中心に、円を描くように残っている。

　その円の内側に、今、自分は立っている。喉の奥が勝手に干上がっていく。

「……この子だ」

　茜音が、ウィンより先に足を踏み出していた。

「え、危ないですよ」

　止めようと伸ばした手は、届かなかった。茜音は背の杖に手もかけないまま、まっすぐに虎へ近づいていく。

　その歩き方を見て、ウィンは手を下ろした。呼び戻しても、たぶん振り向かない。

　虎は、唸り声一つ上げなかった。伏せたまま、目だけがゆっくりと茜音を追っている。

　ウィンは警戒を解かないまま、少し離れたところで足を止めた。

　茜音は虎のそばに膝をつき、傷だらけの体にそっと手をかざした。手のひらから、ウィンの傷を治したのと同じ淡い光がこぼれる。

　だが、傷は塞がらなかった。わずかに滲んでいた血が止まった程度で、目に見える変化はそれ以上進まない。

「わたしのレベルじゃ、この傷は治せないのかな……」

　茜音は手を止めて、じっと耳を澄ますような顔をした。それから、ハッと顔を上げる。

「違うって。傷のせいじゃない……喉のところ?」

　ウィンは虎の喉元へ目を凝らした。急所看破——狼の首筋や猪の白い一点を教えてくれるあの感覚が、毛の奥の一点だけを浮かび上がらせる。

「……毛の奥に、何か埋まってます」

　茜音が毛をかき分ける。白い毛のあいだから、小さな宝石が覗いた。

　場違いなほど人工的な輝きだ。表面には、細かな紋様が刻まれている。

「これ……これが、この子を苦しめてるみたい」

　茜音は両手を宝石にかざし、目を閉じた。

　光の向きが、さっきと違った。傷にかざした時は手のひらから零れていた光が、今度は宝石のほうへ吸い寄せられていく。

「傷を治すんじゃなくて……こっちを、外すんだ」

　紋様が一本ずつ細くなり、ぱきん、と乾いた音を立てて宝石が毛の間から浮き上がった。転がり落ちた石は、もう何の光も帯びていない。

　虎が長く息を吐く。舞い上がった霜が、そのまま溶けていく。

　直後、光が二人と虎を包むように膨れ上がった。眩しさにウィンは思わず目を細める。

　光が引いたとき、虎は縮んでいた。見上げるほどだった体が、両手に抱えられるくらいの大きさに変わっている。裂けていた毛並みも、元通りに戻っていた。

　細くなった後ろ脚から鎖が抜けて、床で音を立てる。

　小さくなった虎が、よろけながら茜音の膝まで歩いてきた。額を、彼女の手にぐいと押しつける。

　声にならない声が、ウィンの頭の中にも直接響いた。

『……助かった』

「わ、わたし、何もしてないよ」

『取ってくれた。だから、そばにいる』

　低く、ひどく疲れた声だった。それだけ言うと、白虎は茜音の膝に顎を乗せて目を閉じてしまう。

　茜音は、目の前の何かを見上げたまま固まっていた。

「……たそがれどき。『誰そ彼刻の解放条件を達成しました』って、出てる」

　聞き慣れない言葉だった。

「わたしのクレストの名前。……それと、『使役に成功しました』、って」

　語尾が半分裏返っていた。

　茜音が慌てて自分の右手を見る。手の甲に浮かぶ、星の意匠を持つ紋章——以前見せてもらった時は、灰色の星が三つ並んでいるだけだった。

　そのうちの一つが今、淡い蒼の光を帯びて色づいている。

　ウィンは、その場から動けずにいた。

　さっきまで、床の石を抉っていた前脚だ。それが今は、茜音の膝の上で丸まっている。

「……ウィンくん、来ないの?」

　振り向いた茜音の頬に、涙の跡が一本ついていた。本人は拭いもしない。

　ウィンは歩み寄って、白い頭にそっと手を置く。ひやりと冷たい毛の下で、確かに息が動いていた。



「ねえ。……誰にやられたの?」

　茜音が膝の上へ問いかける。白虎は目を開けなかった。喉の奥で低く鳴っただけで、それきり黙ってしまう。

　答えないのか、答えられないのか、ウィンには判断がつかなかった。

　代わりに、床へ転がったままの鎖に目をやる。杭は、石の床を割って打ち込まれていた。輪の一つ一つに、赤黒い錆が浮いている。

「……錆びてます。昨日今日で繋がれた、という話ではないですね」

「じゃあ、ずっとここに?」

「たぶん」

　茜音はそれきり何も言わず、膝の上の白い頭をゆっくり撫でていた。

「……誰そ彼刻」

　ウィンは、さっき聞いた名前をもう一度小さく呟いた。国語の授業でうろ覚えに聞いた言葉と、同じ響きだった。

「誰そ彼、って……たしか、夕暮れで相手の顔が見えなくて、『誰そ、彼』——あれは誰だ、って聞く言葉です。授業で一度やっただけなので、あやしいですけど」

「……ぴったりだ」

　茜音が、膝の上を見下ろしたまま言う。

「この子が誰なのか、わたし、何も知らないもん」

　ウィンは、自分のクレストの名前を思い出していた。彼は誰。あれは誰だ、と明け方の薄闇で問う言葉だ。

「……俺のは、明け方のほうです」

「え?」

「『彼は誰』っていうんです。俺のクレストの名前」

　茜音がゆっくり顔を上げた。

「……逆だ」

「はい」

　二人はしばらく黙り込んだ。

　先に口を開いたのは、茜音のほうだった。

「これ、みんなできることなの?」

「聞いたことがないです。刻紋種は、出たら討伐報告しか流れません。先週も北の湿地に出て、どこかのクランが獲ったって騒ぎになってました」

「……獲った」

　白い頭を撫でていた手が、止まった。

「じゃあ、この子も。見つかったら、そうなるってこと?」

「たぶん」

「やだ」

　即答だった。

「言わない。誰にも言わない」

「はい。……ただ、調べるのはやりたいです。同じことができる人が、他にもいるかもしれません」

「わたしも探す。使役系の人がいないか、それとなく聞いて——」

「聞き方でだいたい伝わっちゃいます」

「……あ。そっか」

「もう誰かが書いているものを、読むだけにしましょう」

「うん」

　茜音は立ち上がりかけて、腕の中を見下ろした。

「……この子、このまま連れて歩くの?」

　真っ白な虎を抱いた冒険者が大通りを歩けば、それだけで人だかりができる。

　茜音が困った顔で手をかざすと、その視線が宙で止まった。

「あ。『紋章に収めますか』って出た」

　はい、と茜音が呟いた次の瞬間、虎の体はふわりと光の粒子に変わり、手の甲の紋章へ吸い込まれるように消えた。もう一度念じてみると、光が集まり直して、足元に白い虎が戻ってくる。

「……よかった。ちゃんと帰ってきた」

「はい」

「じゃあ……また後でね」

　茜音は言い聞かせるように白い頭をひと撫でしてから、もう一度紋章へ帰した。


　　　　◇


　セイレスへ戻る頃には、日はだいぶ傾いていた。討伐の報告と素材の売却を済ませ、二人で割ってなお、今日はいい実入りだった。

　ギルドの掲示の前で、ウィンは一度だけステータスを開いた。二つ上がったレベルの分だけ、足の運びも指先の動きも軽くなっている。

　ただ、殴られたときの痛みだけは初日と同じだった。今日の一撃も、上着がなければ倒れていた。

「今日はほんと、色々あったね」

　茜音が伸びをしながら言う。

「依頼も終わったし、パーティは一回解散しとこっか。組みっぱなしだと、他の子と組みたいとき困るし」

「そうですね」

「あ、でもその前に。フレンド登録しとこ?」

「え」

「解散したら、連絡取れなくなっちゃうじゃん」

　茜音のほうから申請が飛んでくる。ウィンは少し迷って、承諾を押した。

```
『フレンドを登録しました』
```

　茜音は続けてパーティ解散の手続きを済ませた。視界の端に小さく表示されていた体力ゲージが、静かに消える。

「じゃ、また今度。あの子のこと、調べてみるね」

「はい。俺も探してみます」

　ウィンはギルドの前で茜音と別れ、すぐにログアウトした。






　　　　◇






　二人が立ち去った後、洞窟の奥には静けさだけが残った。

　床に落ちたままの宝石が、ふいに浮き上がる。紋様の消えた表面を、光が一度だけ舐めるように走った。

「……また、駄目でしたか」

　誰のものとも知れない声だった。宝石は暗がりの中でぱきりと砕け、粉になって床へ落ちる。

　気配はしばらく、二人が下りていった石段のほうに留まっていた。

　やがて、洞窟には水の落ちる音だけが残った。
