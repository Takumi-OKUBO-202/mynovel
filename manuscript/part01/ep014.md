  - **末尾の声の場面**: 同一人物の台詞が二連続していた箇所に一拍を挿入(「気配が、床に落ちたままの宝石のそばで止まる。紋様は光を失って、ただの石くれのように転がっていた。」——**外れた宝石が拾われないまま残っている絵はF010・F011の補強にもなる**)/締めの三段(留まる→薄れる→闇に溶けて消えた)が**同じ「消えていく」を三度書いていた**ので「声はそれきり途切れた。冷えた空気だけが、じわりと洞窟の奥まで満ちていく。」の二文に圧縮。**詠嘆で閉じず、冷気だけを残す**

# 第十四話　誰そ彼刻

　茜音は洞窟の入り口で足を止めなかった。

「……声、さっきより大きくなってる」

　もう歩き出している。杖を握る手に力が入っているのが、後ろからでも分かった。

　ウィンは土に落ちたままの短剣を拾い上げ、鞘へ戻して後を追った。傷は治してもらっても、疲れまでは抜けていない。

　奥へ進むほど、壁と天井の苔が光を増していく。足元の道筋だけが、青白く浮かんで見えた。

　ウィンに聞こえるのは、奥で水が落ちる音だけだ。声のほうは、茜音の手の甲の明滅でしか分からない。

　崩れかけた石段が奥まで続き、ところどころに倒れた柱が転がっている。積もった砂埃に、足跡は自分たちのものしかなかった。

「なんか……寒くない?」

「ええ。奥へ行くほど冷えてきますね」

　茜音の手の甲で、紋章の明滅が速くなっている。

　足音を殺しながら石段を上りきると、天井の高い円形の広間に出た。



　息が、白かった。

　ここだけ、いま来た通路とも外とも気温が違う。床の石にはうっすらと霜が降りている。

　冷気の中心に、白い山があった。

　巨大な虎だった。横たわっていてなお、ウィンの背丈より高い。投げ出された前脚は、大熊の頭ほどもある。

　毛並みのそこかしこが裂けて、乾いた血で固まっていた。呼吸のたびに白い息が漏れ、床の霜を巻き上げる。

　その後ろ脚に、鎖が巻かれていた。腕ほどの太さの鎖が、床へ打ち込まれた杭まで一直線に伸びている。

　名前の表示が浮かぶ。その上に、見たことのない一行が乗っていた。

```
刻紋種
氷牙の白虎(ひょうがのびゃっこ)
```

　刻紋種。名前を持つ個体は別枠だと、ガイドの隅に書いてあった。

　床の石には、深い抉れが何本も走っている。爪の跡だ。杭を中心に、円を描くように残っている。

　その円の内側に、今、自分は立っている。喉の奥が勝手に干上がっていく。

「……この子だ」

　茜音が、ウィンより先に足を踏み出していた。

「え、危ないですよ」

　止めようと伸ばした手は、届かなかった。茜音は背の杖に手もかけないまま、まっすぐに虎へ近づいていく。

　振り向きもしない。ウィンは伸ばした手を下ろした。

　虎は、唸り声一つ上げなかった。伏せたまま、目だけがゆっくりと茜音を追っている。

　ウィンは短剣の柄に手をかけたまま、茜音のすぐ後ろに立った。

　茜音は虎のそばに膝をつき、傷だらけの体にそっと手をかざした。手のひらから、ウィンの傷を治したのと同じ淡い光がこぼれる。

　だが、傷は塞がらなかった。わずかに滲んでいた血が止まった程度で、目に見える変化はそれ以上進まない。

「わたしのレベルじゃ、この傷は治せないのかな……」

　茜音は手を止めて、じっと耳を澄ますような顔をした。それから、ハッと顔を上げる。

「違うって言ってる。傷のせいじゃなくて……喉のところ?」

　白虎が、わずかに顎を上げた。差し出すような動きだった。

　茜音が喉元の毛をかき分ける。血と土で汚れた毛の奥に、小さな石が埋まっていた。

　そこだけ、濁りがない。表面に細い線が幾筋も彫られている。

「これ……これが、この子を苦しめてるみたい」

　茜音がもう一度、今度はその石に手をかざした。

　手のひらから零れた光が、傷にかざした時とは逆に、石のほうへ吸い込まれていく。

　茜音が白虎の顔を見た。声の主に確かめるような目だった。

「……こっち? 治すんじゃなくて、外すの?」

　彫られた線が、端から一本ずつ薄くなっていく。石がわずかに浮いて、その下の肉が引き攣れるのが見えた。

　白虎が吼えた。

　痛いのだ、とウィンにも分かった。埋まっていたものが、皮膚を裂きながら剥がれようとしている。

　伏せていた後ろ脚が跳ね上がる。垂れていた鎖が石の床を叩き、輪が鞭のようにしなって跳ね回った。

「茜音さん!」

　肩を掴んで引き倒す。頭のあった高さを、鎖が横に走っていった。

　背中を打たれたが、上着の革が衝撃のほとんどを殺してくれる。それでも息が詰まった。

「ご、ごめん、わたし——」

「手は止めないでください」

　虎を押さえることはできない。押さえるなら鎖のほうだ。

　ウィンは足元の石を拾って、意識を通した。手の中で石が伸び、太い釘の形に変わる。

　鎖の輪が床を叩いて跳ね上がる、その手前を狙って打ち込んだ。二度、三度と柄を叩く。

　鎖は床に貼りついたまま動かなくなった。これで、こちらへは飛んでこない。

「今です」

　茜音の手のひらで光が跳ね上がった。ぱきん、と乾いた音を立てて、石が毛の間から抜け落ちる。

　床を転がったそれは、もう何の光も帯びていない。

　白虎の唸りが、長く尾を引いて途切れた。

　そして、茜音の手から溢れていた光が、今度はまっすぐ白虎の体へ流れ込んでいく。

　さっきはあれだけ塞がらなかった裂け目が、端から順に閉じていく。石が刺さっているあいだは、この光が届かなかったのだ。

　直後、光が二人と虎を包むように膨れ上がった。眩しさにウィンは目を細める。

　光が引いたとき、虎は縮んでいた。見上げるほどだった体が、両手に抱えられるくらいの大きさに変わっている。傷はもうどこにも残っていない。

　細くなった後ろ脚から鎖が抜け落ちて、床で音を立てた。

　小さくなった虎が、よろけながら茜音の膝まで歩いてきた。額を、彼女の手にぐいと押しつける。

　声にならない声が、ウィンの頭の中にも直接響いた。

『……かたじけない』

　ウィンは思わず自分の耳を押さえた。耳では聞いていない。頭の内側で、直接そう言われた。

「今の、聞こえた……?」

「……はい」

　それ以上の言葉が出てこなかった。茜音も片手で口を押さえたまま、何も言わない。

『……長かった』

　年寄りが縁側で喋るような、ゆっくりとした声だった。見た目とまるで釣り合っていない。

『借りができたな。戦のときは、力を貸そう。……いまは、少し眠らせてくれ』

　言い終わらないうちに、白虎は茜音の膝に顎を乗せて目を閉じてしまった。

　茜音は顔を上げたまま動かない。何かを読んでいる目だった。

「……『誰そ彼刻』の、解放条件を達成しました、って」

　たそがれどき、と茜音は読んだ。ウィンには初めて聞く名前だった。

「それと……『使役に成功しました』、って」

　語尾が半分裏返っていた。

　茜音が自分の右手を見た。ここまでずっと明滅していた、星の意匠の紋章。

　灰色だった三つの星のうち、一つが淡い蒼の光を帯びて色づいている。明滅は、いつのまにか止まっていた。

「星、あと二つ灰色のままなんだけど……これ、どういうこと?」

「……わかりません。俺のクレストにも、説明はついてないので」

「あ。……『魂力が足りないため、召喚状態を維持できません』、だって」

　茜音が膝の上を見下ろす。

「この大きさなのって……そのせい? ごめんね、わたしが弱くて」

　茜音の目が、まだ何かを追っている。

「その下に、『紋章に収める』っていうのも出てる」

　ウィンは床に膝をついたまま、その小さくなった体を見ていた。ついさっきまで、前脚の一本が自分の頭より大きかった。

「……ウィンくん」

　振り向いた茜音は、目を赤くしていた。

「もう、聞こえない」

「え」

「ずっと聞こえてた声。……止まった」

　ウィンは立ち上がって歩み寄り、白い頭にそっと手を置いた。ひやりと冷たい毛の下で、息が動いている。

「……そうですか」

　茜音は指の背で目元を拭って、それから笑った。



「ねえ。……誰にやられたの?」

　茜音が膝の上の白虎に問いかける。返ってきたのは、寝入りかけた声だった。

『……覚えておらぬ』

　それきり、白虎は答えなかった。

　ウィンは床へ転がったままの鎖に目をやった。杭は、石の床を割って打ち込まれている。輪の一つ一つに、赤黒い錆が浮いていた。

「……錆びてます。ずっと前から、ここに繋がれてたんだと思います」

　それから、床に落ちた石を拾い上げた。彫られていた線は消えて、ただの硝子の粒にしか見えない。

「倒していたら、こんなものが埋まっていたことも分からないままですね」

　茜音は答えなかった。膝の上の白い頭を、ゆっくり撫でている。

「……誰そ彼刻」

　国語の授業でうろ覚えに聞いた言葉と、同じ響きだった。

「誰そ彼、って、夕暮れの言葉です。薄暗くて相手の顔が見えないから、あれは誰だ、って聞く」

　茜音が、膝の上を見下ろしたまま言う。

「……この子が誰なのか、わたし、何も知らないもんね」

「俺のクレスト、『彼は誰』っていうんです。同じ意味で、明け方のほうの言葉です」

　茜音は、しばらく何も言わなかった。それから自分の手の甲と、ウィンの顔を順に見る。

「……逆だ」

「はい」

　二人はしばらく黙り込んだ。

「……今の、みんなできることなの? 刻紋種を、こうやって」

「聞いたことがないです。刻紋種は、出たら討伐報告しか流れません。先週も北の湿地に出て、どこかのクランが獲ったって騒ぎになってました」

「……獲った」

　白い頭を撫でていた手が、止まった。

「じゃあ、この子も。見つかったら、そうなるってこと?」

「たぶん」

「……なんで。この子、もう暴れてないよ」

「たぶん、そこは見てもらえないと思います」

　茜音は口を開きかけて、やめた。膝の上の白い頭を、何度か撫でる。

「……やだ。言わない、誰にも」

「はい。……そのうえで、調べたいです」

「うん。……わたしも探してみる」

　茜音は膝の上の白虎を抱き上げて、立ち上がった。

「……この子、このまま連れて歩くの?」

「大通りだと、人だかりができますね」

「だよね」

　茜音が腕の中を見下ろした次の瞬間、虎の体はふわりと光の粒に変わり、手の甲の紋章へ吸い込まれるように消えた。もう一度念じてみると、光が集まり直して、足元に白い虎が戻ってくる。

「……よかった。ちゃんと帰ってきた」

「じゃあ……また後でね」

　茜音は言い聞かせるように白い頭をひと撫でしてから、もう一度紋章へ帰した。

　セイレスへ戻り、討伐の報告と素材の売却を済ませる頃には、日はだいぶ傾いていた。

　茜音が大きく伸びをした。

「あ、そうだ。フレンド登録しとこ? 依頼が終わったら、パーティ解散になっちゃうし」

　茜音のほうから申請が飛んでくる。ウィンは承諾を押した。

```
『フレンドを登録しました』
```

　茜音は続けてパーティ解散の手続きを済ませた。視界の端に小さく表示されていた体力ゲージが、静かに消える。

「じゃ、また今度。あの子のこと、調べてみるね」

「はい。俺も読んでみます」

　茜音と別れて、ウィンはギルドの掲示の前に立った。討伐依頼の紙が並んでいるだけで、刻紋種の三文字はどこにもない。

　夕暮れと、夜明け。あの二つが並んで出てくるものなのかどうかも、帰ったら調べてみよう。






　　　　◇






　床に転がったままの石が、ふいに浮き上がった。

　彫られていた線の消えた表面を、光が一度だけ走る。

「……ずいぶん長く、かけたのですが」

　声は暗がりの中にあった。姿はどこにもない。

「あと少しで、地図がいくつか書き換わるところでした。……惜しい」

　ぱき、と乾いた音がした。

　石の表面に細い罅が走り、枝分かれしながら全体へ広がっていく。罅の隙間から、黒い霧のようなものが糸を引いて漏れ出した。

　霧は床へ落ちると、石段のほうへ這っていく。二人が下りていった方向だ。

　半ばまで進んだところで、力尽きたように途切れた。

「まあ、壊れた道具の話はよしましょう。……面白いものが、二つ増えましたので」

　石が粉になって落ちた。

　洞窟には、水の落ちる音だけが残った。
