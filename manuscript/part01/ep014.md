# 第十四話　誰そ彼刻

　茜音は洞窟の入り口で足を止めなかった。

「……声、さっきより大きくなってる」

　もう歩き出している。膝が震えているのが後ろからでも分かるのに、足のほうは止まらない。

　ウィンは土に落ちたままの短剣を拾い上げ、鞘へ戻して後を追った。傷は治してもらっても、疲れまでは抜けていない。踏み出す足が、いまさらのように重い。

　奥へ進むほど、壁と天井の苔が光を増していく。足元の道筋だけが、青白く浮かんで見えた。

　ウィンの耳に届くのは、奥のほうで水が落ちる音だけだ。声を聞けるのは茜音で、ウィンに分かるのは、彼女の手の甲で明滅している紋章の間隔しかない。

　崩れかけた石段が奥まで続き、ところどころに倒れた柱が転がっている。積もった砂埃に、足跡は自分たちのものしかなかった。

「なんか……寒くない?」

「ええ。奥へ行くほど下がってます」

　茜音の手の甲で、紋章の明滅が速くなっている。

　足音を殺しながら石段を上りきると、天井の高い円形の広間に出た。



　息が、白かった。

　外は夏の盛りだ。それがこの広間だけ、冬の朝のように冷えている。床の石にはうっすらと霜が降りている。

　冷気の中心に、白い山があった。

　巨大な虎だった。横たわっていてなお、ウィンの背丈より高い。投げ出された前脚は、大熊の頭ほどもある。

　毛並みのそこかしこが裂けて、乾いた血で固まっていた。呼吸のたびに白い息が漏れ、床の霜を巻き上げる。

　その後ろ脚に、鎖が巻かれていた。腕ほどの太さの鎖が、床へ打ち込まれた杭まで一直線に伸びている。

　名前の表示が浮かぶ。その上に、見たことのない一行が乗っていた。

```
刻紋種
氷牙の白虎(ひょうがのびゃっこ)
```

　刻紋種。名前を持つ個体は別枠だと、ガイドの隅に書いてあった。

　床の石には、深い抉れが何本も走っている。爪の跡だ。杭を中心に、円を描くように残っている。

　その円の内側に、今、自分は立っている。喉の奥が勝手に干上がっていく。

「……この子だ」

　茜音が、ウィンより先に足を踏み出していた。

「え、危ないですよ」

　止めようと伸ばした手は、届かなかった。茜音は背の杖に手もかけないまま、まっすぐに虎へ近づいていく。

　振り向きもしない。足も速めない。ウィンは伸ばした手を下ろした。

　虎は、唸り声一つ上げなかった。伏せたまま、目だけがゆっくりと茜音を追っている。

　ウィンは短剣の柄に手をかけたまま、茜音の斜め後ろまで詰めた。

　茜音は虎のそばに膝をつき、傷だらけの体にそっと手をかざした。手のひらから、ウィンの傷を治したのと同じ淡い光がこぼれる。

　だが、傷は塞がらなかった。わずかに滲んでいた血が止まった程度で、目に見える変化はそれ以上進まない。

「わたしのレベルじゃ、この傷は治せないのかな……」

　茜音は手を止めて、じっと耳を澄ますような顔をした。それから、ハッと顔を上げる。

「違うって言ってる。傷のせいじゃなくて……喉のところ?」

　茜音が毛をかき分ける。喉元の毛のあいだから、小さな宝石が覗いた。

　場違いなほど人工的な輝きだ。表面には、細かな紋様が刻まれている。

「これ……これが、この子を苦しめてるみたい」

　茜音がもう一度、今度は宝石に手をかざす。

　光の向きが、さっきと違った。今度は宝石のほうへ吸い寄せられていく。

「傷を治すんじゃなくて……こっちを、外すんだ」

　紋様が、端から一本ずつ細くなっていく。

　白虎の体が、びくりと跳ねた。

　喉の奥から低い唸りが漏れる。伏せたままだった後ろ脚が跳ね上がり、たるんでいた鎖が一息で伸びきった。

　鉄の輪が跳ね上がる。ウィンは茜音の肩を掴んで引き倒した。頭のあった位置を、鎖が唸りを上げて通り過ぎる。

　背中を叩かれた衝撃は、上着の革がほとんど殺してくれた。それでも息が詰まる。

「ご、ごめん、わたし——」

「続けてください」

　鎖はまだ跳ね回っている。ウィンは足元の石を一つ掴み、意識を通した。手の中で、石が太い釘のような形に伸びる。

　輪が床を叩いた一瞬に、それを打ち込んだ。鎖は床へ縫い止められ、それきり動かなくなる。

「今です」

　茜音の手のひらで光が跳ね上がった。ぱきん、と乾いた音を立てて、宝石が毛の間から浮き上がる。

　転がり落ちた石は、もう何の光も帯びていない。

　白虎の唸りが、長く尾を引いて途切れた。長い息が吐き出され、舞い上がった霜がそのまま溶けていく。

　直後、光が二人と虎を包むように膨れ上がった。眩しさにウィンは目を細める。

　光が引いたとき、虎は縮んでいた。見上げるほどだった体が、両手に抱えられるくらいの大きさに変わっている。裂けていた毛並みも、元通りに戻っていた。

　細くなった後ろ脚から鎖が抜けて、床で音を立てる。

　小さくなった虎が、よろけながら茜音の膝まで歩いてきた。額を、彼女の手にぐいと押しつける。

　声にならない声が、ウィンの頭の中にも直接響いた。

『……助かった』

　ウィンは思わず自分の耳を押さえた。耳では聞いていない。頭の内側で、直接そう言われた。

「今の、聞こえた……?」

「はい。……喋るんですね、この子」

　茜音が片手で口を押さえる。

『取ってくれた。だから、そばにいる』

　低く、ひどく疲れた声だった。それだけ言うと、白虎は茜音の膝に顎を乗せて目を閉じてしまう。

　茜音は顔を上げたまま動かない。何かを読んでいる目だった。

「『誰そ彼刻の解放条件を達成しました』……たそがれどき、って読むのかな」

　膝の上の白虎は、もう寝息を立てている。

「わたしのクレストの名前。……それと、『使役に成功しました』、って」

　語尾が半分裏返っていた。

　使役、という言葉に釣られたように、茜音が自分の右手を見た。ここまでずっと明滅していた、星の意匠の紋章。

　灰色だった三つの星のうち、一つが淡い蒼の光を帯びて色づいている。明滅は、いつのまにか止まっていた。

「星、あと二つ灰色のままなんだけど……これ、どういうこと?」

「……三つまで、ということじゃないでしょうか」

「三つって、何が」

「わかりません」

「あ。……『魂力が足りないため、召喚状態を維持できません』、だって」

　茜音が膝の上を見下ろす。

「この大きさなのは、そのせいなんだ。……ごめんね、わたしが弱くて」

　茜音の目が、まだ何かを追っている。

「その下に、『紋章に収める』っていうのも出てる」

　ウィンは、引き倒したときの体勢のまま床に膝をついていた。

　杭の周りの石を抉ったのは、この前脚だ。それが今は、茜音の膝の上で丸まっている。

「……ウィンくん」

　振り向いた茜音の頬に、涙の跡が一本ついていた。本人は拭いもしない。

　ウィンは立ち上がって歩み寄り、白い頭にそっと手を置いた。ひやりと冷たい毛の下で、息が動いている。

「……間に合ったんですね」

「うん」

　茜音は指の背で目元を拭って、それから笑った。



「ねえ。……誰にやられたの?」

　茜音が膝の上の白虎に問いかける。白虎は目を開けなかった。喉の奥で低く鳴っただけで、それきり黙ってしまう。

　ウィンは床へ転がったままの鎖に目をやった。杭は、石の床を割って打ち込まれている。輪の一つ一つに、赤黒い錆が浮いていた。

「……錆びてます。ずっと前から、ここに繋がれてたんだと思います」

　それから、床の宝石を拾い上げた。紋様は消えて、ただの硝子の粒にしか見えない。

「倒してしまったら、これも残らないんでしょうね。……誰も気づかないわけです」

　茜音はそれきり何も言わず、膝の上の白い頭をゆっくり撫でていた。

「……誰そ彼刻」

　ウィンは、さっき聞いた名前をもう一度小さく呟いた。国語の授業でうろ覚えに聞いた言葉と、同じ響きだった。

「誰そ彼、って、夕暮れの言葉です。薄暗くて相手の顔が見えないから、あれは誰だ、って聞く」

　茜音が、膝の上を見下ろしたまま言う。

「……この子が誰なのか、わたし、何も知らないもんね」

「俺のクレスト、『彼は誰』っていうんです。同じ意味で、明け方のほうの言葉です」

　茜音がゆっくり顔を上げた。自分の手の甲と、ウィンの顔を見比べる。

「……逆だ」

「はい」

　二人はしばらく黙り込んだ。

「……今の、みんなできることなの? 刻紋種を、こうやって」

「聞いたことがないです。刻紋種は、出たら討伐報告しか流れません。先週も北の湿地に出て、どこかのクランが獲ったって騒ぎになってました」

「……獲った」

　白い頭を撫でていた手が、止まった。

「じゃあ、この子も。見つかったら、そうなるってこと?」

「たぶん、そうなります」

「やだ」

「言わない。誰にも言わない」

「はい。……そのうえで、調べたいです。同じことができる人が、他にもいるかもしれません」

「わたしも探す。使役系の人がいないか、それとなく聞いて——」

「聞き方でだいたい伝わっちゃいます。刻紋種をテイムした人を探している、って言っているのと同じなので」

「……あ。そっか」

「掲示板で、もう誰かが書いているものを読むだけにしましょう」

「うん」

　茜音は膝の上の白虎を抱き上げて、立ち上がった。

「……この子、このまま連れて歩くの?」

「大通りだと、人だかりができますね」

「だよね。……じゃあ、収めます」

　言い終わらないうちに、虎の体はふわりと光の粒子に変わり、手の甲の紋章へ吸い込まれるように消えた。もう一度念じてみると、光が集まり直して、足元に白い虎が戻ってくる。

「……よかった。ちゃんと帰ってきた」

「はい」

「じゃあ……また後でね」

　茜音は言い聞かせるように白い頭をひと撫でしてから、もう一度紋章へ帰した。


　　　　◇


　セイレスへ戻る頃には、日はだいぶ傾いていた。討伐の報告と素材の売却を済ませ、二人で割ってなお、今日はいい実入りだった。

　茜音が大きく伸びをした。

「あ、そうだ。フレンド登録しとこ? 依頼が終わったからパーティは解散になるし、そしたら連絡取れなくなっちゃうし」

　茜音のほうから申請が飛んでくる。ウィンは承諾を押した。

```
『フレンドを登録しました』
```

　茜音は続けてパーティ解散の手続きを済ませた。視界の端に小さく表示されていた体力ゲージが、静かに消える。

「じゃ、また今度。あの子のこと、調べてみるね」

「はい。俺も読んでみます」

　茜音と別れて、ウィンはギルドの掲示の前に立った。討伐依頼の紙が並んでいるだけで、刻紋種の三文字はどこにもない。

　夕暮れと、夜明け。あの二つが並んで出てくるものなのかどうかも、帰ったら調べてみよう。






　　　　◇






　床に落ちたままの宝石が、ふいに浮き上がる。紋様の消えた表面に、光が一度だけ走った。

「……もう少しで、育つところだったのですが」

　声は暗がりの中にあって、姿はどこにもない。

　宝石はぱきりと砕け、粉になって床へ落ちる。

　気配はしばらく、二人が下りていった石段のほうに留まっていた。

　やがて、洞窟には水の落ちる音だけが残った。
