# 第二十五話　食われた噂

　森を抜けるまでの道のりを、冬夜はほとんど覚えていない。

　気づくと木立が途切れて、丘の斜面に出ていた。足のほうが勝手に街の方角を向いている。

　視界の隅で、通知がまだ明滅していた。倒した直後に出て、そのままにしてあったものだ。

　冬夜は道端の切り株に腰を下ろして、それを開いた。

　――避けたつもりの位置に、爪のほうが届いてきた。

　あれは、体が硬ければ耐えられたという話ではない。単純に、遅かったから当たった。

```
冬夜
Lv11
職業:暗器使い
ソウルクレスト:彼は誰(かはたれ)

スキル:投擲、隠密行動、暗器生成、毒の調合、急所看破、会心の一撃、精密投擲
```

　スキルの並びも、レベルの数字も、この前開いたときより確かに増えている。自分では何ひとつ選んでいないのに、勝手に増えていく。

　それでも、強くなった気は少しもしなかった。あの仮面の前で、ここに並んだもののどれか一つでも意味を持ったとは思えない。



　セイレスの南門をくぐると、通りが妙に騒がしかった。

　ギルドの建物に入ると、掲示板の前に人だかりができている。依頼を選ぶ列ではない。全員が同じ方を向いて喋っていた。

「マレイアだよ、港の。沖に出たらしい」

「船が三隻やられたって聞いたぞ。荷が丸ごと止まってる」

「見に行ったやつは」

「近づけないんだと。遠目に背中が見えるだけで、名前も何も分かってない」

　港町マレイア。冬夜は行ったことがない。この国の沿岸にある貿易の町だ、という程度の知識しかなかった。

　誰かが、あれ刻紋種だろ、と言った。それきり話は、どこのクランが討伐に名乗りを上げるかという方へ流れていく。

　冬夜はその輪の外に立ったまま、しばらく動かなかった。

　虎の話をしている者は、一人もいなかった。

「そういや、灰狼の森のあれ、結局どうなったんだ」

「知らん。今そんな話してる場合か」

　それだけで、話題は海へ戻っていった。

　あれほど書き込まれていたものが、たった一日で誰の口にも上らなくなっていた。

　ふと思い立って、冬夜はフレンド一覧を開いた。

　灰色に沈んでいた名前に、色が戻っている。

```
茜音:『ただいま! 今どこ?』
```



　ギルドの裏手の路地は、あの日と同じで人通りがなかった。

　壁にもたれて待っていると、茜音が小走りで角を曲がってきた。ローブの裾も、背負った杖も、別れた日と何ひとつ変わっていない。

「おまたせ! ごめんね、思ったより長くなっちゃって」

　詰めていた息が、ようやく抜けた。

「……おかえり」

　言ってから、冬夜は次の言葉に詰まった。

　この人は、何も知らない。掲示板に本人を名乗る書き込みが出たことも、名前のないメッセージが届いたことも、自分が一人であの洞窟へ行ったことも。

　どこから話せば伝わるのか、順番がまるで組み立てられなかった。

「あのさ、わたし戻ってきたばっかりで、まだ何も見てないんだけどさ」

　茜音が、ローブの袖から手を出して指を一本立てた。

「『ちょっと森まで行ってくる。戻ったら連絡する』。最後に来てたの、これ」

「……送った」

「うん。だから、その続きを聞きに来た」

　急かす調子ではなかった。ただ、まっすぐ待っている顔だった。

「冬夜くん、なんかあった?」

「……全部ある」

　冬夜は順番に話した。

　掲示板に「本人ですけど」と書いた者がいたこと。誰も知らないはずの細部を知っていたこと。

　虎がまた出たという書き込みに、八人が向かって戻ってこなかったこと。名前の欄が読めないメッセージが届いたこと。

　そして、それを誰にも言わずに確かめに行ったこと。



　仮面の人型の話をすると、茜音は一度も口を挟まなかった。

　浩二の名前が出たところでも、期待しています、と言われたところでも、ただ聞いていた。

　目の前で大熊に紋章を刻まれ、刻紋種が作られたところまで話すと、茜音がようやく口を開いた。

「その熊、どうなったの」

「倒した」

「……一人で?」

「刻まれたばっかりで、痛みで動きが荒れてた。まともに仕上がってたら、たぶん無理だった」

　言いながら、あの手応えが腕の付け根に戻ってくる。覚えていた場所に賭けて、当たっただけだ。

「……その熊、なんにも悪くないのにね」

　茜音は、路地の壁のほうへ目を移した。

「……ねえ。じゃあ、あの子も、そうだったってこと?」

「そう言ってた。都市級か、天災級まで育てるつもりだったって」

「……途中で、わたしが持ってっちゃったから、当てが外れた」

　冬夜は否定しなかった。当てが外れました、と言ったときのあの声には、悔いの色すらなかった。

「あの子、生まれつきあれだったんじゃないんだ」

　茜音の声が、少しだけ低くなった。

「痛かったから、鎖に繋がれてたんじゃなくて。誰かが痛くしたから、繋いでたってことだよね」

「たぶん」

「そっか」

　しばらく間があってから、茜音がぽつりと言った。

「……許せないよ、そんなの」

　怒鳴りもしなければ、泣きもしない。ただ壁の一点を見ている時間が、いつもより長かった。

「じゃあ、答えは一つだね」

　やがて、茜音は顔を上げた。

「刻紋種を作ってる人が、いる」

　冬夜は頷いた。

「いる。全部じゃないけど、いる」

　自然に生まれるものもある、と本人が言っていた。全部だと決めつけるほうが、たぶん間違っている。

　それでも、作っている者がいるという一点だけは、もう動かない。

「マレイアの話、聞いた?」

　冬夜が言うと、茜音は目を丸くした。

「なにそれ、聞いてない」

「港町の沖に、でかいのが出たらしい。船が沈められて、荷が止まってる」

「……それって、その、試験体ってやつ?」

「分からない」

　冬夜は首を振った。

「別の国へ移すって言ってた。マレイアはこの国だから、たぶん違う。でも、確かめようがない」

　確かめる手立てが自分たちの側に一つもない、というのが、いちばん落ち着かなかった。

「あともう一つ。今、街で虎の話をしてる人が、一人もいない」

　茜音が瞬きをした。

「一人も?」

「一人も。みんな海のほうを見てる」

「……なんか、複雑」

「助かったのは確かだ」

　言ってから、冬夜は少し迷って、続けた。

「それとは別に、一つだけ言っておきたいことがある」

「なに」

「これ、たぶん、ただのゲームじゃない」

　茜音は茶化さなかった。頷きもせず、しばらく考えてから、うん、とだけ言った。

「わたしも、あの子の声が聞こえた時から、ちょっとだけ思ってた」

　路地の向こうを、荷車が一台通り過ぎていく。



　ログアウトすると、部屋の時計は零時を回っていた。

　冬夜はヘッドギアを机の端に置いて、ノートパソコンを開いた。

```
【灰狼の森】エリア情報まとめスレ

531: 名無しの冒険者
虎の件って結局どうなったの

532: 名無しの冒険者
知らん
マレイアのほう見てこい、そっちのが百倍やばい

533: 名無しの冒険者
例の八人、まだ戻ってきてないらしいぞ

534: 名無しの冒険者
もういいってその話
```

　それきり、スレッドは伸びていなかった。

　代わりに、昨日まで影も形もなかったスレッドが、もう三本目まで伸びていた。

　桟橋から背びれだけが見えた。小屋くらいの大きさがあった。

　名前が読めるところまで近づいた者は、まだ帰ってきていない。書かれているのは、そんな話ばかりだった。

　名前は、まだどこにも出ていない。

　冬夜はしばらく画面を眺めてから、そっと蓋を閉じた。

　噂は、放っておけば大きくなるものだと思っていた。実際には、もっと大きな噂が来れば、それに食われて跡形もなく消える。

　この何日か、自分たちが払ってきたものは、何ひとつ効いていなかった。

　机の上のスマートフォンを取って、連絡先の一覧を開く。

　浩二おじさん、という登録名は、上から数えて四番目にあった。最後のやり取りは、始めたばかりの頃に届いた『どうだ、楽しんでるか』で止まっている。

　あの仮面は、浩二をよく知っていると言った。機材を送るよう仕向けたのも自分だと言った。そして、浩二がどこまで分かっていたのかだけは、答えなかった。

　訊いたところで、はぐらかされるかもしれない。そもそも本人が何も知らされていない可能性のほうが高い。それでも、こちらから手を伸ばせる先は、今のところそこしかなかった。

　冬夜は画面を伏せて、机の明かりを落とした。

　――明日、連絡しよう。

　窓の外では、夏の夜がまだ明ける気配もなく、街灯だけが白く灯っていた。
