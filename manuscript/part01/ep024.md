# 第二十四話　覚えている場所

　崩れた柱の陰へ体を沈めても、心臓の音までは隠せなかった。

　人影が消えてから、まだ十も数えていない。目の前で一頭のモンスターが作り変えられるのを見て、手の震えが指先にそのまま残っている。

　――考えるのは、あとだ。

　自分にそう言い聞かせて、ウィンは岩の縁からそっと顔を出した。

　見覚えのある場所だった。崩れかけた石段が奥へ続き、苔むした床のあちこちに倒れた柱が転がっている。壁の光苔が道筋だけをぼんやりと浮かび上がらせているのも、あの日のままだった。

　白虎に会うために、茜音とこの道を歩いた。上りきった先に円形の広間があることも、手前の石段が途中から崩れていることも、体のほうが覚えている。

　知らない場所ではない。今の自分にある材料は、それしかない。

　視界の隅に、見慣れた書式の表示が浮かんでいる。

```
刻紋種
苔纏いの大熊(こけまといのおおぐま)
```

　目の前で刻まれたものに、確かにその表示が出る。見間違いでも、思い込みでもなかった。

　大熊は苦しげに首を振っていた。額から背へ走る紋様が、皮膚の下でまだ落ち着かないようにうねっている。

　唸り声は絶え間なく続くのに、狙いはどこにも定まらない。刻まれたばかりで、痛みのほうが体の主導権を握っている。動きが荒れているうちが勝負だ、とウィンはもう一度自分に確かめた。

　握ったままの目眩し玉に目を落とす。今ここで割っても、見えなくなった大熊がでたらめに暴れる時間が生まれて終わるだけだ。ウィンは指をほどき、それを懐へ戻す。

　使うのは、詰みを作ってからだ。

　ウィンは入り口へ続く通路へ目をやった。逃げ道を残したままでは、旗色が悪くなった時点で距離を稼がれる。

　走れば外套の消してくれる足音も戻る。追いかける勝負にだけは、持ち込むわけにいかなかった。



　通路の入り口の脇に、根元から斜めに傾いだ柱が一本、辛うじて立っている。

　ウィンは短剣を鞘に戻し、体を低くしたまま柱の根元へ回り込んだ。石畳の割れ目に食い込んだ柱の裾と床の間に、拳が入るほどの隙間がある。

　足元に転がっていた瓦礫を一つ拾う。持ち主のいない石くれだ。誰に断りを入れる必要もなく、手のひらの中で形が動き始めた。

　ごつごつした欠片が、短く太い楔の形へ変わっていく。単純な形にしか変えられない自分の力では、これで十分だった。

　壁は作れない。仮に作れたとしても、意識を外した途端にただの石へ戻る。クレストで生んだ形は、置いておける障害物にはならない。

　だが、動かした結果は別だ。倒れた柱は、自分が作ったものではなくなる。

　ウィンは楔を隙間へ打ち込み、肩で押し上げた。ゴリ、と石の擦れる嫌な音がして、柱がわずかに傾く。

　傾いた分だけ広がった隙間へ楔を打ち直し、また押し上げる。二度、三度と繰り返して、四度目でようやく重心が越えた。

　ズウン、と崩落が洞窟を端から端まで揺らした。太い柱が通路を斜めに塞ぎ、砕けた破片が石段の下まで転がっていく。

　手の中の楔から意識を外すと、それはただの欠片に戻って指の隙間から落ちた。塞がった通路だけが、そのまま残る。

　一つに意識を向けている間は、次のものを借りられない。用の済んだ形を抱えたままでは、その一枠が死ぬ。

　大熊が、音のした方へ振り向いた。

　突進に迷いはなかった。ウィンは横へ跳んだが、続けて払われた爪は思っていたより速く、低かった。

　ドッ、と肩口を掠められた。体が半回転して床に叩きつけられ、当て革の擦れる音が耳のすぐ横で鳴る。

　――速い。

　あの日、二人がかりで削り合った個体とは、そもそも爪の伸びてくる速さが違う。門番の座を継いだからではない。額の紋様が、この獣を別物に作り替えている。

　あのときは、見切って避けるだけならどうにかなった。今は、避けたつもりの位置に爪のほうが届いてくる。

　二撃目を避けきる姿勢は残っていなかった。ウィンは懐の目眩し玉を掴み、自分の足元へ叩きつける。

　白い霧が一気に膨れ上がり、大熊の鼻先ごと包み込んだ。獣が戸惑ったように首を振る。

　その数秒で、ウィンは霧の外へ這い出し、倒した柱の裏へ体を運んだ。

　肩が熱を持っている。傷薬を一本抜いて呷ると、痛みが鈍く遠のいていった。

　残り四本。目眩し玉は、あと一つきり。



　柱の陰から、ウィンは大熊の顔を見た。

　急所看破の白い光は、どこにも浮かばなかった。目を凝らしても、開いた口の奥にも、太い首筋にも、輪郭ひとつ灯らない。

　あの日も、見えにくかった。分厚い苔に阻まれているのだとそのときは思ったし、最後には光ってくれたから、それで納得もしていた。

　だが今日は、いくら見ても浮かぶ気配すらない。苔のせいではないのかもしれない、と初めて思った。相手が格上であるほど見えなくなるのだとしたら、この先も同じことが起きる。

　頼れるものは、一つだけあった。あの日、大きく吼えた大熊の口の奥、喉元の苔が薄くなっていた一点。そこへ切っ先を届かせたときの重さを、腕がまだ覚えている。

　だが、これは別の個体だ。爪の欠け方も、背の傷の位置も違う。同じ場所が同じように薄いという保証は、どこにもない。

　外れれば、二度目を作る余裕はない。かといって、時間をかけて見極める余裕も、もう自分の側にはなかった。

　――覚えている場所に賭ける。

　腹を決めると、震えは不思議と止まった。

　まず、位置を作らなければならない。倒した柱に取りつくには、大熊をそこから引き剥がして、数秒だけ稼ぐ必要があった。

　ウィンは足元の欠片をもう一つ借り、手のひらの中で平たい円盤の形に整える。霧の中で霞蜘蛛に使ったのと、同じ手だ。見えていない方向で音が鳴れば、獣はそちらを向く。

　体を低くしたまま横へ回り、円盤を奥の岩壁へ投げつけた。カアン、と高い音が天井にぶつかって二度跳ねる。

　大熊が鼻先を上げ、音のした奥へ向き直った。ウィンはその隙に柱の陰まで移り、意識を欠片から外す。手を離れた円盤は、床に転がる頃にはただの瓦礫に戻っていた。

　倒した柱の胴は、床から胸ほどの高さで斜めに寝ている。踏み込んで蹴れば、大熊の顎の高さまで届く。

　足場は、もうある。作ったのではなく、倒しただけのものが。

　ウィンは拳ほどの石を拾い、意識を通した。角が伸び、薄く鋭い刃へ変わる。

　投擲ナイフなら手を加える必要もないが、あれは投げれば手元から消える。刃も柄も自分の持ち物である以上、失えばそれきりだった。借りた石なら、役目が済めば勝手に石へ戻る。

　柱の陰から身を起こし、大熊の鼻面へ投げつけた。分厚い苔も、鼻の頭までは覆いきれていない。

　ザッ、と石が狙い通りその一筋を裂く。獣が大きく仰け反り、悲鳴じみた唸りとともに顎が持ち上がって、口が開いた。

　ウィンは柱を蹴った。跳びながら、最後の目眩し玉を、開いたその口の目の前で叩き割る。

　パンッ、と白い霧が膨れ上がり、大熊の視界を丸ごと塗り潰す。咆哮が洞窟を揺らしたが、痛みによるものではない。何も見えなくなったことへの、ただの混乱だった。

　空いた手で短剣を抜き、意識するだけで長く鋭い穂先に変えた。同じ瞬間、鼻面に食い込んでいた刃が形を失い、ただの石になって落ちる。

　霧の中へ、覚えている場所へ、ウィンは全体重を乗せて切っ先を突き入れた。



　ズブッ、と根元まで入った。

　手応えが、腕の付け根まで一気に走る。あの日と同じ重さだった。骨の隙間に届いた感触が、そこにあったと教えてくれる。

　絶叫が霧を割いた。巨躯が大きくのけ反る。

　ウィンは弾かれるように後ろへ跳び、着地と同時に体勢を立て直した。

　二度、三度と痙攣した大熊は、やがて動きを止めた。苦痛に灼かれていた目から光が抜け、巨躯が粒子となって崩れていく。

```
『Lv11に上がりました』
```

　視界の隅に浮かんだ通知を、ウィンはぼんやり眺めていた。一つだけか、と思ってから、思い直す。あの大熊は、まだ出来上がっていなかったのだ。

　霧が薄れた床に、灰色がかった何かが落ちている。拾い上げると、視界に表示が開いた。

```
刻紋銘・苔纏いの手甲(こけまといのてこう)
分類:佳品(Cランク)

重ねた苔を鞣して編んだ、片手分の手甲。
```

　刻紋種を倒さなければ手に入らない印、刻紋銘。だが分類は、茜音から譲られた外套より一つ下だった。説明文もその一行きりで、何ができるものなのかは読み取れない。

　しかも片手分しかない。外套と当て革の上から着けて、据わりがいいとも思えなかった。

　倒した相手のクレストと相性のいいものが出やすい、という話は聞いたことがある。だとすれば、これは自分に合っているということなのだろうか。

　当たりなのか外れなのかすら、ウィンには判断がつかなかった。確かめる気にもならないまま、それをインベントリへ放り込む。



　息が整うまで、ウィンはその場に座り込んでいた。手のひらが、まだ細かく震えている。

　立ち上がって見回すと、通路を塞いだ柱と、砕けた瓦礫だけが残っていた。楔も、円盤も、刃も、どこにもない。意識を外した時点で、全部ただの石に戻っている。

　自分が組み上げたものの形は、何ひとつ残っていなかった。

　斜めに倒れた柱と天井の間には、体を横にすれば抜けられるだけの隙間がある。帰り道の心配だけは、しなくてよさそうだった。

　持ち帰るべきものは山ほどあったはずなのに、今の頭ではどれも形を結ばない。

　ウィンは崩れた石段に腰を下ろし、暗い天井を見上げた。

　――何だったんだ、あれは。

　答えの出ない問いだけが、静かな洞窟の中でいつまでも宙に浮いていた。
