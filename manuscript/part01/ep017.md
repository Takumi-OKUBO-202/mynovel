# 第十七話　誰が何を調べていたか

　現実では二日後の昼過ぎだった。バイトのない日を選んで、冬夜はヘッドギアを被った。

　視界が開けると、セイレスはよく晴れた朝だった。現実の時計とゲームの中の空はいつも噛み合っていないが、それにももう慣れてきている。

　待ち合わせの噴水のふちに、白に近い髪がすでに座っていた。

「おそーい」

「まだ約束の時間になってない」

　冬夜が言い返すと、茜音は「そういうことじゃないの」と笑って立ち上がった。

　呼び捨てで返すことにも、敬語を落とすことにも、まだ少しだけ据わりの悪さが残っている。二日経っても、口を開く前に一拍だけ考えてしまう。

　刻の図書館は、大通りから一本入った静かな一角にあった。

　石造りの二階建てで、看板には砂時計と本を組み合わせた意匠が彫られている。近くには露店も呼び込みもなく、通りの喧騒がここだけ一段引いていた。

「思ってたより、ふつうの建物だね」

「クランの持ち物らしいけど、看板に人数も強さも書いてないからな」

　両開きの扉は開け放たれていて、脇の板にひとこと「閲覧自由」とだけ書かれていた。冬夜は一度襟を正してから、中へ入った。

　中は思っていたよりずっと広かった。

　天井まで届く書架が壁沿いにぐるりと並び、中央に長机と椅子がいくつも据えられている。紙とインクの匂いまで律儀に再現されていて、話し声はほとんど聞こえない。

　長机には先客が四、五人。羊皮紙の束を積み上げて黙々と書き写している者もいれば、地図らしきものを広げて指でなぞっている者もいる。

「わあ……」

　茜音が小さく声を上げて、その場でくるりと一周した。声を潜めることは覚えているらしい。

「わたし、図書館って初めて。本ってこんなに並ぶんだ」

　入り口脇のカウンターに、一人だけ座っている人物がいた。冬夜の視界には、その人の名前の脇に小さく「刻の図書館」と表示されている。

　プレイヤー情報の所属クラン欄は、公開と非公開を自分で選べる。公開にしていれば、こうして名前の横にクラン名が並ぶ仕組みだった。

「ご利用は初めてですか」

　声をかけられて、冬夜は頷いた。

「はい。クラン員じゃないんですが、大丈夫ですか」

「もちろんです。閲覧は無料ですし、登録も要りません。書架のものはご自由にどうぞ」

　カウンターの人物は慣れた調子で続けた。持ち出しは禁止、その場での書き写しは自由。写しを取る紙が要るなら売ってくれるという。

「ただ、奥の部屋の書架だけは別です。原本しかない記録や、まだ整理の済んでいない報告が置いてあるので、うちの者が立ち会うのが決まりになっています」

「立ち会うというのは、どういうことですか」

「隣で見ています。それだけです。何をお探しかは伺いませんよ。うちはそういうところなんです」

　言い方に含みはなかった。誰が何のために来たかを詮索しない、というのがこのクランの気風らしい。

　好都合だ、と思いかけて、冬夜はすぐに思い直した。名簿を取らないということは、記録に残らないというだけの話でしかない。

　現に今、長机の先客たちは顔も上げないが、誰がどの棚の前に立って、どの束を抜いたかは、この静かな部屋の中では丸見えだった。

「モンスター関係の記録は、どのあたりですか」

　冬夜はそう尋ねてから、一拍おいて付け足した。

「あと、遺跡とか、古い建物の調査記録も見たいんですが」

「モンスターは右手の奥、遺構調査は二階です。目撃報告の綴りは年ごとに分けてありますので」

　礼を言って離れる。歩きながら、冬夜は自分の心臓がわずかに速いのを自覚していた。

　訊きたいことは一つに決まっている。刻紋種を仲間にした人間がいるかどうか、それだけだ。

　だが、それをそのまま口に出した瞬間、この街で唯一そんな質問をした人間として記憶される。あの目撃談が出回っている今なら、なおさらだ。

「ねえ、あの人に直接聞けば早くない? 刻紋種を仲間にした人っていますかって」

「言うな」

　冬夜は反射的に茜音の袖を引いて、書架の陰へ寄せた。

「今それを聞いたら、一発で覚えられる。掲示板に虎の話が出た直後に、そんなことを聞きに来た二人組だぞ」

「……あー」

　茜音が口を手で押さえた。素直に理解が早いのが、この人の助かるところだった。

「調べるものを一つに絞らない。刻紋種も、遺跡も、従魔も、ぜんぶ並べて漁る。そうすれば、何を知りたくて来たのか読めなくなる」

「なるほど。うろうろするのが正解なんだ」

「そういうこと」

　実際、冬夜は関係のない棚からも束を抜いた。地方の伝承、古い地名の由来、初期の街道整備の記録。

　長机に積み上げてしまえば、傍から見て何を追っているのかは分からない。手間はかかるが、手間をかけるくらいしか自分たちにできることはなかった。



　まず手をつけたのは、刻紋種そのものについての基礎的な記録だった。

　束の一枚目に、危険度の区分がまとめられている。討伐された記録と被害の規模から、後づけで整理された等級らしい。

```
刻紋種 危険度区分

第一級・地域級
　一つの狩場を荒らす規模。報告される刻紋種の大半がこれにあたる
第二級・都市級
　街ひとつの機能が止まるほどの被害を出す
第三級・天災級
　国の規模で被害が及ぶ。討伐の記録そのものが数えるほどしかない
```

「森閉ざしの灰狼、載ってる?」

「載ってる。第一級だ」

　冬夜は該当の行を指でなぞった。地域級。一つの狩場を荒らす程度、と書かれている。

　その一つの狩場を荒らす相手を、あの白い虎は息一つで凍らせた。ならばあれは何級に相当するのか——どの頁にも、その答えはない。

　落とすものについての記述も短かった。刻紋種の落とす装備には例外なく刻紋銘の刻印が入り、分類の高低に関わらず別格の扱いを受ける。それだけだ。

　冬夜は無意識に自分の外套の裾に触れて、すぐに手を離した。

　天災級の綴りは、驚くほど薄かった。この世界が始まってから今日までで、たった六件しかない。

```
刻紋種 討伐記録(第三級・天災級)

・アルディア／念喰らいの大百足(ねんぐらいのおおむかで) 二つ名「哭禍(こくか)」
　討伐者 ユイ=カネシロ 二つ名「無音の刃」 所属 白鞘
　ドロップ 刻紋銘・万念(ばんねん)〈刀〉
・ヴァルドレア／陽喰らいの大蛇(ひぐらいのおろち) 二つ名「蝕禍(しょっか)」
　討伐者 リィン=ハーヴ 二つ名「陽還し」 所属 銀嶺の楔
・トゥルガ／灰塗れの巨兵(はいまみれのきょへい) 二つ名「灰禍(かいか)」
　討伐者 グレン=オルド 二つ名「山断ち」 所属 鉄槌の門
・ラウゼリア／渇きの砂鯨(かわきのすなくじら) 二つ名「涸禍(こか)」
　討伐者 ドゥーン=サラフ 二つ名「井戸守り」 所属 金の轍
・セルフィナ／鈴鳴りの群蝗(すずなりのぐんこう) 二つ名「飢禍(きか)」
　討伐者 オルガ=レント 二つ名「実り返し」 所属 波紋の輪
・出現国の記載なし／無明の黒龍(むみょうのこくりゅう) 二つ名「静禍(せいか)」
　討伐者 ミナト 二つ名「形なき者」 所属 単独
```

「国、ばらばらだね。ぜんぶ違う」

「そうだな。特定の場所に出るわけじゃないらしい」

　六件のうち五件が、それぞれ別の国。冬夜が名前しか知らない国も混じっている。

　しばらく眺めていて、冬夜はもう一つのことに気づいた。刻紋種側の二つ名が、揃って同じ字を持っている。

「禍、って字。全部についてる」

「ほんとだ。こっか、しょっか、かいか……全部」

「天災級まで行った個体にだけ付ける決まりなんだろうな。名前を見た瞬間に、どの級かが分かる」

　哭禍、蝕禍、灰禍、涸禍、飢禍、静禍。読み上げていくと、それぞれが起こしたことの輪郭までうっすらと見えてくる。

　泣き声。日食。灰。渇き。飢え。そして——静けさ。

「二つ名って、討伐した人にも付いてるんだね。かっこいい」

「勝手につくものらしいぞ。自分で名乗るんじゃなくて、みんなが呼んでるうちに定着して、記録する側がそれを採用する」

「じゃあ、自分では選べないんだ。ちょっと怖いね」

　言われてみればそうだ、と冬夜は思った。呼ばれ方は他人が決める。噂と同じ構造をしている。

　一段目に目が留まった。アルディア。自分たちの国だ。

　念喰らいの大百足を斬ったのは、ユイ=カネシロという女性で、二つ名は「無音の刃」。落ちた刻紋銘は刀だった。

```
刻紋銘・万念(ばんねん)〈刀〉

・使い手の思念の強さに応じて、斬れ味が変化する
・数値による表示は行われない
```

「これ、強さが決まってないってこと?」

「持ち主次第、ってことなんだろうな」

　斬れ味が数字で出ない武器。強く念じれば応え、そうでなければただの鉄でしかない。刀を扱う人間が、刀に試されているようなものだ。

　自分の外套とはまるで方向性が違う。それでも、刻紋種の落とすものが持ち主を選ぶという点だけは、どこか通じている気がした。

　最後の一件だけが、少し違った。出現した国が書かれていない上に、討伐者の所属クランの欄に、ただ「単独」とだけある。

　他は全員がクランの名を背負っているのに、この一人だけが一人で名を残していた。物好きな人もいるものだ、と思って、冬夜は次の頁をめくった。



　二時間ほどが過ぎた。

　従魔の記録から分かったのは、掲示板で読んだ内容とほとんど同じだった。使役系のクレストの報告は数えるほどしかなく、いずれも小鳥や小動物の類。刻紋種を仲間にした例は、一件も載っていない。

「……やっぱり、前例ないね」

「ないな」

　これだけの記録を集めている場所で一件も出てこないなら、もう「まだ見つかっていない」のではない。存在しないと考えたほうが早い。

　空振りだと分かっていた調べ物で、本当に空振りを引き当てた。それでも確かめられたこと自体には意味がある、と冬夜は自分に言い聞かせた。

　遺構調査の綴りには、灰狼の森の奥についても数ページが割かれていた。石段と柱まで到達した記録はあるが、その先の洞窟に触れたものは見当たらない。

　門番の熊に阻まれて引き返した、という文言が何度も繰り返されている。

「あの熊、みんなの前でもちゃんと仕事してたんだね」

「してたな」

　冬夜が最後に手を伸ばしたのが、刻紋種の目撃報告の綴りだった。

　討伐報告、遭遇の状況、逃げ延びた者の証言。エリアごとに分けられ、報告された順に紙が綴じられている。

　数はさほど多くない。月に数件しか遭遇報告がない相手なのだから、当然といえば当然だった。

　束の古いほうを繰っていた指が、あるページで止まった。

```
刻紋種 目撃報告綴り(エリア別・報告順)
報告番号 一一四

・場所:森。詳しい位置の記載なし
・報告者:一名。同行者なし
・内容:木々の間に刻紋種がいた。前脚を鎖のようなもので繋がれ、
　　　　その場から動けずにいた。首のあたりに、紋章の入った石が見えた
・整理者注:同一地点の後続報告なし。再現の確認も取れていない。
　　　　　　刻紋種が繋がれていたとする記述は、本綴りの中で他に例がない。
　　　　　　信頼性は低いものとして扱い、参考記録として保存する
```

　紙の端を持つ指に、じわりと力が入った。

　冬夜は無言で綴りを横へ滑らせ、茜音に見せた。読み進める茜音の目が、途中で丸くなる。

「これ……」

「声、抑えて」

　冬夜は自分にも言い聞かせるように言った。心臓が勝手に速くなっている。

　あの洞窟の奥で、白虎の前脚を繋いでいた鎖。首元にあった、紋章の入った宝石。どちらも、この短い報告の中にそのまま書かれていた。

「あの子だけじゃなかったってこと?」

「……分からない」

　冬夜は慎重に首を振った。書かれているのは『森』の一語だけで、どの森かも分からない。報告者は一人きりで、裏を取った者もいない。

　整理した側もそう判断したから、信頼性は低いと注釈をつけて隅に置いている。この一枚を根拠に何かを言い切ることは、誰にもできなかった。

「ただ……他に例がない、って書いてあるだろ。これだけ報告を集めてる人たちが、そう書いてる」

「うん」

「つまり、俺たちが見たものは、この世界でほとんど誰も見たことがないものだったってことだ」

　言葉にしてみると、背中のあたりが冷えた。

　鎖に繋がれた刻紋種。これだけ報告を集めた綴りの中に一件しか残っていないものを、自分たちは先日この目で見ている。

　あの洞窟で起きていたことは、事故でも偶然でもない何かだったことになる。

　冬夜は綴りの後ろのほうも探した。紋章そのものについての整理もあった。位置も形も個体ごとに違うこと、討伐後に紋章だけが残った例はないこと。

　そして、紋章を失った刻紋種の報告は存在しないこと。

　茜音がそっと自分の手の甲を押さえたのが、視界の端に見えた。あの日、白虎の首から外れて消えた石のことを思い出しているのだろう。

「奥の書架、行ってみる?」

「やめておこう」

　冬夜は綴りを閉じた。

「拘束された刻紋種の記録を見せてくださいって、クラン員に立ち会われながら頼むことになる。今それをやるのは、看板を掲げて歩くのと変わらない」

「……たしかに」

「今日はここまでだ。持って帰れるものは持って帰った」

　書き写す紙は買わなかった。番号と文面くらいなら、覚えて帰れる。



　外へ出ると、日はすっかり高くなっていた。

　薄暗い書架の間に長くいたせいで、白い光が目に痛い。茜音が眩しそうに手をかざして、大きく伸びをした。

「あー、頭つかった。お腹すいた」

「まだ昼前だ」

「頭を使ったからでしょ」

　冬夜は苦笑して、外套の裾を軽く払った。石畳を踏む自分の足音は、相変わらず耳に届かない。

「すみません」

　声は、すぐ横からかかった。

　冬夜は思わず足を止めた。人が近づいてくる気配に、まるで気づいていなかった。

　振り向いた先に立っていたのは、中肉中背の男だった。落ち着いた色合いの外套に軽装。腰に提げているものも見当たらず、装飾らしい装飾もない。

　目を細めるような、柔らかい笑みを浮かべている。街ですれ違っても、三歩で忘れてしまいそうな顔立ちだった。

「刻紋種の棚のあたりに、長くいらっしゃいましたよね」

　背筋が、すっと冷たくなった。

　あの部屋にいた先客の顔は、一通り覚えている。長机に四、五人。そのどれとも、この男の顔は結びつかなかった。

　誰が何を調べていたかは丸見えだと、自分で気づいていたはずだった。それでも、この人物にだけは見られた覚えがない。

「……どちら様ですか」

　冬夜は丁寧語のまま、一歩だけ茜音の前に出た。

「失礼しました。名乗るのが先ですね」

　男はまったく気を悪くした様子もなく、軽く頭を下げた。

「要と申します」

　茜音が「かなめさん」と繰り返すのが聞こえた。冬夜のほうは、そこで一度、思考が止まっていた。

　どこかで見た名前だった。それも、ずいぶん前だ。

　夜会について書かれたものを読めば、必ずと言っていいほど同じ但し書きがついてくる。人数も所属者も公表されていない、と。そのうえで、たった一つだけ名指しで挙がる名前がある。

　いつ、どのスレッドで見たのかまでは思い出せない。それでも、夜会で唯一名前の割れている人物という一行だけが、妙に頭の隅に残っていた。

「常闇の夜会にいます」

　冬夜が口を開くより先に、要はそう言った。

　そして、こちらが疑う顔をするより早く、続けた。

「口で言っても信じられないでしょうから。疑うのが当然ですから、先にお見せしますね」

　視界の中で、目の前の男の名前の脇に、白い文字が浮かび上がった。

```
要
所属クラン:常闇の夜会

※本人の許可により、あなたにのみ表示されています
```

　冬夜は、その一行を二度読んだ。

　所属クラン欄の表示はシステムが出しているものだ。名乗りと違って、詐称のしようがない。

　夜会のメンバーは全員がこの欄を非公開にしている。だからこそ人数すら分からない、と掲示板には書かれていた。

　裏を返せば、閉じているはずの欄を開いて見せられる人間は、本物しかいないということでもある。

　名前だけは知っている。職業も、クレストも、どれだけ強いのかも、何一つ知らない。

　その空白の大きさが、目の前の穏やかな笑みの奥で、そのまま口を開けている気がした。

「……ええと」

　茜音が冬夜の袖を軽く引いた。夜会という名前の重さは、この人にも伝わっているらしい。

「僕は、探し物が昔から得意なだけの人間です。怖がらないでください」

　要は困ったように眉を下げて、それから思い出したように付け足した。

「冬夜さんと、茜音さんですよね」

　名乗っていない。

　冬夜の口の中が、わずかに乾いた。名前の非表示設定をしていない以上、見えていて当たり前ではある。当たり前のはずなのに、うまく飲み込めなかった。

「少しだけ、お時間をいただけませんか」

　要は道の端へ半歩寄って、通行の邪魔にならない位置に立った。

「取り立てて用があるわけではありません。ただの世間話です」

　用がないのに声をかける人間はいない、と冬夜は思った。

　そうは思ったが、その言葉をそのまま返すには、目の前の笑みはあまりに穏やかすぎた。
