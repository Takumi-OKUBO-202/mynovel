# 第十一話　四人目の誘い

　書店のバイトを終えて帰宅したのは、午後二時半を少し過ぎた頃だった。制服代わりのエプロンを畳んで鞄にしまい、母親に「ただいま」とだけ告げて自室にこもる。

　平積みの雑誌を運んだり、返本の伝票を整理したり。今日も特に代わり映えのしない、静かな数時間だった。

　悪くはないが、心が浮き立つような瞬間もない。そういう仕事だと分かった上で選んだアルバイトだ。

　汗を流し、遅めの昼食を軽く済ませてから、冬夜はヘッドギアに手を伸ばした。時刻は十五時。画面の隅の時計を一度だけ確認し、そのまま装着する。

　起動音が耳の奥で響き、意識がゆっくりと沈んでいく感覚があった。次に瞼を開けたときには、見慣れたセイレスの大通りが広がっていた。



　向かった先は、いつも通り冒険者ギルドの依頼掲示板だった。灰色狼の間引き、薬草の追加採取、猪型の討伐――張り出された紙をひとつずつ眺めながら、冬夜は今日の一件をどれにするか思案する。

　ふと、埒もない疑問が頭をよぎった。

　これだけ何もかもが精巧に作り込まれた世界なのに、なぜクエストを選ぶにはわざわざギルドまで足を運ばなければならないのだろう。家からでも一覧くらい見られてよさそうなものだが、律儀に石造りの建物まで来させる作りになっている。

　妙にリアルな仕様だ、と思いはするものの、深く考えるほどのことでもない。冬夜は肩をすくめ、また掲示板の紙に視線を戻した。

「ねえ、そこの人!」

　不意に声をかけられ、冬夜は紙から顔を上げた。

　声の主は、冬夜よりだいぶ背の低い女の子だった。白に近い色の長い髪が、歩くたびに揺れている。

　血色のいい頬に、屈託のない笑み。澄んだ目はまっすぐにこちらへ向けられている。

　装備は簡素なローブ姿で、お世辞にも戦闘向きとは言えない。それでいて物怖じする様子は微塵もなく、彼女は迷いのない足取りでずいと距離を詰めてきた。

「あの、俺……ですか」

「うん、きみ! さっきからずっと掲示板の前で悩んでたでしょ」

　覗き込むように顔を近づけられ、冬夜は思わず半歩下がる。人との距離感が、明らかに近い。

「見てただけですけど」

「装備、初心者っぽいなーって。あと、なんか怖い人には見えなかったし」

　値踏みされているのか褒められているのか判然としない評価に、冬夜は微妙な顔をした。

「わたし、茜音。今日ちょっと、パーティの人数が足りなくて困ってるんだよね」

　名乗った彼女――茜音(あかね)は、悪びれもせずそう続けた。ギルドの掲示板には「パーティ募集」の欄もあり、そこに登録すると近くにいる同じ帯のプレイヤーが候補として表示される仕組みらしい。

「いつもは友達と一緒にやってるんだけど、今日は都合が悪いみたいで」

「友達……多いんですね」

　思わずそんな言葉が漏れる。自分と違って、と続けそうになるのを冬夜はどうにか呑み込んだ。

「多いってほどでもないけど。でね、わたし前に出て戦う職業じゃないから、殴ってくれる人がいないと、正直ちょっと厳しくて」

「魔法職、ってことですか」

「まあ、そんな感じ。回復とか守りは得意なんだけどね、一人だと数の多い相手にすぐ押されちゃうんだ」

「で、俺なんですけど……」

「うん! きみ、冬夜くんだっけ。ちょうど良さそうだなーって」

　ギルド証に刻まれた名前を、いつの間にか覗き見られていたらしい。冬夜は一瞬言葉に詰まった。急に距離を詰められ、しかも初対面でここまで踏み込まれる展開に、正直なところついていけていない。

「初めて会ったばかりですし、俺そんなに強くもないですよ」

「立つ鳥跡を濁さず、って言うでしょ?」

「それ、たぶん関係ないです」

　冬夜は即座に突っ込んだが、茜音はまるで動じない。

「じゃあこっち。ヘレン・ケラーだっけ、偉い人が言ってたよ。『一人でできることはわずかでも、力を合わせれば驚くほど多くのことができる』って」

「その人の名前、あってます?」

「たぶん! とにかく、一人より二人のほうがいいってこと」

　押しの強さに気圧されつつも、冬夜は内心で少し考える。断る理由も、これといって見当たらない。掲示板の前で一人立ち尽くしていたのを見透かされたようで、気恥ずかしくはあったが。

　思えば、これまでパーティを組んだことは一度もなかった。誘われる当てもなかったし、自分から誰かを誘うという発想も特になかった。それが今、見ず知らずの相手にここまでまくし立てられて頷こうとしている――我ながら妙な話だ、と冬夜は思う。

「……分かりました。俺でよければ」

「よし、決まり!」

　茜音は満面の笑みでそう言うと、迷わずシステムメニューを操作した。直後、視界に見慣れない通知が浮かぶ。

```
『パーティを編成しました』
```

　これまで話にだけ聞いていた仕組みだった。パーティを組むと、互いの位置やおおまかな状態が視界の端に小さく表示されるようになるらしい。呼びかけも専用の通話に切り替わり、依頼の達成報告や報酬も、あとで人数分に振り分けられるのだと茜音が説明してくれた。

「はい、これでよろしくね、冬夜くん。こんな美少女と組めるんだから、感謝してよね」

「自分で言いますか、それ」

　冬夜は苦笑まじりに返したが、悪い気はしなかった。

「で、依頼なんだけどさ」

　茜音が指差したのは、掲示板の中でもやや大きめの依頼票だった。

　「灰狼の森・奥側の間引き」――猪型モンスターを三体、それに「角兎(つのうさぎ)」という見慣れない名の小型モンスターを五体討伐する内容だった。角兎については依頼票の欄外に、群れで行動する小型のモンスターだと一言だけ注記がある。詳しい戦い方までは書かれていない。

　報酬は六百ユン。一人でもどうにかなりそうな気はするが、正直、心もとない難度だ。猪型は勝手を知っているが、角兎は初めて聞く名前で、少し身構えてしまう。

「これ、わたし一人だと絶対無理なやつなんだよね。数が多いと、守りきれなくて」

「猪型はやったことありますけど、角兎は初めてです」

「わたしも! だから二人で行けば、ちょうどいい感じっしょ」

　受付でパーティ登録済みの依頼票を提示すると、係の職員は慣れた手つきで確認し、あっさりと受注を通してくれた。



　外に出ると、日差しはまだ高い位置にあった。灰狼の森までは、少し歩く距離がある。

「じゃ、行こっか」

　茜音が軽い足取りで先に歩き出す。冬夜はその背中を見ながら、まだどこか実感の伴わないまま、腰の短剣に触れて足を踏み出した。
