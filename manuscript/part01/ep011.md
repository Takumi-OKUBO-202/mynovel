# 第十一話　掲示板の前で

　書店のバイトを終えて家に着いたのは、午後二時半だった。台所にはラップのかかった皿が置いてあって、冬夜は誰もいない廊下に「ただいま」と一声かけてから、それを電子レンジに放り込む。

　平積みの雑誌を運んで、返本の伝票を整理して、あとはレジに立つ。今日も代わり映えのしない数時間だった。

　悪くはないが、心が浮き立つ瞬間もない。そういう仕事だと分かった上で選んだのだから、文句を言う筋合いでもなかった。

　遅い昼食を平らげてから、冬夜は自室へ上がった。時刻は十五時。机の脇に置いたヘッドギアを手に取り、そのまま頭に被せる。

　起動音が耳の奥で響き、意識がゆっくりと沈んでいく。次に瞼を開けたときには、見慣れたセイレスの大通りが目の前に広がっていた。



　向かった先は、いつも通り冒険者ギルドの依頼掲示板だった。灰色狼の間引き、薬草の追加採取、猪型の討伐――張り出された紙を端から眺めながら、冬夜は今日の一件を決めかねていた。

　受けられるのは自分のランク以下の依頼だけだ。冬夜はEランクのギルド証を手の中でひっくり返しながら、報酬と手間を見比べていく。

　ふと、埒もない疑問が頭をよぎった。

　これだけ何もかもが精巧に作り込まれた世界なのに、なぜクエストを選ぶのにわざわざギルドまで足を運ばなければならないのだろう。家から一覧くらい見られてよさそうなものを、律儀に石造りの建物まで来させる作りになっている。

　妙なところでリアルだ、とは思う。とはいえ、深く考えるほどのことでもない。冬夜は肩をすくめ、また掲示板へ視線を戻した。

「ねえ、そこの人!」

　不意に声をかけられて、冬夜は紙から顔を上げた。

　立っていたのは、冬夜より頭ひとつ分は背の低い女の子だった。白に近い色の長い髪が、動きに合わせてふわりと揺れる。

　血色のいい頬に、屈託のない笑み。澄んだ目がまっすぐこちらを向いている。装備は簡素なローブ姿で、お世辞にも戦闘向きとは言えない。背には、彼女の身の丈ほどもある細身の杖を一本、斜めに提げていた。柄の先には小さな水晶のような飾りがついていて、歩くたびにかすかに揺れている。

　それでいて物怖じする様子は微塵もなく、彼女は跳ねるような足取りでずいと距離を詰めてきた。

「……俺ですか」

「うん、きみ! さっきからそこ、全然動いてないでしょ」

　覗き込むように顔を近づけられ、冬夜は思わず半歩下がる。距離感が、明らかに近い。

「見てただけですけど」

「そうそう、それ! ずっと見てるだけで受けないから、暇なんだろうなーって」

「暇……まあ、否定はしないです」

　女の子は満足そうに頷くと、ローブの袖からギルド証を引っ張り出して掲げてみせた。刻まれたランクは、冬夜と同じE。

「わたし、茜音。あそこにパーティ募集出してるんだけど、全然埋まらなくてさ」

　茜音が顎で示したのは、掲示板の右端に設けられた一角だった。人を探しているプレイヤーが名前とランクを張り出しておく欄で、冬夜も存在だけは知っていたが、これまで一度も覗いたことはなかった。

「待ってるだけじゃ埒があかないから、直接声かけることにしたんだよね」

　言いながら、茜音は冬夜の手元をひょいと覗き込んだ。

「あ、その証、冬夜って書いてある。冬夜くんね、覚えた」

「勝手に読まないでください」

「名前くらいいいじゃん。これから一緒に行くんだし」

「まだ行くとは言ってないです」

　突っ込みは軽く聞き流された。茜音は唇を尖らせ、それから大げさに肩を落としてみせる。

「いつもは友達と組んでるんだけどさ、今日は都合が悪いって言われちゃって。別の子を誘っても、その日は先約がー、って」

「それは、災難でしたね」

「ほんとだよ。友達が多いのも考えものだよねー」

　愚痴なのか自慢なのか判然としない言い方に、冬夜は返す言葉を探して、結局黙った。

「でね。わたし、前に出て戦う職業じゃないんだよね。殴ってくれる人がいないと、正直きつくて」

「魔法職ってことですか」

「まあ、そんな感じ。回復とか守りは得意なんだけど、数で来られるとあっという間に押されちゃう」

　それは分かる。近づかれた時点で終わる相手が、群れで来る依頼を単独で受けるのは無謀だ。

「でも、俺そんなに強くないですよ」

「わたしよりは強いって。ね、いいでしょ? どうせ暇なんだし」

　あまりにとんとん拍子で、冬夜はふと勘繰りたくなる。初対面の相手が、こうもあっさり持ち上げてくるものだろうか。何か裏があるんじゃないか、変な勧誘やアイテムの売りつけに繋がるんじゃないか――そんな考えが一瞬だけ頭をかすめた。

　だが、すぐに馬鹿らしくなって打ち消す。金銭のやり取りが絡むわけでもない、しがないクエストの誘いだ。仮に厄介事だったとしても、パーティを解散すればそれで終わる話でしかない。

　押しの強さに気圧されつつ、冬夜は少しだけ考えた。断る理由は、探しても見当たらない。

　思えば、このゲームを始めてから誰かと組んだことは一度もなかった。誘われる当てもなかったし、自分から声をかけるという発想も、そもそも湧いてこなかった。

　それが今、会って三分も経たない相手にまくし立てられて、頷きかけている。我ながら妙な話だ、と冬夜は思う。

「……分かりました。俺でよければ」

「よし、決まり!」

　茜音は満面の笑みで頷くと、迷う素振りもなくシステムメニューを操作した。直後、視界に見慣れない通知が浮かぶ。

```
『パーティを編成しました』
```

　同時に、視界の左端に小さな表示が増えていた。「茜音」という名前と、その下に細い帯が一本。おそらく体力の残量を示すものだ。

　冬夜がそれを目で追っていると、茜音が横から指を差して教えてくれた。

「それ、パーティメンバーの体力ね。あと、離れてても声が届くようになるよ。報酬も終わったら勝手に人数分で分けてくれるし」

「便利ですね。……というか俺、パーティ組むの初めてなんですけど」

「えっ、初めて? じゃあわたしが記念すべき一人目だ。こんな美少女と組めるんだから、感謝してよね」

「自分で言いますか、それ」

　冬夜は苦笑したが、悪い気はしなかった。

「そもそも、なんで俺だったんですか。他にも人はいたでしょう」

「んー、装備がそんなにゴツくなかったから」

「それ、褒めてます?」

「褒めてる褒めてる。ゴツい人って強そうで話しかけづらいし。あと掲示板の前でずーっと悩んでたし、話しかけても斬られなさそうだったし」

「基準が低すぎませんか」

「大事だよ、そこは」

　真顔で言い切られ、冬夜はそれ以上突っ込むのをやめた。ちなみに腰の投擲ナイフはこの前買ったばかりの新品で、それなりの値段はしたのだが――言ったところで伝わる気はしなかった。

「で、依頼なんだけど。これとかどうかな」

　茜音が指差したのは、掲示板の中でもやや大きめの依頼票だった。

　「灰狼の森・奥側の間引き」――猪型モンスターを三体、それに角兎(つのうさぎ)という見慣れない名前の小型モンスターを五体、討伐する内容だ。

　角兎については依頼票の欄外に、群れで行動する小型のモンスター、と一言だけ注記がある。倒し方も弱点も書かれていない。

　報酬は六百ユン。討伐数が多い分、灰色狼の間引きよりはまとまった額だ。

　一人でも何とかならなくはない、という気はする。ただ、猪型は勝手を知っているが、角兎は初耳だ。群れ、という単語がどうにも引っかかる。

「猪型はやったことありますけど、角兎は初めてです」

「わたしも! だから二人ならちょうどいいっしょ」

「ちょうどいいの基準が、ずいぶんざっくりしてますね」

　軽口を返しつつ、冬夜はインベントリのウィンドウを開いた。傷薬(小)が二本、投擲ナイフ、自作の投げ道具、刃に塗るための毒。

　初めて戦う相手がいるなら、薬は多いに越したことはない。薬屋に寄って買い足すか――そう考えかけたところで、茜音があっさり言った。

「あ、回復ならわたしがやるよ。そういうの、得意だから」

「……じゃあ、二本で足りますね」

　受付でパーティを組んだ旨を伝え、依頼票を差し出す。職員は慣れた手つきで二人のギルド証を検分すると、Eランクのお二人ですね、と確認だけしてあっさり受注を通してくれた。



　ギルドを出ると、日はまだ高い位置にあった。灰狼の森までは、街道を少し歩く距離がある。

「じゃ、行こっか!」

　茜音が軽い足取りで先に立って歩き出す。歩幅は小さいくせに、やたらと速い。

　冬夜は腰の短剣に一度だけ触れ、その背中を追って足を踏み出した。実感はまだ伴わないままだったが、悪くない気分ではあった。
