# 第十一話　一人で狩るより

　書店のバイトを終えて家に着いたのは、午後二時半だった。台所にはラップのかかった皿が置いてあって、冬夜は誰もいない廊下に「ただいま」と一声かけてから、それを電子レンジに放り込む。

　平積みの雑誌を運んで、返本の伝票を整理して、あとはレジに立つ。本に囲まれた仕事は嫌いじゃない。大学に入ってすぐ始めて、かれこれ四ヶ月になる。

　遅い昼食を平らげて自室へ上がり、机の脇のヘッドギアをそのまま頭に被せる。

　起動音が耳の奥で響き、意識がゆっくりと沈んでいく。次に瞼を開けたときには、セイレスの大通りに立っていた。


　　　　◇


　向かった先は、いつも通り冒険者ギルドの依頼掲示板だった。並んでいる依頼の顔ぶれは、昨日と変わらない。

　ウィンはギルド証を手の中でひっくり返しながら、どれを受けるか決めかねていた。

「ねえ、そこの人!」

　不意に呼ばれて、ウィンは顔を上げた。

　立っていたのは、頭ひとつ背の低い女の子だった。白に近い長い髪がふわりと揺れて、大きな目がまっすぐこちらを見上げている。

　簡素なローブに、身の丈ほどもある細い杖。武骨な革鎧ばかりのギルドの中で、その一角だけ妙に華やいで見えた。

「……俺ですか」

「うん、きみ! さっきからそこ、全然動いてないでしょ」

「どれを受けるか、迷ってて」

「だよね。ずーっと難しい顔してたもん」

　彼女は物怖じする様子もなく、跳ねるような足取りでずいと距離を詰めてきた。

「まだ決めてないなら、ちょうどよかった! わたし、あそこにパーティ募集出してるんだけど、全然埋まらなくてさ」

　示された先は、掲示板の右端の一角だった。人を探しているプレイヤーが名前とランクを張り出しておく欄で、Eランクに上がったときに使えると言われたきり、ウィンは一度も覗いたことがなかった。

「待ってるだけじゃ埒があかないから、直接声をかけることにしたの。わたし、茜音。きみは――」

　視線がふっと、こちらの頭の上へ動く。

「――ウィンくん、ね。よろしく!」

　言って、茜音はローブの袖からギルド証を引っ張り出して掲げてみせた。刻まれたランクは、ウィンと同じEランク。

「いつもは友達と組んでるんだけど、今日はみんな用事があるんだって。夏休みって、案外みんな忙しいんだよね」

「それで、募集を」

「そう。でも、朝から誰も来なくて」

　茜音は大げさに肩を落としてから、すぐに顔を上げた。

「わたしね、魔法で戦う後衛なの。魔法は強いんだけど、撃つまでに溜めがいるから、一人だときついんだ。溜めてるあいだに懐へ入られたら、それでおしまい」

「なるほど」

「だから、前で動いてくれる人がいると全然違うの。それに――」

　茜音は杖を両手で抱えて、にっと笑った。

「一人で狩るより、誰かと一緒のほうが楽しいでしょ?」

「……俺、受け止める型の前衛じゃないですよ。避けて時間を稼ぐくらいなら、できますけど」

「充分充分! 時間さえ稼いでもらえれば、あとはわたしが撃つから」

　ウィンは少し考えた。

　誰かと組んで戦ったことは、まだ一度もない。一人の試行錯誤も楽しいが、二人でどうなるかは、二人でやってみないと分からない。

「……分かりました。俺でよければ」

「よし、決まり!」

　茜音がシステムメニューを操作すると、ウィンの視界に確認画面が浮かんだ。

```
茜音があなたをパーティに招待しています

承諾する / 断る
```

　「承諾する」に触れる。

```
『パーティを編成しました』
```

　視界の左端に、小さな表示が増えた。「茜音」という名前と、その下に細い帯が一本。おそらく体力の残量を示すものだ。

「報酬の分け方は設定で選べるから、等分にしておくね」

「便利ですね。……というか俺、パーティを組むこと自体が初めてなんですけど」

「じゃあわたしが記念すべき一人目だ。ふっふっふ、最初の相手がこんな美少女なんて、ウィンくんは運がいいなあ」

「自分で言いますか、それ」

「言うよー? 言ったもん勝ちだもん」

　言い切ってから自分で笑い出すので、ウィンも釣られて口元が緩んだ。

「そもそも、なんで俺だったんですか。他にも人はいたでしょう」

「んー、まず、装備がゴツくなかったから」

「装備、ですか」

「ゴツい人って、強そうだけど話しかけづらいんだもん。あとは、一人で掲示板の前にいたから、声をかけやすかった。それだけだよ?」

「そんなものですか」

「そんなものです」

　ちなみに腰の投擲ナイフは買ったばかりの新品で、それなりの値段はしたのだが――言ったところで伝わる気はしなかった。

「で、依頼なんだけど。これとかどうかな」

　茜音が指差したのは、掲示板の中でもやや大きめの依頼票だった。

　「灰狼の森・奥側の間引き」――猪型モンスターを三体、それに角兎(つのうさぎ)という小型モンスターを五体、討伐する内容だ。

　角兎については、群れで行動する、と短い注記があるだけだった。

　兎なら、西の野で嫌というほど狩った。だがあちらは逃げるだけの獣だ。こちらは名前からして角を持ち、しかも群れる。

　群れ、という一語に足が止まる。二匹に前後から来られたら捌ききれない――それが分かっているから、この手の依頼を一人で受けたことはない。

　ただ、今日は一人ではない。

「猪型はやったことありますけど、角兎は初めてです」

「奇遇だね、わたしも! じゃあ初めて同士、仲良く手探りだ」

「そういうものですか」

　受付でパーティを組んだ旨を伝え、依頼票を差し出す。職員は慣れた手つきで二人のギルド証を検分すると、Eランクのお二人ですね、と確認だけで受注を通してくれた。

　受注を済ませると、ウィンはインベントリを開いた。傷薬(小)が二本、投擲ナイフ、自作の投げ刃、それに毒が少し。

　初めての相手と当たる。傷薬を足して、刃の毒も塗り直しておきたい。

「支度があるので、少しだけ待ってもらえますか」

「オッケー! じゃ、準備できたら南門の前ね!」


　　　　◇


　薬屋で傷薬を二本足し、人気のない路地で刃に毒を塗り直してから、南門へ向かう。

　茜音はもう門の前にいて、こちらを見つけると大きく手を振った。

「こっちこっち!」

　門を抜けると、街道の両側に丘の緑が続いている。灰狼の森までは、しばらく歩く。

「じゃ、行こっか!」

　茜音が先に立って歩き出す。歩幅は小さいのに一歩ごとに弾んで、白い髪が跳ねる。今にも鼻歌が出そうな足取りだった。

　ウィンは腰の短剣に一度だけ触れ、その背中を追った。
