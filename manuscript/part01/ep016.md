# 第十六話　こんなもので騙されません

　翌朝、冬夜が目を覚ましたのは十時前だった。

　バイトは昼からだ。それまで少しログインしておこうと、冬夜はまず机のノートパソコンを開いた。

　昨夜はログインしたのが九時近くになってしまい、フレンド一覧の茜音の名前はすでに灰色に沈んでいた。深部の狼の話は伝えそびれたままだ。まあ今日でいいか、と思って寝たのが昨夜の話だった。

　刻紋種の総合スレッド、従魔のスレッドと昨日と同じ順に巡る。どちらも代わり映えはしない。

　最後に灰狼の森のまとめスレッドを開いて、指が止まった。昨夜は三百四十番台で止まっていたはずの書き込みが、四百近くまで伸びている。

```
【灰狼の森】エリア情報まとめスレ

352: 名無しの冒険者
昨日の昼、深部で変なもん見たんだけど聞いてくれる?
狼のほうがやられてた。でかい白い虎が、一発で凍らせた

356: 352
狼のほうには名前の表示が出てた
森閉ざしの灰狼、って書いてあった。あれ刻紋種だろ
虎のほうには何も出てなかったけどな。それをワンパンだぞワンパン

358: 352
で、虎の横に女の子が立ってた
ローブの、背の小さい子。虎が倒したあと普通に撫でてた

359: 名無しの冒険者
テイム系のクレストか? 小鳥を一羽出せるってやつの話は聞いたことあるけど、虎て

361: 352
信じなくていい。ただ深部には行くな。狼より虎のほうが怖かった
```

　背中のあたりが、すっと冷たくなっていく。ローブの、背の小さい子。心当たりが一人しかいない。

　しかも、あの人が昨日行ったというなら、それは自分が「深部は様子がおかしいらしい」と伝えそびれた、まさにその場所だ。

　嫌な予感がして、冬夜はセイレスの雑談スレッドを開いた。

```
【雑談】今日のセイレス 137スレ目

712: 名無しの冒険者
灰狼スレ読んだ?
刻紋種をワンパンする虎を従えた美少女がいるらしいぞ

713: 名無しの冒険者
情報が渋滞してる

714: 名無しの冒険者
どうせ夜会の誰かだろ。あそこなら何が出てきても驚かない
```

　一晩で、エリアのまとめスレから雑談スレへ流れ出している。話は移るたびに短く、覚えやすい形に削られていく。

　冬夜はノートパソコンを閉じ、ヘッドギアに手を伸ばした。昼からログインしよう、などと言っている場合ではなくなった。



　視界が開けると、セイレスは夕暮れどきだった。現実ではまだ午前中だが、この世界の空はいつも現実と噛み合っていない。

　冬夜はメニューを開き、フレンドの一覧から茜音の名前を選んだ。今度はちゃんと明るく灯っている。短い文を送ると、返事は数秒で返ってきた。

```
茜音:『いいよー。どこ行けばいい?』
```

　冬夜が指定したのは、ギルド裏手の細い路地だった。樽と木箱が積み上げられ、人通りは少ない。

　それでも街の中には違いないから、ここで白虎を呼び出すことはできない。人気のない場所限定、というのが二人で決めた取り決めだ。

　ほどなくして、路地の入り口から白に近い髪が覗いた。

「おまたせ。……なんか、怒られる気がしてるんだけど」

　いつも通りの調子で駆けてくる茜音を見て、冬夜は言うべき言葉を一度飲み込んだ。

「昨日、灰狼の森の深部に行きましたよね」

　茜音の足が、ぴたりと止まる。

「……なんで知ってるの」

「掲示板に出てます。虎が刻紋種を一撃で倒した、そばにローブの背の低い女の子が立っていた、と」

　茜音は目を丸くして、それからばつが悪そうに視線を落とした。木箱の縁を指でなぞりながら、しばらく黙っている。

「……見られてたのは、わかってたんだ。最後にログアウトしてった人がいたから」

「聞かせてもらえますか。何があったのか」

　茜音は素直に話した。あの子が本当はどれくらい強いのか確かめたくなったこと。開けた草地で本来の大きさに戻したら、それだけで魂力を根こそぎ持っていかれたこと。

　そこへ森閉ざしの灰狼が現れ、白虎の吐いた氷の息が、一呼吸で終わらせてしまったこと。

「ちゃんと見たんだよ。ぐるっと一周して、誰もいないの確かめてから出したの」

「はい。それは、そうだと思います」

　冬夜は頷いた。人気のない場所でしか呼び出さない、という取り決めを、この人は破ってはいない。

　そこを責めるのは筋が違う。問題は、もっと手前にあった。

「ただ……見回して誰もいなかったことは、誰にも見られない保証にはならないんです」

「え」

「森ですよ。木立で視界は遮られるし、街から歩いてくる人もいる。何より、あれだけ大きいものが出てきたら、気配だけで人も獣も寄ってきます」

　現に、真っ先に寄ってきたのが森閉ざしの灰狼だ。人間が一人紛れ込んでいたところで、何の不思議もない。

　茜音は反論しかけて、口を閉じた。

「……たしかに」

「怒ってるわけじゃないんです」

　冬夜は少し声を落とした。

「深部の狼の様子がおかしいって書き込み、昨日のうちに読んでたんですよ。伝えそびれました。俺が先に言っていれば、そもそも行かなかったかもしれません」

「刻紋種と鉢合わせたって聞いて、正直、そっちのほうが肝が冷えました。あの子がいなかったら、どうなってたか」

　茜音はしばらく黙ってから、へへ、と力なく笑った。

「怒られると思ってたのに、心配されると弱いんだけど」

　木箱に腰を下ろして、しばらく自分の靴の先を見ている。

「……軽率だったのは本当。ごめんね、冬夜くん」

　茜音はぴょんと立ち上がって、きちんと頭を下げた。取り繕わずに謝るところだけは、いつも早い。



「あ、そうだ」

　顔を上げた茜音が、思い出したように手を叩いた。

「謝るだけっていうのも、なんかね。これ、あげる」

　インベントリから取り出した深い灰色の布が、両手で差し出される。薄手の外套だった。

「あの狼を倒したときに出たの。ほら、刻紋銘ってやつ」

「……機嫌を取ろうとしてませんか」

「してるけど?」

　あまりに堂々としているので、かえって毒気を抜かれる。冬夜は腕を組んで、わざとらしく首を横に振った。

「こんなもので騙されませんよ」

「えー」

「そもそも話をすり替えないでください。今しているのは、これからどうするかっていう——」

　言いながら、視界の端に浮かんだ表示に、冬夜の目が吸い寄せられた。

```
刻紋銘・森閉ざしの外套(もりとざしのがいとう)
分類:逸品(Bランク)

・気配と足音を大きく抑える
・隠密行動の精度を上げる
・軽く、身のこなしを妨げない
・防御力はほとんど期待できない

装備条件:なし
```

　冬夜の言葉が、そこで途切れた。

　暗器使いのために誂えたと言われても、信じてしまいそうな並びだった。

　防御力がないという一点すら、避けることに全部を振ってきた自分の組み立てと綺麗に噛み合っている。

「今ちょっと揺れたでしょ」

　茜音が身を乗り出して、にやにやと覗き込んでくる。

「揺れてません」

　咳払いを一つして、冬夜はどうにか話を戻す。

「……本気で言ってます? これ、刻紋種を倒さないと出ないやつですよ」

「うん、そうだね」

「掲示板でも刻紋銘は別格扱いです。市場に流れたら、値段のつけようがないと思いますよ」

　冬夜は自分の財布の中身を思い浮かべた。その物差しでは、この外套はまるで測れない。

「売ったほうがいいですよ。それだけで、しばらく何も考えずに装備を揃えられます」

「売ったら、誰が持ってたか分かっちゃうんじゃない?」

　茜音の一言に、冬夜は口をつぐんだ。売るという選択肢は、最初から潰れている。

「……渡すのは、大丈夫なんですか」

「誰が誰に渡したかって、外からは見えないようになってるって。だからこれは平気」

　冬夜はもう一度、差し出された外套を見た。それから、真顔で言った。

「本当にいいんですか」

　軽口の続きではないと、声の調子で伝わったのだろう。茜音がまばたきをする。

「これ、茜音さんが自分の力で手に入れたものです。俺は隣にいたわけでもありません。仲直りの品にするには、高すぎます」

　茜音は少しの間、何か考えるように外套を見下ろしていた。

「あのね。わたしが持ってても、たぶん一生使わないんだよ、これ」

　顔を上げた茜音は、いつもの調子に戻っていた。

「わたし、後ろで杖振って光を撃つ人だもん。技名も声に出さなきゃいけないし。そんな人が足音消したって、なんの意味もないでしょ」

「使える人が使ったほうが、この子だってうれしいと思うんだよね。……あと、半分くらいはごめんなさいの気持ち。両方ってことでいいでしょ」

　冬夜は少し考えて、それから素直に頭を下げた。

「……ありがとうございます。大事に使います」

「そうそう、最初からそう言えばいいの」

　茜音が外套を押しつけてくる。受け取ろうとしたところで、視界に小さな確認が浮かんだ。

```
茜音から『刻紋銘・森閉ざしの外套』を受け取りますか?

はい / いいえ
```

　押しつけや事故を防ぐため、渡す側と受け取る側の両方が承諾しないと成立しない仕組みらしい。冬夜は「はい」を選び、外套を肩に羽織った。

　重さはほとんど感じない。試しに二、三歩歩いてみて、冬夜は思わず足を止めた。石畳を踏んでいるはずの自分の足音が、耳に届いていなかった。

「うわ、ほんとに消えた」

「でしょ。びっくりするよね」

　得意げに笑ってから、茜音はふと思い出したように首を傾げた。

「そういえばさっき、茜音さんって言った?」

「……言いましたけど」

　冬夜は少し身構えた。馴れ馴れしかっただろうか、という考えが先に立つ。

「呼び捨てでよくない?」

　あまりにあっさりした申し出だった。

「いや、それは」

「あと敬語もいらないよ。ずっと思ってたんだけど、わたしだけタメ口なの、なんか一人だけ距離詰めてるみたいで落ち着かないんだもん」

　言われてみれば、こちらは最初から丁寧語で通していた。年上か年下かも知らないまま、失礼のない側に倒し続けていただけだ。

「じゃあ練習。はい、わたしのこと呼んでみて」

　両手を腰に当てて、茜音が待っている。逃げ道がなさそうだった。

「……茜音」

「はい、よくできました」

　自分で言わせておきながら、茜音は嬉しそうに笑った。冬夜は据わりの悪さに耳の後ろを掻く。



　外套の裾を確かめてから、冬夜は改めて本題に戻した。

「あの書き込み、まだ何も特定されてない。あの子が元は刻紋種だった、なんて話は、どこにも出てない」

　虎の名前も書かれていなかった。テイムされた個体には、あの表示が出ないのだろう。

「よかった……」

　茜音の肩から力が抜けるのが分かった。

「そもそも刻紋種は、見つけたら討伐するもので、それ以外の選択肢がないと思われてる。だから誰も、そういう発想自体をしない」

「じゃあ、まだ大丈夫ってこと?」

「まだ、な。名前まで書かれる日は、いつか来ると思っておいたほうがいい。今回は運がよかっただけだから」

「……うん」



　石畳に落ちる夕日の色が、少しずつ濃くなっていく。

　冬夜は外套の襟を整えながら、頭の中を組み直していた。昨日まで、自分たちは秘密を隠し通すつもりだった。誰にも知られなければそれでいい、と。

　だが、噂はもう出てしまった。一度書かれた文字は消せないし、消そうとして書き込めば、それこそ火に油になる。

「方針、変えないか」

「変える?」

「隠し通すのは、もう無理だと思う。噂は出てしまったから」

　茜音の顔がわずかに曇るのを見て、冬夜は続けた。

「でも、噂が出たこと自体は、そう悪いことでもないと思うんだ。世の中に『そういう話がある』っていう状態が先にできてしまえば、あとは俺たちがその噂と結びつかないように動けばいい」

「あー……なるほど。なかったことにするんじゃなくて、他人事にするんだ」

「そういうこと」

　冬夜は思いつく限りを並べた。しばらく深部には近づかない。本来の大きさで呼ぶのはどうしようもないときだけにする。

　噂話が出たら、隠れずに普通に驚いておく。妙に避けるほうが、かえって覚えられてしまう。

「なんか、悪だくみみたいで楽しくなってきた」

「楽しむな」

　言いながら、冬夜自身も少し気が楽になっているのを感じていた。隠し通すという不可能な目標を下ろしたぶん、やるべきことがはっきりしている。

「掲示板は、たぶんこれ以上使えない。書けば目立つし、読むだけじゃ何も出てこない」

「じゃあ、どうする?」

「人が集めた記録を当たろうと思う」

　冬夜は、以前ギルドの掲示板前で耳にした噂話を思い出していた。森奥の遺跡を調べているクランがある、というあの話だ。

「刻の図書館、って名前のクランがあるらしいんだ。歴史とか過去の記録を集めてるところで、セイレスに資料館を構えてるとか」

「クランなのに、図書館なんだ」

「クラン員じゃなくても、大体の資料は見せてもらえるらしい。刻紋種の目撃記録も置いてあるとか」

　テイムの前例。刻紋種の記録。そして、あの洞窟で白虎の脚を繋いでいた鎖——誰が、何のために、という問い。掲示板で手に入らなかったものが、そこにあるかもしれない。

「行ってみよう。近いうちに」

「うん、行く行く。図書館って、わたし、入ったことないんだよね」

　茜音が嬉しそうに身を乗り出す。彼女にとっては、調べ物ですら初めての遠足になるらしい。

　冬夜は苦笑して、それから路地の外へ視線を向けた。夕暮れの大通りを、名前も知らないプレイヤーたちが歩いていく。

　あの中の何人が、もう例の噂を聞いているのだろうか。
