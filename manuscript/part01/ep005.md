# 第五話　始まりの街

　光が引いていく。

　代わりに広がったのは、見上げるほど高い石造りの建物と、澄み渡った青空だった。

　ウィンは思わず息を呑んだ。

　風が吹いている。頬に当たる空気には、確かな温度がある。石畳を踏む足の裏には、重みと硬さがしっかりと伝わってくる。どこかから漂う、パンでも焼いているような香ばしい匂い。

　画面越しに眺めていたはずの景色が、今は自分を包み込む「その場所」そのものになっていた。

　――これが、フルダイブ。

　想像していたよりも、ずっと生々しい。現実の自分は今、ベッドの上で眠っているだけのはずなのに、そんなことはとても信じられなかった。



　ウィンが立っていたのは、広々とした石畳の広場だった。

　中央には大きな噴水があり、水しぶきが陽の光を受けてきらきらと輝いている。広場を囲む建物はどれも石造りで、遠くには塔のように高い建物や、山際に霞む城らしき影も見えた。

　その噴水の周りに、同じように呆然と立ち尽くす人影がいくつも見えた。おそらく自分と同じ、たった今フルダイブしてきたばかりの新規プレイヤーたちだろう。

　誰かが自分の手のひらを眺めながら「うわ、マジで手ある……」と呟いているのが聞こえる。誰もが似たような反応をしていることに、ウィンは少しだけ安心した。



　視界の端に、半透明の案内表示が浮かんでいる。

　触れてみると、地図やクエスト一覧、パーティ機能など、簡単な説明が順番に表示された。中に「初めての方は、まず冒険者ギルドでクエストを受注しましょう」という一文があり、地図上には近くのギルドの場所が淡く光って示されている。

　「国情報」という項目も目に留まり、何気なく開いてみる。

『アルディア――列強の一角に数えられる国。出自よりも実力がものを言う「自由の国」。北方の大国ヴァルドレアとは長らく緊張関係にあり、国境付近では小規模な小競り合いが絶えない。先王の崩御に伴い、若い王子が新たに王位に就いた。

首都セイレスは政治の中心であり、国内最大の交易地でもある。沿岸の港町マレイアは、海路で他国と結ぶ貿易の拠点。ほかにも、それぞれ違う産業と気風を持つ都市が国内にいくつかある』

　列強、王位交代、緊張関係、という物々しい単語が並んでいるわりに、どこか他人事のように読めてしまう。今の自分には、まだ実感の持ちようがなかった。

　ついでに、自分の状況も確認しておくことにする。ステータス画面を開くと、思っていたよりずっと簡素な一覧が浮かんだ。

```
ウィン
Lv1(第一段階)
職業:暗器使い
ソウルクレスト:彼は誰(かはたれ)

スキル:投擲、隠密行動、生成(暗器)、調合(毒)
```

　「第一段階」という表示にも見覚えがあった。事前に読んだガイドにあった、あの段階制の話だ。レベルが上がるごとに段階が進み、そのたびに上限そのものが引き上げられていく――今の自分は、その一番下にいる。

　投擲や隠密行動に混じって、生成(暗器)、調合(毒)という文字まで並んでいる。武器を作り、毒を仕込むところまでが自分の受け持ちに入っている。戦う前に手先の作業が並んでいるのが、なんだかおかしかった。

　クレストの欄には、名前だけがぽつんと表示され、効果の説明は空欄のままだった。



　噴水のそばでは、案内役らしき制服姿の人物が、数人の新規プレイヤーに何かを説明していた。

「困ったことがあれば、いつでも声をかけてくださいね」

　その口調や間の取り方が、思いのほか人間くさい。他のVRMMOのNPCは決まりきった台詞を繰り返すだけだと友人から聞いていたが、ここではまるで勝手が違う。

　ウィンはその輪には加わらず、少し離れたところから景色を眺めるだけに留めた。



　広場を囲むように、露店がいくつも並んでいた。

　武器や薬草の束を並べている店もあれば、串に刺した肉を炙っている店もある。香ばしい匂いに、腹の虫が小さく鳴る。

　所持金はそう多くない。装備に回すことを考えれば、我慢するのが賢明だろう。頭ではそう分かっていたが、足は気づけば屋台の前で止まっていた。

「一本、ください」

「はいよ、まいど」

　あっさりと注文が通ってしまい、ウィンは自分でも少し驚く。串を受け取りながら、値札に並んでいた見慣れない単位を、あらためて目でなぞった。

　手持ちから引かれた分は、この程度の贅沢なら許容範囲だと思える額だった。

　肉は少し硬かったが、香辛料の効いた味付けは悪くなかった。現実の食べ物と何ら変わらない歯応えに、ウィンはまた小さく驚かされる。



　少し離れた場所では、露店の店主が手のひらの上に小さな炎を灯し、くるくると形を変えて客に見せていた。

　あれがクレストなのか、職業のスキルなのかは、ウィンには分からない。ただ、こういうものが、この街には当たり前に転がっている。

　ウィンは自分の右手を見下ろす。さっきまで紋様が浮かんでいたはずの場所には、もう何の跡形もない。

　この手の中に、まだ得体の知れない力が眠っているとは、正直あまりぴんとこなかった。街に降り立ってからというもの、頭の隅に何かがすとんと収まったような感覚が続いていたが、次々に押し寄せる物珍しさに紛れて、ウィンはそれをさして気にも留めなかった。


　　　　◇


　地図の案内に従って、冒険者ギルドのある方角へ歩き出す。途中の通りには、武具屋や薬屋も並んでいた。

　まずは武具屋に立ち寄り、初心者向けに用意されていた短剣を二本購入する。腰の後ろの鞘に差してみると、寸法はあつらえたように収まった。

　棚の奥には投擲用のナイフも並んでいて、袖の内側の留め具にちょうど嵌まりそうな細さだった。値札を見て、素直に諦める。

　いつか買えるようになったら、と胸の内にだけ留めておく。

　すぐ隣の薬屋も覗いてみる。並んでいる小瓶には「傷薬(小)」「解毒薬」といったラベルが貼られている。これから外に出るなら、一つも持たずに行くのはさすがに心もとない。

　ウィンは傷薬を二本買い足した。二つの店を回り終えた頃には、手元はほとんど空になっていた。


　装備を整えたところで、ようやく冒険者ギルドに到着した。遠目にもわかるほど大きな石造りの建物で、正面には剣と羽根を組み合わせたような紋章の看板が掲げられ、「冒険者ギルド」という文字がその下に添えられている。

　中に入ると、外観以上の広さに驚かされる。壁一面に依頼の紙を張り出した掲示板があり、奥には受付のカウンターがいくつも並んでいた。カウンターの脇には「素材買取」「依頼達成報告」と書かれた別口の窓口もあり、行き交う人の多さに、ちょっとした役所のような賑わいがある。

　何より目を引いたのは、そこにいるプレイヤーたちの佇まいだった。大剣を無造作に背負った大柄な男、全身を漆黒の装備で固めた集団、談笑しながらも隙のない足運びをする女性。すれ違いざまにこちらへ向けられる視線は、一瞬でこちらを値踏みし終えたように鋭く、ウィンは思わず目を逸らしてしまった。



　カウンターの前に立つと、係の女性がにこやかに声をかけてきた。

「ご新規の方ですね。まずは登録から行いましょうか」

　クエストはギルドの掲示板に貼ってあるものを、誰でも自由に受けられるわけではなかった。まず正式にギルドへ登録し、身分を証明する「ギルド証」を発行してもらう必要があるという。手のひらをカウンターの水晶にかざすと、光がひとつ瞬き、それだけで手続きは終わった。

　現れたギルド証には、名前と一緒に「Fランク」という文字が刻まれている。

「ランクは依頼の難易度に対応していて、実績を積むごとに上がっていきます。今のFランクだと、受けられるのはこのあたりの依頼までですね」

　案内された掲示板の一角には、確かに「Fランク」と書かれた紙ばかりが集まっていた。「街の周辺で薬草を集める」「案内所への届け物」「郊外に出る小型モンスターの間引き」。地味な内容ばかりだが、これが今の自分に見合った範囲ということだ。

「依頼を終えたら、さっきの達成報告の窓口に戻ってきてくださいね」



　すぐそばで、少し年季の入った様子のプレイヤーが、新規らしい二人組に声をかけていた。

「街の北側には、まだ行かないほうがいいよ。刻紋種が出たって話があってさ。慣れてないうちに近づくもんじゃない」

　刻紋種――ガイドで読んだ、あの特殊個体のことだろう。専用の名前と強力なドロップを持つ代わりに、危険度も相応に高いという注意書きがあったのを思い出す。実際に街のすぐ近くまで来ているとなると、ただの読み物では済まされない現実味があった。

　詳しい説明を聞く間もなく、その場を離れていってしまったが、初心者が下手に近づくべきではない何かがいる、ということだけは改めて伝わってくる。

　迷った末、ウィンは一番地味に見える「薬草集め」の紙に指をかけた。

　剥がして受付に出すと、ギルド証の表面に、依頼の名前が細い一行になって浮かび上がる。

　街の外で薬草を摘む。それだけの仕事だ。あの映像に映っていたものからは、どこまでも遠い。

　それでも、さっき目を逸らした大剣の男も、漆黒の装備の集団も、最初はこの一角の紙を剥がしていたはずだ。

　ウィンはギルド証をしまい、外へ続く扉のほうへ歩き出した。
