# 第二十八話　夏の終わりが見えてくる

　素材買取の窓口に、深部で溜めた牙と毛皮をまとめて出した。

　差し出された袋は、思っていたより軽い。返ってくるものの重さは、数をこなした実感とは比例しない。

　それでも足りなければ、依頼の報酬を足すしかない。ウィンはギルドを出て、広場脇の武具屋へ向かった。

　台に並べた二本の短剣を、店主はひっくり返して刃元を覗き込んだ。

「よく使ったな。ここまで刃こぼれしてると、研いでも戻らん」

「無茶な使い方をしました」

「何をどうしたらこうなる。……まあいい」

　店主は奥の棚から布に巻いた一組を持ってきて、台の上で開いた。

　同じ形をしている。同じ長さで、同じ反りだ。それなのに、置かれた瞬間の音が、こちらのほうが低い。

「佳品だ。一つ上になる。鋼から違うぞ。値も違うがな」

　ウィンは袋の中身と、値札を交互に見た。手が届くかどうかの瀬戸際で、届かせるには依頼の報酬を全部積むしかない。

　貯めておく理由を探そうとして、一つも見つからなかった。

「これ、ください」

　防具屋には、肩の裂けた上着を持ち込んだ。縫い直すより作り直したほうが早いと言われ、素直に頷く。

　あわせて、奥側で余分に溜めておいた霞蜘蛛の硬毛を袋ごと預けた。当て革をもう一枚ぶん厚く編み直し、肩から鎖骨のあたりまで覆えるようにしてほしい、と頼む。

「明日の朝に取りに来い。それより早くはならん」

　一晩なら構わない。

　店を回り終えるころには、財布はほとんど残っていない。

　その代わり、腰にかかる重みが変わった。街の外れで新しい刃を抜き、試しに槍状へ伸ばしてみた。

　前の短剣で同じことをすると、突いた瞬間にわずかな撓みがあった。形は槍でも、中身は初心者向けの鋼のままだったからだ。

　借りたものは、形だけが変わって、素材はそのまま残る。自分の得物でも同じことだった。

　新しい刃は、撓まない。

　――なるほど。

　装備で埋める、というのはこういうことかと、ウィンはようやく腑に落ちた。

　書店には、その足で二日ぶんの代わりを頼みに行った。融通の利く店で、店長は「学生は夏くらい遊べ」と笑っただけだった。

　空いた二日を、冬夜は一つも埋めずに残す。



　その日は、日が落ちるまで深部に籠もった。

　やることは前と変わらない。変わったのは、組み立てを考える時間が要らなくなったことだ。斜面を見れば誘い込む場所が決まり、坂を塞ぐのに借りるものも迷わない。

　向こうの空が二度暗くなり、二度明るくなった。

　途中から、通知の音を数えるのをやめた。ログアウトする前にレベルだけ確かめると、朝より七つ動いている。

　同じ狩場だ。同じ相手だ。それでも、時間を丸ごと注ぎ込めば返ってくるものが違う。

```
『Lv22に上がりました』
```

　翌朝、当て革を受け取った。明らかに一枚ぶん重くなっている。

　上着の下で紐を締めてみる。肩から鎖骨までを覆っても、腕を回して引っかからない。動きを殺さない範囲で、ぎりぎりまで詰めてくれたのだと分かる。

　その足でギルドへ寄り、昨日ぶんの依頼をまとめて報告した。受付は書類の厚みを見てから、ウィンのギルド証を端末にかざした。

　戻ってきた手には、見覚えのあるギルド証があった。刻まれた文字が、Eから一つ変わっている。

「Dです。おめでとうございます」

「……あの、間違いではありませんか」

「昨日の分だけでも数が揃っていますし、ここ最近の頻度が異常なんですよ」

　受付は淡々と続けた。ランクが上がれば、受けられる依頼の上限も一つ上がる。遠出のもの、危険度の高いもの、これまで掲示板の上のほうに貼られていて手が出せなかったものが、まとめて選べるようになるらしい。

　ウィンはギルド証を受け取り、もう一度掲示板の前に立った。

　見える紙の枚数が、まるで違う。

　そこからは、狩場を移した。

　東の街道沿いに出る依頼を受け、荷馬車を襲う獣を間引く。北へ二日歩いた岩場では、灰色狼より二回り大きい四足の獣が群れを作っていた。

　どれも、森の深部より一段上だ。まともに受ければ立っていられない。

　だから受けない。街道では荷馬車の轅を借りて柵に変え、逃げ道ごと道を細くする。岩場では、こちらの立つ場所を先に決めてから当たる。

　深部で使った手が、そのまま一段大きくなっただけだ。

　深部の狼を何十頭とかけて上がったぶんが、この岩場では一群れで返ってくる。

　フレンド一覧の茜音の名前は、灰色のままだった。それでも、こちらが潜っている間に短い文だけは届いている。

```
茜音:『生きてる?』
ウィン:『生きてる』
茜音:『よかった』
```

　依頼書に「岩喰みの角熊」と書かれた個体だけは、半日かかった。

　名前のとおり、肩から背にかけての皮が石を貼ったように白い。投げたナイフが、カッ、と乾いた音を立てて滑る。

　二本目は角に当たって、キンッ、と高く跳ねた。刃の数をいくら足しても、この皮の内側までは届かない。

　だから、削るのをやめた。

　崖の縁のほうへ、少しずつ追い上げる。正面には立たず、回り込まれる前に、嫌なほうへ一歩ぶんだけ動く。

　角が来る。ガッ、と岩壁が抉れて、砕けた欠片が頬を打った。

　躱しながら、縁の岩に意識を通す。厚みだけを、指で薄く削ぐように抜いていく。

　前脚が乗った。

　ズンッ、と縁が落ちる。

　巨体が空を掻いた一瞬、腹が上を向いた。石を貼っていないのは、そこだけだ。

　ドッ、と喉の下へ刃を入れる。崖下まで落ちきる前に、光が抜けた。

　レベルは動いたが、硬いものを正面から割る手は、ひとつも増えていない。増えたのは、正面に立たずに済ませる手のほうだ。

```
『Lv24に上がりました』
『スキル「連ね投げ」を習得しました』
```

　連ね投げ。刃を一本ずつ投げていては削りきれない相手が続いたので、二本目を抜く手が勝手に早くなっていた。それを見られていたらしい。

　試しに立て続けに放ってみると、二本目が一本目の落ち際に追いつく。狙いは甘くなるが、当てるべき場所が広い相手なら、この甘さは問題にならない。

　覚えたぶん、受けられる相手がまた一つ増えた。

　この日も、向こうの空は二度暗くなった。二日目が終わる頃には、通知が鳴っても手を止めなくなっている。

```
『Lv30に上がりました』
```

　ウィンは岩場の縁に腰を下ろして、久しぶりにステータス画面を開いた。

```
ウィン
Lv30
職業:暗器使い
ソウルクレスト:彼は誰(かはたれ)

スキル:投擲、隠密行動、生成(暗器)、調合(毒)、急所看破、会心の一撃、精密投擲、見切り、連ね投げ
```

　欄の末尾に、二つ増えていた。

　どちらも、意識して取りにいったものではない。避け続けた結果と、投げ続けた結果が、そのまま名前になって並んでいる。

　九つ並んだそれを見て、ウィンが思い浮かべたのは数の多さではなく、この組み合わせで何ができるかという心当たりだった。



　二日ぶりにレジへ入った日の、夕方六時過ぎだった。西尾が参考書を二冊、無造作にカウンターへ置く。

　冬夜が顔を上げて、そこで初めて目が合った。

「あ。お前ここだったのか」

「西尾さん。……いらっしゃいませ」

「いらっしゃいませって」

　西尾は笑って、財布を出しながらカウンターに肘をついた。

「後期の必修、これ買っとけって言われてさ。履修登録、もう始まってんぞ」

　手が止まりかけて、冬夜はバーコードを読み直す。

「……そうでしたか」

「そうだよ。まだ出してないだろ」

「まだです」

「一年は締切に気をつけろよ。あれ落とすと後がだるい」

　袋に入れて渡すと、西尾は受け取って、思い出したように付け足した。

「そういやゲーム、続けてる?」

「続けてます」

「俺は最近ちょっと落ちてんだよな。二十そこそこで止まってる。そっちは?」

　冬夜は少し迷ってから、正直に答えた。

「三十です」

　西尾の眉が上がった。袋を持ったまま、しばらく黙っている。

「……夏の間だけでそれか」

「時間はありましたから」

「時間だけなら、みんな持ってんだけどな」

　西尾はそう言って、また来る、と軽く手を上げて出ていった。自動ドアが閉まって、店内の音が戻ってくる。

　シフトを削ったぶん、閉店を待たずに上がれる。冬夜はレジ横の棚を直しながら、さっきのやり取りを頭の中で巻き戻していた。

　帰り道の空は、もう暗くなりかけていた。少し前まで、この時間はまだ明るかった。

　夏休みは、いつの間にか折り返しを過ぎていた。終わりが、初めて具体的な日付として見えた気がする。

　この夏、現実で決めたことが一つでもあるかと考えて、冬夜は何も思い出せなかった。履修も、サークルも、来年の話も、一つ残らず先送りにしてある。シフトを二日空けるのだけは、何のためらいもなく決めたのに。

　この夏で変わったのは、本気になれる場所が一つだけ見つかってしまったことだ。

　そしてそれは、この世界のどこにもない。



　夕食を済ませてログインすると、セイレスの広場には昼の光が落ちていた。

　視界の端で、小さな表示が明滅している。

　フレンド一覧の名前が、灰色から明るい色へ変わっていた。

```
茜音:『ウィンくん、久しぶり! ちょっと相談があるんだけど、いま平気?』
```
