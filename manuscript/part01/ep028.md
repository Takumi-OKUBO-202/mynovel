# 第二十八話　夏の終わりが見えてくる

　素材買取の窓口に、深部で溜めた牙と毛皮をまとめて出した。

　差し出された袋は、思っていたより軽い。返ってくるものの重さは、数をこなした実感とは比例しない。

　それでも足りなければ、依頼の報酬を足すしかない。冬夜はギルドを出て、広場脇の武具屋へ向かった。

　台に並べた二本の短剣を、店主はひっくり返して刃元を覗き込んだ。

「よく使ったな。ここまで刃こぼれしてると、研いでも戻らん」

「無茶な使い方をしました」

「何をどうしたらこうなる。……まあいい」

　店主は奥の棚から布に巻いた一組を持ってきて、台の上で開いた。

　同じ形をしている。同じ長さで、同じ反りだ。それなのに、置かれた瞬間の音が、こちらのほうが低い。

「佳品だ。一つ上になる。鋼から違うぞ。値も違うがな」

　冬夜は袋の中身と、値札を交互に見た。手が届くかどうかの瀬戸際で、届かせるには依頼の報酬を全部積むしかない。

　貯めておく理由を探そうとして、一つも見つからなかった。

「これ、ください」

　防具屋には、肩の裂けた上着を持ち込んだ。縫い直すより作り直したほうが早いと言われ、素直に頷く。

　あわせて、奥側で余分に溜めておいた霞蜘蛛の硬毛を袋ごと預けた。当て革をもう一枚ぶん厚く編み直し、肩から鎖骨のあたりまで覆えるようにしてほしい、と頼む。

「三日もらうぞ。それより早くはならん」

　三日待つのは構わない。薬屋で傷薬を、武具屋で投擲ナイフを買い足す。

　インベントリの隅の手甲は、今日も出さなかった。誰かに見せれば正体が分かるのかもしれないが、刻紋銘を人前に置く気にはならない。

　店を回り終えるころには、財布はほとんど残っていない。

　その代わり、腰にかかる重みが変わった。街の外れで新しい刃を抜き、試しに槍状へ伸ばしてみた。

　前の短剣で同じことをすると、突いた瞬間にわずかな撓みがあった。形は槍でも、中身は初心者向けの鋼のままだったからだ。

　借りたものは、形だけが変わって、素材はそのまま残る。自分の得物でも同じことだった。

　新しい刃は、撓まない。

　――なるほど。

　装備で埋める、というのはこういうことかと、冬夜はようやく腑に落ちた。



　三日後に受け取った当て革は、明らかに一枚ぶん重くなっていた。

　上着の下で紐を締めてみる。肩から鎖骨までを覆っても、腕を回して引っかからない。動きを殺さない範囲で、ぎりぎりまで詰めてくれたのだと分かる。

　その足でギルドへ寄り、この三日で片付けた深部の依頼をまとめて報告した。受付は書類を確認してから、冬夜のギルド証を端末にかざした。

　戻ってきた手には、見覚えのあるギルド証があった。刻まれた文字が、Eから一つ変わっている。

「Dです。おめでとうございます」

「……あの、間違いではありませんか」

「深部の分だけでも数が揃っていますし、ここ最近の頻度が異常なんですよ」

　受付は淡々と続けた。ランクが上がれば、受けられる依頼の上限も一つ上がる。遠出のもの、危険度の高いもの、これまで掲示板の上のほうに貼られていて手が出せなかったものが、まとめて選べるようになるらしい。

　冬夜はギルド証を受け取り、もう一度掲示板の前に立った。

　見える紙の枚数が、まるで違っていた。

　そこからは、狩場を移した。

　東の街道沿いに出る依頼を受け、荷馬車を襲う獣を間引く。北へ二日歩いた岩場では、灰色狼より二回り大きい四足の獣が群れを作っていた。

　どれも、森の深部より一段上だ。まともに受ければ立っていられない。

　だから受けない。街道では荷馬車の轅を借りて柵に変え、逃げ道ごと道を細くする。岩場では足場を崩して落とす。

　深部で使った手が、そのまま一段大きくなっただけだ。

```
『Lv18に上がりました』
```

　深部の狼を何十頭とかけて上がったぶんが、この岩場では一群れで返ってくる。

　同じ時間を使うなら、上を殴ったほうが早い。それは分かっていて、これまでは受けられなかっただけの話だった。

　書店のシフトは、その週から減らしてもらった。

　店長は「学生は夏くらい遊べ」と笑っていた。空いた時間は全部、向こう側に流れ込んでいく。

　フレンド一覧の茜音の名前は、灯っている時間がこちらとずれるようになった。用のない文を送ることも、いつからかしなくなっている。

```
『Lv24に上がりました』
```

　岩場の主のような個体を、丸一日かけて崖の縁まで追い上げた日もある。足場を借りて崩し、落ちてきたところの喉に刃を入れた。

　依頼を報告して、素材を売って、傷薬を買い足して、また掲示板の前に立つ。

　その繰り返しの果てに、通知が出た。

```
『Lv30に上がりました』
```

　冬夜は岩場の縁に腰を下ろして、久しぶりにステータス画面を開いた。

```
冬夜
Lv30
職業:暗器使い
ソウルクレスト:彼は誰(かはたれ)

スキル:投擲、隠密行動、暗器生成、毒の調合、急所看破、会心の一撃、精密投擲
```

　スキルの欄は、投擲ナイフを買った頃から一つも増えていない。

　増えたのは、この七つで何ができるかという心当たりのほうだ。

　三十という数字を、どう受け取ればいいのかは分からない。ひと月前の自分に見せても、たぶん同じ顔をする。



　書店のレジに西尾が現れたのは、夕方の六時を回った頃だった。

　参考書を二冊、無造作にカウンターへ置く。冬夜が顔を上げて、そこで初めて目が合った。

「あ。お前ここだったのか」

「西尾さん。……いらっしゃいませ」

「いらっしゃいませって」

　西尾は笑って、財布を出しながらカウンターに肘をついた。

「後期の必修、これ買っとけって言われてさ。もうすぐ夏休み終わるだろ」

　手が止まりかけて、冬夜はバーコードを読み直した。

「……もう、ですか」

「もうだよ。履修登録は?」

「まだです」

「一年は締切に気をつけろよ。あれ落とすと後がだるい」

　袋に入れて渡すと、西尾は受け取って、思い出したように付け足した。

「そういやゲーム、続けてる?」

「続けてます」

「俺は最近ちょっと落ちてんだよな。二十そこそこで止まってる。そっちは?」

　冬夜は少し迷ってから、正直に答えた。

「三十です」

　西尾の眉が上がった。袋を持ったまま、しばらく黙っている。

「……夏の間だけでそれか」

「時間はありましたから」

「時間だけなら、みんな持ってんだけどな」

　西尾はそう言って、また来る、と軽く手を上げて出ていった。自動ドアが閉まって、店内の音が戻ってくる。

　シフトを削ったぶん、閉店を待たずに上がれる。冬夜はレジ横の棚を直しながら、さっきのやり取りを頭の中で巻き戻していた。

　帰り道の空は、もう暗くなりかけていた。少し前まで、この時間はまだ明るかった。

　夏休みの残りは、指で数えられるところまで来ている。

　この夏、現実で決めたことが一つでもあるかと考えて、冬夜は何も思い出せなかった。履修も、サークルも、来年の話も、一つ残らず先送りにしてある。西尾に訊かれるまで、締切があることすら忘れていた。

　その一方で、向こうでは毎日、決めることがあった。どの依頼を受けるか、どこへ誘い込むか、どちらの刃を先に投げるか。夜中まで考えて、翌日に試して、うまくいかなければ組み直す。

　本気になれない、という自覚は昔から持っていた。ここへ来て変わったのは、本気になれる場所が一つだけ見つかってしまったことだ。

　そしてそれは、この世界のどこにもない。

　情けないことなのかどうか、冬夜には判断がつかなかった。ただ、シフトを減らしたときに何のためらいもなかったことだけは、はっきり覚えている。



　夕食を済ませてログインすると、セイレスの広場には昼の光が落ちていた。

　視界の端で、小さな表示が明滅している。

　フレンド一覧の名前が、灰色から明るい色へ変わっていた。

```
茜音:『冬夜くん、久しぶり! ちょっと相談があるんだけど、いま平気?』
```
