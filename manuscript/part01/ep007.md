# 第七話　夜明けの掲示板

　ヘッドギアを外すと、部屋の窓の外はとうに真っ暗だった。壁の時計は、深夜一時を少し回っている。

　フルダイブから覚めたばかりの体は、まだどこかふわふわとしていて、現実の重みを取り戻すのに数秒かかった。今日一日で、名前のついた力が二つ増えた。頭の芯はまだ興奮でざわついているのに、体のほうは正直に眠気を訴えてくる。

　冬夜はろくに着替えもせず、ベッドに倒れ込むようにして目を閉じた。



　目が覚めると、カーテンの隙間から差し込む光がずいぶん高い位置にあった。スマホを確認すると、もう十時を過ぎている。こんな時間まで眠っていたのは久しぶりだった。

　大学は夏休みに入ったばかりで、特にこれといって予定もない。去年までなら、こうして昼近くまで寝て、それでも一日をやり過ごせてしまうことに何の疑問も持たなかった。今はなぜか、早くヘッドギアを被りたくてうずうずしている自分がいる。

　台所に降りていくと、母親はすでに出かけた後らしく、テーブルには「昼はレンジで温めて」とだけ書かれたメモと、ラップのかかった器が置かれていた。冬夜はメモを横目に、スマホだけを手に取って自室に戻る。

　叔父の浩二から、一件だけメッセージが届いていた。『どうだ、楽しんでるか』。それだけの、ずいぶんそっけない文面だった。冬夜は「まあまあ」とだけ短く返し、特に気にも留めずスマホを置く。あの機材を送ってきた時から、浩二らしいといえば浩二らしいノリだった。

　普段そこまで熱心に誘ってこない人だったのに、今回はやけに乗り気だった。そのことを少し不思議に思ったのを、冬夜はぼんやりと思い出す。もっとも、深く考えるほどのことでもない。単に良い暇つぶしを見つけて、誰かと分かち合いたくなっただけかもしれなかった。

　こういう時のために、プレイヤー同士の掲示板があったはずだ。わざわざヘッドギアを被らなくても、パソコンのブラウザから同じ掲示板を覗けることを思い出す。冬夜は机のノートパソコンを開き、外部の攻略サイトへアクセスした。

　攻略スレの上のほうに、見覚えのある単語が並んでいた。

```
【号外】北の刻紋種、討伐報告スレ

12: 名無しの冒険者
北の刻紋種、もう討伐済みらしいぞ

13: 名無しの冒険者
え、はやくない?

14: 名無しの冒険者
夜会が動いたって話。単独討伐だとか

15: 名無しの冒険者
さすがというかなんというか……
```

　昨日忠告された、あの北側の個体のことだろう。書き込みを追っていくと、事情はすぐに飲み込めた。昨晩のうちに、国内最強とも噂される少数精鋭クラン「常闇の夜会(とこやみのやかい)」――プレイヤーたちはみな「夜会」と略して呼んでいる――が、単独で仕留めていたらしい。

　自分が現場に行っていたら、というifを想像しかけて、冬夜は苦笑した。行っていたところで、何もできずに終わっていただろう。少し拍子抜けするような、それでいてどこか安心するような感覚だった。

　クランという言葉自体は初耳ではないが、詳しい仕組みまでは知らなかった。掲示板の別のスレッドで、ちょうど解説してくれている投稿を見つける。

```
【初心者質問】クランとパーティって何が違うの?

58: 名無しの冒険者
クランって結局パーティと何が違うの?

59: 名無しの冒険者
パーティは最大4人まで。クランはそのパーティがいくつも集まった集団のこと

60: 名無しの冒険者
高難度クエストとか国絡みの大きい脅威だと、パーティ単体じゃ手が足りないからな

61: 名無しの冒険者
クラン単位で動くことが多い、ってだけで加入は自由。緩い集まりもあれば審査ありの所もある
```

　なるほど、と冬夜は頷いた。スレッドには、他のクランの名前もいくつか挙がっていた。

```
【雑談】有名クラン語ろうぜ

101: 名無しの冒険者
うちは海賊気取りの荒くれ集団だから審査とか無いぞ、来る者拒まず

102: 名無しの冒険者
陽だまりは初心者にも優しいってよく聞くな

103: 名無しの冒険者
リーダーのファンクラブと化してるとこもあるし、色々あるよな

104: 名無しの冒険者
歴史オタクの集まりも地味に人気らしい

105: 名無しの冒険者
夜会と比べるのは酷だろ、あそこは別格
```

　海賊気取りの荒くれ者揃いだという一団、初心者にも間口を広く開いている大所帯、カリスマ的なリーダーを慕う信者めいた集団、ゲームの歴史ばかり調べている変わり種まで、色とりどりだ。夜会はその中でも別格の存在として扱われているらしく、書き込みの語調にも一目置いているような空気が滲んでいた。

　冬夜はしばらく画面をスクロールしながら、この世界の広さを改めて実感していた。自分もいつか、どこかに属することがあるのだろうか。今はまだ、パーティすら組んだことのない身では、想像もつかない話だった。

　それでも、そういう大きな集まりの噂話を追いかけているだけで、なんとなく胸が高鳴る。誰かに勧められたから始めたゲームのはずなのに、いつの間にか自分から情報を追いかけている。そのことに、冬夜自身が一番驚いていた。何をやってもそこそこで終わっていた自分にしては、珍しいことだった。



　情報収集を終えると、今日の予定を頭の中で組み立てる。薬草集めのクエストはまだ何回か受けられそうだし、せっかくレベルも上がったのだから、モンスター討伐のクエストにも挑戦してみたい。急所を突く感覚は、まだ体に馴染みきっていない気がする。

　稼いだお金は、あの投擲ナイフに充てるつもりだった。武具屋で見た時は手が届かなかったが、少しずつ貯めていけば、そう遠くないうちに買えるはずだ。暗器使いを名乗るなら、一度は自分の得物で試してみたい。

　そういえば、と冬夜は思い出す。昨日多めに摘んだ薬草が、まだ手元に残っているはずだ。毒にもなるという話だったから、「毒の調合」のスキルと組み合わせれば、何か面白いことができるかもしれない。傷薬(小)も、たしか二本とも手つかずのままだったはずだ。

　ノートパソコンを閉じ、冬夜は椅子から伸びをした。時計を見ると、もう昼が近い。台所のメモを思い出し、一階に降りることにした。

　テーブルに置かれていたのは、野菜がたっぷり入った煮物だった。レンジで温め直すと、湯気とともに優しい匂いが広がる。席についてゆっくり食べ終える頃には、頭の中の予定もすっかり固まっていた。

　食器を洗って自室に戻り、ヘッドギアを手に取る。装着すると、起動音に続いて意識が引っ張られるような感覚がやってくる。まだ二回目だというのに、もう体がこの感覚を覚え始めていた。



　意識が浮上すると、そこは見慣れたセイレスの通りだった。朝の光が差し込む通りは、昨日よりもさらに人通りが多い気がした。冬夜はそのまま、冒険者ギルドへ向かって歩き出す。

　石造りの建物をくぐると、相変わらず腕利きらしいプレイヤーたちの気配で満ちている。受付の女性が、冬夜の顔を見るなり小さく会釈した。通い始めてまだ間もないのに、もう顔を覚えられているらしい。

「今日は討伐のご依頼もいかがですか。Fランクの方でも受けられるものをご用意していますので」

　声をかけられ、冬夜は苦笑いしながら頷いた。目当ての依頼掲示板には今日も、薬草採取の張り紙と並んで、討伐系の依頼がいくつも貼り出されている。Fランクでも受けられる範囲のものだけに絞っても、選択肢は思っていたより多かった。

　張り紙の中には、「丘の周辺で増えすぎた獣の間引き」という、昨日戦ったのと似たような相手を指定した依頼もあった。勝手はもう分かっている。まずはこれから始めてみようか、と冬夜は張り紙の一枚に手を伸ばした。
