# 第七話　夜明けの掲示板

　ヘッドギアを外すと、部屋の窓の外はとうに真っ暗だった。壁の時計は、深夜三時を少し回っている。

　フルダイブから覚めたばかりの体は、まだどこかふわふわとしていて、現実の重みを取り戻すのに数秒かかった。頭の中はまだ興奮でざわついているのに、体のほうは正直に眠気を訴えてくる。

　冬夜はろくに着替えもせず、ベッドに倒れ込むようにして目を閉じた。


　　　　◇


　目が覚めると、カーテンの隙間から差し込む光がずいぶん高い位置にあった。スマホを確認すると、もう十時を過ぎている。

　大学は夏休みの真っ最中で、特にこれといって予定もない。それなのに、早くヘッドギアを被りたくてうずうずしている自分がいる。

　台所に降りていくと、母親はすでに出かけた後らしく、テーブルには「昼はレンジで温めて」とだけ書かれたメモと、ラップのかかった器が置かれていた。冬夜はメモを横目に、スマホだけを手に取って自室に戻る。

　「浩二おじさん」とのやり取りは、正月で止まったままだった。

　『機材ありがとう。昨日から始めた。めちゃくちゃ面白い』

　そう送った。

　代金のことは、まだ訊けていない。

　まあ、そのうち親戚の集まりで顔を合わせる。訊くなら、そのときでいい。

　それより、昨日聞いた北の刻紋種がどうなったのかが気にかかった。

　わざわざヘッドギアを被らなくても、プレイヤーの掲示板はパソコンから覗ける。冬夜は机のノートパソコンを開き、外部の攻略サイトへアクセスした。

　一覧の一番上に、「北の刻紋種」の見出しがあった。

```
【号外】北の刻紋種、討伐報告スレ

12: 名無しの冒険者
北の刻紋種、もう討伐済みらしいぞ

13: 名無しの冒険者
え、はやくない?

14: 名無しの冒険者
夜会が動いたって話。単独討伐だとか

15: 名無しの冒険者
さすがというかなんというか……
```

　書き込みを追っていくと、事情はすぐに飲み込めた。昨晩のうちに、「夜会」と呼ばれるクランが単独で仕留めたという。

　昨日聞いたときには、ずいぶん遠い話に思えたのに。一晩で片がついている。

　クランという言葉自体は初耳ではないが、詳しい仕組みまでは知らなかった。攻略サイトの用語集を探すと、ちょうど分かりやすいまとめ記事が見つかる。

```
【まとめ】クラン制度とアルディアの主要クラン

■クランとは
パーティ(最大4人)がいくつも集まって結成される、大規模なプレイヤー集団。高難度のクエストや国絡みの大きな脅威など、パーティ単体では対応しきれない目標に共同で挑むための仕組み。加入は任意で、緩やかな寄り合いから審査制の組織まで、性格は様々。

■アルディア国内の主なクラン
潮風の海賊団:港町マレイアを拠点に、交易路の護衛や海上のクエストを中心に請け負う自由な気風のクラン
陽だまり:数百人規模の大所帯。初心者の受け入れに積極的
白百合の使徒:カリスマ的なリーダーを慕う結束の強いクラン
刻の図書館:ゲームの歴史や設定資料の収集・考証を専門とする、情報収集力に定評のあるクラン
常闇の夜会(とこやみのやかい)※通称「夜会」:アルディア最強とも噂される超少数精鋭クラン。所属人数は公表されていない
```

　ずいぶん色とりどりだ。所属人数すら公表していないクランが最強と噂されている、というあたりに、この世界の広さがそのまま出ている。

　情報収集を終えると、今日の予定を頭の中で組み立てる。薬草集めのクエストはまだ何回か受けられそうだし、せっかくレベルも上がったのだから、モンスター討伐のクエストにも挑戦してみたい。昨日の一撃がまぐれだったのかどうかは、もう一度やってみないと分からない。

　稼いだお金は、あの投擲ナイフに充てるつもりだった。武具屋で見た時は手が届かなかったが、少しずつ貯めていけば、そう遠くないうちに買えるはずだ。暗器使いを名乗るなら、投げるための得物は要る。

　そういえば、と冬夜は思い出す。昨日多めに摘んだ薬草が、まだ手元に残っているはずだ。毒にもなるという話だったから、「調合(毒)」のスキルと組み合わせれば、何か面白いことができるかもしれない。

　ノートパソコンを閉じ、冬夜は椅子から伸びをした。時計を見ると、もう昼が近い。台所のメモを思い出し、一階に降りることにした。

　テーブルに置かれていたのは、野菜がたっぷり入った煮物だった。レンジで温め直すと、湯気とともに優しい匂いが広がる。席についてゆっくり食べ終える頃には、頭の中の予定もすっかり固まっていた。

　食器を洗って自室に戻り、ヘッドギアを手に取る。装着すると、起動音に続いて意識が引っ張られる。


　　　　◇


　意識が浮上すると、セイレスの石畳の上に立っていた。現実では昼を回っていたはずなのに、こちらの空はまだ朝の高さにある。向こうの一日と、この世界の一日は、同じ速さでは進まない。

　通りの人出は昨日より多い。ウィンはそのまま、冒険者ギルドへ向かって歩き出す。

　石造りの建物をくぐると、中は今日も装備を整えたプレイヤーで混み合っていた。受付に立つ女性が、こちらに気づいて顔を上げる。

「今日は討伐のご依頼もいかがですか。Fランクの方でも受けられるものをご用意していますので」

　声をかけられ、ウィンはちょうどいいタイミングだと頷いた。目当ての依頼掲示板には今日も、薬草採取の張り紙と並んで、討伐系の依頼がいくつも貼り出されている。Fランクでも受けられる範囲のものだけに絞っても、選択肢は思っていたより多かった。

　張り紙の中に、「丘の周辺で増えすぎた獣の間引き」という一枚があった。昨日戦ったのと似たような相手だ。

　ウィンは、その一枚に手を伸ばした。
