# 第十九話　見えている前提

　乾杯の音頭が終わって最初に届いたのは、汗をかいたジョッキが並ぶ音だった。

　駅前の居酒屋の座敷に、大学の顔ぶれが十四人。夏休みの中日に、誰かが思いつきで声をかけて集まった、名前のない飲み会だった。

　注文を取りに来た店員が、卓を一周しながら年齢を確認していく。冬夜のところで手が止まった。

「一年です。十八なので、ウーロン茶でお願いします」

　冬夜がそう言うと、店員は慣れた様子で頷いて次へ移った。ほどなく運ばれてきたグラスは、周りのどれよりも背が低くて、色だけが濃かった。

「じゃ、乾杯だけな」

　斜め向かいの先輩がジョッキを差し出してくる。ガラスとガラスがぶつかる音は、中身が何であろうと同じだった。

　三十分もすると、卓の空気が目に見えて変わった。顔が赤くなる人がいて、声だけが二段階大きくなる人がいて、同じ話を二度している先輩を誰も指摘しない。

　冬夜はウーロン茶を舐めながら、その様子を眺めていた。楽しそうではある。ただ、その楽しさの中身がどういう手触りをしているのかは、こちらからは見えなかった。

　あと二年もすれば、たぶん自分もあちら側の卓に座っている。そう考えても、待ち遠しいという気持ちにはならなかった。

「冬夜、サークルどこ入ったんだっけ」

　話の枝が一本、こちらへ伸びてきた。

「入っていません」

「まじで? じゃあ夏休み何してんの」

「バイトです。近所の書店で、週に何回か」

「へえ。将来そっち系?」

「いえ、特には」

　三往復で枝は枯れて、話は別のほうへ流れていった。冬夜は自分でも、もう少し何か言えたはずだと思ったが、その何かが出てこない。

　いつもこうだ。答えを持っていないわけではなく、答えるほどのものを持っていない。

　卓の向こうでは、就職の話と、去年の合宿の話と、誰かの失恋の話が同時に進んでいた。その音の中で、冬夜の頭はいつのまにか別のことを転がしていた。

　――報告番号、一一四。

　前脚を鎖で繋がれた刻紋種。首に、紋章の入った石。他に例がなく、信頼性は低いものとして参考記録に回されていた一枚。

　あの綴りの紙の質感まで思い出せるのに、目の前の話は三秒前の内容が抜け落ちている。

「おい、寝てんのか」

　肩を小突かれて、冬夜は顔を上げた。

　いつのまにか隣に座り直していたのは、二年の西尾だった。学部の集まりで何度か顔を合わせている、気さくで、それでいて距離を詰めすぎない先輩だ。

「起きています。すみません」

「顔が完全に別のとこ行ってたぞ」

　西尾は笑って、自分のジョッキと冬夜のグラスを見比べた。それから店員を呼んで、勝手にウーロン茶のおかわりを頼んだ。

「飲めない席ってつまんねえだろ。俺も一年のとき、これで二時間耐えた」

「……そうでもないです。見ているだけでも、そこそこ面白いです」

「なにその観察日記みたいな感想」

　言いながら、西尾は大きくあくびをした。目の下がうっすら暗い。

「昨日、夜中までゲームやってたんだよな。寝てない」

「何をやっているんですか」

「ソウルクレスト。知ってる?」

　冬夜の手が、グラスの半ばで止まった。

「……俺も、やっています」

「まじで」

　西尾の姿勢が変わった。座り方が三センチほど前に出た、という程度の変化だったが、はっきり分かった。

　そこから先は速かった。どこの狩場が旨いとか、あの依頼は報酬が渋いとか、そういう話が交互に飛び交う。

「クレスト何出た?」

「地味なやつです。派手なことは、何もできません」

「奇遇だな、俺のも地味」

　西尾は自分のクレストの名前を言わなかった。互いにそこは触れない、という呼吸だけが、なぜか一発で合った。

「ソロ?」

「……たまに、組む人がいます」

　言ってから、冬夜はグラスに口をつけた。それ以上は続けなかった。

　白い虎の話も、資料館の話も、塀の影で笑っていた人の話も、この卓には一つも置けない。持ってきてはいけない類の荷物だ。

　茜音なら、たぶん十四人全員と名前を交換して帰るのだろう。想像したら、少しだけ可笑しかった。

「じゃあさ、今度一緒に行こうぜ。俺、北のほうの湿地なら案内できる」

「北の湿地、ですか」

　冬夜は首を傾げた。セイレスから北へ出たことはあるが、湿地という話は聞いた覚えがない。

「あれ。お前どこの国?」

「アルディアです」

「あー」

　西尾が天井を仰いだ。心底残念そうな、間の抜けた声だった。

「俺、ヴァルドレア」

　その一言で、話が終わってしまったのが分かった。

「登録したときの経路で、最初の国が決まるんですよね」

「そうそう。俺は高校の友達に誘われて入ったから、そいつと同じ国。お前は?」

「叔父です」

「はい終了。国またぐには、実際に自分の足で国境越えるしかないからな。途中の道が、俺らのレベルだとまず無理」

　知識としては知っていた。ただ、その一文がこういう形で目の前に現れるとは思っていなかった。同じ夜に、同じ世界にログインしていて、それでも会えない。

「いつか行けるようになったら、連絡します」

「おう。そのときは案内するわ」

　西尾はあっさりそう言って、枝豆に手を伸ばした。落胆を引きずらないところが、この人らしかった。

「そういやアルディアだろ。そっちの新しい王様、めっちゃ有能らしいじゃん」

「……王様」

「知らねえの?」

　知らなかった。冬夜はセイレスの城のほうへ足を向けたことすら一度もない。

「うちの掲示板で言われてんだよ。アルディアは当たりを引いたって。前の王様が亡くなって、息子が継いだんだろ? それが評判いいらしくて」

　西尾は指を折りながら、又聞きらしい話を並べた。街道の警備が増えたとか、通行の手数料が下がったとか、その程度のことだ。

「隣の国のことって、逆によく見えるんだよな。自分とこの悪いところは見えないくせに」

「……そういうものですか」

「そういうもんだろ」

　それきり話は屋台の値段に流れて、王様の話は二度と戻ってこなかった。

　自分の国の話を、他の国のプレイヤーから聞かされた。冬夜が持ち帰ったのは、その据わりの悪さだけだった。

　世界は、自分が見ている範囲よりずいぶん外側で、勝手に動いているらしい。

　九時前にお開きになって、駅の改札前で解散になった。

「じゃあな。また飲もう」

「俺、ウーロン茶ですけど」

「じゃあまたウーロン茶飲もうな」

　西尾はひらひらと手を振って、反対側のホームへ降りていった。

　電車を待つあいだ、冬夜はさっきの自分を思い返していた。サークルは、と訊かれて三語で終わった。なのに、ゲームの話になった途端、訊かれてもいないことまで喋っていた。

　現実で「これがやりたい」と言えたことは、たぶん一度もない。



　家に着いたのは十時過ぎだった。

　母はもう寝ていて、台所の明かりだけが点けたままになっている。冬夜はそれを消して、自分の部屋に上がった。

　ヘッドギアを手に取る前に、机のノートパソコンを開く。掲示板はゲームの中からは覗けないから、調べ物はどうしてもこの時間になる。

　灰狼の森のまとめスレッドは、まだ虎の話で緩く回っていた。ただ、新しい事実は一つも出ていない。「どうせ夜会の誰かだろ」で片付けたがる流れが、この数日で完全に固まっている。

　安心すべきなのだろうな、と冬夜は思った。思っただけで、肩の力は抜けなかった。

　冬夜はメモ帳を新しく開いて、分かっていることだけを四行に並べてみた。

```
・白い虎は、脚を鎖で繋がれていた
・森閉ざしの灰狼は、群れを完璧に統べていたのに、
　侵入者にだけ度を越して執拗だった
・報告番号 一一四。前脚を鎖、首に紋章入りの石。
　他に例がなく、信頼性は低いものとして参考記録
・夜会が刻紋種を狩る理由は、報酬でも名声でもない
```

　共通しているのは、全部が刻紋種の話だということ。それだけだ。

　鎖の話が二件ある。だが片方は自分の目で見たもので、もう片方は「信頼性は低い」と注記された紙一枚だ。並べれば同じ形に見えるというだけで、同じだと言い切れる根拠はどこにもない。

　誰かが刻紋種に何かをしている――そういう形になりそうで、あと一歩のところでならない。

　冬夜はメモを保存して、ついでに「アルディア　新王」と打ち込んでみた。出てきたのは西尾が言っていたのとほとんど同じ、当たり障りのない好意的な書き込みばかりだった。

　ゲームの話をしているはずなのに、書いてある内容だけを見ると現実の記事と区別がつかない。それが少しだけ、おかしかった。

　時計は十時半を回っていた。冬夜はパソコンを閉じて、ヘッドギアを手に取った。



　ゲームの中は、よく晴れた午後だった。

　現実とゲームで時間の流れが噛み合っていないことには、もう慣れた。夜に潜って昼に立つ、というのが最近の常態になっている。

　フレンド一覧を開くと、茜音の名前は灰色に沈んでいた。ログアウト中ということだ。

　冬夜は短い文だけ送っておくことにした。

```
冬夜:今日は一人で、外套の性能を確かめてくる。
　　　中層までしか行かない
```

　深部には近づかない、という取り決めは自分にも等しくかかっている。書いてから、これはあの人に対する報告というより、自分への念押しだなと思った。

　セイレスのギルドは、いつも通り人で溢れていた。冬夜は掲示板の前を端から端まで眺めて、一枚の依頼票の前で足を止める。

```
討伐依頼(Eランク)

霞蜘蛛(かすみぐも)の間引き 三体
場所:灰狼の森・奥側(中層)
備考:糸を張らないため、巣を目印に探すことが
できません。口から霧状の分泌物を吐き、獲物の
視界を奪ってから仕留めます。動かずに待ち伏せる
性質のため、遭遇に気づくのが遅れがちです。
```

　受付のカウンターへ持っていくと、職員は依頼票に目を落として、少しだけ眉を上げた。

「霞蜘蛛は初めてですか」

「はい、初めてです」

「でしたら一つだけ。あれの霧は毒ではありません。吸っても体は何ともないので、そこは心配なさらなくて結構です」

「では、何が困るんですか」

「見えなくなります。それだけです」

　職員はあっさりそう言って、依頼票に受理の印を押した。

「見えないだけで、人は驚くほど動けなくなります。落ち着いて、まず霧から出てください」

「……分かりました。ありがとうございます」

　ギルドを出る前に、冬夜はインベントリを開いて中身を確かめた。

　インベントリを一通り眺め、頼れる得物はまだ十分にあることを確かめる。気になったのは、傷薬(小)が一本しか残っていないことだった。

　薬屋に寄るべきだ、というのはすぐに分かった。ただ、これから防具の加工を頼むつもりでいて、その相場をまだ知らない。財布の組み直しは、今日の稼ぎを受け取ってからにしたかった。

　――一本しかない前提で組む。

　冬夜は自分にそう言い聞かせた。霧に巻かれて姿勢が崩れたら、そこで一度退く。

　深追いをしない。それが今日の条件だ。

　条件を先に決めてしまえば、あとは守るだけでいい。



　灰狼の森の手前側は、いつもの顔ぶれだった。

　冬夜はまず、勝手を知った灰色狼で外套を試すことにした。深い灰色をした薄手の外套は、羽織っていることを忘れるほど軽い。

　下生えを踏まないよう気をつけながら、一頭の背後へゆっくり近づいていく。

　いつもなら、十歩ほど手前で耳がぴくりと動く。今日はそれが起こらなかった。

　八歩。六歩。五歩。

　狼が振り向いたのは、四歩まで詰めたところだった。そこからは急所看破の白い点を刺すだけで、こちらの一方的な仕事になった。

　冬夜は同じことを、相手を変えて何度か繰り返した。消えるのは音と気配だけで姿は消えないらしく、走れば足音もわずかに戻る。何より痛感したのは、防御力だけは本当に何もないということだった。

　四頭目の爪先が肩をかすめたとき、外套の生地は裂けもしなかったが、衝撃だけがそっくり素通りしてきた。下の軽装の上着が受け止めていなければ、かすり傷では済まなかったはずだ。

　冬夜は肩を回して、痛みが引くのを待った。この穴をどうにかしないことには、この外套は「見つからないまま死ねる装備」でしかない。



　中層に入ると、木が太くなり、下生えが減った。

　霞蜘蛛を最初に見つけたのは、見つけたというより、見つけられたと言うほうが正しかった。

　太い幹の根元で、樹皮の色をした塊が動いた。

　大型犬ほどの胴に、長く折れ曲がった脚が六本。灰白色の体には樹皮そっくりの斑が浮いていて、口元だけが不自然に膨らんでいる。

　こちらの足音は消えていた。それでも意味がなかった。相手は探していたのではなく、ただそこで待っていたのだ。

　膨らんだ口元が、収縮した。

　視界が、白くなった。

　三歩先の幹が消えた。自分の手が、肘から先だけ見えない。

　冷たくもなければ、息苦しくもない。ただ何も見えないというだけのことが、これほど足を止めるとは思わなかった。

　急所看破の白い点は、どこにも浮かばない。見えているものにしか働かない技なのだと、冬夜はこのとき初めて理解した。

　投げるのも無理だ。的が見えなければ、精密投擲も何の役にも立たない。

　霧の中で、かさ、と脚の音が回り込んだ。冬夜は反射的に後ろへ下がって、背中を幹に当てた。

　そこで、音が止まった。蜘蛛が、こちらを探している。

　――向こうも、見えていない。

　当たり前のことに、冬夜はようやく気づいた。

　自分で吐いた霧の中では、あの蜘蛛も目が使えない。だから音と気配で探す。そして今、こちらは音も気配も薄い。

　互いに見えない状況で、見つからないことにかけては、こちらのほうが上手だった。

　冬夜は息を殺し、幹に沿って横へ五歩ずれた。霧の切れ目から、灰白色の背中が覗く。

　白い点が、一つだけ浮かんだ。

　投擲ナイフが吸い込まれるように刺さり、蜘蛛が跳ねた。だが落ちない。素の火力の低さは、こういうときに正直に出る。

　跳ねた勢いのまま、脚の一本が横薙ぎに来た。冬夜は身を捻ったが、肩をまた掠られる。衝撃が素通りする感覚は、さっきと同じだった。

　距離を取りながら、腰の短剣を握る。自分の持ち物だから、断りを入れる必要はない。意識を通すだけで、刃はぬるりと伸びて槍の形になった。

　霧が薄れ、白い点がもう一度浮かぶ。冬夜は踏み込んで、そこへ突き込んだ。

　蜘蛛の体が光の粒子になって散った。

　息が上がっていた。冬夜は膝に手をついて、ようやく気づく。

　見えなくなった時点で、自分は何もできなくなっていた。急所看破も、精密投擲も、会心の一撃も、全部「見えている」ことを前提にした技だ。

　その前提を、あの蜘蛛は一息で外してきた。

　冬夜はしばらく、その場から動かなかった。

　見えなくされた側は、何もできない。

　なら、見えなくする側に回ればいい。

　冬夜はゆっくりと立ち上がり、霧の名残がまだ薄く漂う木立の奥へ目を向けた。
