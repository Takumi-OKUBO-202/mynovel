# 第二十七話　ただの獣

　ギルドの掲示板に、見慣れない一角ができていた。

　灰狼の森・深部。見出しにそう書かれた依頼が、五枚も並んでいる。この森の依頼といえば、手前側と奥側しかなかったはずだ。

　ウィンは受付のカウンターへ回った。

「深部の依頼、急に増えましたね」

「ここのところ、あのあたりが落ち着いているんです」

　受付は書類の束を揃えながら、事もなげに答える。

「少し前までは、狼の追い方がおかしいという報告ばかりでしたけど。今はもう、ただの獣ですよ。……そのぶん、数が増えすぎてしまって」

「入ったきり戻らない、という話も聞きましたが」

「それも、ここ何日かは聞きません」

　押さえが利かなくなった、ということらしい。

　何がいなくなったせいでそうなったのか——それを、掲示板の噂としてではなく自分たちのやったこととして知っているのは、二人だけだ。ウィンは表情を動かさずに、依頼を三枚まとめて受けた。

　ギルド証を返しながら、受付が付け足す。

「深部は、奥側よりもう一段上です。お一人で行かれるなら、無理はなさらないでください」

「引き返せなくなる前に、引き返します」

　言ってから、それができれば苦労はないな、と自分でも思った。

　帰り道に薬屋と武具屋を回った。刃の数が足りなくなって困るのは、決まって後半だ。

　街を出る前に、毒も仕込み直した。塗ってから日を跨げば効きは落ちるので、結局は使う日の分をそのつど作ることになる。

　空のままの目眩し玉の欄も、奥側で霧腺を稼げば埋まる。


　　　　◇


　灰狼の森の奥側。霞蜘蛛は、木立の陰で息を殺して獲物を待つ。

　ついこのあいだは、その霧に巻かれて何ひとつできなかった。見えていることを前提にした技しか、持っていなかったからだ。

　今は、吐かれる前に位置が取れる。枝の高さから風向きを読み、木の裏を回り、口の向きが変わるより早く背後へ抜ける。

```
『Lv12に上がりました』
```

　通知が出たのは、二体目を仕留めた直後だった。

　どこがどう伸びたのかは、相変わらず見せてもらえない。ただ、手が早くなっているのは自分でも分かる。

　霧腺が溜まったところで、木の根方に腰を下ろして道具袋を広げた。

　潰した霧腺を丸め、乾いた殻で包んで目眩し玉にする。前より数を揃えられたのは、単に霞蜘蛛の狩り方が身についたからだ。

　初めて作ったときは、大きさもばらばらだった。今は掌の中で同じ重さに揃う。同じ重さなら、同じ軌道で投げられる。

　ついでに、狩った狼の牙を削って投げ刃を足しておく。買ったナイフより粗いが、回収を諦めていい刃が増えるだけで、投げ方の選択肢は変わる。

　そこから先は、深部へ入った。

　狼は、手前側の個体より一回り大きい。まともに組めば押し負けるが、群れの動きそのものは素直だった。

　斜面の中腹まで誘い込み、足元の石を借りて楔に変える。傾いだ倒木の根方へ打ち込んで押せば、坂の半分が塞がった。

　あとは、通れるほうへ来た順に仕留めていくだけだ。

　狼、猪型、また狼。角兎の群れに囲まれたときは外套の裾を噛まれ、傷薬を一本使わされた。

```
『Lv13に上がりました』
```

　もっと稼げるはずだ、という感触だけはあった。

　ただ、深部は勝手が違う。斜面の角度も、狼が回り込んでくる速さも、一戦ごとに測り直すことになる。組み立てが決まるまでに時間を食い、そのぶん本数が伸びない。

　バイトを終えてから潜れる時間には限りがある。今日のところは、これで上出来だ。

　フレンド一覧に、色が灯っている。短い文を送る。

```
ウィン:『そっち、順調?』
```

　返事は、少ししてから来る。

```
茜音:『うん、まあまあ! そっちは?』
ウィン:『まあまあ』
茜音:『じゃあ、おたがいまあまあだね』
```

　それきり。何をしているのかは訊かないし、向こうも訊いてこない。

　深部の斜面で三体目を仕留めたところで、ウィンはいったん手を止めた。

　息が上がっていない。四頭まとめて来られても捌ける、という感覚が、日が傾く頃になってようやく手に入った。

　刃を拭って鞘に戻す。指先が、以前より正確に柄の位置を掴む。

　それでも、あの大熊とまともにやり合える気は、どうしてもしなかった。

　あのとき勝てたのは、腕でもレベルでもない。目の前で紋章を刻まれた直後で、痛みに動きが荒れていたからだ。

　縄張級。狩場を一つ丸ごと荒らす規模で、腕利きのパーティか、クランの一部隊で討つ相手。資料館の綴りには、そうある。

　――あれは、本来の力じゃなかった。

　ウィンは短剣の刃を布で拭って、斜面を登り直す。


　　　　◇


　その群れに出くわしたのは、最後の一枚を片付けようとしていたときだった。向こうの空は、この日二度目の夕暮れに入っている。

　窪地の底へ降りたところで、斜面の上に灰色が並ぶ。一頭、二頭では利かない。数えるより先に、輪が閉じた。

　正面は無理だ。ウィンは背中を岩の裂け目へ滑り込ませる。

　幅は肩ひとつ分。左右から同時には来られない。来られるのは、一度に一頭だけ。

　先頭が跳ぶ。伸びてきた鼻面へ、槍状に変えた短剣を突き上げる。

　ズッ、とぶつかる勢いのぶんだけ深く入って、灰色が地面へ落ちた。

　二頭目。三頭目。裂け目の口に骸が積み上がり、後ろの列がそれを踏み越えられずに苛立ち始める。

　一頭が横から回った。ガリッ、と岩の縁に爪をかけ、上から落ちてくる。

　ドッ、と肩で受けた。上着ごと持っていかれて、当て革の縁まで熱が走る。

　押し返して喉に刃を入れ、崩れる体を蹴り落とす。栓を歯で抜いて、傷薬をあおった。残りは、数えるほどしかない。

　そこへ、足元から目眩し玉を叩きつける。

　パンッ、と白い霧が窪地の底を舐めるように広がった。前が見えなくなった群れが、互いの体にぶつかって声を上げる。

　ウィンは霧に紛れて裂け目を出た。外套が足音を吸う。あとは匂いだけだ。

　風向きを確かめ、狼たちの風下へ回り込む。見えず、聞こえず、嗅げない。三つとも塞いでしまえば、この獣にできることは何も残らない。

　見えないのはこちらも同じだ。だが、ぶつかり合って上げる声が、居場所のほうから教えてくれる。

　背後から一頭。喉を突いて、抜く。

　次の一頭が振り返るより先に、その後ろへ。

　霧が薄れ始めた頃、窪地に立っていたのは一頭だけだった。

　群れで最も大きい個体は、混乱の間ずっと動かなかったらしい。鼻先を低く保ったまま、霧の切れ目からまっすぐこちらを見ている。
