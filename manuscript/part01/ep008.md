# 第八話　急所を積み重ねる

　冬夜が手を伸ばした張り紙には、「丘周辺で増えすぎた灰色狼(はいいろおおかみ)を5体、間引いてほしい」と書かれていた。討伐の証は自動記録、報酬は280Y。

　昨日と同じ丘に出る獣、ということは、相手の強さもだいたい見当がつく。冬夜は張り紙を受付に持っていき、依頼を受ける手続きを済ませた。

「今回は間引きの依頼ですので、指定の5体を倒していただければ結構です。討伐の証は自動的に記録されますので、素材を持ち帰る必要はありません」

　受付の説明に頷きながら、冬夜は報酬欄の数字を確認する。280Yと書かれていた。薬草採取の依頼とは実入りの相場も違うらしい。

　依頼を懐にしまい、冬夜はギルドを出て南の丘へ向かった。



　薬草採取の時と違い、今日は自分から相手を探して仕掛けなければならない。草むらの奥にじっと息を潜める獲物を見つけて、逃げ場のない間合いまで踏み込む必要がある。

　植物を摘む作業とは、緊張の質がまるで違った。相手にも意志があり、こちらの隙を窺っている――そう思うだけで、丘の斜面を歩くだけの足取りが、いやに慎重になる。

　最初の一体は、あっさり見つかった。灰色の毛並みをした獣が、茂みの陰からこちらの様子を見ている。

　腰を落とし、じりじりと間合いを詰める。獣が飛びかかってくる一瞬、体を沈めて懐に潜り込む。

　狙うのは喉元――だが今日は、まぐれで捉えたわけではない。急所看破のおかげか、獣の急所だけが妙にくっきりと視界に浮かび上がって見える感覚があった。

　狙って、当てる。それだけのことが、こんなにも違うのかと冬夜は思う。

　短剣の切っ先が正確に急所を貫き、獣は光の粒子になって消えていった。

　二体目、三体目、四体目と、同じ調子で仕留めていく。狙いの精度は一体ごとに上がっていく実感があった。

　5体目――最後の一匹の喉元に切っ先を突き立てた瞬間、視界の端に見慣れない通知が浮かんだ。

```
『Lv3に上がりました』
獲得ポイント　自動:20　割り振り可能:20
```

　まさかこれでレベルまで上がるとは思わなかった。冬夜は達成感とともに通知を見つめる。

　自動で振られる分は職業の適性任せ、残りは自分で決められる――この仕組みにはもう慣れた。前回と同じように、素早さと器用さに均等に注ぎ込むことにする。

　避ける速さと、狙った通りに当てる正確さ。今の自分の戦い方には、その二つが何より効いている気がした。



　5体を仕留め終え、冬夜はギルドへ戻った。受付に報告を済ませると、あっさりとした調子で「確かに受領しました、280Yです」と告げられる。派手な演出はレベルアップの通知だけで十分だった。

　まだ日は高い。せっかくレベルも上がったのだから、と冬夜は掲示板でもう一件、討伐依頼を選んだ。今度は森の外れをうろつく、一回り大きな魔物の群れの間引きだった。



　森に踏み込んで早々、群れの一体が茂みから飛び出してきた。冬夜は横に転がるようにしてかわしたつもりだったが、避けたはずの位置に、もう一体が回り込んでいた。爪先が脇腹をかすめ、じわりと熱い痛みが走る。

　――甘く見ていた。数が多い分、動きを追いきれていない。

　痛みを噛み殺しながら、冬夜は体勢を立て直す。向き直った獣の喉元へ、低く滑り込むように踏み込んだ。

　短剣の切っ先が急所を捉えた瞬間、これまでとは違う重い手応えが腕を伝う。会心の手応えとともに、通知が浮かんだ。

```
『スキル「会心の一撃」を習得しました』
```

　急所看破で見極めた一点を、さらに深く鋭く、そして重く射抜き続けたことで芽生えたスキルらしい。詳しい効果までは表示されなかったが、狙った急所への一撃そのものが、これまでよりもう一段階、力強く決まりやすくなる――そんな手応えが、体の芯にじんわりと残った。

　狙って、当てて、決める。だが決め切るには、当てるだけの正確さと同じくらい、押し込むだけの力も要るらしい。避けることばかり考えていた自分に、足りなかったものが少し見えた気がした。



　残りの群れを片付け、依頼をこなし終える頃には、また見慣れた通知が浮かんでいた。

```
『Lv4に上がりました』
獲得ポイント　自動:20　割り振り可能:20
```

　今度は迷わなかった。冬夜は割り振り可能な20点を、すべて力(STR)に注ぎ込む。会心の一撃を本当に決め切るなら、当てる正確さだけでなく、それを支えるだけの力も要る――さっきの一撃で、そう実感したばかりだった。



　依頼をいくつもこなしたその足で、冬夜はいつものように達成報告の窓口に立ち寄った。受付の女性が、冬夜のギルド証を受け取って端末にかざす。

「積み重ねてこられましたね。ランクがEに上がりました」

　あっさりとした調子で告げられ、冬夜は一瞬反応が遅れた。Fランクのままだと思っていた自分の証が、いつの間にか一段上がっていたらしい。

「受けられる依頼の幅も、少し広がりますよ」

　受付はそう付け加えて、いつもの会釈を返した。冬夜は礼を言ってギルドの扉をくぐる。



　依頼をひとしきり終えた帰り道、人通りの少ない小道に入ったところで、冬夜はふと自分のステータスを確認してみることにした。

```
冬夜
Lv4
職業:暗器使い
ソウルクレスト:彼は誰(かはたれ)

HP 32/32
MP 10/10
魂力(SP) 8/8
STR 28
AGI 57
DEX 44
INT 7
VIT 9
LUK 22

スキル:投擲、隠密行動、暗器生成、毒の調合、急所看破、会心の一撃

所持金:1600Y
```

　たった一日でレベルが二つ上がり、スキルまで一つ増えている。薬草を摘んでいた頃とは、明らかに景色が違う。

　所持金の欄に並ぶ数字にも、目が留まる。千六百ユン。武具屋で見た投擲ナイフの値札を思い出すと、もう手が届く距離まで来ている気がした。

　次にログインしたら、まずは武具屋に寄ってみよう。冬夜はそう決めて、静かにステータス画面を閉じた。
