# 第八話　試したいことが、いくつか

　ウィンが手を伸ばした張り紙には、「丘の周辺で増えすぎた獣の間引き」と書かれていた。昨日戦った灰色狼のことだ。

　剥がしかけたところで、手が止まる。隣に並んだ二枚が、目に入っていた。

```
討伐依頼(Fランク)
丘の南で群れを成し始めた灰色狼の間引き
討伐した数だけ報酬を加算します
```

```
討伐依頼(Fランク)
西の野の野兎(のうさぎ) 二十匹
畑の被害が続いているため、村からの上乗せがあります
```

　歩合のほうが、実入りはいい。相手も昨日と同じ獣だ。

　ウィンは一度そちらへ手を伸ばして、途中でやめた。

　昨日、初めて獣を仕留めたとき、肩に爪をもらっている。一頭でそれだ。二頭に前後から来られたら、そこで終わる。

　自分の手数では、一度に一匹しか捌けない。それは昨日はっきりした。

　――今日は、そこを増やしたい。

　昨日の終わりに、足元の小石を鏃の形に変えて獣を仕留めた。あのとき手のひらに残ったのは、うまくいった実感より、鏃以外にもできることがあるはずだという引っかかりのほうだった。

　試すなら、数が要る。何度も外していい相手が要る。

　ウィンは、野兎の張り紙のほうを剥がした。

「二十匹ですね。素材は持ち帰っていただいて構いません」

　受付は数を確かめて、依頼票に印を押す。

「一匹あたりは大したことがありませんが、まとめれば悪くない額になりますよ。畑が荒らされていますので」

「弱いんですか」

「弱いです。ただ、速いので」

　受付は少し言葉を選ぶような間を置いた。

「追いかけて捕まえる相手ではありません。穴に入られたら、それきりです」

　追えないなら、来てもらうしかない。ウィンは礼を言って、依頼票を懐にしまった。


　　　　◇


　ギルドを出て、ウィンは広場の露店を端から覗いて回った。

　買ったのは、麻の縄を一巻きと、鉄の釘をひと掴み。どちらも、何に使うか決めて買ったわけではない。

　昨日、自分の短剣で確かめたことが一つある。最初から自分のものなら、自分のものにする一手間が要らない。

　拾った石や枝は、その場にあるものしか選べない。だが持ち歩くものなら、形を変える前の姿を、こちらで選んでおける。

　縄と釘は、そのための元手だった。


　　　　◇


　セイレスの西門を出ると、街道の両側がしばらく畑になる。丘とは反対の方角だ。

　膝の高さの麦が風で一斉に傾き、その向こうに、柵の途切れた草地が広がっていた。

　畑の際の土が、あちこち掘り返されている。穴の口は拳ほどで、周りに囓られた根が散っていた。

　最初の一匹は、麦の列の隙間から出てきた。

　膝下ほどの灰茶色の体に、体の半分ほどもある長い耳。鼻先が二度動いて、こちらを向く。

　ウィンが一歩踏み出した瞬間、耳が寝た。

　跳ぶ。三度跳ねたときには、もう草地の真ん中にいた。

　急いで投げた短剣は、トッ、と間の抜けた音を立てて土に刺さっただけだった。

　なるほど、追う相手ではない。


　拾い直した短剣を握って、ウィンは意識を通した。

　届かないなら、伸ばせばいい。切っ先が飴のようにゆっくりと伸びていく。

　刃渡りが倍を越えたところで、手の中の重さが変わっていないことに気づいた。

　長くなったぶん、薄い。指の腹で押すと、頼りなくたわむ。

　次に出てきた一匹へ振り下ろすと、刃は背中に当たって、ザリッ、とそのまま横へ滑った。毛皮も裂けない。

　形は変えられる。だが、元の量までは増えない。

　当たり前の話だった。増やせるなら、石ころ一つで剣が作れてしまう。

　ウィンは刃を元の長さに戻して、鞘に収めた。


　次は、縄だった。

　巻いたまま意識を通すと、一本の縄が手のひらの中でほどけるように分かれていく。

　網目を細かくするほど、一本ずつが細くなった。さっきの刃と同じだ。

　畳一枚ぶんの粗い網。それが、この一巻きで作れる限界だった。

　草地の一匹へ向けて投げる。網は空中で広がりきらず、バサッ、と束のまま落ちた。

　もう一度巻き直して、今度は近づいてから被せようとする。腕を上げた時点で、耳が寝ていた。

　投げるのは、向いていない。

　ウィンは網を引き寄せながら、掘り返された土のほうへ目を戻した。

　穴は、いくつも並んでいる。そのうちの二つは、土の盛り方からして中で繋がっていそうだった。

　片方から入れば、もう片方から出てくる。

　出口のほうに網を広げて、草の茎に端を引っ掛ける。それから畑を回り込んで、入り口の前で足を踏み鳴らした。

　草の下を、何かが走る音が抜けていく。

　出口の網が、内側から膨れた。

　絡まって跳ねている白い喉元が、周りより白く浮かんで見える。ウィンは網ごと押さえて、そこへ切っ先を落とした。

　一匹。

　だが、二匹目からは通じなかった。追い立てても、別の穴のほうへ逃げていく。網は一つきりで、穴は野じゅうにある。


　ウィンは腰の袋から釘をひと掴み取り出し、意識を通そうとする。

　その瞬間、張ってあった網が、パサッ、とただの縄に戻って草の上に落ちた。

　形を変えていられるのは、一度に一つきりだ。昨日、枝と短剣で確かめたはずだった。

　ウィンはしばらく、片手の縄と片手の釘を見比べていた。

　張るだけなら、網である必要はない。

　縄は、縄のままでいい。変える枠は、こちらに空けておける。


　ウィンは縄を解いて、二つの穴のあいだに低く渡した。草の穂に隠れて、膝より下の高さで一本。

　その手前の落ち葉を寄せて、釘をひと掴み置く。意識を通すと、掌ほどの薄い板になり、上を向いた棘が並んだ。落ち葉を戻して、覆う。

　長くは保たない。魂力が尽きれば、板はただの釘に戻る。

　起動しておくのは、追い立てる直前でいい。

　ウィンは畑を回り込んで、穴の入り口を踏み鳴らした。

　土を蹴る音が近づいてくる。

　灰茶色が草を割って飛び出し、張った縄を見て跳ねた。

　――見える。

　跳び越えた先の、落ち葉の上へ。



　キッ、と短い声が上がった。

　着地した後ろ足が棘を踏んで、跳ねる勢いがそこで死んでいる。二度、三度と足を替えるが、そのたびに草へ体が傾いた。

　ウィンは踏み込んで、揺れの止まった喉元へ切っ先を沈める。

　ザクッ、と入って、そのまま光になった。

　二匹目。


　あとは、同じことを場所を変えて繰り返した。

　棘板は踏まれるたびに位置がずれるので、そのつど置き直す。魂力が続かないので、追い立てる直前まで釘のまま持っておく。縄は、ただの縄なのでいくらでも張り替えが利いた。

　網が要る場所では、釘を袋に戻してから縄に意識を通す。使えるのが一度に一つ、というのは、要するに順番を決める作業だ。

　日が真上を過ぎるころには、掘り返された穴のあたりが静かになっていた。

```
『Lv3に上がりました』
```

　草地の側へ移って、また同じ手を組み直す。

　急所看破の白い点は、灰色狼のときより小さくて、跳ねるたびに揺れた。それでも、動きの止まった一瞬なら、外さなくなっている。

　二十匹目を仕留めて、ウィンは縄を巻き取った。

　視界の端に、二つ続けて通知が浮かぶ。

```
『スキル「会心の一撃」を習得しました』
```

```
『Lv4に上がりました』
```

　会心の一撃。名前だけが出て、何がどう変わるのかは書かれていない。


　　　　◇


　西門をくぐってセイレスへ戻る頃には、日が傾きかけていた。

　達成報告の窓口で、受付の女性がウィンのギルド証を受け取り、端末にかざす。かざした先の表示を見て、女性は手を止めた。

「Eランクに上がりましたよ」

「もうですか」

　こんなに早く上がるものだとは思っていなかった。証を返してもらって覗き込むと、確かに刻まれた文字が一つ変わっている。

「何回受ければ上がる、みたいな決まりがあるんですか」

「回数では決めていません。採取と討伐を一通りこなして、任せて問題ないと判断できればEです。ここまでは、皆さんだいたいすぐですね」

「その先は」

「Dまでは、討伐が続いていればそう遠くありません。Cから急に遠くなります。上はAまでですね」

「Sは」

「Sは、実績で登る枠ではないので」

　それきり受付は説明を継がず、証をカウンターの上で軽く滑らせた。

「Eになると、受けられる依頼の幅が少し広がります。あとは、掲示板の募集欄に自分の名前を出せるようになりますよ」

「今のところは、一人でいいです」

　女性は気を悪くした様子もなく頷いて、報酬をまとめて渡してくれた。薬草の束を数えてもらっていた昨日とは、受け取るものの重さが違う。

　隣の「素材買取」の窓口にも寄る。二十匹ぶんの毛皮を差し出すと、係の女性はまとめて検分し、袋ごと押し返してきた。

　戻りぎわ、ウィンは掲示板の前をもう一度通った。

　群れの張り紙は、朝と同じ場所に貼られたままだった。剥がした跡もない。

　ウィンは足を止めずに、扉のほうへ歩いた。


　　　　◇


　串に刺した肉を炙る店の前で、ウィンは足を止めた。

　昨日はここで、買うかどうかをずいぶん迷った。

「一本、ください」

「はいよ、まいど」

　受け取った串は、昨日と同じように少し硬い。香辛料の匂いが、傾いた日差しの中に立ち上る。

　噛みながら、ウィンは自分のステータスを開いた。

```
ウィン
Lv4
職業:暗器使い
ソウルクレスト:彼は誰(かはたれ)

スキル:投擲、隠密行動、生成(暗器)、調合(毒)、急所看破、会心の一撃
```

　串を食べ終えて、ウィンは武具屋へ足を向けた。

　戸はもう半分下りていた。ウィンは腰をかがめて中を覗き、棚の投擲ナイフがまだそこにあるのを確かめる。

「明日の朝、買いに来ます」

　奥から、店主の手だけが上がって返した。
