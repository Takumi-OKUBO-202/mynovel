# 第八話　急所を積み重ねる

　ウィンが手を伸ばした張り紙には、「丘周辺で増えすぎた灰色狼(はいいろおおかみ)を5体、間引いてほしい」と書かれていた。討伐の証は自動記録。

　昨日と同じ丘に出る獣、ということは、相手の強さもだいたい見当がつく。ウィンは張り紙を受付に持っていき、依頼を受ける手続きを済ませた。

「間引きの依頼ですので、指定の5体を倒していただければ結構です。素材を持ち帰る必要はありません」

　受付の説明に頷きながら、ウィンは報酬欄を確認する。薬草採取の依頼とは、実入りの相場がまるで違う。

　依頼を懐にしまい、ウィンはギルドを出て南の丘へ向かった。



　薬草採取の時と違い、今日は自分から相手を探して仕掛けなければならない。草むらの奥にじっと息を潜める獲物を見つけて、逃げ場のない間合いまで踏み込む必要がある。

　植物を摘む作業とは、緊張の質がまるで違った。相手にも意志があり、こちらの隙を窺っている――そう思うだけで、丘の斜面を歩くだけの足取りが、いやに慎重になる。

　日の高いうちの丘は、腰までの草がひと続きに風で倒れて、身を隠せる場所がどこにもない。向こうから見えるということは、こちらからも見えるということだ。

　最初の一体は、あっさり見つかった。灰色の毛並みをした獣が、茂みの陰からこちらの様子を見ている。

　腰を落とし、じりじりと間合いを詰める。獣が飛びかかってくる一瞬、体を沈めて懐に潜り込む。

　狙うのは喉元――だが今日は、まぐれで捉えたわけではない。急所看破のおかげか、獣の急所だけが妙にくっきりと視界に浮かび上がって見える感覚があった。

　狙って、当てる。それだけのことが、こんなにも違うのかとウィンは思う。

　ザシュッ、と短剣の切っ先が急所を貫く。獣は光の粒子になって消えていった。後には小さな牙が残る。ウィンはそれを拾い、インベントリに収めた。

　二体目、三体目、四体目と、同じ調子で仕留めていく。狙いの精度は一体ごとに上がっていく実感があった。倒すたびに残る牙や毛皮も、律儀に一つずつ拾い集めていく。

　5体目――最後の一匹の喉元に切っ先を突き立てた瞬間、視界の端に見慣れない通知が浮かんだ。

```
『Lv3に上がりました』
```

　今日も伸ばされたのは、速さと手先と、それを支える力のところだった。避ける速さと、狙った通りに当てる正確さ。自分の戦い方に効いているのはその二つだと、体のほうが先に納得している。

　ギルドへ戻って報告を済ませると、受付はあっさりと「確かに受領しました」とだけ告げた。まだ日は高い。ウィンは掲示板の前へ引き返し、もう一件を選ぶ。

　「丘の奥で群れを成し始めた灰色狼を、可能な限り間引いてほしい」。単独で動くことが多いはずの丘の獣が、珍しく群れを作っているという。討伐した数だけ報酬が加算される、歩合制の依頼だった。

　丘の奥は、様子が違った。草はまばらになり、代わりに背の低い木立が斜面を覆っている。足元は乾いた土と落ち葉で、踏むたびに小さく音が鳴った。

　見通しが利かない。そのぶん、こちらの足音も向こうへ届く。

　木立の陰に、これまでとは違う数の気配があった。数えて、四、五匹はいる。一匹ずつ静かに狩ってきたこれまでとは、明らかに勝手が違いそうだった。

　先頭の一匹が飛びかかってくる。ウィンは横に転がるようにしてかわした――はずだった。着地の直後、死角から二匹目が突っ込んでくる気配に気づくのが、コンマ数秒遅れる。

　ザッ、と爪先が脇腹をかすめ、じわりと熱い痛みが走った。

　――甘く見ていた。数で来られると、動きを追いきれない。

　痛みを噛み殺しながら、ウィンは体勢を立て直す。突っ込んできた勢いのまま体勢を崩した二匹目の喉元へ、低く滑り込むように踏み込んだ。

　――そこだ。

　ドンッ、と短剣の切っ先が急所を捉える。これまでとは違う重い手応えが腕を伝った。通知が浮かんだ。

```
『スキル「会心の一撃」を習得しました』
```

　急所看破で見極めた一点を、さらに深く鋭く、そして重く射抜き続けたことで芽生えたスキルらしい。詳しい効果までは表示されなかったが、狙った急所への一撃そのものが、これまでよりもう一段階、力強く決まりやすくなる――そんな確信だけが、体の芯にじんわりと残った。

　狙って、当てて、決める。だが決め切るには、当てるだけの正確さと同じくらい、押し込むだけの力も要る。避けることばかり考えていた自分に、足りなかったものが少し見えた気がした。

　新しい感覚を確かめるように、ウィンは残る三匹にも順番に切っ先を突き立てていく。一匹仕留めるごとに、狙いから踏み込みまでの流れがなめらかになっていく。

　地面に残る牙や毛皮も、その都度拾ってインベントリに詰め込んでいく。数が数だけに、一覧はいつの間にかそれなりの量になっていた。

　群れをすべて片付ける頃には、また見慣れた通知が浮かんでいた。

```
『Lv4に上がりました』
```



　ウィンはその足で、達成報告の窓口に立ち寄った。受付の女性が、ウィンのギルド証を受け取って端末にかざす。

「積み重ねてこられましたね。ランクがEに上がりました」

　あっさりとした調子で告げられ、ウィンは一瞬反応が遅れた。Fランクのままだと思っていた自分の証が、いつの間にか一段上がっていた。

「受けられる依頼の幅も、少し広がりますよ」

　受付はそう付け加えて、いつもの会釈を返した。歩合制だった二件目の依頼は、四匹分の討伐でしめて相応の額になるという。

　ウィンは礼を言うと、隣の「素材買取」の窓口にも寄った。今日一日でどっさり溜まった牙と毛皮を差し出すと、係の女性はまとめて検分し、思っていたよりまとまった額を渡してくれる。数をこなした甲斐はあった。

　受け取った代金のうち、屋台の軽食に使ったのはほんの一部で、残りはそのまま懐に収まった。

　ウィンはギルドの扉をくぐった。

　人通りの少ない小道に入ったところで、ふと自分のステータスを確認してみる。

```
ウィン
Lv4
職業:暗器使い
ソウルクレスト:彼は誰(かはたれ)

スキル:投擲、隠密行動、暗器生成、毒の調合、急所看破、会心の一撃
```

　たった一日でレベルが二つ上がり、スキルまで一つ増えている。薬草を摘んでいた頃とは、明らかに景色が違う。

　そういえば、さっきの被弾も、思ったほど深手にはならなかった気がする。レベルが上がるごとに、こういう地力の部分も勝手に底上げされているらしい。

　財布の中身も、今朝とはずいぶん違っていた。討伐依頼の実入りに加えて、今日は牙や毛皮もいつになくまとまった額になっている。

　武具屋で見た投擲ナイフの値札を思い出す。手が届く。

　欲しいものがあって、そのために丸一日動いた。そんな覚えは、しばらくなかった。
