# 第八話　急所を積み重ねる

　ウィンが手を伸ばした張り紙には、「丘周辺で増えすぎた灰色狼(はいいろおおかみ)を5体、間引いてほしい」と書かれていた。討伐の証は自動記録。

　昨日と同じ丘に出る獣だ。一度倒している相手なら、どのくらい強いかの見当はつく。ウィンは張り紙を受付に持っていき、依頼を受ける手続きを済ませた。

「間引きの依頼ですので、指定の5体を倒していただければ結構です。素材を持ち帰る必要はありません」

「素材は、こっちのものになるんですか」

「はい。買取に回していただいても構いません」

　受付が示した報酬欄に、ウィンは目を落とす。昨日、摘んだ薬草の束と引き換えに受け取ったものを思い出す。あれとは、はっきり違う。

「それと、一つだけ」

　依頼票に印を押しながら、受付が付け足した。

「丘の南のほうで、数が増えているようです。まとまって動いているという報告も来ていますので、狙うのは単独でいるものにしてください」

「まとまっていると、まずいですか」

「お一人なら、まずいです」


　　　　◇


　南の丘は、薬草を摘んだ斜面がそのまま続いている。腰までの草が、風の通り道に沿って一方向へ倒れていた。

　薬草採取と違うのは、獲物のほうが動くことだ。向こうに先に見つかれば、間合いを取られるか、逃げられる。

　ウィンは斜面を登りきる手前で膝を折り、草の高さより頭を下げた。風は背中から前へ抜けている。

　これでは匂いが先に届く。斜面を横切るように、風下へ回り込んだ。

　草の切れ目に、灰色の背中が見えた。鼻先を地面に近づけて、何かの匂いを追っている。

　ウィンは短剣を抜き、呼吸を浅くして、足の裏から順に体重を移した。狙うのは喉元だ。急所看破のおかげで、そこだけが周りより白く浮かんで見える。

　あと三歩。

　踏み出した足の下で、乾いた草の茎がパキッと折れた。

　背中が跳ね起きる。耳が伏せ、体が低く沈んだ。剥き出しになった歯のあいだから、喉を鳴らす音が漏れる。

　白い点は見えている。だが、獣が首を振るたびに、点も一緒に動いた。

　獣が地を蹴り、間合いが一息で潰れる。ウィンは体を沈めて懐へ潜り込み、白い点へ切っ先を送った。

　届いたのは、そこから指一本ぶん外れた肩口だった。

　ザッ、と毛皮が裂ける。それでも獣は倒れない。悲鳴のような鳴き声を上げて身をよじり、刺さったままの短剣ごと横へ跳んだ。

　柄が、手から抜けた。

　ウィンは後ろへ転がって、腰のもう一本を抜く。武具屋で二本まとめて買ったうちの、まだ使っていなかったほうだ。

　獣が向き直る。肩から刃を生やしたまま、また体を沈めた。

　――跳ぶ。

　跳んでいるあいだ、獣は横に動けない。まっすぐこちらへ来るしかない。

　二度目は、待った。飛び込んできた喉元へ、下から切っ先を合わせる。

　ドッ、と重い音が手首まで返ってきた。

　獣は光の粒子になって崩れ、地面には小さな牙と、抜けた短剣が残る。

　ウィンは短剣を拾い、刃を草で拭ってから鞘に戻した。一頭倒すのに、二度かかっている。

　原因は分かっていた。あの一歩だ。


　二頭目からは、足を置く場所を選んだ。倒れた草の上は茎が乾いていて鳴る。踏むのは、土の見えている隙間だけにする。

　風下から、背中の三歩後ろまで。今度は振り向かれる前に、白い点へ切っ先が届いた。

　三頭目は、草の切れた開けた場所にいた。あそこまで近づけば、先に見つかる。

　ウィンは足元に転がっていた拳ほどの石を拾い、意識を通した。手のひらの中で角が伸び、細く尖った鏃の形に変わる。昨日、二頭目をこれで仕留めた。

　草の際まで這って、投げる。

　狙ったのは喉元だったが、鏃が刺さったのは前脚の付け根だった。この距離では、それが精一杯だ。

　獣がつんのめる。ウィンは走り込んで、届く間合いから喉を突いた。

　四頭目には、動く前に気づかれた。追い足で仕留めるまでに、草の斜面を半分ほど下りることになる。

　肩で息をしていると、視界の端に通知が浮かんだ。

```
『Lv3に上がりました』
```

　残るは一頭。


　　　　◇


　丘を南へ下りきると、腰の草がまばらになり、代わりに背の低い木立が斜面を覆い始める。丘はここで終わりで、その先は森になるらしい。

　足元は乾いた土と落ち葉に変わった。踏むたびに小さく音が鳴る。草のように面で身を隠せる場所はなく、隠れられるのは幹の裏だけだ。

　幹に体を寄せて、ウィンは木立の奥を覗いた。

　灰色の背中が、三つ。

　一頭が伏せ、残りの二頭がその周りをうろついている。受付の言っていたとおりだった。

　依頼は、あと一頭。三頭とやり合う理由はどこにもない。

　――一頭だけ、こっちへ引き離す。

　音を立てれば来る。それは丘で分かったばかりだ。だが、釣った先で三頭に囲まれたら、そこで終わる。

　来られるのが一頭ずつになる場所が要る。

　ウィンは木立の縁を見渡した。斜面の途中に、二本の木が人ひとりぶんの幅を空けて並んでいる。両脇は下生えが密に絡んでいた。

　抜けるとすれば、木と木のあいだだ。

　地面に、腕ほどの太さの落ち枝が転がっている。

　拾い上げて意識を通すと、枝は手のひらの中で真っすぐに伸び、両端が二本の幹に食い込んだ。膝より少し上の高さに、一本の横木が渡る。

　これで、通り抜けるには跳ぶしかない。長くは保たない。魂力が尽きれば、横木はただの枯れ枝に戻る。

　あとは音だ。ウィンは足元の石へ手を伸ばして、そこで止めた。

　石を鏃に変えれば、横木のほうが解ける。形を変えていられるのは、一度に一つきりだ。

　変えなくていい、とすぐに思い直す。投げれば、音は鳴る。

　拾った石を、木立の外の岩へ向けて放った。

　カツン、と乾いた音が返る。

　落ち葉を蹴る足音が、こちらへ寄ってきた。

　最初の一頭が木立を抜け、横木の前で速度を落とす。前脚が浮いた。

　跳んでいる体の下へ、ウィンは体を滑り込ませる。

　――見える。

　仰いだ喉元が、これまでで一番はっきりと白く浮かんだ。



　ドスッ、と鈍い音が、柄を握った手から肩まで抜けた。

　獣は宙で止まり、そのまま光になって散る。落ちてきた牙が、落ち葉の上で跳ねた。

　これで五頭。依頼の数は、これで足りる。

　だが、落ち葉の音は止まっていなかった。

　バサッ、と絡んだ蔓が鳴る。下生えの薄いところから、二頭目が横合いへ体をねじ込んでくる。

　気づいたのは、爪が脇腹をかすめた後だった。じわりと熱が走る。

　――一頭だけ来るとは限らない。

　体勢を崩したまま、ウィンは横へ転がる。枝に通していた意識が切れて、カタン、と横木が落ち葉の上に落ちた。もう、ただの枯れ枝だった。

　仕掛けはない。ウィンは下がりながら、二本の短剣を握り直す。

　下がれば、追ってくる。追ってくるなら、いつかは跳ぶ。

　二頭目が沈み込み、地を蹴った。

　その喉へ、丘で四度やったのと同じ形で切っ先を合わせる。獣は崩れて、光になった。

　三頭目は、下生えの奥から出てこない。低い唸りだけが聞こえている。

　ウィンは短剣を下ろした。依頼は足りている。追う理由はない。

　脇腹に手を当てると、指先が浅く濡れた。傷薬を使うほどではない。息が整うまで幹に背を預けて、それから落ち葉に散った牙と毛皮を拾い集めた。

　視界の端に、二つ続けて通知が浮かぶ。

```
『スキル「会心の一撃」を習得しました』
```

```
『Lv4に上がりました』
```

　会心の一撃。名前だけが出て、何がどう変わるのかは書かれていない。


　　　　◇


　丘を下ってセイレスへ戻る頃には、日が傾きかけていた。

　達成報告の窓口で、受付の女性がウィンのギルド証を受け取り、端末にかざす。かざした先の表示を見て、女性は手を止めた。

「Eランクに上がりましたよ」

「もうですか」

　こんなに早く上がるものだとは思っていなかった。証を返してもらって覗き込むと、確かに刻まれた文字が一つ変わっている。

「何回受ければ上がる、みたいな決まりがあるんですか」

「回数では決めていません。採取と討伐を一通りこなして、任せて問題ないと判断できればEです。ここまでは、皆さんだいたいすぐですね」

「その先は」

「Dまでは、討伐が続いていればそう遠くありません。Cから急に遠くなります。上はAまでですね」

「Sは」

「Sは、実績で登る枠ではないので」

　それきり受付は説明を継がず、証をカウンターの上で軽く滑らせた。

「Eになると、受けられる依頼の幅が少し広がります。あとは、掲示板の募集欄に自分の名前を出せるようになりますよ」

「今のところは、一人でいいです」

　女性は気を悪くした様子もなく頷いて、報酬をまとめて渡してくれた。薬草の束を数えてもらっていた昨日とは、受け取るものの重さが違う。

「それと、報告しておきたいことが」

　ウィンは南の端の木立のことを話した。三頭が固まっていたこと、そのうち二頭は倒したが、残りには手を出さずに引き返してきたこと。

「助かります。その形になっていると、うちも一人では出せませんので」

　受付は書き付けに何か記して、顔を上げた。

「近いうちに、そちらは何人かで組む形の依頼にして出します」

　隣の「素材買取」の窓口にも寄る。今日一日で溜まった牙と毛皮を差し出すと、係の女性はまとめて検分し、袋ごと押し返してきた。

　ギルドの扉を出ると、広場の露店に灯りが入り始めている。


　　　　◇


　串に刺した肉を炙る店の前で、ウィンは足を止めた。

　昨日はここで、買うかどうかをずいぶん迷った。

「一本、ください」

「はいよ、まいど」

　受け取った串は、昨日と同じように少し硬い。香辛料の匂いが、傾いた日差しの中に立ち上る。

　噛みながら、ウィンは自分のステータスを開いた。

```
ウィン
Lv4
職業:暗器使い
ソウルクレスト:彼は誰(かはたれ)

スキル:投擲、隠密行動、生成(暗器)、調合(毒)、急所看破、会心の一撃
```

　串を食べ終えて、ウィンは武具屋へ足を向けた。

　戸はもう半分下りていた。ウィンは腰をかがめて中を覗き、棚の投擲ナイフがまだそこにあるのを確かめる。

「明日の朝、買いに来ます」

　奥から、店主の手だけが上がって返した。
