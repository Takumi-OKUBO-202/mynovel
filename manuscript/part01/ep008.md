# 第八話　急所を積み重ねる

　ウィンが手を伸ばした張り紙には、「丘周辺で増えすぎた灰色狼(はいいろおおかみ)を5体、間引いてほしい」と書かれていた。討伐の証は自動記録。

　昨日と同じ丘に出る獣だ。一度倒している相手なら、どのくらい強いかの見当はつく。ウィンは張り紙を受付に持っていき、依頼を受ける手続きを済ませた。

「間引きの依頼ですので、指定の5体を倒していただければ結構です。素材を持ち帰る必要はありません」

「素材は、こっちのものになるんですか」

「はい。買取に回していただいても構いません」

　受付が示した報酬欄に、ウィンは目を落とす。昨日、摘んだ薬草の束と引き換えに受け取ったものを思い出す。あれとは、はっきり違う。

　依頼を懐にしまい、ウィンはギルドを出て南門をくぐった。


　　　　◇


　南の丘は、薬草を摘んだ斜面がそのまま続いている。腰までの草が、風の通り道に沿って一方向へ倒れていた。

　薬草採取と違うのは、獲物のほうが動くことだ。向こうに先に見つかれば、間合いを取られるか、逃げられる。

　ウィンは斜面を登りきる手前で膝を折り、草の高さより頭を下げた。風は背中から前へ抜けている。

　これでは匂いが先に届く。斜面を横切るように、風下へ回り込んだ。

　草の切れ目に、灰色の背中が見えた。

　鼻先を地面に近づけて、何かの匂いを追っている。ウィンは呼吸を浅くして、足の裏から順に体重を移した。

　足元に、拳ほどの石が転がっている。

　拾い上げて、意識を通す。手のひらの中で石の角が伸び、細く尖った鏃の形に変わった。初めて獣を仕留めたときと同じ手だ。

　狙いをつけて、投げる。

　石は灰色の背中の手前で草をはたき、カツン、と地面の何かに当たって転がる。

　獣が跳ね起きる。耳が伏せ、体が低く沈む。

　剥き出しになった歯のあいだから、喉を鳴らす音が漏れた。ウィンを見つけている。

　――止まっている的とは、違う。

　距離が詰まる。獣が地を蹴った。

　急所看破のおかげか、跳んだ獣の喉元だけが、周りより白く浮かび上がって見える。ウィンは短剣を握り直し、体を沈めて懐へ潜り込んだ。

　切っ先は、白い点から指一本ぶんだけ外れて、肩口に入った。

　ザッ、と毛皮を裂く感触。獣は消えない。悲鳴のような鳴き声を上げて身をよじり、刺さったままの短剣ごとウィンを振り回そうとする。

　柄を手放し、後ろへ転がる。着地した獣が向き直る。肩から刃を生やしたまま、また体を沈めた。

　――跳ぶ。

　跳んでいるあいだ、獣は横に動けない。まっすぐこちらへ来るしかない。

　二度目は、待った。飛びかかってきた腹の下へ滑り込み、突き出た柄を掴んで引き抜きざま、白く浮かんだ点へ押し込む。

　ドッ、と重い音が手首まで返ってきた。

　獣は光の粒子になって崩れ、後には小さな牙が一つ残った。

　肩で息をしながら、ウィンはそれを拾う。一体倒すのに、二度かかった。


　二体目からは、同じ手順を組み立て直した。風下から近づき、石を投げて気づかせ、跳ばせる。跳んだ軌道の下へ入る。

　三体目は毛皮の厚いところに当たって浅く入り、また二度手間になった。四体目は跳ぶ前に横へ逃げられ、追い足で仕留めるまでに草の斜面を半分ほど下りた。

　五体目の喉元へ切っ先を沈めたところで、視界の端に通知が浮かぶ。

```
『Lv3に上がりました』
```

　牙と毛皮をひととおり拾い集めて、ウィンは丘を下りた。


　　　　◇


　ギルドへ戻って報告を済ませ、ウィンはもう一度掲示板の前に立った。日はまだ高い。

　目に留まったのは、「丘の南の端で群れを成し始めた灰色狼を、可能な限り間引いてほしい」という一枚だった。さっきまで相手にしていたのと同じ獣だ。

　ただし、単独で動くはずのそれが、珍しく数を揃えているらしい。討伐した数だけ報酬が加算される、歩合制の依頼だった。

　張り紙を持っていくと、受付の女性がわずかに間を置いた。

「群れの依頼ですので、お一人ですと少しお勧めしにくいのですが」

「一匹ずつなら、さっき何度かやりました」

　言ってから、それが理由になっていないことにウィンも気づく。

　それでも、相手は同じ獣だ。まとめて来られなければいい。数を減らす手立てなら、丘で一つ覚えたばかりだった。

　受付は少し考えてから、頷く。

「では、無理はなさらないでくださいね。危なくなったら引いて構いません。歩合ですので、途中でやめても倒したぶんはお支払いします」


　　　　◇


　丘を南へ下りきると、腰の草がまばらになり、代わりに背の低い木立が斜面を覆い始める。この先はもう森だ。ギルドの地図では、灰狼の森と呼ばれている一帯の入り口にあたる。

　足元は乾いた土と落ち葉に変わった。踏むたびに小さく音が鳴る。草の丘と違って、伏せても隠れる高さがない。

　木の陰に、灰色の背中が一つ見えた。

　ウィンは幹の裏に体を寄せ、風下を確かめる。石を探して、視線を落とした。

　そのとき、獣が短く鳴いた。

　少し離れた木立の奥から、同じ調子の鳴き声が返る。さらにもう一つ、別の方向から。

　ウィンは石を拾う手を止めた。

　声は三方向から返っている。見えているのは一匹でも、この木立には少なくとも四匹いる。同じ手で一匹を跳ばせれば、残りが声を聞きつけて集まってくる。

　――まとめて来られたら、終わる。

　足音を殺して、ウィンは木立の縁まで後退した。

　斜面の途中に、二本の木が人ひとりぶんの幅を空けて並んでいる。両脇は下生えが密に絡んでいた。

　抜けられるとすれば、木と木のあいだだ。

　地面に、腕ほどの太さの落ち枝が転がっていた。

　拾い上げて意識を通すと、枝は手のひらの中で真っすぐに伸び、両端が二本の幹に食い込んだ。膝より少し上の高さに、一本の横木が渡る。

　これで、通り抜けるには跳ぶしかない。

　長くは保たない。魂力が尽きれば、横木はただの枯れ枝に戻る。決めるなら、それまでだ。

　ウィンは横木の手前に立ち、口の中で舌を鳴らした。

　落ち葉を蹴る音が、四方から一斉に近づいてくる。

　最初の一匹が木立を抜け、横木の前で減速した。跳ぶ。

　跳んでいる体の下へ、ウィンは滑り込んだ。白く浮かんだ喉元へ、下から切っ先を突き上げる。

　二匹目も同じように跳んだ。今度は着地際の首筋を捉えた。

　三匹目は、横木を跳ばなかった。

　バサッ、と絡んだ蔓が鳴った。下生えの薄い場所から強引に体をねじ込んで、横合いへ回り込んでいる。

　気づいたのは、爪が脇腹をかすめた後だった。じわりと熱が走る。

　――同じ手は、二度までだった。

　体勢を崩したまま、ウィンは横へ転がる。三匹目が向き直り、四匹目が横木を跳び越えて着地する。挟まれた。

　枝に通していた意識が切れた。カタン、と横木が落ち葉の上に落ち、ただの枯れ枝に戻る。

　二匹が同時に沈み込む。

　ウィンは下がらなかった。下がれば二匹に追われる。踏み込む先を、右の一匹に絞る。

　――見える。

　跳んできた獣の喉元が、これまでで一番はっきりと白く浮かんだ。

　その一点へ、体ごと切っ先を押し込む。



　ドスッ、と鈍い音が、柄を握った手から肩まで抜けた。

　獣は宙で止まり、そのまま光になって散る。落ちてきた牙が、落ち葉の上で跳ねた。

　残った一匹は、着地の姿勢のまま動かなかった。喉が低く鳴る。数歩下がり、木立の奥へ身を翻して、下生えの音だけを残して消えた。

　ウィンは短剣を下ろし、追わなかった。依頼票の注意書きに、深追いは危険だと書いてある。

　脇腹に手を当てると、指先が浅く濡れた。傷薬を使うほどではない。息が整うまで幹に背を預けて、それから地面に散った牙と毛皮を拾い集めた。

　視界の端に、二つ続けて通知が浮かぶ。

```
『スキル「会心の一撃」を習得しました』
```

```
『Lv4に上がりました』
```

　会心の一撃。名前だけが出て、何がどう変わるのかは書かれていない。


　　　　◇


　丘を下ってセイレスへ戻る頃には、日が傾きかけていた。

　達成報告の窓口で、受付の女性がウィンのギルド証を受け取り、端末にかざす。かざした先の表示を見て、女性は手を止めた。

「Eランクに上がりましたよ」

「もうですか」

　こんなに早く上がるものだとは思っていなかった。証を返してもらって覗き込むと、確かに刻まれた文字が一つ変わっている。

「何回受ければ上がる、みたいな決まりがあるんですか」

「回数では決めていません。採取と討伐を一通りこなして、任せて問題ないと判断できればEです。ここまでは、皆さんだいたいすぐですね」

「その先は」

「Dまでは、討伐が続いていればそう遠くありません。Cから急に遠くなります。上はAまでですね」

「Sは」

「Sは、実績で登る枠ではないので」

　それきり受付は説明を継がず、証をカウンターの上で軽く滑らせた。

「Eになると、受けられる依頼の幅が少し広がります。あとは、掲示板の募集欄に自分の名前を出せるようになりますよ。人を集めたいときにお使いください」

「今のところは、一人でいいです」

「そうおっしゃる方も多いです」

　女性は気を悪くした様子もなく、歩合の分をまとめて渡してくれた。二件目で仕留めたのは三匹。それでも、薬草の束を数えてもらっていた昨日とは、受け取るものの重さが違った。

　隣の「素材買取」の窓口にも寄る。今日一日で溜まった牙と毛皮を差し出すと、係の女性はまとめて検分し、袋ごと押し返してくる。

　ギルドの扉を出ると、広場の露店に灯りが入り始めていた。


　　　　◇


　串に刺した肉を炙る店の前で、ウィンは足を止めた。

　昨日はここで、我慢するのが賢明だと考えてから買った。今日は考えなかった。

「一本、ください」

「はいよ、まいど。――兄ちゃん、今日は羽振りがいいね」

「丘で狼をやってきました」

「そりゃ稼ぎどきだ。あのへんは今、増えすぎて手に負えないらしいからな」

　受け取った串は、昨日と同じように少し硬い。香辛料の匂いが、傾いた日差しの中に立ち上る。

　噛みながら、ウィンは自分のステータスを開いた。

```
ウィン
Lv4
職業:暗器使い
ソウルクレスト:彼は誰(かはたれ)

スキル:投擲、隠密行動、生成(暗器)、調合(毒)、急所看破、会心の一撃
```

　スキルの欄が、また一つ伸びている。

　串を食べ終えて、ウィンは武具屋の前を通った。戸口はもう半分下りている。

　棚の投擲ナイフには、昨日と同じ値札が下がっていた。明日の朝いちばんに、買いに来ればいい。
