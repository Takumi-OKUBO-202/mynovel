# 第八話　急所を積み重ねる

　冬夜が手を伸ばした張り紙には、「丘の周辺で増えすぎた獣の間引き」とだけ書かれていた。討伐対象の数と報酬が並び、末尾に「達成報告は受付まで」と添えられている。

　昨日と同じ丘に出る獣、ということは、相手の強さもだいたい見当がつく。冬夜は張り紙を受付に持っていき、依頼を受ける手続きを済ませた。

「今回は間引きの依頼ですので、指定数を倒していただければ結構です。討伐の証は自動的に記録されますので、素材を持ち帰る必要はありません」

　受付の説明に頷きながら、冬夜は報酬欄の数字を確認する。280Yと書かれていた。薬草採取の依頼とは実入りの相場も違うらしい。

　依頼を懐にしまい、冬夜はギルドを出て南の丘へ向かった。



　薬草採取の時と違い、今日は自分から相手を探して仕掛けなければならない。草むらの奥にじっと息を潜める獲物を見つけて、逃げ場のない間合いまで踏み込む必要がある。

　植物を摘む作業とは、緊張の質がまるで違った。相手にも意志があり、こちらの隙を窺っている――そう思うだけで、丘の斜面を歩くだけの足取りが、いやに慎重になる。

　最初の一体は、あっさり見つかった。灰色の毛並みをした獣が、茂みの陰からこちらの様子を見ている。

　腰を落とし、じりじりと間合いを詰める。獣が飛びかかってくる一瞬、体を沈めて懐に潜り込む。

　狙うのは喉元――だが今日は、まぐれで捉えたわけではない。急所看破のおかげか、獣の急所だけが妙にくっきりと視界に浮かび上がって見える感覚があった。

　狙って、当てる。それだけのことが、こんなにも違うのかと冬夜は思う。

　短剣の切っ先が正確に急所を貫き、獣は光の粒子になって消えていった。

　指定された数をこなすまで、同じ調子で二体、三体と仕留めていく。狙いの精度は一体ごとに上がっていく実感があった。



　依頼を果たし、ギルドへ戻る。受付に報告を済ませると、視界の端に見慣れた通知が浮かんだ。

```
『依頼達成:報酬280Yを受け取りました』
『Lv3に上がりました』
```

　初めての討伐依頼を無事にやり遂げられたことに、まず安堵した。まさかこれでレベルまで上がるとは思わなかった。冬夜は達成感とともに通知を見つめる。

　続けて、ステータスポイントの割り振り画面が現れる。

```
獲得ポイント　自動:20　割り振り可能:20
```

　自動で振られる分は職業の適性任せ、残りは自分で決められる――この仕組みにはもう慣れた。前回と同じように、素早さと器用さに均等に注ぎ込むことにする。

　避ける速さと、狙った通りに当てる正確さ。今の自分の戦い方には、その二つが何より効いている気がした。



　それから数日、大学の休みをいいことに、冬夜はログインしては同じような討伐依頼をいくつもこなす日々を送った。丘の獣だけでなく、街道沿いに出る小型の魔物、森の外れをうろつく群れ――受けられる依頼の幅は少しずつ広がっていった。

　最初の頃は、急所を捉えられても偶然の延長のような感覚が拭えなかった。だが繰り返すうちに、相手の動きの癖、隙が生まれる瞬間が、少しずつ読めるようになってくる。

　ある日の戦いで、冬夜は接近してくる魔物の一撃を紙一重で受け流し、体をひねりざま急所へ切っ先を突き立てた。会心の手応えとともに、通知が浮かぶ。

```
『スキル「会心の一撃」を習得しました』
```

　急所看破で見極めた一点を、さらに深く正確に射抜き続けたことで芽生えたスキルらしい。詳しい効果までは表示されなかったが、狙った急所への一撃そのものが、これまでよりもう一段階、鋭く決まりやすくなる――そんな手応えが、体の芯にじんわりと残った。

　狙って、当てて、決める。その一連の流れが、少しずつ自分のものになっていく感覚があった。



　もっとも、慣れてきたからといって無傷で済むわけではない。ある依頼の最中、群れで襲ってきた魔物の一体をやり過ごしきれず、脇腹に鈍い衝撃を受けた。

　避けたはずの位置に、もう一体が回り込んでいたのだ。息が詰まるほどの痛みに、冬夜は顔をしかめる。

　――避けることばかり考えていた。

　素早さを伸ばせば伸ばすほど、避けられる場面は増える。だが今みたいに、避けきれない一撃をもらう場面は、これからも消えてなくならないだろう。多少殴られても耐えられる体があれば、今の一撃はここまで響かなかったはずだ。

　痛みを噛み殺しながら、冬夜は残った獲物へ意識を切り替える。急所を捉えた一撃で仕留め、その日の依頼を終える頃には、また見慣れた通知が浮かんでいた。

```
『Lv4に上がりました』
獲得ポイント　自動:20　割り振り可能:20
```

　今度は迷わなかった。冬夜は割り振り可能な20点を、すべて耐久に注ぎ込む。避ける速さばかりを伸ばしてきた反動を、少しはここで埋めておきたかった。



　依頼をいくつもこなしたその足で、冬夜はいつものように達成報告の窓口に立ち寄った。受付の女性が、冬夜のギルド証を受け取って端末にかざす。

「積み重ねてこられましたね。ランクがEに上がりました」

　あっさりとした調子で告げられ、冬夜は一瞬反応が遅れた。Fランクのままだと思っていた自分の証が、いつの間にか一段上がっていたらしい。

「受けられる依頼の幅も、少し広がりますよ」

　受付はそう付け加えて、いつもの会釈を返した。冬夜は礼を言ってギルドの扉をくぐる。



　依頼をひとしきり終えた帰り道、人通りの少ない小道に入ったところで、冬夜はふと自分のステータスを確認してみることにした。

```
冬夜
Lv4(第一段階)
職業:暗器使い
ソウルクレスト:彼は誰(かはたれ)

HP 32/32
MP 10/10
魂力(SP) 8/8
STR 8
AGI 57
DEX 44
INT 7
VIT 29
LUK 22

スキル:投擲、隠密行動、暗器生成、毒の調合、急所看破、会心の一撃

所持金:1600Y
```

　わずか数日でレベルが二つ上がり、スキルまで一つ増えている。数字を目で追いながら、冬夜はしばらく画面を見つめたまま動けなかった。

　薬草を摘んでいた頃とは、明らかに景色が違う。まさかこんな短期間で、これほど変わるとは思っていなかった。器用貧乏を自認していた自分が、狙って急所を突けるようになったことにも、まだどこか実感が追いついていない。

　所持金の欄に並ぶ数字にも、目が留まる。千六百ユン。武具屋で見た投擲ナイフの値札を思い出すと、もう手が届く距離まで来ている気がした。

　次にログインしたら、まずは武具屋に寄ってみよう。冬夜はそう決めて、静かにステータス画面を閉じた。
