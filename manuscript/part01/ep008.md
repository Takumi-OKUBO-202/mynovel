# 第八話　試したいことが、いくつか

　ウィンが手を伸ばした張り紙には、「丘の周辺で増えすぎた獣の間引き」と書かれていた。昨日戦った灰色狼のことだ。

　その隣に、新しい張り紙が二枚、並んで貼られている。

```
討伐依頼(Fランク)
丘の南で群れを成し始めた灰色狼の間引き
討伐した数だけ報酬を加算します
```

```
討伐依頼(Fランク)
西の野の野兎(のうさぎ) 二十匹
畑の被害が続いているため、村からの上乗せがあります
```

　三枚を見比べる。実入りがいちばんいいのは、数だけ報酬の乗る群れの間引きだ。

　だが、昨日は一頭を仕留めるのに、肩へ爪をもらっている。二頭に前後から来られたら、そこで終わる。群れは、まだ早い。

　それに、確かめたいことがあった。昨日、二度目に出くわした一頭は、足元の小石を鏃に変えて仕留めた。あの力でできることは、鏃のほかにもあるはずだ。

　相手が兎なら、しくじっても爪までは飛んでこないだろう。

　ウィンは、野兎の張り紙を剥がした。

「二十匹ですね。素材は持ち帰っていただいて構いません」

　受付は数を確かめて、依頼票に印を押す。

「倒すのに、コツみたいなものはありますか」

「足が速いので、皆さん色々と工夫していらっしゃるようですよ。臆病な性質で、敵を見つけると戦わずに巣穴へ戻る、と記録にはありますね」

　戦わずに逃げる相手は、初めてだった。ウィンは礼を言って、依頼票を懐にしまう。


　　　　◇


　ギルドを出て、ウィンは広場の露店を端から覗いて回った。買ったのは、麻の縄を一巻きと、鉄の釘をひと掴み。

　昨夜、ログアウトしてから寝つくまで、考えていたことがある。

　自分の短剣は、自分のものにする一手間なしで形を変えられた。そして拾う石や枝は、その場に転がっているものしか選べない。

　なら、最初から持ち歩けばいい。形を変える前の姿を、こちらで選んでおける。

　縄と釘は、その思いつきの元手だった。

　どちらも、腰回りの物入れにそのまま収まる。暗器使いの装備は細々したものを差しておく口があちこちにあって、刃物でなくても、手を伸ばせばすぐに出せた。

　妙なところで、職業と噛み合っている。


　　　　◇


　セイレスの西門を出ると、街道の両側がしばらく畑になる。南の丘とは、別の方角だ。

　膝の高さの麦が風で一斉に傾き、その向こうに、柵の途切れた草地が広がっていた。

　畑の際の土が、あちこち掘り返されている。穴の口は拳ほどで、周りに囓られた根が散っていた。

　最初の一匹は、麦の列の隙間から出てきた。

　膝下ほどの灰茶色の体に、体の半分ほどもある長い耳。鼻先が二度動いて、こちらを向く。

　ウィンが一歩踏み出した瞬間、その長い耳が背中へぴたりと伏せた。

　次の瞬間には、跳んでいる。三度跳ねて、畑の際の穴へ潜り込んだ。

　急いで投げた短剣は、トッ、と間の抜けた音を立てて土に刺さっただけだった。

　あの長い耳が伏せるのが、逃げる合図らしい。敵を見つけると戦わずに巣穴へ戻る――受付の言っていた習性のとおりだった。

　顔を上げると、草地のあちこちに同じ灰茶色が見え隠れしている。数だけなら、依頼の二十匹はすぐに揃いそうだった。


　まずは、短剣を試す。

　意識を通して、切っ先をゆっくり伸ばしてみた。どこまで伸ばせて、伸ばすと何が起きるのか、まだ確かめていない。

　刃渡りが倍を越えたあたりで、手の中の重さが変わっていないことに気づく。長くなったぶんだけ、刃が薄い。指の腹で押すと、頼りなくたわんだ。

　柵の折れた杭へ、試しに振り下ろしてみる。

　ザリッ、と刃は杭の皮を一枚めくっただけで、横へ滑った。

　伸ばした先が薄すぎて、これでは引っかき傷しかつけられない。形は変えられても、元の材料までは増えないのだ。

　ウィンは刃を元の長さに戻して、鞘に収めた。


　その代わりに、と物入れから縄を取り出す。

　巻いたまま意識を通すと、一本の縄が手のひらの中でほどけるように分かれていった。

　網目を細かくするほど、一本ずつが細くなる。伸ばした刃が薄くなったのと同じで、元の量から増えてはくれない。

　両腕を広げたくらいの、粗い網。この一巻きで作れるのは、そこまでだった。

　草を食んでいる一匹へ、少し離れた位置から投げてみる。

　網は空中で開ききらず、バサッ、と半分畳まれたまま落ちた。端に重りのない網は、開いた形のまま飛んではくれない。

　もう一匹には、歩いて近づいてから被せようとした。腕を上げた時点で、もう耳が伏せている。


　ウィンは網を提げたまま膝を折り、草地を低い位置から見渡した。

　草の丈が揃っていない場所がある。踏み分けられて倒れたまま起きなくなった、幅一つ分の細い筋だ。穴と穴のあいだを繋ぐように、何本も走っている。

　兎の通り道だ。

　臆病で、追われれば巣穴へ戻る。戻るときも、この筋を走るはずだ。

　なら、この道の上で待てばいい。

　筋の一本を選んで、途中に網を垂らした。両端を草の茎に引っ掛けて、道を塞ぐ形にする。

　それから草地側へ回り込み、餌を食んでいる一匹の前へ、わざと足音を立てて踏み出した。

　耳が伏せる。兎は身を翻し、巣穴への筋を一直線に駆け戻っていく。

　狙いどおり――と思えたのは、網の三歩手前までだった。

　兎は急に足を止め、網を避けて草へ割り込むと、別の穴へ消えた。

　止めようとすれば、避けられる。網は、遠くからでも壁に見えるのだ。


　止められないなら、跳ばせればいい。

　草に紛れた低い一本なら、気づくのは直前になる。避ける間はなく、跳んで越えるしかない。

　そして跳べば、降りる場所はもう決まっている。

　網を筋の上に低く寝かせて、その先に釘の棘を並べる。頭の中でそういう絵を組みながら、ウィンは物入れから釘をひと掴み出し、意識を通そうとした。

　ふっ、と手の中の張りが抜けた。

　提げていた網が編み目からほどけて、ただの一本の縄に戻っている。

　形を変えていられるのは、一度に一つきり。昨日、枝と短剣で確かめたとおりだ。網を残したまま、釘まで変えることはできない。

　ウィンは、垂れ下がった縄と手の中の釘を見比べた。

　考えてみれば、跳ばせるだけなら網の形は要らない。低く一本張ってあれば、それで足りる。

　縄は、縄のまま。形を変える一つ分は、釘に回す。


　ウィンは筋の途中に、縄を膝より低い高さで一本張った。倒れた草に紛れて、走ってくる側からはまず見えない。

　その数歩先の草を掻き分けて、釘をひと掴み並べる。意識を通すと、釘同士が寄り集まって掌ほどの薄い板になり、上を向いた棘がずらりと並んだ。倒れた草を被せて、隠す。

　あとは、板が釘に戻る前に追い立てるだけだ。魂力が尽きれば、仕掛けはただの釘の山に戻る。

　ウィンは草地側へ回り込み、餌を食んでいる一匹の前へ踏み出した。

　今度は、隠れなくていい。臆病さのほうが、勝手に走り出してくれる。

　耳が伏せ、灰茶色が筋を一直線に駆けていく。縄の手前で、体が沈んだ。

　――見える。

　跳んだ体が、隠した板の上へ降りてくる。



　キッ、と短い声が上がった。

　倒れた草が撥ねて、隠していた棘の列が覗く。後ろ足がそこに乗ったまま、兎は前へ出られずに体だけを二度捻った。

　次の一跳びが、来ない。

　ウィンは踏み込んで、動きの止まった喉元へ切っ先を沈めた。

　ザクッ、と入って、そのまま光になる。

　一匹目。


　あとは、筋を変えて同じ形を組み直すだけだった。

　縄を低く張り、数歩先に棘板を隠し、草地側から姿を見せて追い立てる。隠れて近づく必要は、どこにもない。

　板に変えたまま歩き回ると魂力が心もとないので、釘に変えるのはいつも最後だ。縄はただの縄だから、先に張っておける。

　踏まれて潰れた棘は、板を解いても、先の潰れた釘のまま戻ってきた。形は元どおりになるのに、傷んだところだけが残る。

　縄のほうも、草の茎に結んでは解くうちに端がほつれてきた。

　昼を回るころで、十一匹。畑の際の筋は、そのあたりでもう使われなくなっている。

```
『Lv3に上がりました』
```

　残りは、柵の途切れた先の草地で稼いだ。草が深いぶん、踏み分けの筋は畑の際よりはっきりしている。

　急所看破の白い点は、灰色狼のときより小さくて、跳ねるたびに揺れる。それでも、棘に足を取られて動きが止まった一瞬なら、もう外さなくなっていた。

　二十匹目を仕留めて、ウィンは縄を巻き取った。

　視界の端に、二つ続けて通知が浮かぶ。

```
『スキル「会心の一撃」を習得しました』
　急所を捉えた一撃が、一段深く決まるようになります
```

```
『Lv4に上がりました』
```

　一段深く。読んで、ウィンは短剣の柄を握り直した。棘に足を取られた兎へ落とした一突きが、後半はどれも一度で終わっていた。


　　　　◇


　西門をくぐってセイレスへ戻る頃には、日が傾きかけていた。

　達成報告の窓口で、受付の女性がウィンのギルド証を受け取り、端末にかざす。かざした先の表示を見て、女性は顔を上げた。

「おめでとうございます。Eランクに上がりました」

「……もう上がるんですか」

　こんなに早く動くものだとは思っていなかった。返してもらった証を覗き込むと、刻まれた文字が一つ変わっている。

「昇格された方には、報酬とは別にお渡しするものがあります」

　受付は依頼の分と、小さめの袋をもう一つ、並べて置いた。

「Eランクからは、受けられる依頼の幅が少し広がります。それと、掲示板の募集欄にお名前を出せるようになりますよ」

「募集は、当分いいです。それより、ランクの仕組みを聞いてもいいですか。何回受ければ上がる、みたいな決まりがあるんでしょうか」

「回数では決めていません。採取と討伐を一通りこなして、任せて問題ないと判断できればEランク。ここまでは、皆さんだいたいすぐですね」

「その先は、どうなるんですか」

「Dランクまでは、討伐を続けていればそう遠くありません。Cランクから、急に遠くなります」

　受付はカウンターの内側の一覧へ目を落とした。

「依頼はランクごとに分けてありますから、上がるほど選べる数も種類も増えます。Bランクのあたりからは、名指しの依頼も回ってくるようになりますね」

「名指し、というと」

「腕を見込んで、この人に頼みたい、というご指名です。ほかにも、閲覧できる資料や、通していただける場所が増えていきますよ」

「一番上は、どこまであるんですか」

「実績で登れるのはAランクまでです。……この国で、Aランクの方は百人に五人もいらっしゃいません」

　それから、少しだけ声を落とす。

「その上にSランクがありますが、あれは実績で登る枠ではないので」

「登れない枠、ですか」

「覚醒者になられた方に、自動でつくんです」

　覚醒者。初めて聞く言葉だった。

　どういう意味か訊き返そうとしたところで、受付はもう次の書類を引き寄せている。

「まずはDランクですね。頑張ってください」

　隣の「素材買取」の窓口にも寄る。二十匹ぶんの毛皮を差し出すと、係の女性はまとめて検分し、袋ごと押し返してきた。

　戻りぎわ、ウィンは掲示板の前をもう一度通った。

　群れの張り紙は、朝と同じ場所に貼られたままだった。剥がした跡もない。

　ウィンは足を止めずに、扉のほうへ歩いた。


　　　　◇


　串に刺した肉を炙る店の前で、ウィンは足を止めた。

「一本、ください」

「はいよ、まいど」

　昨日と同じやり取りで、同じ串を受け取る。香辛料の匂いが、傾いた日差しの中に立ち上った。

　噛みながら、ウィンは自分のステータスを開く。

```
ウィン
Lv4
```
