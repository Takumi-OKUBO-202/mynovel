# 第八話　試したいことが、いくつか

　ウィンが手を伸ばした張り紙には、「丘の周辺で増えすぎた獣の間引き」と書かれていた。昨日戦った灰色狼のことだ。

　剥がしかけたところで、手が止まる。隣に並んだ二枚が、目に入っていた。

```
討伐依頼(Fランク)
丘の南で群れを成し始めた灰色狼の間引き
討伐した数だけ報酬を加算します
```

```
討伐依頼(Fランク)
西の野の野兎(のうさぎ) 二十匹
畑の被害が続いているため、村からの上乗せがあります
```

　歩合のほうが、実入りはいい。相手も昨日と同じ獣だ。

　ウィンは一度そちらへ手を伸ばして、途中でやめた。

　昨日、初めて獣を仕留めたとき、肩に爪をもらっている。一頭でそれだ。二頭に前後から来られたら、そこで終わる。

　その二頭目は、足元の小石を鏃の形に変えて仕留めた。あのとき手のひらに残ったのは、鏃以外にもできることがあるはずだ、という引っかかりだった。

　群れに手を出すのは、そこを確かめてからでいい。

　試すなら、数が要る。何度も外していい相手が要る。

　ウィンは、野兎の張り紙のほうを剥がした。

「二十匹ですね。素材は持ち帰っていただいて構いません」

　受付は数を確かめて、依頼票に印を押す。

「倒すのに、コツみたいなものはありますか」

「走って追わないことです」

　即答だった。

「穴に入られたら、それきりですので。皆さん、通り道のほうを塞いでいらっしゃいますね」

　塞ぐ、という言葉が耳に残った。ウィンは礼を言って、依頼票を懐にしまった。


　　　　◇


　ギルドを出て、ウィンは広場の露店を端から覗いて回った。買ったのは、麻の縄を一巻きと、鉄の釘をひと掴み。

　昨日、自分の短剣で確かめたことが一つある。最初から自分のものなら、自分のものにする一手間が要らない。

　拾った石や枝は、その場にあるものしか選べない。だが持ち歩くものなら、形を変える前の姿を、こちらで選んでおける。

　縄と釘は、そのための元手だった。


　　　　◇


　セイレスの西門を出ると、街道の両側がしばらく畑になる。丘とは反対の方角だ。

　膝の高さの麦が風で一斉に傾き、その向こうに、柵の途切れた草地が広がっていた。

　畑の際の土が、あちこち掘り返されている。穴の口は拳ほどで、周りに囓られた根が散っていた。

　最初の一匹は、麦の列の隙間から出てきた。

　膝下ほどの灰茶色の体に、体の半分ほどもある長い耳。鼻先が二度動いて、こちらを向く。

　ウィンが一歩踏み出した瞬間、その長い耳が背中へぴたりと伏せた。

　次の瞬間には、跳んでいる。三度跳ねたときには、もう草地の真ん中にいた。

　急いで投げた短剣は、トッ、と間の抜けた音を立てて土に刺さっただけだった。

　あの長い耳が背中へ伏せるのが、逃げる合図らしい。

　ただし、伏せたのを見てから動いたのでは間に合わない。走って追わないこと、と受付が言ったのはこれだ。


　拾い直した短剣を握って、ウィンは意識を通した。

　追いつけないなら、刃のほうを伸ばせばいい。切っ先が飴のようにゆっくりと伸びていく。

　刃渡りが倍を越えたところで、手の中の重さが変わっていないことに気づいた。

　長くなったぶん、薄い。指の腹で押すと、頼りなくたわむ。

　麦の列から次の一匹が跳び出したところへ、ウィンは伸ばした刃を振り下ろした。

　届いた。届いただけだった。

　ザリッ、と刃は背中の毛を撫でて、そのまま横へ滑る。裂けもしない。

　長さは足りたのに、その先が薄すぎた。

　形は変えられても、材料そのものが増えるわけではないらしい。増えるのなら、石ころ一つから剣が作れてしまう。

　ウィンは刃を元の長さに戻して、鞘に収めた。


　ウィンは腰の袋から、買ってきた縄を取り出した。

　巻いたまま意識を通すと、一本の縄が手のひらの中でほどけるように分かれていく。

　網目を細かくするほど、一本ずつが細くなった。さっきの刃と同じだ。

　両腕を広げたくらいの、粗い網。それが、この一巻きで作れる限界だった。

　草地の一匹へ向けて投げる。網は空中で広がりきらず、バサッ、と束のまま落ちた。

　もう一度巻き直して、今度は近づいてから被せようとする。腕を上げた時点で、もう耳が伏せていた。

　投げるのも、被せるのも、向いていない。

　――通り道を塞ぐ、と言っていた。

　ウィンは膝を折って、草地を低い位置から見渡した。

　草の丈が揃っていない場所がある。踏み分けられて倒れたまま起きなくなった、幅一つ分の細い筋だ。それが穴と穴のあいだを繋いでいる。

　毎日ここを通っているなら、追われたときも同じ道を走る。

　ウィンは筋の途中に網を垂らして、両端を草の茎に引っ掛けた。それから穴のほうへ回り込み、口の前で足を踏み鳴らす。

　草の下を、何かが走る音が近づいてきた。

　だが、網の手前で音が止まる。

　灰茶色が筋から外れて、草を分けながら横へ逃げていった。

　止めようとすれば、避けられる。

　ウィンは網を外しながら、逃げていった先を目で追った。

　――止めるのではなく、跳ばせればいい。

　跳んでいるあいだなら、降りてくる場所はこちらで決められる。


　網を手に提げたまま、ウィンは腰の袋から釘をひと掴み取り出し、意識を通そうとした。

　その瞬間、パサッ、と手の中で網がほどけた。

　残ったのは、ただの縄が一巻き。

　昨日、枝と短剣で確かめたとおりだった。形を変えていられるのは、一度に一つきりだ。網を保ったままでは、釘には手が出せない。

　ウィンはしばらく、片手の縄と片手の釘を見比べていた。

　跳ばせるだけなら、網の形をしている必要はない。低く一本、張ってあればいい。

　縄は、縄のまま使う。

　そうすれば、形を変える一つ分を、釘のほうに回せる。


　ウィンは筋の途中に、縄を膝より低い高さで一本張った。倒れた草に紛れて、走ってくる側からは見えない。

　これを越えるには、一度跳ぶしかない。

　跳べば、降りてくるのは、縄から数歩先だ。

　ウィンはそこの草を掻き分けて、釘をひと掴み並べた。意識を通すと、釘は掌ほどの薄い板に集まり、上を向いた棘がずらりと並ぶ。倒れた草を戻して、板を隠す。

　残っているのは、時間だけだった。魂力が尽きれば板は釘に戻るし、この場を離れてしまえば、もう形を変え直すこともできない。

　ウィンは筋を大きく迂回して穴のほうへ戻り、息を切らしながら口の前で足を踏み鳴らした。

　草の下を走る音が、こちらから向こうへ抜けていく。

　灰茶色が筋を駆け上がり、縄の手前で体を沈めた。

　――見える。

　跳んだ体が、隠した板の上へ降りてくる。



　キッ、と短い声が上がった。

　倒れた草が撥ねて、隠していた棘の列が覗く。後ろ足がそこに乗ったまま、兎は前へ出られずに体だけを二度捻った。

　次の一跳びが、来ない。

　ウィンは踏み込んで、動きの止まった喉元へ切っ先を沈めた。

　ザクッ、と入って、そのまま光になる。

　一匹目。


　あとは、筋を変えて同じ形を組み直すだけだった。

　縄を張って、跳ばせて、降りてくる場所に棘板を置く。手順はいつも同じで、面倒なのは順番のほうだ。

　板に変えたまま走って回り込むと、着く頃には魂力が心もとない。だから釘は最後に変える。縄はただの縄なので、先に張っておける。

　踏まれて潰れた棘は、板を解いても、先の潰れた釘のまま戻ってきた。形は元どおりになるのに、傷んだところだけが残る。

　縄のほうも、草の茎に結んでは解くうちに端がほつれてきた。

　昼を回るころで、十一匹。畑の際の筋は、そのあたりでもう使われなくなっている。

```
『Lv3に上がりました』
```

　残りは、柵の途切れた先で稼ぐ。草が深いぶん、踏み分けの筋は畑の際よりはっきりしていた。

　急所看破の白い点は、灰色狼のときより小さくて、跳ねるたびに揺れる。それでも、棘に足を取られて動きが止まった一瞬なら、もう外さなくなっていた。

　二十匹目を仕留めて、ウィンは縄を巻き取った。

　視界の端に、二つ続けて通知が浮かぶ。

```
『スキル「会心の一撃」を習得しました』
　急所を捉えた一撃が、一段深く決まるようになります
```

```
『Lv4に上がりました』
```

　一段深く。読んで、ウィンは短剣の柄を握り直した。棘に足を取られた兎へ落とした一突きが、後半はどれも一度で終わっていた。


　　　　◇


　西門をくぐってセイレスへ戻る頃には、日が傾きかけていた。

　達成報告の窓口で、受付の女性がウィンのギルド証を受け取り、端末にかざす。かざした先の表示を見て、女性は顔を上げた。

「おめでとうございます。Eランクです」

「……もうですか」

　こんなに早く上がるものだとは思っていなかった。返してもらった証を覗き込むと、刻まれた文字が一つ変わっている。

「昇格された方には、報酬とは別にお渡しするものがありますので」

　受付は依頼の分と、小さめの袋をもう一つ、並べて置いた。

「Eになると、受けられる依頼の幅が少し広がります。あとは、掲示板の募集欄に自分の名前を出せるようになりますよ」

「今のところは、一人でいいです」

　女性は気を悪くした様子もなく頷いた。

「何回受ければ上がる、みたいな決まりがあるんですか」

「回数では決めていません。採取と討伐を一通りこなして、任せて問題ないと判断できればEです。ここまでは、皆さんだいたいすぐですね」

「その先は」

「Dまでは、討伐が続いていればそう遠くありません。Cから急に遠くなります」

　受付はカウンターの内側の一覧へ目を落とした。

「依頼はランクごとに分けてあります。上がるほど、選べる数も種類も増えますよ。Bのあたりからは、名指しで人を探す依頼も回ってくるようになります」
