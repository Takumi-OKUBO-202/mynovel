# 第八話　試したいことが、いくつか

　ウィンが手を伸ばした張り紙には、「丘の周辺で増えすぎた獣の間引き」と書かれていた。昨日戦った灰色狼のことだ。

　剥がしかけたところで、手が止まる。隣に並んだ二枚が、目に入っていた。

```
討伐依頼(Fランク)
丘の南で群れを成し始めた灰色狼の間引き
討伐した数だけ報酬を加算します
```

```
討伐依頼(Fランク)
西の野の野兎(のうさぎ) 二十匹
畑の被害が続いているため、村からの上乗せがあります
```

　歩合のほうが、実入りはいい。相手も昨日と同じ獣だ。

　ウィンは一度そちらへ手を伸ばして、途中でやめた。

　昨日、初めて獣を仕留めたとき、肩に爪をもらっている。一頭でそれだ。二頭に前後から来られたら、そこで終わる。

　自分の手数では、一度に一匹しか捌けない。それは昨日はっきりした。

　――今日は、一度に相手にできる数を増やしたい。

　昨日、足元の小石を鏃の形に変えて、二頭目を仕留めた。あのとき手のひらに残ったのは、鏃以外にもできることがあるはずだ、という引っかかりだった。

　試すなら、数が要る。何度も外していい相手が要る。

　ウィンは、野兎の張り紙のほうを剥がした。

「二十匹ですね。素材は持ち帰っていただいて構いません」

　受付は数を確かめて、依頼票に印を押す。

「倒すのに、コツみたいなものはありますか」

「走って追わないことです」

　即答だった。

「穴に入られたら、それきりですので。皆さん、通り道のほうを塞いでいらっしゃいますね」

　塞ぐ、という言葉が耳に残った。ウィンは礼を言って、依頼票を懐にしまった。


　　　　◇


　ギルドを出て、ウィンは広場の露店を端から覗いて回った。買ったのは、麻の縄を一巻きと、鉄の釘をひと掴み。

　昨日、自分の短剣で確かめたことが一つある。最初から自分のものなら、自分のものにする一手間が要らない。

　拾った石や枝は、その場にあるものしか選べない。だが持ち歩くものなら、形を変える前の姿を、こちらで選んでおける。

　縄と釘は、そのための元手だった。


　　　　◇


　セイレスの西門を出ると、街道の両側がしばらく畑になる。丘とは反対の方角だ。

　膝の高さの麦が風で一斉に傾き、その向こうに、柵の途切れた草地が広がっていた。

　畑の際の土が、あちこち掘り返されている。穴の口は拳ほどで、周りに囓られた根が散っていた。

　最初の一匹は、麦の列の隙間から出てきた。

　膝下ほどの灰茶色の体に、体の半分ほどもある長い耳。鼻先が二度動いて、こちらを向く。

　ウィンが一歩踏み出した瞬間、その長い耳が背中へぴたりと倒れた。

　次の瞬間には、跳んでいる。三度跳ねたときには、もう草地の真ん中にいた。

　急いで投げた短剣は、トッ、と間の抜けた音を立てて土に刺さっただけだった。

　耳が倒れたら、もう遅い。走って追わないこと、と受付が言ったのはこれだ。


　拾い直した短剣を握って、ウィンは意識を通した。

　追いつけないなら、刃のほうを伸ばせばいい。切っ先が飴のようにゆっくりと伸びていく。

　刃渡りが倍を越えたところで、手の中の重さが変わっていないことに気づいた。

　長くなったぶん、薄い。指の腹で押すと、頼りなくたわむ。

　麦の列から次の一匹が跳び出したところへ、ウィンは伸ばした刃を振り下ろした。

　届いた。届いただけだった。

　ザリッ、と刃は背中の毛を撫でて、そのまま横へ滑る。裂けもしない。

　長さは足りたのに、その先が薄すぎた。

　形は変えられても、材料そのものが増えるわけではないらしい。増えるのなら、石ころ一つから剣が作れてしまう。

　ウィンは刃を元の長さに戻して、鞘に収めた。


　ウィンは腰の袋から、買ってきた縄を取り出した。

　巻いたまま意識を通すと、一本の縄が手のひらの中でほどけるように分かれていく。

　網目を細かくするほど、一本ずつが細くなった。さっきの刃と同じだ。

　両腕を広げたくらいの、粗い網。それが、この一巻きで作れる限界だった。

　草地の一匹へ向けて投げる。網は空中で広がりきらず、バサッ、と束のまま落ちた。

　もう一度巻き直して、今度は近づいてから被せようとする。腕を上げた時点で、もう耳が倒れていた。

　投げるのは、向いていない。

　ウィンは網を引き寄せながら、掘り返された土のほうへ目を戻した。

　穴は、三歩ほど離れて二つ並んでいる。掘り出された土が片方の口にだけ盛られていて、もう片方の口は平らだった。中で繋がっていて、片方が出口として使われている。

　入り口から追い立てれば、出口から出てくる。

　ウィンは出口の口に網を広げ、四隅を草の茎に引っ掛けた。それから畑を回り込んで、入り口の前で足を踏み鳴らす。

　草の下を、何かが走る音が抜けていった。

　網が、内側から膨れる。

　絡まって跳ねている喉元が、周りより白く浮かんで見えた。ウィンは網ごと押さえて、そこへ切っ先を落とす。

　一匹。

　だが、この手が使えるのは、繋がった二つの穴を見つけたときだけだった。ほかの穴から追い立てても、兎はどこか別の口から出て、そのまま草地へ逃げていく。

　網は一つきりで、穴は野じゅうにある。


　網を張ったまま、ウィンは腰の袋から釘をひと掴み取り出し、意識を通そうとした。

　その瞬間、後ろでパサッ、と音がした。

　振り返ると、張ってあった網がただの縄に戻って、草の上に落ちている。

　昨日、枝と短剣で確かめたとおりだった。形を変えていられるのは、一度に一つきりだ。網を保ったままでは、釘には手が出せない。

　ウィンはしばらく、片手の縄と片手の釘を見比べていた。

　網が要るのは、逃げ道を塞ぐためだ。だが、塞ぐだけなら網の形をしている必要はない。

　縄は、縄のまま張ればいい。

　そうすれば、形を変える一つ分を、釘のほうに使える。


　ウィンは縄を解いて、穴の口から三歩ほど先に、地面すれすれで一本張った。草の穂に隠れて、膝より下の高さだ。

　走ってきた兎が、これを越えるには一度跳ぶしかない。

　そして跳べば、着地する場所はもう決まっている。

　ウィンはその着地点の落ち葉をどけて、釘をひと掴み並べた。意識を通すと、釘は掌ほどの薄い板に集まって、上を向いた棘がずらりと並ぶ。落ち葉を戻して、板を隠す。

　残っているのは、時間だけだった。魂力が尽きれば板は釘に戻るし、この場を離れてしまえば、もう形を変え直すこともできない。

　ウィンは畑を回り込み、息を切らして反対側の穴まで戻ると、その口の前で足を踏み鳴らした。

　土の下を走る音が、こちらから向こうへ抜けていく。

　灰茶色が穴から飛び出した。三歩先の縄を見て、体を一度沈める。

　――見える。

　跳んだ体が、落ち葉の上へ降りてくる。



　キッ、と短い声が上がった。

　落ち葉が撥ねて、隠していた棘の列が覗く。後ろ足がそこに乗ったまま、兎は前へ出られずに体だけを二度捻った。

　次の一跳びが、来ない。

　ウィンは踏み込んで、動きの止まった喉元へ切っ先を沈めた。

　ザクッ、と入って、そのまま光になる。

　二匹目。


　あとは、穴を変えて同じ形を組み直すだけだった。

　縄を張って、跳ばせて、着地点に棘板を置く。手順はいつも同じで、面倒なのは順番のほうだ。

　板に変えたまま走って回り込むと、着く頃には魂力が心もとない。だから釘は最後に変える。縄はただの縄なので、先に張っておける。

　繋がった二つの穴を見つけたときだけは、棘板を使わずに出口へ網を張る。そのときは、釘を袋へ戻してから縄に意識を通した。

　昼を回るころで、十一匹。畑の際の穴は、そのあたりでもう掘り返されなくなっている。

```
『Lv3に上がりました』
```

　残りは、柵の途切れた先の草地で稼ぐ。畑と違って土が固く、穴は浅い。そのぶん出口が見つけやすい。

　急所看破の白い点は、灰色狼のときより小さくて、跳ねるたびに揺れる。それでも、棘に足を取られて動きが止まった一瞬なら、もう外さなくなっていた。

　二十匹目を仕留めて、ウィンは縄を巻き取った。

　視界の端に、二つ続けて通知が浮かぶ。

```
『スキル「会心の一撃」を習得しました』
　急所を捉えた一撃が、一段深く決まるようになります
```

```
『Lv4に上がりました』
```

　一段深く。読んで、ウィンは短剣の柄を握り直した。棘に足を取られた兎へ落とした一突きが、後半はどれも一度で終わっていた。


　　　　◇


　西門をくぐってセイレスへ戻る頃には、日が傾きかけていた。

　達成報告の窓口で、受付の女性がウィンのギルド証を受け取り、端末にかざす。かざした先の表示を見て、女性は顔を上げた。

「おめでとうございます。Eランクです」

「……もうですか」

　こんなに早く上がるものだとは思っていなかった。返してもらった証を覗き込むと、刻まれた文字が一つ変わっている。

「昇格された方には、報酬とは別にお渡しするものがありますので」

　受付は依頼の分と、小さめの袋をもう一つ、並べて置いた。

「Eになると、受けられる依頼の幅が少し広がります。あとは、掲示板の募集欄に自分の名前を出せるようになりますよ」

「今のところは、一人でいいです」

　女性は気を悪くした様子もなく頷いた。

「何回受ければ上がる、みたいな決まりがあるんですか」

「回数では決めていません。採取と討伐を一通りこなして、任せて問題ないと判断できればEです。ここまでは、皆さんだいたいすぐですね」

「その先は」

「Dまでは、討伐が続いていればそう遠くありません。Cから急に遠くなります」

　受付はカウンターの内側の一覧へ目を落とした。

「依頼はランクごとに分けてあります。上がるほど、選べる数も種類も増えますよ。Bのあたりからは、名指しで人を探す依頼も回ってくるようになります」

「名指し」

「腕を見込んで、この人に頼みたいという方がいらっしゃるんです。あとは、閲覧できる資料や、通していただける場所も増えますよ」

「一番上は」

「実績で登れるのはAまでです。……この国で、Aの方は百人に五人もいらっしゃいません」

　それから、少しだけ声を落とす。

「その上にSがありますが、あれは実績で登る枠ではないので」

「登れないんですか」

「覚醒者になられた方に、自動でつくんです」

　覚醒者。初めて聞く言葉だった。

　訊き返そうとしたところで、受付はもう次の書類を引き寄せている。

「まずはDですね。頑張ってください」

　隣の「素材買取」の窓口にも寄る。二十匹ぶんの毛皮を差し出すと、係の女性はまとめて検分し、袋ごと押し返してきた。

　戻りぎわ、ウィンは掲示板の前をもう一度通った。

　群れの張り紙は、朝と同じ場所に貼られたままだった。剥がした跡もない。

　ウィンは足を止めずに、扉のほうへ歩いた。


　　　　◇


　串に刺した肉を炙る店の前で、ウィンは足を止めた。

　昨日はここで、買うかどうかをずいぶん迷った。

「一本、ください」

「はいよ、まいど」

　受け取った串は、昨日と同じように少し硬い。香辛料の匂いが、傾いた日差しの中に立ち上る。

　噛みながら、ウィンは自分のステータスを開く。

```
ウィン
Lv4
職業:暗器使い
ソウルクレスト:彼は誰(かはたれ)

スキル:投擲、隠密行動、生成(暗器)、調合(毒)、急所看破、会心の一撃
```

　串を食べ終えて、ウィンは朝に縄を買った露店へ戻った。

　袋から出した縄は、張り替えを繰り返したせいで端が毛羽立っている。釘は、半分ほどが曲がって使い物にならない。

　ウィンは同じ縄をもう一巻きと、釘をひと掴み買い足した。
