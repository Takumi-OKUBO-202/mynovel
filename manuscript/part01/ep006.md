# 第六話　借りものの刃

　冒険者ギルドの受付で薬草の採取先を尋ねると、案内係は地図を広げて丁寧に印をつけてくれた。街の南、なだらかな丘を越えた先の草原らしい。

　セイレスの門をくぐると、石畳の道はすぐに踏み固められた土の道に変わった。

　戦う前に、まず自分の力がどんなものか確かめておきたい。そんな考えが、門を出てすぐ頭をよぎった。丘までの道すがら、少し寄り道をする余裕くらいはあるはずだ。

　アルディアに降り立ってから、まだ数時間しか経っていない。それでも冬夜は、自分のクレストがどんな力なのか、なんとなく見当がついていた。

　自分のものではない道具や、持ち主のいない物を一時的に「借り」、借りている間はその形を思い通りに「変え」られる。使い終えたら「返す」と、借りたものは元の姿にひとりでに戻る――そういう力らしい。

　誰かに説明された覚えはない。ステータス画面のクレスト欄には、名前が並んでいるだけで、効果の説明は空欄のままだった。

　それでも、アルディアに降り立った直後から、頭の隅に何かがすとんと収まったような感覚がずっと続いていた。物珍しさに紛れてろくに気にも留めていなかったが、今にして思えば、あれがこの力の使い方を教えてくれていたのかもしれない。



　道端に落ちていた枯れ枝に目を留める。誰の持ち物でもない、ただ転がっていただけのものだ。冬夜は枝に向かって、「借りる」をそっと思い描いてみた。

　体のどこかが、やり方だけはもう知っているとでも言うように動く。頭で思い描いていた通りの手応えが、寸分の狂いもなく指先に返ってくる。

　手の甲の紋章が、かすかに熱を持つ。淡い光を帯びて輪郭が浮かび上がったかと思うと、次の瞬間、枯れ枝がふわりと宙に浮き、まるで手の中にあるかのような感覚が伝わってきた。誰かに断りを入れる必要すらないのに、「盗る」ではなく「借りる」という言葉が自然と浮かぶあたり、我ながら律儀というか、妙なところで日本人らしいなと冬夜は思う。

　次は「変える」だ。棒状のそれを、もう少し武器らしい形にできないか。冬夜は枝の先端が薄く鋭くなる様子を思い描く。枝は粘土のように輪郭を崩し、思い描いた通り、片刃の小さな刃物のような形に変わっていった。素材はあくまで木のままらしく、切れ味はあまり期待できそうにない。

　試しに、意識を緩めて枝を手放してみる。宙に浮いていた感覚がふっと消え、枝は元のただの棒切れに戻って地面に落ちた。借りて、変えて、使って、返せば元に戻る――その一連の流れはなぜか最初から知っていたことのように腑に落ちた。

　ここまでは、なんとなく予感していた通りの結果だ。次は、自分の持ち物でも同じことができるのか試してみる。腰の短剣を一本抜き、刃の幅を少しだけ変えることを思い描いてみた。

　こちらは呆気ないほど素直に応じた。手の甲の紋章がまた薄く光っただけで、「借りる」の一手間を挟む必要すらなく、最初から自分のものは当たり前のように姿を変える。

　次は道端の雑草にも「借りる」を向けてみる。だが何の手応えもない。感覚そのものが空振りするような感触で、雑草にはまるで働きかけられなかった。根を張って生きているものは対象外らしい、とここで確認が取れた。

　もう一つ、確かめたいことがある。短剣を変形させたまま、今度は落ちていた小枝にも「借りる」を向けてみた。すると、握っていたはずの短剣の変形がふっと解け、元の形に戻ってしまう。どうやら、一度に姿を変えられるのは一つだけらしい。欲張って両方は無理、ということのようだ。

　枝を刃物に変えたまま、しばらく歩いてみることにする。数十秒ほど経った頃だろうか、何の前触れもなく、刃物の形がひとりでに崩れて元の枝に戻った。同時に、手の甲でずっと灯っていた紋章の光も、すっと消えていることに気づく。手放したつもりはないのに、と首をかしげたところで、視界の端のステータス表示に目が留まる。魂力(SP)の数値がゼロになっていた。

　どうやら、形を変えた状態を保つには魂力を使い続けるらしい。手持ちの魂力では、せいぜい一分程度しか保たないということか。ゼロになった数値は、歩いているうちに、ほんの少しずつではあるが回復していくのが見て取れた。

　使えるような、使えないような。結局のところ、自分次第だなあ、というのが率直な感想だった。動画で見た上位プレイヤーたちの、光を撒き散らすような派手な必殺技とは、明らかに毛色が違う。地味で、制約だらけで、それでも――工夫のしがいだけは、やたらとありそうな力だった。



　その後もクレストの検証をしながら歩いていると、丘の斜面に差しかかったところで、茂みの奥から低い唸り声が聞こえた。

　姿を現したのは、中型犬ほどの大きさの、灰色の毛並みをした獣だった。ガイドで見た「初心者向けモンスター」の一覧に、似たような絵が載っていた気がする。

　さほど強くはないはずだが、実際に対峙するのは初めてだ。心臓が、思っていたより速く音を立てている。

　冬夜は短剣を構えたが、すぐに思い直して、腰を落としたまま距離を取った。自分は真正面からやり合うタイプの戦い方ではない。相手の出方を伺うことにした。

　獣が飛びかかってくる。冬夜は横に転がるようにして避けたつもりだったが、避けきれなかった爪先が肩をかすめた。じわりと熱いような痛みが走り、思わず息が詰まる。

　――甘く見ていた。

　体勢を崩しかけたところを、なんとか堪える。獣が二撃目を繰り出そうと構え直す、その一瞬の隙。冬夜は痛みを押し殺し、低く滑り込むように懐へ潜り込んだ。狙うのは、獣の喉元。

　短剣の切っ先が、寸分違わずそこを捉える。獣は悲鳴を上げる間もなく、光の粒子になって消えていった。

　視界の端に、見慣れない通知が二つ並んで浮かぶ。

『Lv2に上がりました』
『スキル「急所看破」を習得しました』

　急所を的確に捉えた一撃が、何か特別な判定を受けたらしい。詳しい効果までは書かれていなかったが、狙って急所を突けば、それだけ手応えが変わるということなのだろう。冬夜は肩の痛みをさすりながら、その一文をもう一度読み返した。一撃をもらってからでないと得られないものがある、というのも、いかにも自分らしい気がした。

　通知に続けて、ステータスポイントを割り振る画面が浮かぶ。

```

獲得ポイント　自動:20　割り振り可能:20
```

　自動で割り振られる分は、暗器使いという職業の適性に応じて勝手に配分されるらしい。残りの二十点は、好きに使っていいという。冬夜は少し考えてから、素早さと器用さに均等に注ぎ込むことにした。

　うまく避けきれなかった爪先の一撃と、急所を的確に捉えた最後の一手。今日の戦いで痛感したのは、その二つの差だった。避ける速さと、狙った通りに動かせる手先の感覚――伸ばすなら、まずはそこからだと思った。

　その後、似たような獣にもう一体遭遇した。距離を詰める前に、ふと思い立って「借りる」を獣そのものに向けてみる。だが、やはり何の手応えもない。さっきの雑草と同じ空振りの感触に、生きているものは軒並み対象外らしいと改めて確信が持てた。

　早々に見切りをつけ、代わりに足元の小石へ意識を向ける。「借りる」、そして「変える」。手のひらほどの石が、薄い刃を持った鏃のような形に姿を変えた。

　獣が飛びかかってくるより先に、冬夜は身を低くして間合いを外す。狙うのは、さっき短剣で仕留めた時と同じ喉元――だが今度は、投げる。手首を返す動きひとつで、変形させた石が唸りを上げて宙を裂いた。

　狙った通りの場所に突き立ち、獣は声を上げる間もなく光の粒子になって消えていく。形を変えたことで殺傷能力を持つ武器となり、投擲スキルも上手く発動したようだった。


　薬草の群生地は、丘を越えてすぐに見つかった。青みがかった葉に、淡く発光する筋が走っている。案内係に見せてもらった見本の絵とじっくり見比べると、探していたものだとすぐに見分けがついた。

　摘み取ろうとしたところで、葉の縁に視線を近づけると、小さな説明文がふわりと浮かぶことに気づく。『傷薬の材料になる薬草。ただし、生のまま多量に摂取すると毒にもなる』。冬夜は思わず葉を摘む手を止めた。

　傷を癒す薬にも、毒にもなる。自分が持っている「毒の調合」というスキルのことが、ふと頭をよぎる。使い道は一つとは限らないらしい、というのは、この葉にも自分にも当てはまる話のような気がした。

　依頼で必要な数はとうに到達している。それでも冬夜は、指定された量より少し多めに摘んでおくことにした。何かの拍子に役立つかもしれない、という程度の、軽い判断だった。屈んで葉を摘む作業自体は、現実の草むしりと大差ない。十分な量の薬を確保する頃には、日が高く昇っていた。



　セイレスの門をくぐり、冒険者ギルドへ向かう。「依頼達成報告」の窓口に薬草の束を差し出すと、受付係は数を数えてから、あっさりとした調子で「確かに受領しました」と告げた。派手な演出は何もない。それでも冬夜は、その地味なやり取りを、しばらく反芻していた。

　報酬はたったの500Y、だが今の自分には十分すぎるくらいの収穫に思えた。窓の外はすでに夕方に近い色をしている。

　――今日はこのくらいにして、ログアウトしよう。

　冬夜はそう決めると、ギルドの扉をくぐって、光の中へ意識を委ねた。
