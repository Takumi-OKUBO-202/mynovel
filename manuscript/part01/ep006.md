# 第六話　借りものの刃

　出がけに薬草の採取先を尋ねると、案内係は地図を広げて丁寧に印をつけてくれた。街の南、なだらかな丘を越えた先の草原だという。

　礼を言って外へ出ると、大通りは相変わらず人で埋まっていた。荷車が石畳を鳴らし、屋台の煙が横切っていく。

　その流れに乗って南へ歩くうち、建物の背が少しずつ低くなっていった。

　突き当たりに、街を囲む石壁が見えてくる。門は荷車が二台すれ違っても余る幅で、人と荷が両側に分かれて出入りしていた。

　門をくぐると、石畳の道はすぐに踏み固められた土の道に変わる。

　丘までは、まだ距離がある。戦う前に、自分の力がどんなものなのか確かめておきたかった。

　とはいえ、何をどうすればいいのかも分からない。ステータス画面のクレスト欄は、名前があるだけで効果は空欄のままだ。

　それでも、歩いているうちに妙な感じがしてきた。

　目に入るものの一つひとつに、何かできる気がする。足元の小石にも、落ち葉にも、道端に転がった枯れ枝にも。

　ウィンは足を止め、その枯れ枝を拾い上げた。当たり前だが、誰の持ち物でもない。ただ転がっていただけのものだ。

　もう少し武器らしくならないか。先端が薄く鋭くなる様子を、頭の中で描いてみる。

　手の甲の紋章が、かすかに熱を持った。

　枝は粘土のように輪郭を崩し、思い描いた通り、片刃の小さな刃物の形に変わっていく。素材はあくまで木のままで、切れ味はあまり期待できそうにない。

　そこでようやく、ウィンは思い当たる。この街に降り立った瞬間から、頭の隅に何かがすとんと収まったような感覚がずっと続いていた。物珍しさに紛れてろくに気にも留めていなかったが、あれがやり方を教えていたのだろうか。

　面白くなって、ウィンは二度、三度と形を変えてみる。刃は思うままに反り、細くなり、また元の太さに戻った。

　試しに、意識を緩めてみる。刃は輪郭を崩し、ただの棒切れに戻った。

　握っているのは、拾ったときと同じ枯れ枝だ。

　借り物だな、とウィンは思う。手の中にあっても、自分のものでいるのは意識を向けているあいだだけらしい。

　持ち主のいないものを、しばらく自分のものにする。この力がやっているのは、たぶんそれだ。

　次は、自分の持ち物でも同じことができるのか試してみる。腰の短剣を一本抜き、刃の幅を少しだけ変えることを思い描いてみた。

　こちらは呆気ないほど素直に応じた。手の甲の紋章がまた薄く光っただけで、形が変わっていく。

　最初から自分のものなら、自分のものにする手間が要らない。当たり前といえば、当たり前の話だ。

　次は、道端の雑草でも同じことができるか試してみる。だが何の手応えもない。

　向けた意識が、そのまま空を切る。角度を変えて何度試しても、同じだった。

　もう一つ、確かめたいことがある。短剣を変形させたまま、今度は落ちていた小枝にも同じことをしてみた。すると、握っていたはずの短剣の変形がふっと解け、元の形に戻ってしまう。

　一度に姿を変えられるのは、一つだけ。

　枝を刃物に変えたまま、しばらく歩いてみることにする。数十秒ほど経った頃だろうか、何の前触れもなく、刃物の形がひとりでに崩れて元の枝に戻った。同時に、手の甲でずっと灯っていた紋章の光も、すっと消えている。

　手放したつもりはないのに、と首をかしげたところで、視界の端に細い帯が一本あることに気づいた。街に降りてからずっとそこにあったはずなのに、一度も目を留めていなかったものだ。

　見ると、帯の脇に『魂力』とだけ表示が出る。帯は端まで空になっていた。

　ステータス画面を開いて、詳細のほうに切り替えてみる。街で見たときの簡素な一覧の下に、STR、AGI、DEX、INT、VIT、LUK——見慣れない略号がずらりと並んでいた。

　どれも、初心者らしい心もとない数字だ。

　魂力の欄には、クレストを使っているあいだ減り続ける、と説明が添えられている。

　形を変えたままにしておくには、これを注ぎ続けることになる。今の自分では、せいぜい一分ほどが限度だ。空になった帯は、歩いているうちに少しずつ戻っていく。

　使えるような、使えないような。結局のところ、自分次第だなあ、というのが率直な感想だった。

　あの映像で見た、光を撒き散らすような派手さとは明らかに毛色が違う。地味で、制約だらけで、それでも――工夫のしがいだけは、やたらとありそうな力だった。

　その後もクレストを試しながら歩いていると、丘の斜面に差しかかったところで、茂みの奥から低い唸り声が聞こえた。

　姿を現したのは、中型犬ほどの大きさの、灰色の毛並みをした獣だった。ガイドで見た「初心者向けモンスター」の一覧に、似たような絵が載っていた気がする。

　さほど強くはないはずだが、実際に対峙するのは初めてだ。心臓が、思っていたより速く音を立てている。

　ウィンは短剣を構えたが、すぐに思い直して、腰を落としたまま距離を取った。まずは相手の出方を伺う。

　獣が飛びかかってくる。ウィンは横に転がるようにして避けたつもりだった。

　ザッ、と爪先が肩をかすめる。

　痛い。

　ゲームなのに、と思うより先に、体のほうが勝手に縮こまっていた。現実で刃物を滑らせたときと同じ、遅れてじわりと広がってくる熱だ。

　――甘く見ていた。

　体勢を崩しかけたところを、なんとか堪える。ガッ、と爪が土を掻いて、獣が二撃目に構え直した。その一瞬の隙。

　ウィンは痛みを押し殺し、低く滑り込むように懐へ潜り込んだ。狙うのは、獣の喉元。

　短剣の切っ先が、寸分違わずそこを捉える。

　ズッ、と入った。

　声はなかった。獣の体が一度だけ大きく跳ね、輪郭の端から光にほどけて消える。

　ウィンはしばらく、突き出した姿勢のまま動けなかった。

　さっきまで喉があったところには、もう何もない。手応えだけが、腕の中に残っている。

　勝った、と思うより先に、肩が痛んだ。

　粒子が薄れた地面には、小さな牙が一本だけ残っている。

　ウィンはそれを拾い上げた。手に取った途端、視界の端にインベントリの一覧がふわりと浮かび、「灰色狼の牙」という項目が一つ増える。

　続けて、見慣れない通知が二つ並んだ。

```
『Lv2に上がりました』
『スキル「急所看破」を習得しました』
```

　急所を的確に捉えた一撃が、何か特別な判定を受けたのだろう。詳しい効果までは書かれていないが、狙って急所を突けば、それだけ手応えが変わるということだ。

　伸びるところは自分で選べない、とガイドにあった。職業と、その日の戦い方を見て、勝手に振り分けられるらしい。暗器使いなら、速さや手先に寄っていくのだろうか。

　ウィンは肩の痛みをさすりながら、その一行をもう一度読み返した。

　肩の傷はまだじんわりと熱を持っている。ウィンは腰の小瓶から傷薬(小)を一本取り出し、傷口に垂らした。

　ひやりとした感触の後、じわりとした温かさが広がり、浅い傷はものの数秒で塞がっていく。買った時は半信半疑だったが、思っていたよりずっとよく効く。残る傷薬は一本だけになった。

　その後、似たような獣にもう一体遭遇した。距離を詰める前に、ふと思い立って、獣そのものに力を向けてみる。

　やはり何の手応えもない。さっきの雑草と、そっくり同じ空振りだった。

　二度続けて同じなら、そういうことなのだろう。生きているものには、この力は届かない。

　早々に見切りをつけ、代わりに足元の小石へ意識を向ける。自分のものにして、形を変える。手のひらほどの石が、薄い刃を持った鏃のような形に姿を変えた。

　獣が飛びかかってくるより先に、ウィンは身を低くして間合いを外す。狙うのは、さっき短剣で仕留めた時と同じ喉元――だが今度は、投げる。

　手首を返す動きひとつ。ヒュッ、と石が宙を裂く。

　ドッ、と狙った場所に突き立った。獣が声もなく光にほどけていく。

　形を変えれば、それだけで武器になる。投擲のスキルも、きちんと乗っている。

　地面には今回も、牙が一本残っていた。

　変形させた石は消えてしまったが、牙のほうは律儀に残る。ウィンはそれも拾い、インベントリに収めた。


　　　　◇


　薬草の群生地は、丘を越えてすぐに見つかった。青みがかった葉に、淡く発光する筋が走っている。案内係に見せてもらった見本の絵と見比べると、探していたものだとすぐに見分けがついた。

　摘み取ろうとしたところで、葉の縁に視線を近づけると、小さな説明文がふわりと浮かぶことに気づく。『傷薬の材料になる薬草。ただし、生のまま多量に摂取すると毒にもなる』。ウィンは思わず葉を摘む手を止める。

　傷を癒す薬にも、毒にもなる。自分が持っている「調合(毒)」というスキルのことが、ふと頭をよぎった。

　使い道は一つとは限らない。この葉にも、たぶん自分にも当てはまる話だった。

　摘み始めてしまえば、作業自体は現実の草むしりと大差ない。屈んで、根元から折って、束にしていく。

　指定された数が揃った頃には、日がだいぶ高くなっていた。

　ウィンはそこで手を止めず、もう少しだけ摘んでおくことにする。何かの拍子に役立つかもしれない、という程度の、軽い判断だ。


　　　　◇


　セイレスの門をくぐり、冒険者ギルドへ向かう。「依頼達成報告」の窓口に薬草の束を差し出すと、受付係は数を数えてから、あっさりとした調子で「確かに受領しました」と告げた。

　派手な演出は何もない。それでもウィンは、その地味なやり取りを、しばらく反芻していた。

　報酬は驚くほど少なかった。討伐依頼に比べれば地味な実入りだが、今の自分にはそれでも十分ありがたい収穫に思える。窓の外はすでに夕方に近い色をしている。

　ついでに、隣の「素材買取」の窓口にも寄ってみる。インベントリに残っていた牙を二つ差し出すと、係の女性は値踏みするように一瞥し、「灰色狼の牙ですね」とだけ言って小銭を渡してくれた。二匹分にしては安い気もしたが、拾っておいて損はなかった。

　そのまま薬屋に立ち寄り、使ってしまった傷薬(小)を一本買い足す。ちょうど牙の代金と同じだけ引かれて、財布の中身は増えも減りもしなかった。これでまた二本、手つかずの傷薬が揃う。

　――今日はこのくらいにして、ログアウトしよう。

　人通りの少ない路地に入り、視界に浮かんだ表示に触れる。

　夕暮れの匂いも、遠くの呼び込みの声も、端から順に薄れていく。

　最後に消えたのは、右手の甲の感覚だった。
