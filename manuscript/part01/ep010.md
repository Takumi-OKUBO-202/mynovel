# 第十話　仕込みと手仕事

　猪の討伐報告を終えたばかりの掲示板の前で、依頼の一覧を眺めていたウィンは、ふと手を止めた。

　どれも見覚えのある内容ばかりだ。灰色狼の間引き、薬草の追加採取、猪型の討伐――ここ数日でさんざん繰り返してきた仕事と、大差ない。

　それより先に、片付けておきたいことがある。ウィンはインベントリのウィンドウを呼び出した。灰色狼の牙が三つ、猪の牙が一つ、そして薬草採取のときに指定数より多めに摘んでおいた分の余りが、そのまま眠っている。

　調合(毒)、生成(暗器)。ステータス画面の隅に並んでいるのを見るたびに気になっていたスキルだ。生の薬草を多めに摂ると毒になる、とあの時の説明文にはあった。

　牙だって、ただ売るだけよりましな使い道があるかもしれない。



　まずは素材買取の窓口に寄り、灰色狼の牙を二つだけ売った。受付の職員は慣れた手つきで牙を検分し、しめて小銭を渡してくる。牙一つと猪の牙、それに薬草の余りはそのままインベントリに残しておいた。

　ギルドを出たついでに、ウィンは隣の防具屋を覗いてみることにした。投擲ナイフを買った時から、身軽さを損なわない防具があれば、と少し気になっていたのだ。

　店先に吊るされていたのは、革を薄く何枚も重ねた造りの上着だった。見た目ほど重くなく、袖を通してみても動きを妨げる感じはしない。

「それ、軽装のわりに当たりに強いぞ。急所さえ庇えば、多少の一撃じゃ貫通しない」

　店主にそう勧められ、値札を確認する。安い。派手な防御力があるわけでもない。

　それでも、身のこなしを犠牲にせず耐久を底上げできるなら悪くない。ウィンは迷わず買い、その場で着込んだ。

　次に向かったのは、薬屋の並びにあるという小さな道具屋だった。看板には小瓶とすり鉢の絵が描かれている。中に入ると、棚には大小の空き瓶やすり鉢、丸めた布切れの束などが所狭しと並んでいた。

「調合か? それとも加工かい」

　店主に聞かれ、ウィンは「両方、初めてで」と正直に答える。店主はこともなげに小瓶を二つ、すり鉢をひとつ、布切れの束をひとつ、カウンターに並べた。

「これだけあれば、簡単なやつは何とかなる。あとは腕次第だな」

　会計を終えると、手持ちから道具代が引かれた。上着を買った直後だけに、痛くないと言えば嘘になるが、大した出費でもない。



　人通りの少ない裏道の隅にしゃがみ込み、ウィンは攻略サイトで読んだ手順を頭の中でなぞる。薬草をすり鉢で細かくすり潰し、牙をほんの少し削って粉にして混ぜ、布切れで濾して小瓶に移す――手順そのものは単純だった。

　すり鉢の中で葉が潰れると、青い草の匂いが立った。指に移った汁は、擦っても落ちそうにない。

　最初の一回は、薄すぎた。濾した液は水のようにさらさらで、指先につけてもすぐに垂れてしまう。

```
『粗悪な毒液を作成しました』
```

　視界に浮かんだ表示に、ウィンは思わず苦笑する。粉の量が足りなかったのか、すり潰し方が甘かったのか。

　牙の粉をもう少し足し、すり鉢を握る手に力を込め、丁寧に、根気よく潰し直す。手先の感覚を頼りに配分を変えていく作業は、思っていたよりずっと地味で、しかし嫌いではなかった。

　二度目は、とろりとした黒みがかった緑色の液体ができた。鼻を近づけると、青い匂いの奥に、鉄に似たものが混じっている。牙のほうだ。

```
『毒(小)を作成しました』
```

　小瓶の中でゆっくりと波打つそれに、布切れの端をひたして刃の表面に薄く塗ってみる。乾く前の液は刃にしっかりと絡みつき、簡単には落ちなかった。これは、ナイフの刃に塗って使えるということらしい。

　塗ってから時間が経つと効果が薄れる、と攻略サイトにはあった。使う直前に塗り直す運びになりそうだと、ウィンは頭の中で段取りを組み立てる。



　毒の目処が立ったところで、ウィンはいったん手を止めて息をついた。今日はもう一つ、試したいことが残っている。すり鉢や布切れをそのままに、今度は生成(暗器)に取りかかることにした。

　残しておいた猪の牙は、灰色狼のものよりずっと大きく、湾曲した硬い作りをしている。

　すり鉢の縁でこすって形を整え、先端を薄く鋭く削り出す。削るたびに白い粉が膝に散り、指の腹がざらついた。

　柄になる部分には余った布切れを巻きつけて、握りやすくする。爪で弾くと、乾いた高い音が返ってくる。

　一本の牙から、小さな投げ道具が三本できあがった。武具屋で買った投擲ナイフと並べてみると、重心もいびつで刃の角度も揃っておらず、お世辞にも上質とは言えない出来だった。

　それでも――数だけは、いくらでも増やせる。買ってきた五本の投擲ナイフをすべて失っても、こうして自分の手で補充が利く。粗くても、切らさずに済むという実用性がそこにはあった。



　試すなら、本物の相手が要る。ウィンは灰狼の森の入り口まで足を運んだ。手前側の、勝手を知った灰色狼が出るあたりだ。

　本当に効くのか、正直まだ半信半疑のままだった。粗削りな得物も、初めて塗った毒も、実戦で通用する保証はどこにもない。

　下草の奥に、二頭の灰色狼が並んで姿を見せた。ウィンは毒を塗り直した投擲ナイフを一本抜き、迷いを振り切るように投げる。

　切っ先は狙い通り、手前の一頭の肩に突き刺さった。獣は一度だけ大きく身をよじり、それから普段と変わらない様子で駆け出そうとする。

　――効果は薄いか。ウィンがそう思った直後、獣の動きがわずかに鈍った。

　毛並みの一部が黒ずんだように見え、足取りが目に見えて重くなっていく。毒が、確かに効いている。

　もう一頭が横合いから飛びかかってくる。ウィンは自作の投げ道具を握り、狙いを定めて放った。刃は狙い通りに突き刺さったが、買った得物ほどの深さでは食い込まない。

　粗削りな分は、やはり仕留めきれない。だが致命傷でなくてもいい。

　すかさず腰の短剣を抜き、急所看破で見えた一点へ叩き込む。手応えとともに、二頭目の獣が光の粒子になって消えた。

　毒に蝕まれていた一頭目は、もう自力で立っていられないほど弱っていた。とどめの一撃を放つと、そちらも同じように消えていく。その瞬間、視界に通知が浮かんだ。

　地面に転がっていた投擲ナイフと自作の投げ道具、それに残った牙を、ウィンは一つずつ拾い集めた。回収を怠ればすぐに手持ちが尽きる、というのはもう身に染みている。

```
『Lv6に上がりました』
```

　流れていく通知を、ウィンはなんとなく目で追った。今日は素材を見極める目も、配分を測る指先も、ずいぶん使ったつもりでいる。



　人気のない場所を選んで、ウィンはステータス画面を開く。

```
ウィン
Lv6
職業:暗器使い
ソウルクレスト:彼は誰(かはたれ)

スキル:投擲、隠密行動、生成(暗器)、調合(毒)、急所看破、会心の一撃、精密投擲
```

　並んだ表示を眺めながら、ウィンはふと今日一日を振り返った。掲示板の前で足を止めたところから始まって、道具屋を覗き、慣れない手つきで毒を仕込み、牙を削って得物を作った。討伐の依頼を一件もこなしていないのに、気づけば日が傾きかけている。

　効率だけを考えるなら、素直に依頼をこなしていたほうが稼ぎは良かったかもしれない。それでも、後悔はまるでなかった。むしろ、時間が経つのを忘れるくらい没頭していた。

　――ああ、自分は結構、このゲームにハマっているんだな。

　そう自覚すると同時に、口元がひとりでに緩むのが分かった。

　一日じゅうしゃがんで牙を削っていただけの日を、悪くなかったと思っている。そんな夏の一日は、たぶん初めてだった。
