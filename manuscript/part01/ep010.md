# 第十話　仕込みと手仕事

　翌朝、目が覚めた冬夜の頭に最初に浮かんだのは、毒の作り方だった。

　昨夜、寝る前に攻略サイトを漁って、調合の手順と要る道具を調べてあった。薬草と、牙の粉。読んだだけの手順を、早く自分の手で試したい。

　台所へ降りて、朝食をかき込む。食器を流しに置いて部屋へ戻るまで、ものの数分だった。

　ヘッドギアを被る。起動音、それから意識が沈む。


　　　　◇


　セイレスに降り立ったウィンは、いつものように冒険者ギルドの依頼掲示板の前に立った。

　新しい依頼が増えていないか、それだけ確かめに来た。だが並んでいるのは、灰色狼の間引きに薬草の採取、猪型の討伐――ここ数日でやった顔ぶればかりだ。

　なら、今日は先に片付けたいことがある。ウィンはインベントリのウィンドウを呼び出した。灰色狼の牙が三つ、猪の牙が一つ、そして薬草採取のときに指定数より多めに摘んでおいた分の余りが、そのまま眠っている。

　調合(毒)、生成(暗器)。ステータス画面の隅に並んでいるのを見るたびに気になっていたスキルだ。生の薬草を多めに摂ると毒になる、とあの時の説明文にはあった。

　牙だって、ただ売るだけよりましな使い道があるかもしれない。



　まずは素材買取の窓口で、灰色狼の牙を二つ売った。調べた手順で使う牙の粉は、ほんの少しでいい。一本あれば足りる。

　売った小銭は、道具代に回す。猪の牙も売らずに残した。大きさからして、削れば投擲ナイフの代わりの刃になりそうだ。

　次に向かったのは、武具屋の隣の防具屋だった。

　昨日の猪の突進が、まだ頭に残っている。あれを避け損ねていたら、ただでは済まなかった。

　とはいえ、避けて戦う以上、重くて動きを鈍らせる防具は着られない。

　店先に吊るされていたのは、革を薄く何枚も重ねた造りの上着だった。袖を通してみても、腕の振りを妨げない。

「革を重ねてあるからな。軽いわりに、爪の一撃くらいなら中まで通さんよ」

　値札は、今の手持ちでも無理なく届く額だった。ウィンはその場で着込んだ。

　それから、昨夜調べておいた薬屋の並びの道具屋へ回る。看板には小瓶とすり鉢の絵が描かれている。中に入ると、棚には大小の空き瓶やすり鉢、丸めた布切れの束などが所狭しと並んでいた。

「調合か? それとも加工かい」

　店主に聞かれ、ウィンは「両方、初めてで」と正直に答える。店主はこともなげに小瓶を二つ、すり鉢をひとつ、布切れの束をひとつ、カウンターに並べた。

「初歩の調合なら、この三つで足りる。出来の良し悪しは、すり潰し方と配分で決まるがね」

　会計を終えると、手持ちがまた軽くなった。


　　　　◇


　人通りの少ない裏道の隅にしゃがみ込み、ウィンは昨夜調べた手順を頭の中でなぞる。薬草をすり鉢で細かくすり潰し、狼の牙を削った粉を混ぜ、布切れで濾して小瓶に移す――手順そのものは単純だった。

　すり鉢の中で葉が潰れると、青い草の匂いが立った。指に移った汁は、擦っても落ちそうにない。

　最初の一回は、薄すぎた。濾した液は水のようにさらさらで、刃につけてもすぐに垂れてしまう。

```
『粗悪な毒液を作成しました』
```

　視界に浮かんだ表示に、ウィンは思わず苦笑する。粉の量が足りなかったのか、すり潰し方が甘かったのか。

　牙の粉をもう少し足し、すり鉢を握る手に力を込めて、根気よく潰し直す。

　二度目は、とろりとした黒みがかった緑色の液体ができた。鼻を近づけると、青い匂いの奥に、鉄に似たものが混じっている。牙のほうだ。

```
『毒(小)を作成しました』
```

　布切れの端をひたして、刃の表面に薄く塗ってみる。乾く前の液は刃に絡みついて、振っても垂れてこない。

　日を跨ぐと効きが落ちる、と攻略サイトにはあった。使う日に、そのつど塗ることになりそうだ。



　毒の目処が立ったところで、ウィンはいったん手を止めて息をついた。今日はもう一つ、試したいことが残っている。すり鉢や布切れをそのままに、今度は生成(暗器)に取りかかることにした。

　残しておいた猪の牙は、灰色狼のものよりずっと大きく、湾曲した硬い作りをしている。

　短剣の背で割り、刃で形を整えて、先端を薄く削り出す。削るたびに白い粉が膝に散り、指の腹がざらついた。

　最初の一本は、薄く削りすぎて指の中で割れた。二本目から、力の入れどころが分かってくる。

　柄には余った布切れを巻いて、握りを作る。爪で弾くと、乾いた高い音が返ってきた。

```
『投げ道具を作成しました』
```

　一本の牙から、投げるための刃が三本。買った投擲ナイフと並べると、重心も角度も揃っていないのが一目で分かる。

　それでも、数は揃えられる。買った五本を全部失っても、牙さえ拾えば自分の手で補充が利く。


　　　　◇


　あとは、実際の相手で確かめるだけだ。ウィンは灰狼の森の入り口まで足を運んだ。手前側の、勝手を知った灰色狼が出るあたりだ。

　下草の奥から、二頭の灰色狼が並んで出てきた。片方が鼻先を上げ、こちらを見る。二頭とも喉を低く鳴らし、体が沈んだ。

　ウィンは毒を塗った投擲ナイフを一本抜き、先に動いたほうへ投げる。

　狙いは、あえて急所を外した。今日は、毒がどれだけ効くのかを確かめに来ている。

　切っ先は手前の一頭の肩に突き刺さった。獣は一度だけ大きく身をよじり、それから何事もなかったように駆け出そうとする。

　――効果は薄いか。ウィンがそう思った直後、獣の動きがわずかに鈍った。

　毛並みの一部が黒ずんだように見え、足取りが目に見えて重くなっていく。毒が、確かに効いている。

　もう一頭が横合いから飛びかかってくる。ウィンは自作の刃を握り、狙いを定めて放った。刃は突き刺さったものの、買った得物ほどの深さでは食い込まない。

　粗削りな分は、やはり止まらない。獣は刃を生やしたまま、距離を詰めてくる。

　ウィンは腰の短剣を抜き、意識を通した。柄はそのままに、切っ先だけが槍のように伸びる。昨日、猪を相手に覚えたばかりの形だ。

　踏み込んでくる勢いへ、伸ばした切っ先を合わせる。急所看破で白く浮かんだ一点に、ズッ、と刃が滑り込んだ。

　二頭目の獣が光の粒子になって消える。

　毒を受けた一頭目は、離れた草の上でうずくまっていた。逃げる足が、もう残っていない。とどめの一撃で、そちらも光になった。

　短剣がひとりでに元の刃渡りへ戻る。ウィンは地面に転がった投擲ナイフと自作の刃、それに残った牙を一つずつ拾い集めた。

```
『Lv6に上がりました』
```



　人気のない場所を選んで、ウィンはステータス画面を開く。

```
ウィン
Lv6
職業:暗器使い
ソウルクレスト:彼は誰(かはたれ)

スキル:投擲、隠密行動、生成(暗器)、調合(毒)、急所看破、会心の一撃、精密投擲
```

　今日は、依頼を一件も受けなかった。しゃがんで手を動かしているうちに、日が傾いていた。

　腰の袋には、毒の小瓶と、牙から削った刃が三本。指は薬草の汁で青く染まったままだ。

　薄すぎた毒は、粉を足したら形になった。割れた牙は、二本目からうまく削れた。効くかどうか分からなかった一瓶が、狼の足を実際に止めた。

　やってみて、駄目で、直したら通る。その繰り返しが、朝からずっと面白い。

　帰り道、頭はもう明日のことを考えている。毒はもっと濃くできるはずだ。牙が二本増えたから、刃も足せる。

　濃くした毒を自作の刃に塗ったら、猪にはどこまで通るだろう。

　――ああ、自分は結構、このゲームにハマっているんだな。

　認めたら、少し笑えた。夕日に赤く染まった街壁を目指して、ウィンは足を速める。

　今夜はログアウトしたら、毒を濃くする方法を探すつもりだった。
