# 第九話　己の得物

　冬夜がログインして最初に向かったのは、依頼掲示板ではなく武具屋だった。

　前回ログアウトする直前に、自分で決めていたことだ。ステータス画面で所持金千六百ユンを目にした瞬間から、頭の中にはずっとあの値札がちらついていた。

　武具屋の扉をくぐると、以前と変わらぬ棚に、暗器使い向けと札のついた投擲ナイフが並んでいた。

　値札には千五百ユンとある。初めてこの店に来た日、同じ値札を見て素直に諦めた記憶が、まだはっきりと残っている。あの頃の所持金は、五百ユンにも届いていなかったはずだ。

　今の自分になら、手が届く。分かっていたはずなのに、いざ札の前に立つと、指先がわずかに強張った。決して安い買い物ではない。

「これ、ください」

　震えを押し殺すように、冬夜は店主に投擲ナイフのセットを指し示した。革のベルトに小ぶりな刃が五本並んだ、投擲専用の得物だ。

「毎度あり。暗器使いにはこれが一番人気だよ」

　会計を終えると、手元に残ったのは百ユンだけになった。心もとない額だが、傷薬は前に買った二本がまだ手つかずで残っている。装備は整った、と冬夜は自分に言い聞かせる。

　腰のベルトに投擲ナイフを提げてみる。短剣とは違う、軽くしなるような重心の感触があった。早く試してみたい――そんな気持ちを抑えられないまま、冬夜はギルドの掲示板へと足を向けた。



　掲示板で選んだのは、Eランクになって初めて目に留まった「森の外れに出る中型モンスターの討伐」という依頼だった。指定された森の入り口に着く頃には、腰の投擲ナイフが早く使ってくれと言わんばかりに、やけに軽く感じられた。

　最初の獲物は、木々の隙間からのっそりと姿を現した猪型の魔物だった。距離を詰めきる前に仕留められるなら、それに越したことはない。

　冬夜はナイフを一本抜き、狙いを定めて投げた。

　だが切っ先はわずかに逸れ、獣の肩先をかすめただけで地面に突き立つ。借り物の石や枝を変形させて投げていた時とは、重さも軸の取り方もまるで違う。分かってはいたつもりだったが、思っていた以上に勝手が違った。

　舌打ちしそうになるのを堪え、すぐさま二本目を抜く。手首の返しをほんの少し浅くして、もう一度放った。

　刃はまっすぐに飛び、獣の急所へ吸い込まれるように突き刺さる。これまで小石や枯れ枝を借りて変形させていた投擲とは、明らかに手応えが違った。

　最初から狙って作られた武器は、重心も刃の角度も、投げるという動作にぴたりと馴染む。借り物を鏃の形に変えるまでの一手間がない分、動きに迷いが生まれない。バランスの良さというのは、こういうことかと冬夜は思う。

　二体目の魔物との距離が、思ったより開いた。手元のナイフはあと数本しかない。ここで冬夜は、以前確かめたある性質を思い出した。

　腰に提げたナイフは、もう自分の持ち物だ。借りる、という手順を踏まなくても、直接その形を変えられるはずだった――あの日、街を出てすぐに検証した通りに。

　手にした一本の刃先を、意識するだけで、いつもより薄く長く変える。柄の握りはそのまま、切っ先だけを槍のように鋭く伸ばした投擲用の一振りへと作り替える。

　借り物の枝や石なら、魂力が尽きて変形が解ければ、元のただの枝や石に戻ってしまう。だがこのナイフは、そもそも刃物として作られたものだ。たとえ魂力切れで元の形に戻ったところで、投げる得物としては十分に役立つ。

　借り物のように「使い物にならない姿に戻ってしまう」心配がないというだけで、気持ちの上ではずいぶん気楽だった。

　もっとも、都合のいいことばかりでもない。この一本を変形させている間は、他の何かを新しく借りて変えることはできない――同時に扱えるのは一つだけ、という制約は、相手が誰の持ち物であっても変わらないらしい。

　それでも、いちいち周囲から材料を探して借りる手間がいらないというだけで、動きの速さがまるで違う。冬夜は伸ばした刃を投げ、二体目の魔物の急所を正確に射抜いた。

　三体目、四体目と続けて仕留めていく最中、視界の端に見慣れた通知が浮かんだ。

```
『Lv5に上がりました』
獲得ポイント　自動:20　割り振り可能:20
```

　まさかこんな早さでまた、と冬夜は一瞬手を止めかける。だがすぐに気を取り直し、自由に振れる二十点を、いつもの通りに素早さと器用さへ均等に注いだ。

　自動で振られる分と合わせ、AGIとDEXがまた大きく伸びた実感がある。詳しい数字は後で確認すればいい。今は目の前の依頼を片付けることが先だ。

　指定された数を仕留め終える頃、投擲ナイフを使った急所への一撃を幾度となく繰り返していたせいか、また新しい通知が届いた。

```
『スキル「精密投擲」を習得しました』
```

　投げるという動作そのものの精度が、これまでよりもう一段階上がる――そんな手応えが、その一投ごとに刃を追う視線の鋭さとなって表れている気がした。急所看破で敵の弱点を見極め、会心の一撃でそこへ深く突き立て、精密投擲でその一投そのものを正確にする。狙って、当てて、決めるという一連の流れが、また一つ噛み合ったように感じられた。



　依頼を終えてギルドへの帰り道、冬夜は人通りの少ない場所を選んでステータスを開いてみた。

```
冬夜
Lv5(第一段階)
職業:暗器使い
ソウルクレスト:彼は誰(かはたれ)

HP 32/32
MP 10/10
魂力(SP) 8/8
STR 28
AGI 75
DEX 62
INT 7
VIT 9
LUK 26

スキル:投擲、隠密行動、暗器生成、毒の調合、急所看破、会心の一撃、精密投擲

所持金:100Y
```

　レベルが一つ上がり、スキルもまた一つ増えている。所持金はほとんど底をついてしまったが、それだけの価値がある買い物だったと今なら胸を張って言える。

　腰のナイフに軽く触れながら、冬夜はふと思い出す。暗器使いを選んだ理由は、大した話ではなかった。戦ってみたい、隠し武器のほうが何となく格好いい――それだけの、子供じみた勢いだけの選択だった。

　理屈で選んだわけではない自分の得物が、こうして手の中にしっくりと収まっている。それだけのことが、思っていたよりずっと満ち足りた気分にさせてくれる。

　冬夜は静かにステータス画面を閉じ、次の依頼を探しにギルドへと歩き出した。
