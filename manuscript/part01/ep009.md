# 第九話　己の得物

　冬夜がログインして最初に向かったのは、依頼掲示板ではなく武具屋だった。

　前回ログアウトする直前に、自分で決めていたことだ。ステータス画面で所持金千六百ユンを目にした瞬間から、頭の中にはずっとあの値札がちらついていた。

　武具屋の扉をくぐると、以前と変わらぬ棚に、暗器使い向けと札のついた投擲ナイフが並んでいた。値札には千五百ユンとある。初めてこの店に来た日、同じ値札を見て素直に諦めた記憶が、まだはっきりと残っている。

　店主に頼んで、実物を手に取らせてもらう。革のベルトに小ぶりな刃が五本並んだ、投擲専用の得物だ。短剣よりも軽く、指先で弾けそうなくらい軽快な作りをしている。

　柄を握るたびに、これが自分の戦い方にぴったりだと分かるような気がした。

　隠し武器のほうが何となく格好いい――暗器使いを選んだ、あの子供じみた理由が、今さらのように胸の奥をくすぐる。今の自分になら、手が届く。分かっていたはずなのに、いざ買うと決めると、指先がわずかに強張った。

「これ、ください」

　震えを押し殺すように、冬夜は店主に投擲ナイフのセットを指し示した。

「毎度あり。暗器使いにはこれが一番人気だよ」

　会計を終えると、手元に残ったのは百ユンだけになった。心もとない額だが、傷薬は前に買った二本がまだ手つかずで残っている。装備は整った、と冬夜は自分に言い聞かせる。

　腰のベルトに投擲ナイフを提げてみる。短剣とは違う、軽くしなるような重心の感触があった。早く試してみたい――そんな気持ちを抑えられないまま、冬夜はギルドの掲示板へと足を向けた。



　掲示板で選んだのは、「灰狼の森の奥に出る、猪型の中型モンスターを1体討伐してほしい」という依頼だった。報酬は350Y。依頼票の隅には小さく、「森のさらに奥は攻略が進んでいない一帯のため、深追いは禁物」という注意書きが添えられている。

　噂では、苔むした石段や崩れかけた古い柱を見た冒険者もいるらしい。今日はそこまで踏み込むつもりはないが、鬱蒼と茂る木々の向こうに何があるのか、少しだけ想像を掻き立てられた。

　丘を越え、森の入り口をくぐる。日差しは葉の隙間から漏れる光の筋に変わり、下草を踏むたびに湿った土の匂いが立ち上った。丘の獣とは違う気配――遠くで鳴く鳥の声、風に揺れる枝葉の音までもが、やけに大きく聞こえる。



　最初に出くわしたのは、見慣れた灰色の毛並みの獣だった。丘で何度も相手をしてきた、あの狼だ。ちょうどいい、と冬夜は思う。新しい得物を試すなら、勝手を知った相手からがいい。

　距離を詰めきる前に、腰のナイフを一本抜いて投げた。

　だが切っ先はわずかに逸れ、獣の肩先をかすめただけで地面に突き立つ。借り物の石や枝を変形させて投げていた時とは、重さも軸の取り方もまるで違う。分かってはいたつもりだったが、思っていた以上に勝手が違った。

　舌打ちしそうになるのを堪え、すぐさま二本目を抜く。手首の返しをほんの少し浅くして、もう一度放った。

　刃はまっすぐに飛び、獣の急所へ吸い込まれるように突き刺さる。獣は光の粒子になって消え、地面には二本のナイフだけが残った。

　最初から狙って作られた武器は、重心も刃の角度も、投げるという動作にぴたりと馴染む。借り物を鏃の形に変えるまでの一手間がない分、動きに迷いが生まれない。バランスの良さというのは、こういうことかと冬夜は思う。

　落ちていた二本を拾い上げ、鞘に戻す。借り物と違ってここで回収しておかないと、次第に手持ちが尽きてしまう。当たり前のことなのに、妙に新鮮な手間だった。

　その後も同じ調子で、灰色狼を二体ほど仕留めた。狙って、投げて、当てる。仕留めるたびに拾い直す。その繰り返しの中で、冬夜は少しずつナイフの重さに手が馴染んでいくのを感じた。



　森が深くなるにつれ、下草の音が変わった。獣の足音にしては重く、規則的な地響きが、少しずつ近づいてくる。

　木々の隙間から姿を現したのは、丘の獣よりも一回り大きな、猪型の魔物だった。土を蹴立てて、まっすぐに突っ込んでくる。

　冬夜はナイフを投げた。切っ先は正確に急所を捉えたが、猪はひるむ様子もなく、勢いのまま突進を続ける。

　――一発じゃ、足りない。

　横に跳んでかわしながら、冬夜は焦りを噛み殺す。急所看破で狙いは定まっているのに、決め手に欠ける。持っている手数だけでは、この重さを止めきれない。

　このナイフはもう自分の持ち物だ。借りる、という手順を挟まなくても、直接姿を変えられる。冬夜は手にした一本の切っ先を、意識するだけで槍のように長く鋭く伸ばした。

　柄の握りはそのまま、切っ先だけをより深く突き刺さる形に作り替える。狙うのは、もう一度同じ急所。

　振り向きざまに突進してきた猪の急所へ、伸ばした切っ先を突き立てる。これまでとは違う、重く鈍い手応えが腕を伝った。会心の手応えとともに、通知が浮かぶ。

```
『スキル「精密投擲」を習得しました』
```

　急所看破で見極めた一点に、狙い通りの一投を正確に届け続けたことで芽生えたスキルらしい。詳しい効果までは表示されなかったが、狙った急所への一投そのものの精度が、これまでよりもう一段階上がる――そんな手応えが、指先に残っていた。

　猪は最後にもう一度だけ暴れ、光の粒子になって消えていく。冬夜は肩で息をつきながら、地面に落ちたナイフを拾い集めた。

```
『Lv5に上がりました』
獲得ポイント　自動:20　割り振り可能:20
```

　自由に振れる二十点を、いつもの通りに素早さと器用さへ均等に注ぐ。狙って、当てて、決める。だが今日みたいに、一発で決め切れない相手もいる――その事実も、頭の片隅に留めておくことにした。



　依頼を終えてギルドへ戻ると、受付はナイフの返り血にも眉一つ動かさず、淡々と告げた。

「討伐、確認できました。350Yになります」

　所持金は、百ユンから四百五十ユンに増えていた。大きな買い物をした直後だけに、その増え方が妙にありがたく感じられる。



　帰り道、人通りの少ない場所を選んで、冬夜はステータスを開いてみた。

```
冬夜
Lv5
職業:暗器使い
ソウルクレスト:彼は誰(かはたれ)

HP 32/32
MP 10/10
魂力(SP) 8/8
STR 28
AGI 75
DEX 62
INT 7
VIT 9
LUK 26

スキル:投擲、隠密行動、暗器生成、毒の調合、急所看破、会心の一撃、精密投擲

所持金:450Y
```

　レベルが一つ上がり、スキルもまた一つ増えている。腰のナイフに軽く触れながら、冬夜はふと思う。理屈で選んだわけではない自分の得物が、こうして手の中にしっくりと収まっている。それだけのことが、思っていたよりずっと満ち足りた気分にさせてくれた。

　冬夜は静かにステータス画面を閉じ、次の依頼を探しにギルドへと歩き出した。
