# 第九話　己の得物

　目を開けると、見慣れたセイレスの大通りが広がっていた。ログインしたウィンが最初に向かったのは、依頼掲示板ではなく武具屋だった。

　前回ログアウトする直前に、自分で決めていたことだ。昨日の稼ぎで、あの値札にようやく手が届く。

　店主に頼んで、棚に並んだ投擲ナイフを手に取らせてもらう。革のベルトに小ぶりな刃が五本並んだ、投擲専用の得物だ。短剣よりも軽く、指先で弾けそうなくらい軽快な作りをしている。

「これ、ください」

「毎度あり。暗器使いにはこれが一番人気だよ」

　店主は会計をしながら、ついでとばかりに刃先を軽く指で弾いてみせた。

「刃こぼれしたら遠慮なく研ぎに持ってきな。買ったばかりの手入れ代くらいはサービスしてやるから」

「そんなに早く傷みますか」

「使い方次第だな。まあ、大事に使えば長持ちする」

　会計を終えると、財布はほとんど空になった。腰のベルトに投擲ナイフを提げてみる。短剣とは違う、軽くしなるような重心の感触がある。

　早く試してみたい――そんな気持ちを抑えられないまま、ウィンはギルドの掲示板へと足を向けた。



　掲示板の近くでは、装備の擦り切れた冒険者が二人、声高に話し込んでいた。

「森奥、また誰か潜ったらしいぜ」

「刻の図書館の連中だろ。飽きずによくやるよ」

「まあ、当たれば一攫千金だからな。あの遺跡、未だに誰も攻略できてないんだろ?」

「噂じゃ、番人みたいなのがいて先に進ませてくれないとか」

　聞くともなしにその話が耳に入ってくる。苔むした石段や崩れかけた古い柱が森の奥に眠っているのは、それなりに知られた話らしい。遺跡目当てのトレジャーハンター系プレイヤーや、ゲームの歴史を調べ回っている「刻の図書館」のようなクランが、たびたび調査に入っているという。

　ウィンは聞き耳を立てるのもそこそこに、掲示板へ向き直った。選んだのは、「灰狼の森の奥に出る、猪型の中型モンスターを一体討伐してほしい」という依頼だった。

　依頼票の隅には小さく、「森のさらに奥は強力なモンスターが出現するため、単独での深追いは危険」という注意書きが添えられている。

　今日はそこまで踏み込むつもりはないが、さっきの話と重なって、鬱蒼と茂る木々の向こうに何があるのか、少しだけ想像を掻き立てられた。

　丘を越え、森の入り口をくぐる。日差しは葉の隙間から漏れる光の筋に変わり、下草を踏むたびに湿った土の匂いが立ち上った。丘の獣とは違う気配――遠くで鳴く鳥の声、風に揺れる枝葉の音までもが、やけに大きく聞こえる。



　最初に出くわしたのは、見慣れた灰色の毛並みの獣だった。丘で何度も相手をしてきた、あの狼だ。

　ちょうどいい。新しい得物を試すなら、慣れた相手からがいい。

　距離を詰めきる前に、腰のナイフを一本抜いて投げる。

　だが切っ先はわずかに逸れ、獣の肩先をかすめただけで、ザクッと地面に突き立った。借り物の石や枝を変形させて投げていた時とは、重さも軸の取り方もまるで違う。

　分かってはいたつもりだが、思っていた以上に手元の感覚が狂う。

　舌打ちしそうになるのを堪え、すぐさま二本目を抜く。手首の返しをほんの少し浅くして、もう一度放った。

　刃はまっすぐに飛び、ザシュッと獣の急所へ突き刺さる。獣は光の粒子になって消え、地面には二本のナイフと、小さな牙が一つ残った。

　最初から狙って作られた武器は、重心も刃の角度も、投げるという動作にぴたりと馴染む。借り物を鏃の形に変えるまでの一手間がない分、動きに迷いが生まれない。バランスの良さというのは、こういうことかとウィンは思う。

　落ちていた二本を拾い上げ、鞘に戻す。借り物と違ってここで回収しておかないと、次第に手持ちが尽きてしまう。当たり前のことなのに、妙に新鮮な手間だった。

　ついでに牙も拾い、インベントリに収める。今日は素材買取に寄る予定もない。今はとりあえず溜めておくことにする。

　その後も同じ調子で、灰色狼を二体ほど仕留めた。狙って、投げて、当てる。仕留めるたびに拾い直す。牙もその都度インベントリへ収めていった。

　その繰り返しの中で、ナイフの重さが少しずつ手に吸い付くようになっていった。



　森が深くなるにつれ、下草の音が変わった。獣の足音にしては重く、規則的な地響きが、少しずつ近づいてくる。

　木々の隙間から姿を現したのは、丘の獣よりも一回り大きな、猪型の魔物だった。土を蹴立てて、まっすぐに突っ込んでくる。急所看破の効果か、疾走する猪の眉間の一点だけが、他よりわずかに白く際立って見えた。

　ウィンはナイフを投げた。ガッ、と切っ先が眉間を捉えたが、猪はひるむ様子もなく、勢いのまま突進を続ける。

　――一発じゃ、足りない。

　横に跳んでかわしながら、ウィンは焦りを噛み殺す。急所看破で狙いは定まっているのに、決め手に欠ける。投げるだけの手数では、この重さを止めきれない。

　ウィンは腰の短剣を一本抜く。投擲ナイフとは違う、勝手を知った自分の得物だ。

　これも自分の持ち物である以上、借りる、という手順を挟まなくても直接姿を変えられる。手にしたその切っ先を、意識するだけで槍のように長く鋭く伸ばした。

　柄の握りはそのまま、切っ先だけをより深く突き刺さる形に作り替える。狙うのは、もう一度同じ急所。

　――今度こそ。

　振り向きざまに突進してきた猪の急所へ、伸ばした切っ先を突き立てる。ズブッ、と重く鈍い感触が腕を伝った。通知が浮かぶ。

```
『スキル「精密投擲」を習得しました』
```

　精密投擲。名前だけが出て、何がどう変わったのかは書かれていない。

　だが、心当たりはあった。土壇場で投げた一本が、迷いも構えもないまま狙った場所へ行った。あれを覚えられたのだと思う。

　猪は最後にもう一度だけ暴れ、光の粒子になって消えていく。短剣はひとりでに元の刃渡りへ戻った。ウィンは肩で息をつきながら、地面に落ちたナイフと、大ぶりな牙を拾い集めた。

```
『Lv5に上がりました』
```

　狙って、当てて、決める。だが今日みたいに、一発で決め切れない相手もいる――その事実だけ、頭の片隅に留めておくことにした。



　依頼を終えてギルドへ戻ると、受付はナイフの返り血にも眉一つ動かさず、淡々と告げる。

「討伐、確認できました」

　空に近かった財布に、また少しだけ厚みが戻る。大きな買い物をした直後だけに、その増え方が妙にありがたく感じられた。



　ギルドの隅に移動し、ウィンは壁に背を預けた。

　そういえば、さっき槍状に伸ばした短剣も、思っていたより長く形を保っていた気がする。魂力の伸びに合わせて、猶予も静かに長くなっているのかもしれない。

　腰のナイフに軽く触れる。理屈で選んだわけではない得物が、こうして手の中にしっくり収まっている。

　似合っているかどうかは、まだ分からない。

　それでも、選んだのは自分だった。
