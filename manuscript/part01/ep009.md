# 第九話　己の得物

　目を開けると、セイレスの大通りだった。ログインしたウィンが最初に向かったのは、依頼掲示板ではなく武具屋だった。

　昨日の稼ぎで、投擲ナイフが買える。

　店主に頼んで、棚に並んだ投擲ナイフを手に取らせてもらう。革のベルトに小ぶりな刃が五本並んだ、投擲専用の得物だ。短剣よりも軽く、指先で弾けそうなくらい軽快な作りをしている。

「これ、ください」

「毎度あり。投げ物を使う客には、これが一番人気だよ」

　店主は会計をしながら、ついでとばかりに刃先を軽く指で弾いてみせた。

「刃こぼれしたら遠慮なく研ぎに持ってきな。買ったばかりの手入れ代くらいはサービスしてやるから」

「そんなに早く傷みますか」

「使い方次第だな。まあ、大事に使えば長持ちする」

　会計を終えると、財布はほとんど空になった。腰のベルトに投擲ナイフを提げてみる。短剣とは違う、軽くしなるような重心の感触がある。

　早く試してみたい――そんな気持ちを抑えられないまま、ウィンはギルドの掲示板へと足を向けた。


　　　　◇


　掲示板の近くでは、装備の擦り切れた冒険者が二人、声高に話し込んでいた。

「森奥、また誰か潜ったらしいぜ」

「刻の図書館の連中だろ。飽きずによくやるよ」

「まあ、当たれば一攫千金だからな。あの遺跡、未だに誰も攻略できてないんだろ?」

「噂じゃ、番人みたいなのがいて先に進ませてくれないとか」

　聞くともなしに耳に入ってくる。

　ウィンは聞き耳を立てるのもそこそこに、掲示板へ向き直った。選んだのは、「灰狼の森の奥に出る、猪型の中型モンスターを一体討伐してほしい」という依頼だった。

　依頼票の隅には小さく、「森のさらに奥は強力なモンスターが出現するため、単独での深追いは危険」という注意書きが添えられている。

　今日はそこまで踏み込むつもりはない。それでも、さっきの話は頭の隅に残った。

　丘を越え、森の入り口をくぐる。日差しは葉の隙間から漏れる光の筋に変わり、下草を踏むたびに湿った土の匂いが立ち上った。丘の獣とは違う気配――遠くで鳴く鳥の声、風に揺れる枝葉の音までもが、やけに大きく聞こえる。



　最初に出くわしたのは、丘でも見た灰色の毛並みの獣だった。木の根元からこちらを見て、喉を低く鳴らしている。

　ちょうどいい。新しい得物を試すなら、慣れた相手からだ。

　間合いの外から、ナイフを一本抜いて投げる。

　切っ先はわずかに逸れ、獣の肩先をかすめて地面に突き立った。石を鏃に変えて投げていた時とは、重さも軸の取り方もまるで違う。

　かすめられた獣が、身を低くして跳びかかってくる。

　考える間はなかった。二本目を抜き、跳んできた喉元へ投げる。

　刃は吸い込まれるように突き刺さり、獣は宙で光の粒子になった。地面には二本のナイフと、小さな牙が残る。

　落ちた二本を拾い、ベルトに差し戻した。投げた刃は、拾わなければそれきりだ。

　牙も拾って、インベントリに収める。

　その後の二体は、風下から忍び寄り、気づかれる前に投げて仕留めた。西の野で覚えた近づき方は、狼にも通じた。

　繰り返すうちに、ナイフの重さが少しずつ手に吸い付くようになっていく。



　森が深くなるにつれ、下草の音が変わった。獣の足音にしては重く、規則的な地響きが、少しずつ近づいてくる。

　木々の隙間から姿を現したのは、丘の獣よりも一回り大きな、猪型のモンスターだった。前脚が地面を二度掻き、乾いた土が後ろへ飛ぶ。

　急所看破の効果か、下げた頭の眉間の一点だけが、他よりわずかに白く際立って見えた。

　猪が土を蹴立てて突っ込んでくる。ウィンはナイフを投げた。切っ先は狙った眉間を捉えたが、猪はひるむ様子もなく、勢いのまま距離を詰める。

　横へ跳んでかわす。猪はすぐには曲がれず、数歩先まで走り抜けてから向き直った。

　――投げた刃じゃ、止まらない。

　かといって、この勢いを正面から突き刺しにいくのは無謀だ。まず、足を止めさせる。

　ウィンは腰の短剣を抜き、意識を通した。切っ先が伸びていく。

　ただし、昨日のようには伸ばさない。倍まで伸ばせば薄くなってたわむことは、柵の杭が教えてくれた。

　半分増しで止めて、浮いたぶんを切っ先の厚みに回す。突き通すための形だ。

　それから、幹の太い木を背にして立つ。

　猪が地面を掻き、二度目の突進が来る。引きつけて、寸前で横へ跳んだ。

　ドゴッ、と鼻面が幹に突き刺さる。木の皮が弾け、巨体がよろめいた。

　その頭の、眉間の一点が白く際立っている。

　伸ばした切っ先を、突き込む。



　ズンッ、と重い音が、柄を握った手から肩の付け根まで届いた。

　猪は最後にもう一度だけ暴れ、光の粒子になって消えていく。短剣はひとりでに元の刃渡りへ戻った。ウィンは肩で息をつきながら、落ちたナイフと大ぶりな牙を拾い集める。

```
『スキル「精密投擲」を習得しました』
　狙った一点へ、構えを取らずに投げられるようになります
```

```
『Lv5に上がりました』
```

　覚えがあった。跳びかかってきた狼へ、考える間もなく投げた二本目。あれが、そのまま狙った場所へ行っていた。


　　　　◇


　依頼を終えてギルドへ戻る。受付は依頼票と端末の記録を突き合わせて、淡々と告げた。

「討伐、確認できました」

　朝に使い果たしたぶんの、いくらかが財布に戻った。



　ギルドの隅に移動して、壁に背を預ける。

　そういえば、さっき槍に変えた短剣は、初日に枝を変えていた時より長く形を保っていた。使い込めば、この持ち時間はまだ延びるのかもしれない。

　ウィンはベルトのナイフを一本抜いて、刃を確かめた。今日いちにち投げて、欠けはまだない。

　研ぎの世話になるのは、まだ先でよさそうだった。
