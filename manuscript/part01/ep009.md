# 第九話　己の得物

　目を開けると、セイレスの大通りだった。ログインしたウィンが最初に向かったのは、依頼掲示板ではなく武具屋だった。

　初日に値札を見て、素直に諦めた得物がある。西の野の稼ぎを足せば、今日は届く。

　店主に頼んで、棚に並んだ投擲ナイフを手に取らせてもらう。革のベルトに小ぶりな刃が五本並んだ、投擲専用の得物だ。短剣よりも軽く、指先で弾けそうなくらい軽快な作りをしている。

「これ、ください」

「毎度あり。投げ物を使う客には、これが一番人気だよ」

　店主は会計をしながら、ついでとばかりに刃先を軽く指で弾いてみせた。

「刃こぼれしたら遠慮なく研ぎに持ってきな。買ったばかりの手入れ代くらいはサービスしてやるから」

「そんなに早く傷みますか」

「使い方次第だな。まあ、大事に使えば長持ちする」

　会計を終えると、財布はほとんど空になった。腰のベルトに投擲ナイフを提げてみる。短剣とは違う、軽くしなるような重心の感触がある。

　早く試してみたい――そんな気持ちを抑えられないまま、ウィンはギルドの掲示板へと足を向けた。


　　　　◇


　掲示板の近くでは、装備の擦り切れた冒険者が二人、声高に話し込んでいた。

「森奥、また誰か潜ったらしいぜ」

「刻の図書館の連中だろ。飽きずによくやるよ」

「まあ、当たれば一攫千金だからな。あの遺跡、未だに誰も攻略できてないんだろ?」

「噂じゃ、番人みたいなのがいて先に進ませてくれないとか」

　聞くともなしに耳に入ってくる。

　ウィンは聞き耳を立てるのもそこそこに、掲示板へ向き直った。選んだのは、「灰狼の森の奥に出る、猪型の中型モンスターを一体討伐してほしい」という依頼だった。

　依頼票の隅には小さく、「森のさらに奥は強力なモンスターが出現するため、単独での深追いは危険」という注意書きが添えられている。

　今日はそこまで踏み込むつもりはないが、さっきの話と重なって、鬱蒼と茂る木々の向こうに何があるのか、少しだけ想像を掻き立てられた。

　丘を越え、森の入り口をくぐる。日差しは葉の隙間から漏れる光の筋に変わり、下草を踏むたびに湿った土の匂いが立ち上った。丘の獣とは違う気配――遠くで鳴く鳥の声、風に揺れる枝葉の音までもが、やけに大きく聞こえる。



　最初に出くわしたのは、灰色の毛並みの獣だった。丘で二度、相手をしている。

　木の根元からこちらを見て、喉を低く鳴らしていた。

　ちょうどいい。新しい得物を試すなら、慣れた相手からがいい。

　間合いが詰まる前に、腰のナイフを一本抜いて投げる。

　だが切っ先はわずかに逸れ、獣の肩先をかすめただけで地面に突き立った。借り物の石や枝を変形させて投げていた時とは、重さも軸の取り方もまるで違う。

　舌打ちしそうになるのを堪え、すぐさま二本目を抜く。手首の返しをほんの少し浅くして、もう一度放った。

　刃はまっすぐに飛び、獣の急所へ吸い込まれるように突き刺さる。獣は光の粒子になって消え、地面には二本のナイフと、小さな牙が一つ残った。

　最初から狙って作られた武器は、重心も刃の角度も、投げるという動作にぴたりと馴染む。借り物を鏃の形に変えるまでの一手間がない分、動きに迷いが生まれない。

　落ちていた二本を拾い上げ、鞘に戻す。借り物と違ってここで回収しておかないと、次第に手持ちが尽きてしまう。当たり前のことなのに、妙に新鮮な手間だった。

　ついでに牙も拾い、インベントリに収める。今日は素材買取に寄らないので、溜めておくだけだ。

　その後も同じ調子で、灰色狼を二体仕留めた。狙って、投げて、当てて、拾い直す。

　その繰り返しの中で、ナイフの重さが少しずつ手に吸い付くようになっていった。



　森が深くなるにつれ、下草の音が変わった。獣の足音にしては重く、規則的な地響きが、少しずつ近づいてくる。

　木々の隙間から姿を現したのは、丘の獣よりも一回り大きな、猪型のモンスターだった。前脚が地面を二度掻き、乾いた土が後ろへ飛ぶ。

　急所看破の効果か、下げた頭の眉間の一点だけが、他よりわずかに白く際立って見えた。

　猪が土を蹴立てて突っ込んでくる。ウィンはナイフを投げた。切っ先は狙った眉間を捉えたが、猪はひるむ様子もなく、勢いのまま距離を詰める。

　――一発じゃ、足りない。

　横に跳んでかわしながら、ウィンは焦りを噛み殺す。急所看破で狙いは定まっているのに、決め手に欠ける。投げるだけの手数では、この重さを止めきれない。

　ウィンは腰の短剣を一本抜き、意識を通した。

　切っ先が伸びていく。ただし、昨日のようには伸ばさない。倍まで伸ばせば薄くなってたわむことは、柵の杭が教えてくれた。

　半分増しで止めて、浮いたぶんを切っ先の厚みに回す。斬るためではなく、突き通すための形だ。

　狙うのは、もう一度同じ急所。

　振り向きざまに突進してきた猪の急所へ、伸ばした切っ先を突き立てる。

　ズンッ、と重い音が、柄を握った手から肩の付け根まで届いた。

　猪は最後にもう一度だけ暴れ、光の粒子になって消えていく。短剣はひとりでに元の刃渡りへ戻った。ウィンは肩で息をつきながら、地面に落ちたナイフと、大ぶりな牙を拾い集める。

```
『スキル「精密投擲」を習得しました』
　狙った一点へ、構えを取らずに投げられるようになります
```

```
『Lv5に上がりました』
```

　構えを取らずに。読んで、ウィンは心当たりに行き着いた。

　土壇場で投げた一本が、迷いも構えもないまま狙った場所へ行った。あれのことだ。


　　　　◇


　依頼を終えてギルドへ戻る。受付は依頼票と端末の記録を突き合わせて、淡々と告げた。

「討伐、確認できました」

　空に近かった財布に、また少しだけ厚みが戻った。



　ギルドの隅に移動して、壁に背を預ける。

　そういえば、さっき槍状に伸ばした短剣は、初日に枝を変えていた時より長く形を保っていた。

　腰のナイフに軽く触れる。理屈で選んだわけではない得物が、こうして手の中にしっくり収まっている。

　似合っているかどうかは、まだ分からない。

　それでも、選んだのは自分だった。
