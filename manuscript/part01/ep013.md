# 第十三話　苔纏いの番人

　残っていた角兎が、正面から跳びかかってくる。ウィンはそれを空中で喉から捉えた。獣は光の粒子になって消え、残るは猪型一体だけになった。

「よし、これで最後!」

　茜音が声を弾ませる。ウィンは突進してくる猪型を半歩でかわし、すれ違いざま、槍状に変えた短剣を首筋の白い一点へ通した。

　猪は一声だけ短く鳴き、粒子となって消えていった。

「討伐目標、たぶんこれで全部だよね」

「ですね。ちょうど揃いました」

　二人は顔を見合わせ、どちらからともなく息をついた。

　依頼としてはこれで十分なはずだった。だが茜音は帰り道へ向かう様子もなく、木々の隙間に目を向けたままだった。

「もうちょい奥、行ってみない?」

「奥、ですか」

「あんまり奥は良くないかもしれないです。前に依頼票で見たんですけど、この先は強いモンスターが出るからって」

「そうなんだ……」

　初めて聞いたというように、茜音は目を丸くした。それから、少し困ったような顔で自分の耳のあたりに手をやる。

「じゃあ、戻りましょう。俺たちにはまだ――」

　言い終わる前に、茜音がふいに足を止めた。

「待って。……なんか、聞こえる」

「何がですか」

「わかんない。声、みたいな……誰かが何か呼んでいるみたいな」

　茜音自身、戸惑っているのが見て取れた。眉を寄せ、耳を澄ますような仕草をしながら、木々の奥へじっと目を凝らしている。

「俺には何も聞こえませんけど」

「うん、自分でも変だと思うんだけど……なんか、行かなきゃいけない気がする」

　冗談を言っているふうではなかった。いつもの朗らかな声とは違う、真剣な響きがある。

「……行きたい、ってことですか」

「うん。ごめん、勝手言ってるのわかってるけど」

　珍しく歯切れの悪い声で、それでも茜音はまっすぐにウィンを見た。ウィンはしばらく黙り込む。

　根拠のはっきりしない「声」を頼りに、危ないと分かっている場所へ踏み込む。普段の自分なら、迷わず断っていた。

　ただ、この奥に崩れた柱の遺構がある、という噂なら、ギルドで小耳に挟んだことがある。誰も正体を知らないという、あの柱だ。

「……分かりました。戦いに行くんじゃなくて、様子を見るだけです。危ないと思ったら、すぐ引き返しますからね」

　声のする方へ、茜音が先に立って歩き出す。下草はいつの間にか薄くなり、地面には苔むした石畳の名残が覗いていた。

　崩れかけた柱が、等間隔にいくつも倒れている。噂の柱は、本当にあった。

　少し進むと、切り立った岩肌に黒々とした穴が口を開けている。踏み荒らされた形跡もない、手つかずの洞窟だ。こんなものがあるという話は、あの噂のどこにもなかった。

「ここから聞こえてくる……気がする」

　茜音が洞窟を指差したその時、入り口の脇に積もっていた苔の山が、ゆっくりと動いた。

　最初は岩塊だとばかり思っていた。だがそれはゆっくりと頭を持ち上げ、二人へ目を向けてくる。

　全身を分厚い苔が覆い、石像と見紛う巨体。体高はウィンの背丈の二倍近く、四肢は太い岩柱を思わせる。

　低く唸る声だけで、地面がびりびりと震えた。

　これまで相手にしてきた灰色狼や猪型とは、明らかに格が違う。ウィンは思わず息を呑み、半歩後ろへ下がる。

「……なんですか、あれ」

「わかんない。けど、なんかすごい圧……」

　茜音の声も強張っている。体を覆う苔の積もり方からして、長いことこの場から動いていないのだろう。まるで、洞窟の門番だった。

　ウィンは茜音の肩を引いて、距離を取らせた。

「戻りましょう。今の俺たちだと、たぶん厳しいです」

「……うん、それはわかる」

　茜音は素直に頷いた。だが、その視線は洞窟から離れない。

「でも、あの奥から聞こえてる気がするんだよね。行きたい」

「危ないですよ、本当に」

「わかってる。無理にとは言わない。でも……行きたい」

　繰り返す声に、譲らない芯があった。ウィンはしばらく黙り、大熊と茜音の顔を交互に見比べる。

　頷けば、この人を危険にさらすことになる。かといって、この目のまま引き下がるとも思えなかった。

「……仕方ありません。やるだけ、やってみましょう。ただし、駄目だと思ったらすぐ退きます。それが条件です」

「うん、約束する」

「あの図体だと、正面から力比べしても勝ち目は薄いです。急所を見極めて、確実に一撃を通す形にします」

「わたしは……ライトウォールで守りつつ、隙があったらライトバレット撃つね」

「詠唱中は無防備になるので、そこは俺が前に出て牽制します。危ないと思ったらすぐ下がってください」

「うん。頼りにしてる」

　二人は短く頷き合い、それぞれの得物に手をかけた。



　ウィンが先に仕掛けた。投擲ナイフを続けざまに投げ、大熊の注意を引く。

　だが、ガッ、と苔の層に阻まれ、浅く食い込んだだけで刃は落ちた。

　硬く分厚い苔そのものが、天然の鎧のように働いているらしい。大熊が唸り、太い前脚を振り上げる。

　ウィンは横に跳んでかわす。ズドッ、と一拍遅れて、さっきまでいた場所の土がえぐれた。もらえば、ただでは済まない。

　幸い、動きそのものは速くない。避けるだけなら、まだ何とかなる。

　だが、こちらの攻撃が決定打になる気配はまるでなかった。

　急所看破で狙いを定めようとするが、白く浮かび上がるはずの一点がなかなか定まらない。分厚い苔に阻まれているせいだと、ウィンはそう判断した。

　ウィンは近くに転がっていた崩れた柱の欠片に目を留める。持ち主のいない、ただの瓦礫だ。断りを入れる必要もなく、意識するだけですぐに形が変わり始めた。

　ごつごつした欠片が、平たく厚みのある板状に姿を変える。

　避け続けるうちに、背中が岩肌へ寄っていた。次の一撃は、跳んでかわす場所がない。

　両手で構えた即席の盾が、ガアン、と爪を受け止める。衝撃が腕の付け根まで抜けたが、なんとか踏みとどまった。

「ライトウォール!」

　茜音が杖を掲げて叫ぶと、薄い光の膜が二人を包む。完全には防げない一枚でも、呼吸を一つ取り戻せる。

　大熊が大きく吼えて頭をのけぞらせた瞬間、喉元の苔がわずかに薄くなっている場所が目に留まる。急所看破の光が、そこだけ白く際立った。

「喉です。苔の薄いところなら通ります……!」

「わかった、援護する。ライトバレット!」

　溜めを経て放たれた光弾が、大熊の顔面を掠める。ひるんだ隙に、ウィンは毒を塗った投擲ナイフを喉元目掛けて投げつけた。

　ザクッ、と刃が薄くなった苔を貫いて、皮膚に食い込む。

　だが好機と見て踏み込んだ瞬間、振り向きざまの一撃が来た。

　ドンッ、と視界が跳ぶ。地面を転がりながら、脇腹に鈍い痛みが走った。

　防具屋で買った上着の裏地が、衝撃のいくらかを殺してくれたのか、覚悟していたほどの痛みではない。それでも息が詰まる。

「ウィンくん!」

　悲鳴に近い声を上げて駆け寄りかけた茜音が、すぐに思い直したように杖を構え直した。

「ライトバレット! ライトバレット!」

　立て続けに放たれた光弾が、大熊の顔面へと吸い込まれていく。唸り声を上げた大熊が、そちらへ向き直った。

「今のうちに、早く!」

　ウィンは懐から傷薬を取り出し、一気に呷った。傷口の痛みが和らいでいくのに合わせて、手のひらほどの淡い光がふわりと体を包み込む。茜音が意識のどこかで、こちらにも力を分けてくれているらしい。

　大熊の前脚が振り下ろされる寸前、「ライトウォール!」という声とともに光の膜が二人の間に割り込んだ。分厚い一撃を受けてもなお、その一枚は破れきらずに持ちこたえる。

「大丈夫です、もう動けます」

「無理しないで、ちゃんと言ってね」

「はい。……次で、決めます」

　毒に蝕まれた大熊の動きは、明らかに精彩を欠いていた。毒への耐性は強くないのかもしれない。大きく体勢を崩した隙を、ウィンは見逃さない。

　板状に変えていた瓦礫を手放すと、意識が逸れた途端にただの欠片へ戻る。空いた手で短剣を抜くと、刃が水を吸うように伸びて、鋭く長い穂先になった。

　喉元の、苔の薄くなった一点。

　地を蹴る。



　ズンッ、と根元まで入った。

　これまでで一番重い手応えが、腕を伝って肩まで抜ける。

　大熊が大きくのけ反った。二度、三度と痙攣するように震え、ずるり、と苔の層が肩から剥がれ落ちる。その下から溢れた光が、輪郭ごと巨体を持っていった。

　辺りに、森のざわめきだけが戻ってくる。

　ウィンは傷薬をもう一本呷った。脇腹の熱が、ゆっくりと引いていく。

```
『Lv7に上がりました』
```

　続けて、視界にもう一つ通知が浮かぶ。

```
『Lv8に上がりました』
```

「二つも……一体でここまで上がったのは初めてです」

「わたしも二つ! ……はー、働いたねえ、わたしたち」

　角兎や猪型の分も、まとめて入ったのだろう。

　大熊が消えた場所には、灰色がかった大きな爪が一つ残っていた。拾い上げると、『苔纏いの大熊の爪』という表示が出る。ウィンはそれをインベントリに収めた。

　顔を上げると、洞窟の入り口は何事もなかったかのように静まり返っていた。

「……まだ、聞こえてる。この奥」

　茜音が暗がりを指す。ウィンはしばらく、そこから目を離せなかった。
