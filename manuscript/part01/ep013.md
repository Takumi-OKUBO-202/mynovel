# 第十三話　苔纏いの番人

　残っていた角兎は、思いのほかあっけなく片が付いた。跳びかかってきた一匹の額を、冬夜は最短の一撃で捉える。獣は光の粒子になって消え、残るは猪型一体だけになった。

「よし、これで最後!」

　茜音が声を弾ませる。突進してくる猪型に、冬夜は短剣を槍状に変形させて迎え撃った。急所看破で見えた白く際立つ一点に、迷いなく切っ先を突き立てる。

　猪は一声だけ短く鳴き、粒子となって消えていった。

「討伐目標、たぶんこれで全部だよね」

「ですね。ちょうど揃いました」

　二人は顔を見合わせ、どちらからともなく息をついた。ここまで大きな怪我もなく来られたことに、密かな安堵がある。

　依頼としてはこれで十分なはずだった。だが茜音は振り返る様子もなく、木々の隙間に目を向けたままだった。

「もうちょい奥、行ってみない?」

「奥、ですか」

　冬夜は少し身構えた。投擲ナイフを買った日に見た依頼票の注意書きを思い出したからだ。――森のさらに奥は強力なモンスターが出現するため、単独での深追いは危険。

　苔むした石段や崩れた古い柱が眠っているという、あの噂の場所だ。トレジャーハンター気取りのプレイヤーや、歴史探究クランが度々調査に入っているらしいが、正体はいまだ分かっていないと聞いている。

「あんまり奥は良くないかもしれないです。前に依頼票で見たんですけど、この先は強いモンスターが出るからって」

「そうなんだ……」

　初めて聞いたというように、茜音は目を丸くした。それから、少し困ったような顔で自分の耳のあたりに手をやる。

「じゃあ、戻りましょう。俺たちにはまだ早いと思います」

　冬夜がそう言いかけたところで、茜音がふいに足を止めた。

「待って。……なんか、聞こえる」

「何がですか」

「わかんない。声、みたいな……誰かが何か呼んでいるみたいな」

　茜音自身、戸惑っているのが見て取れた。眉を寄せ、耳を澄ますような仕草をしながら、木々の奥へじっと目を凝らしている。

「俺には何も聞こえませんけど」

「うん、わたしにも変な感じなんだけど……なんか、行かなきゃいけない気がする」

　冗談を言っているふうではなかった。いつもの朗らかな声とは違う、真剣な響きがある。

「……行きたい、ってことですか」

「うん。ごめん、勝手言ってるのわかってるけど」

　珍しく歯切れの悪い声で、それでも茜音はまっすぐに冬夜を見た。冬夜はしばらく黙り込む。

　危険だと分かっている場所に、根拠のはっきりしない「声」を頼りに踏み込む――普段の自分なら、迷わず断っていたはずだった。だが、この世界はゲームなんだし、少しくらい冒険しても良い気がした。きっとこれは茜音の影響も受けているのだろうと冬夜も自覚していた。

「……分かりました。少しだけ、様子を見に行きましょう」

　声のする方へ、茜音が先に立って歩き出す。下草はいつの間にか薄くなり、地面には苔むした石畳の名残らしきものが覗いていた。崩れかけた柱が、等間隔にいくつも倒れている。

　人の手が入った痕跡は、周囲の木々とは明らかに異質だった。

　少し進むと、切り立った岩肌に黒々とした穴が口を開けている。踏み荒らされた形跡もない、手つかずの洞窟だ。

　柱の噂は聞いていたが、洞窟があるとは聞いていない。おかしなルートを通った覚えもないが、探索済みなのかどうかまでは判断がつかなかった。

「ここから聞こえてくる……気がする」

　茜音が洞窟を指差したその時、入り口の脇に積もっていた苔の山が、ゆっくりと動いた。

　最初は岩塊だとばかり思っていた。だがそれは鎌首をもたげるように頭を持ち上げ、二人へ双眸を向けてくる。

　全身を分厚い苔が覆い、石像と見紛う巨体。体高は冬夜の背丈の二倍近く、四肢は太い岩柱を思わせる。

　低く唸る声だけで、地面がびりびりと震えた。

　これまで相手にしてきた灰色狼や猪型とは、明らかに格が違う。冬夜は思わず息を呑み、半歩後ろへ下がった。

「……なんですか、あれ」

「わかんない、けど……すごい、圧」

　茜音の声も強張っている。長くこの洞窟の入り口に居座っていたのだろう、苔纏いの大熊とでも呼ぶべきその姿は、まさに門番そのものだった。

　冬夜は一度、茜音の肩を押さえて距離を取らせた。

「戻りましょう。今の俺たちだと、たぶん厳しいです」

「……うん、それはわかる」

　茜音は素直に頷いた。だが、その視線は洞窟から離れない。

「でも、あの奥から聞こえてる気がするんだよね。行きたい」

「危ないですよ、本当に」

「わかってる。無理にとは言わない。でも……行きたい」

　繰り返す声には、いつもの軽さの中に、譲らない芯があった。冬夜はしばらく黙り、大熊と茜音の顔を交互に見比べる。

　無理強いはしたくない。かといって、頷いた自分がこの人を危険にさらすことにもなりかねない。

「……仕方ありません。やるだけ、やってみましょう」

　まず状況の整理から始めた。

「あの図体だと、正面から力比べしても勝ち目は薄いです。急所を見極めて、確実に一撃を通す形にします」

「わたしは……ライトウォールで守りつつ、隙があったらライトバレット撃つね」

「詠唱中は無防備になるので、そこは俺が前に出て牽制します。危ないと思ったらすぐ下がってください」

「うん。頼りにしてる」

　二人は短く頷き合い、それぞれの得物に手をかけた。



　冬夜が先に仕掛けた。投擲ナイフを続けざまに投げ、大熊の注意を引く。

　だが、ガッ、と苔の層に阻まれる。浅く刺さっただけで、刃は弾かれた。

　硬く分厚い苔そのものが、天然の鎧のように働いているらしい。大熊が唸り、太い前脚を振り上げる。

　冬夜は横に跳んでかわす。ズドッ、と空を切った一撃だけで足元の土がえぐれた。もらえば、ただでは済まない。

　幸い、動きそのものは速くない。速さばかりを伸ばされてきた冬夜なら、避けるだけならまだ何とかなる。

　だが、こちらの攻撃が決定打になる気配はまるでなかった。

　急所看破で狙いを定めようとするが、白く浮かび上がるはずの一点がなかなか定まらない。分厚い苔に阻まれているせいだと、冬夜はそう判断した。

　冬夜は近くに転がっていた崩れた柱の欠片に目を留める。持ち主のいない、ただの瓦礫だ。断りを入れる必要もなく、意識するだけですぐに形が変わり始めた。

　ごつごつした欠片は、平たく厚みのある板状に姿を変える。まだ単純な形にしか変えられない自分の力では、これが精一杯だ。

　両手で構えた即席の盾で、二撃目の爪撃を受け止める。ガアン、と衝撃が腕の付け根まで抜けたが、なんとか踏みとどまった。

「ライトウォール!」

　茜音が杖を掲げて叫ぶと、薄い光の膜が二人を包む。完全には防ぎきれないが、そのわずかな一枚が、冬夜に安心感を与えてくれる。

　大熊が大きく吼えた瞬間、開いた口の奥、喉元の苔がわずかに薄くなっている場所が目に留まる。急所看破の光が、そこだけ白く際立った。

「口の中が弱点のようです……!」

「わかった、援護する。ライトバレット!」

　溜めを経て放たれた光弾が、大熊の顔面を掠める。ひるんだ隙に、冬夜は毒を塗った投擲ナイフを喉元目掛けて投げつけた。

　ザクッ、と刃が薄くなった苔を貫いて、皮膚に食い込む。すぐには倒れないまでも、大熊の動きにわずかな鈍りが見え始めた。毒が効き始めている証拠だ。

　だが好機と見て踏み込んだ瞬間、振り向きざまの一撃が来た。

　ドンッ、と視界が跳ぶ。地面を転がりながら、脇腹に鈍い痛みが走った。

　防具屋で買った上着の裏地が、衝撃のいくらかを殺してくれたのか、覚悟していたほどの痛みではない。それでも息が詰まるような一撃だった。

「冬夜くん!」

　悲鳴に近い声を上げながら、茜音は冬夜に駆け寄ろうとする素振りを見せたが、すぐに思い直したように杖を構え直した。

「ライトバレット! ライトバレット!」

　立て続けに放たれた光弾が、大熊の顔面へと吸い込まれていく。狙いは冬夜ではなく、自分へ意識を向けさせるための連射だった。唸り声を上げた大熊がそちらへ向き直る。

「今のうちに、早く!」

　冬夜は懐から傷薬を取り出し、一気に呷った。傷口の痛みが和らいでいくのに合わせて、手のひらほどの淡い光がふわりと体を包み込む。茜音が意識のどこかで、こちらにも力を分けてくれているらしい。

　大熊の前脚が振り下ろされる寸前、「ライトウォール!」という声とともに光の膜が二人の間に割り込んだ。分厚い一撃を受けてもなお、その一枚は破れきらずに持ちこたえる。

「大丈夫です、もう動けます」

「無理しないで、ちゃんと言ってね」

「はい……もう一回、いけます」

　毒に蝕まれた大熊の動きは、明らかに精彩を欠いていた。毒への耐性は強くないのかもしれない。大きく体勢を崩した隙を、冬夜は見逃さない。

　板状に変えていた瓦礫を手放すと、意識が逸れた途端にただの欠片へ戻る。空いた手で短剣を抜くと、刃が水を吸うように伸びて、これまでにないほど鋭く長い穂先になった。

　喉元の、苔の薄くなった一点。

　地を蹴る。



　ズンッ、と根元まで入った。

　これまでで一番重い手応えが、腕を伝って肩まで抜ける。

　大熊が大きくのけ反った。二度、三度と痙攣するように震え、ずるり、と苔の層が肩から剥がれ落ちる。その下から溢れた光が、輪郭ごと巨体を持っていった。

　辺りに静寂が戻る。二人はしばらく、荒い息をついたまま動けずにいた。

```
『Lv7に上がりました』
```

　続けて、視界にもう一つ通知が浮かぶ。

```
『Lv8に上がりました』
```

　一気に二段階も上がった実感に、冬夜は思わず声を漏らす。

「二つも……一体でここまで上がったのは初めてです」

　角兎や猪型を狩っていた分もまとめて入ったのだろうが、それだけでは説明のつかない伸び方だった。以前も一日のうちに二段階上がったことはあるが、あれは複数の討伐を重ねた末の話だ。今回はたった一体、あの大熊がどれだけ格上だったか、数字が何より雄弁に語っている。

　大熊が消えた場所には、灰色がかった大きな爪が一つ残っていた。冬夜はそれを拾い、インベントリに収める。

　顔を上げると、洞窟の入り口が、何事もなかったかのように静かな口を開けていた。声の主は、まだこの奥にいるのだろうか。

　冬夜は乱れた息を整えながら、じっとその暗がりを見据えた。
