# 第十五話　白虎の、本来の大きさ

　玄関を開けると、廊下の奥からカレーの匂いが漂ってきた。

　母と向かい合って夕飯を済ませ、食器を洗ってから自室に上がる。時計は七時半を回ったところだった。

　いつもならそのままヘッドギアを手に取るところだが、今日はその前にやることがある。冬夜は机の上のノートパソコンを開いた。

　聞いて回るつもりはない。「刻紋種をテイムした人はいますか」などと書き込めば、それだけで手の内を明かすことになる。すでに出回っているものを、静かに読むだけにする。

　掲示板はゲームの中からは覗けない。潜っているあいだは、外の画面が何一つ見られない仕組みになっている。だから調べ物は、こうしてログイン前の時間に回ってくる。

　冬夜はまず、刻紋種の総合スレッドを開いた。

```
【総合】刻紋種について語るスレ Part17

204: 名無しの冒険者
先週北の湿地に出たやつ、結局どこが獲ったの?

205: 名無しの冒険者
夜会。というかここ最近ぜんぶ夜会

206: 名無しの冒険者
ドロップ晒しスレ見てきたけど刻紋銘マジで格が違うな
一生縁がなさそう

207: 名無しの冒険者
そもそも遭遇報告自体が月に数件だからな
見つけたら即討伐、それ以外の選択肢がない
```

　討伐報告と、落ちた装備の自慢話。スレッドの中身はほとんどそれで埋まっていた。夜会、という名前だけが何度も出てくる。

　「即討伐、それ以外の選択肢がない」という一文の上で、冬夜はしばらく指を止めた。昨日自分が立ち会ったのは、まさにその「それ以外」だった。

　次に、従魔やペットに関するスレッドを探して開く。

```
【相談】従魔・ペット系の話をするスレ

88: 名無しの冒険者
そもそもこのゲーム、テイマー系のジョブ自体が用意されてないんだよな

89: 名無しの冒険者
クレストで使役っぽいの引いたやつはいるらしい
小鳥を一羽出せるとか、そのくらいって聞いた

90: 名無しの冒険者
ロマンはあるけど戦力にはならんでしょ

91: 名無しの冒険者
刻紋種を手懐けたって話、どっかで見た気がするんだけど

92: 名無しの冒険者
それ去年のエイプリルフールのネタスレ
```

　冬夜は短く息を吐いた。見た気がする、と言い出した人がいて、それがネタスレ扱いで終わっている。

　前例が一つでもあれば、その人がどうやって隠しているのかも分かる。そう思って開いたスレッドだった。

　昨日「知られたらまずい」と言ったのは間違っていなかった。ただ、隠し方のほうは、誰も教えてくれない。

　最後に、地元の狩場の情報を確かめておくつもりで、灰狼の森のまとめスレッドを開いた。ここ数日ずっと通っている場所だ。

```
【灰狼の森】エリア情報まとめスレ

341: 名無しの冒険者
奥の遺跡側はさんざん調べられてるからもういいとして、
問題は深部な。あのへんの狼、明らかに様子がおかしい

342: 名無しの冒険者
わかる。縄張りから出たのにまだ追ってくる
こっちが背中を向けても延々ついてくるんだよ

343: 名無しの冒険者
四人で入って全滅した
数もだけど、動きの揃い方が普通じゃない
なんかいるだろあそこ

344: 名無しの冒険者
初心者向けエリアの皮を被った別のなにか
深部にだけは行くな
```

　冬夜は椅子の背にもたれた。深部が荒れているという話自体は前から出ていて、だから近づかずにいた。

　度を越して執拗な狼。妙に揃った動き。昨日見た、鎖に繋がれていた白い虎の姿が、なぜだか頭の隅にちらついた。

　同じ森の話だ。無関係と決めつけるには、いささか近すぎる。

　ログインしたら茜音にも伝えておこう、と冬夜は思った。あの人は好奇心の塊みたいなところがあるから、「面白そうな場所がある」という言い方だけは絶対にしないでおこう、とも。

　時計を見ると、もう八時半近い。今日はログインが遅くなりそうだった。


　　　　◇


　同じ日の昼下がり。冬夜がまだ書店の棚を整理していた頃のことだ。

　灰狼の森には、高い日が差していた。

　木漏れ日が斑に落ちる獣道を、茜音は一人で歩いていた。手前の縄張りには灰色狼が数匹いたが、どれも遠巻きにこちらを窺うばかりで、寄ってはこない。

　人目につかない場所がいい。そう考えて、茜音は昨日通った遺跡の一帯をさらに越え、奥へと足を延ばしていた。

　やがて木立が途切れ、ひらけた草地に出る。ここまで来れば、誰かとすれ違うこともない。

　ぐるりと一周、目で確かめる。人影はなく、聞こえるのは風と葉擦れの音だけだった。

「よし、誰もいない」

　茜音は満足げに頷いて、手の甲に浮かぶ紋章へ意識を向けた。淡い光の粒がこぼれ、足元に小さな白い虎が姿を現す。

　両腕で抱えられるくらいの白虎は、草の上でひとつ伸びをして、丸い目で茜音を見上げた。

「あのね。ちょっとだけ、試してみたいことがあるんだけど」

　茜音は屈み込んで、白虎と目線の高さを合わせた。

　昨日、この子を紋章へ収めたとき、表示にもう一行あった。ちゃんと読まないまま街へ戻ってしまったが、確かにそう出ていた。魂力が足りないから、この大きさなのだと。

　つまり足りていれば、洞窟で最初に見たときの——見上げるほどの体に戻せる。

「元の大きさに戻ってもらっても、いい?」

　白虎は答えの代わりに、ゆっくりと一度だけ瞬きをした。

　茜音が息を吸い、意識を向ける。

　次の瞬間、体の芯からごっそりと何かを引き抜かれるような感覚が走って、茜音は思わず片膝をついた。

「うわ、なにこれ」

　走ったわけでも魔法を撃ったわけでもないのに、全力疾走の直後みたいに息が上がっていた。

　顔を上げた茜音は、そのまま言葉を失う。

　真っ白な毛並みが、視界をふさぐように広がっていた。

　太い前脚が草を踏むたび、地面がわずかに震える。見上げないと顔が見えないほどの巨躯が、洞窟で見たときとまったく同じ姿でそこに立っていた。

「……おっきい」

　間の抜けた感想が口をついて出た。

　昨日この子を助けたのは自分のはずなのに、こうして見上げていると、自分がひどくちっぽけに思えてくる。

　やがて我に返って、茜音は自分の体の内側に意識を向けた。魔法を使ったときに減るものとは別の、クレストを動かすための力——それが、じわじわと目減りしていくのが分かる。

　減りが、はやい。

　呼び出しただけで一気に持っていかれた上に、こうして立たせているだけでも、じわじわと削られ続けている。

　小さいままで連れ歩いていたときは、こんな目減りは一度もなかった。あの姿は、ほとんど力を食わずに済む形だったのだ。

　そういえば、と茜音は思い出す。同じくらいのレベルの子より、自分はこの帯だけが長かった。

　職業のせいだろうと流していたが、今にして思えば——と考えかけて、やめた。今はそれどころではない。

　それでも、レベルが低すぎる。この調子だと、いくらももたない。

「ごめん、やっぱり戻ってもらお——」

　言いかけた声が、途中で止まる。

　森が、静かになっていた。

　葉擦れの音はする。風もある。ただ、さっきまで遠巻きにうろついていた灰色狼たちの気配だけが、いっせいに草地の外へ引いていた。

　代わりに、茂みの奥から次々と灰色狼が姿を現した。手前で見かけたのとは比べものにならない数だ。だが、どれ一匹として襲いかかってこない。

　この大きさのものを森に出せば、気づかれる。そこまで考えていなかった、と茜音は思った。

　狼たちは草地の縁にずらりと並び、それから左右に割れて、道を開けた。

　開いた道の奥から、それは悠然と歩いてきた。

　灰色の狼だ。ただし、周りの個体の三倍はある。額から背にかけて、焼き印を押したような黒い紋様が走り、歩くたびに鈍い光を帯びて明滅している。

　茜音の視界の隅に、見覚えのある表示が浮かぶ。

```
刻紋種
森閉ざしの灰狼(もりとざしのはいろう)
```

　喉の奥が引き攣った。刻紋種。昨日、洞窟の奥で見たのと同じ言葉だ。

　灰狼が低く一声唸る。並んでいた狼たちが、いっせいに腹を地につけた。

　訓練された兵のような、寸分の乱れもない伏せ方だった。手を出すな、と言われたのだと分かる。

　王様だ、と茜音は思った。群れの一匹一匹まで、この一頭に従っている。

　だが、その目だけが違った。

　灰狼は瞬きひとつしない。こちらだけを見て、ここから生きて帰さないと決めている目だった。

　落ち着き払った佇まいと、それがどうにも噛み合わない。

　伏せていた狼のうち数匹が、音もなく身を起こす。茜音が歩いてきた獣道を、静かに塞ぐ位置だった。

　茜音は膝に力を入れて立ち上がった。両手で杖を握りしめてはみたが、指先の震えは自分でも分かる。

「……えっと。わたし、帰るところ、なんだけど」

　声が上ずった。

　茜音は戦うのが怖い。前に出なくていい職を選んだのも、もとはといえばそれが理由だ。

　灰狼が、地を蹴った。

　ドッ、と土が跳ねる。巨体からは想像もつかない速さで、黒い紋様を纏った体が跳んだ。

「ラ、ライト——」

　技名の途中で、声が喉に張りついた。間に合わない。詠唱には溜めが要る。

　白虎が、前に出た。

『下がっておれ』

　声にならない声が、頭の奥に直接響く。

　白虎が大きく息を吸い込む。

　同時に、茜音の内側から力が引かれていくのが分かった。呼び出したときの比ではない。あと何秒もつのか、数えるより先に空になりそうだった。

　あたりの空気がすっと冷えた。草の葉先が白く縁取られ、パキ、パキ、パキ——霜の走る音が、足元から前へ向かって広がっていく。

　次の瞬間。



　ゴオッ、と白が噴き出した。

　白い奔流が、茜音の頭のすぐ上を越えて、まっすぐ前へ伸びる。

　跳んだ姿勢のままの灰狼が、その中に飲み込まれた。声はひとつも聞こえない。

　奔流が途切れる。ミシ、ミシ、と正面の木々の幹が軋んだ。

　視界が晴れたとき、そこには氷に閉じ込められた灰色の塊があった。跳びかかる姿勢のまま、宙に浮いた前脚の爪の一本一本まで白く凍りついている。

　やがて、パキン、と乾いた音がひとつ。塊が内側から崩れて、光の粒子になって散っていった。

　草地には、白い帯が一本残っていた。茜音の少し前から正面の木立まで、そこだけが霜で塗り替えられている。

　帯の外にいた狼たちが弾かれたように立ち上がり、獣道を塞いでいた数匹も含めて、我先にと茂みの奥へ散っていった。

　視界に通知が浮かぶ。

```
森閉ざしの灰狼を討伐しました
ドロップ品を入手しました

刻紋銘・森閉ざしの外套(もりとざしのがいとう)
分類:逸品(Bランク)
```

　レベルの通知は出なかった。倒したのがこの子だからなのか、それとも別の理由なのか、茜音には分からない。

「……いっ、一撃……」

　茜音の声が、白い息になって漂う。

　それから、さっき頭の中に響いた声を思い出した。下がっておれ、と確かに言われた。

「……しゃべった、よね。いま」

　白虎は答えない。振り向きもしない。

　背筋が冷えた。あの巨大な王様が、たった一息で、跡形もなくなってしまった。

　その直後だった。膝から力が抜けて、茜音はその場にへたり込む。

　視界の端に、通知が浮かんだ。

```
魂力が尽きたため、召喚状態を維持できません
```

　目の前で、白い山が急速に縮んでいく。あっという間に、両腕で抱えられるくらいの大きさに戻ってしまった。

「え、ちょ、待って——」

　茜音は慌てて手の甲を見た。三つ並んだ星のうち、昨日色づいた一つは、変わらず淡い蒼の光を帯びている。

　足元では、小さくなった白虎が何事もなかったような顔で座り込んでいる。繋がりはそのままで、大きさだけが元に戻ったのだ。

　茜音はようやく肩の力を抜いた。

「……びっくりした。いなくなったのかと思った」

　小さな白虎が、鼻先を茜音の膝に押しつけてくる。

　次に出しても、たぶん同じくらいしかもたない。一戦交えれば、それで空になる。

「……気軽に出せる子じゃなかったんだね」

　白虎は目を細めたまま、やはり何も言わない。

　さっきの通知にあったドロップ品を、インベントリから取り出してみる。深い灰色をした薄手の外套だった。

　広げても重さをほとんど感じない。肩にかけて一歩踏み出すと、下生えを踏む音が、自分の耳にもほとんど届かなくなった。

　裾の内側には、あの灰狼の紋様によく似た刻印が小さく打たれていた。

　こんなものを持っている人を、茜音は見たことがない。

「……わたしが着ても、しょうがないやつだ」

　苦笑して、茜音は外套を畳んだ。技名を叫んで光を撃つのに、足音だけ消してどうする。

　これが似合う人なら、一人だけ知っている。



　草地の縁で、枝の鳴る音がした。

　茜音が顔を上げる。木立の隙間に人影があった。腰まで届く長さの弓の、先だけが枝の間から覗いている。

「あ、あの——」

　声をかけた時にはもう遅かった。人影は弾かれたように後ずさり、それきり輪郭が薄れて、その場から消える。ログアウトだ。

　名前を確かめる間もなかった。見てはいけないものを見た、という下がり方だけが目に残っている。

　あとには、霜の残る草地と、踏み荒らされた下生えだけが残された。

　茜音は誰もいなくなった木立をしばらく見つめてから、外套を抱えたまま、小さく呟く。

「……見られた、よね。たぶん、ぜんぶ」

　白虎が、木立のほうをじっと見ていた。
