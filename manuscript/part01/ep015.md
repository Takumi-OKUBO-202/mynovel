# 第十五話　本来の大きさ

　書店のバイトを終えて家に着いたのは、午後六時半だった。

　今日は夕方までのシフトだったので、帰りはいつもよりずいぶん遅い。玄関を開けると、廊下の奥からカレーの匂いが漂ってきた。

　母と向かい合って夕飯を済ませ、食器を洗ってから自室に上がる。時計は七時半を回ったところだった。

　いつもならそのままヘッドギアを手に取るところだが、今日はその前にやることがある。冬夜は机の上のノートパソコンを開いた。

　昨日、茜音と決めたことがある。自分から書き込んで聞き回るのはやめる。すでに出回っている情報を、静かに漁るだけにする——そういう方針だった。

　掲示板はゲームの中からは覗けない。ヘッドギアを被る前か、脱いだ後、こうして現実のパソコンから見るしかない仕組みになっている。だから調べ物は必然的に、ログイン前のこの時間に回ってくる。

　冬夜はまず、刻紋種の総合スレッドを開いた。

```
【総合】刻紋種について語るスレ Part17

204: 名無しの冒険者
先週北の湿地に出たやつ、結局どこが獲ったの?

205: 名無しの冒険者
夜会。というかここ最近ぜんぶ夜会

206: 名無しの冒険者
ドロップ晒しスレ見てきたけど刻紋銘マジで格が違うな
一生縁がなさそう

207: 名無しの冒険者
そもそも遭遇報告自体が月に数件だからな
見つけたら即討伐、それ以外の選択肢がない
```

　討伐報告と、落ちた装備の自慢話。スレッドの中身はほとんどそれで埋まっていた。

　「即討伐、それ以外の選択肢がない」という一文の上で、冬夜はしばらく指を止めた。昨日自分が立ち会ったのは、まさにその「それ以外」だった。

　次に、従魔やペットに関するスレッドを探して開く。

```
【相談】従魔・ペット系の話をするスレ

88: 名無しの冒険者
そもそもこのゲーム、テイマー系のジョブ自体が用意されてないんだよな

89: 名無しの冒険者
クレストで使役っぽいの引いたやつはいるらしい
小鳥を一羽出せるとか、そのくらいって聞いた

90: 名無しの冒険者
ロマンはあるけど戦力にはならんでしょ

91: 名無しの冒険者
刻紋種を手懐けたって話、どっかで見た気がするんだけど

92: 名無しの冒険者
それ去年のエイプリルフールのネタスレ
```

　冬夜は思わず短く息を吐いた。前例なし、というより、前例があると言い出すこと自体が冗談として扱われている。

　昨日「知られたらまずい」と言ったのは間違っていなかったらしい。予想していたとはいえ、こうも綺麗に空振りだと、それはそれで途方に暮れる。

　最後に、地元の狩場の情報を確かめておくつもりで、灰狼の森のまとめスレッドを開いた。ここ数日ずっと通っている場所だ。

```
【灰狼の森】エリア情報まとめスレ

341: 名無しの冒険者
奥の遺跡側はさんざん調べられてるからもういいとして、
問題は深部な。あのへんの狼、明らかに様子がおかしい

342: 名無しの冒険者
わかる。縄張りから出たのにまだ追ってくる
こっちが背中を向けても延々ついてくるんだよ

343: 名無しの冒険者
四人で入って全滅した
数もだけど、動きの揃い方が普通じゃない
なんかいるだろあそこ

344: 名無しの冒険者
初心者向けエリアの皮を被った別のなにか
深部にだけは行くな
```

　冬夜は椅子の背にもたれた。遺跡の一帯には昨日足を踏み入れたが、深部というのはそこからさらに外れた区域のことらしい。

　度を越して執拗な狼。妙に揃った動き。昨日見た、鎖に繋がれていた白い虎の姿が、なぜだか頭の隅にちらついた。

　同じ森の話だ。無関係と決めつけるには、いささか近すぎる。

　ログインしたら茜音にも伝えておこう、と冬夜は思った。あの人は好奇心の塊みたいなところがあるから、「面白そうな場所がある」という言い方だけは絶対にしないでおこう、とも。

　時計を見ると、もう八時半近い。今日はログインが遅くなりそうだった。



ーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーー

　ここで、時間を半日ほど巻き戻す。

　冬夜がまだ書店の棚を整理していた、同じ日の昼下がりのことだ。

　灰狼の森には、夏の日差しが降りていた。

　木漏れ日が斑に落ちる獣道を、茜音は一人で歩いていた。手前側の縄張りには灰色狼が数匹うろついていたが、どれも遠巻きにこちらを窺うばかりで、襲いかかってくる気配はない。

　やがて木立が途切れ、ひらけた草地に出る。あたりを見回しても人影はなく、聞こえるのは風と葉擦れの音だけだった。

　その場でぐるりと一周、目で確かめる。それで十分だと、このときの茜音は思っていた。

「よし、誰もいない」

　茜音は満足げに頷いて、手の甲に浮かぶ紋章へ意識を向けた。淡い光の粒がこぼれ、足元に小さな白い虎が姿を現す。

　ぬいぐるみのような大きさの白虎は、草の上でひとつ伸びをして、丸い目で茜音を見上げた。

「あのね。ちょっとだけ、試してみたいことがあるんだけど」

　茜音は屈み込んで、白虎と目線の高さを合わせた。

　昨日この子を仲間にしたときから、なんとなく分かっていたことがあった。この小さな姿は、あくまで連れ歩きやすくするための便宜上の形にすぎない。念じれば、洞窟で最初に見たときの——見上げるほどの本来の体に戻せる。

　仲間になったからといって弱くなったわけではないのだ、という手応えも一緒についてきていた。大きさが変わっても、この子の力そのものは変わらない。ただ、鞄に折り畳んでしまってあるだけだ。

「元の大きさに戻ってもらっても、いい?」

　白虎は答えの代わりに、ゆっくりと一度だけ瞬きをした。

　茜音が息を吸い、意識を向ける。

　次の瞬間、体の芯からごっそりと何かを引き抜かれるような感覚が走って、茜音は思わず片膝をついた。

「うわ、なにこれ」

　走ったわけでも魔法を撃ったわけでもないのに、全力疾走の直後みたいに息が上がっていた。

　顔を上げた茜音は、そのまま言葉を失う。

　真っ白な毛並みが、視界をふさぐように広がっていた。

　太い前脚が草を踏むたび、地面がわずかに震える。見上げないと顔が見えないほどの巨躯が、洞窟で見たときとまったく同じ姿でそこに立っていた。

「……おっきい」

　間の抜けた感想が口をついて出た。

　それきり茜音は、しばらくその場に座り込んだまま白虎を見上げていた。抱き上げられる大きさの生き物が、瞬きひとつの間にこうなってしまうことに、頭のほうが追いついていない。

　昨日この子を助けたのは自分のはずなのに、こうして並んで立つと、自分がひどくちっぽけに思えてくる。

　やがて我に返って、茜音は自分の体の内側に意識を向けた。魔法を使ったときに減るものとは別の、クレストを動かすための力——それが、じわじわと目減りしていくのが分かる。

　減りが、はやい。

　呼び出しただけで一気に持っていかれた上に、こうして立たせているだけでも、じわじわと削られ続けている。

　小さいままで連れ歩いていたときは、こんな目減りは一度もなかった。あの姿は、ほとんど力を食わずに済む省エネの形だったのだと今さら分かる。

　目の前のこの大きさこそが本来の姿なのだと、頭より先に体のほうが理解していく。

　そういえば、と茜音は思い出す。自分は最初から、魂力だけが他の数字に比べて不自然に高かった。当時は何かの割り振りの都合だろうと流していたが、今にして思えば、この子を呼ぶためのものだったのかもしれない。

　それでも、レベルが低すぎる。この調子だと、あと二分ももたない。

「ごめん、やっぱり戻ってもらお——」

　言いかけた声が、途中で止まる。

　森が、静かになっていた。

　葉擦れの音はする。風もある。ただ、さっきまで遠巻きにうろついていた灰色狼たちの気配だけが、いっせいに草地の外へ引いていた。

　そして、退いたはずのその狼たちが、今度は茂みの奥から次々と姿を現す。十匹はいる。だが、どれ一匹として襲いかかってこない。

　狼たちは草地の縁にずらりと並び、それから左右に割れて、道を開けた。

　開いた道の奥から、それは悠然と歩いてきた。

　灰色の狼だった。ただし、周りの個体の三倍はある。額から背にかけて、焼き印を押したような黒い紋様が走り、歩くたびに鈍い光を帯びて明滅していた。

　茜音の視界の隅に、見覚えのある表示が浮かぶ。

```
刻紋種
森閉ざしの灰狼(もりとざしのはいろう)
```

　喉の奥が引き攣った。刻紋種。昨日、洞窟の奥で見たのと同じ言葉だ。

　灰狼が低く一声唸ると、並んでいた狼たちがいっせいに腹を地につけた。訓練された兵のような、寸分の乱れもない伏せ方だった。

　王様だ、と茜音は思った。この森の深いところをまるごと支配して、群れの一匹一匹まで統べている。そういう風格が、その巨体には確かにあった。

　だが、その目だけが違った。

　灰狼は瞬きひとつしないまま、茜音を見据えていた。獲物を値踏みする目でも、縄張りを侵した相手を威嚇する目でもない。ここから絶対に生かして帰さない、と決めきってしまった目だった。

　それは統率者の落ち着き払った佇まいと、どうにも噛み合っていなかった。

　伏せていた狼のうち数匹が、音もなく身を起こす。茜音が歩いてきた獣道を、静かに塞ぐ位置だった。

「……えっと、わたし、帰ろうと思ってたんだけど」

　声が上ずる。両手で杖を握りしめてはみたが、指先が震えているのが自分でも分かった。

　茜音は戦うのが怖い。前に出なくていい職を選んだのも、もとはといえばそれが理由だった。

　灰狼が、地を蹴った。

　その巨体からは想像もつかない速さで、黒い紋様を纏った体が一直線に迫る。茜音は反射的に目をつぶった。

　白虎が、前に出た。

『下がっていろ』

　声にならない声が、頭の奥に直接響く。

　白虎が大きく息を吸い込んだ。あたりの空気がすっと冷え、草の葉先が白く縁取られていく。ぱき、ぱき、と小さな音を立てて、地面のあちこちに霜が降りた。

　次の瞬間、白虎はそれを吐き出した。

　白い奔流だった。凍てついた息が、地面ごと草地を薙ぎ払っていく。

　跳躍の途中だった灰狼が、その中に飲み込まれた。悲鳴も唸り声も上がらない。

　風がやみ、視界が晴れたとき、そこには氷に閉じ込められた灰色の塊があった。跳びかかる姿勢のまま、宙に浮いた前脚の爪の一本一本まで白く凍りついている。

　やがて、その塊が内側から音もなく崩れ、光の粒子になって散っていった。

　残された草地は、一面が霜に覆われていた。周りの木々も、幹の半ばまで白く塗り替えられている。

　伏せていた狼たちが弾かれたように立ち上がり、我先にと茂みの奥へ散っていった。統率も何もあったものではなかった。

「……いっ、一撃……」

　茜音の声が、白い息になって漂う。

　勝ったという実感より先に、背筋が冷えた。あの巨大な王様が、たった一息で、跡形もなくなってしまった。

　その直後だった。膝から力が抜けて、茜音はその場にへたり込む。

　視界の端に、通知が浮かんだ。

```
魂力(SP)が尽きたため、召喚状態を維持できません
```

　目の前で、白い山が急速に縮んでいく。あっという間に、両腕で抱えられるくらいの大きさに戻ってしまった。

「え、ちょ、待って——」

　茜音は慌てて手の甲を見た。星の意匠の紋章。その一つは、昨日と変わらず淡い蒼白い色を帯びたままだ。

　足元では、小さくなった白虎が何事もなかったような顔で座り込んでいる。繋がりの感覚も、消えていない。

　消えたわけでも、契約が切れたわけでもない。ただ、大きさだけが元に戻された。それだけのことだと理解して、茜音はようやく肩の力を抜いた。

「……びっくりした。いなくなったのかと思った」

　小さな白虎が、鼻先を茜音の膝に押しつけてくる。

　茜音はその頭を撫でながら、たった今起きたことを頭の中で並べ直した。

　この子を本当の大きさで出しておけるのは、ほんの数分だ。一戦交えれば、それだけでもう空になる。

　強い。文句なしに強い。けれどその強さは、いつでも好きなときに取り出せるものではないらしい。

「……気軽に出せる子じゃなかったんだね、きみ」

　白虎は答えず、ただ心地よさそうに目を細めていた。

　そこで、視界に別の通知が重なる。

```
森閉ざしの灰狼を討伐しました
ドロップ品を入手しました

刻紋銘・森閉ざしの外套(もりとざしのがいとう)
分類:逸品(Bランク)
```

　インベントリから取り出してみると、深い灰色をした薄手の外套だった。広げても重さをほとんど感じない。肩にかけてみると、自分の足音が急に遠のいたような、奇妙な心地がした。

　気配と足音を抑えて、隠れて動くのを助けてくれる装備らしい。裾の内側には、あの灰狼の紋様によく似た刻印が小さく打たれていた。

「隠れるの、わたしがいちばん向いてないやつだ」

　苦笑して、茜音は外套を畳んだ。杖を振り回して光を撃つ人間が、気配を消したところで意味がない。

　誰か向いている人がいれば——と考えかけたところで、心当たりが一人しかいないことに気づいて、少しだけ口元が緩んだ。



　草地の縁で、枝の鳴る音がした。

　茜音が顔を上げる。木立の隙間に、こちらを見ている人影があった。

「あ、あの——」

　声をかけた時にはもう遅かった。人影は弾かれたように後ずさり、それから光の粒子になって、その場からかき消える。

　ログアウトだ。あの慌てぶりからして、見てはいけないものを見てしまった、という顔だった。

　あとには、霜の残る草地と、踏み荒らされた下生えだけが残された。

　茜音は誰もいなくなった木立をしばらく見つめてから、外套を抱えたまま、小さく呟いた。

「……見られた、よね。たぶん、ぜんぶ」

　白虎が、静かに耳を伏せた。
