# 第二十話　見えなくする側
　一体目を仕留めた霧の匂いが、まだ鼻の奥に残っていた。

　灰狼の森の中層。受けた依頼は三体で、残りは二体だ。冬夜は木立の奥へ、足音を殺したまま入っていった。

　二体目は、こちらが先に見つけた。

　樹皮に紛れた塊が、風が吹いても揺れなかった。周りの葉が全部動いているのに、そこだけが動かない。不自然さのほうが、色より先に目についた。

　冬夜は迷わず、正面から一歩踏み込んだ。

　口元が収縮し、白い霧が広がる。今度は自分から、その中へ入った。

　視界は同じように塞がれる。だが今度は、それでいい。

　霧の中では、蜘蛛も目を使えない。使えるのは音と気配で、そこはこちらが消してある。つまりこの霧は、蜘蛛が自分の得意な狩り場を作ったつもりで、こちらの得意な狩り場を作ってくれたのと同じことだ。

　冬夜は爪先から静かに体重を移して、大きく回り込んだ。

　霧が薄れ始める。灰白色の胴、脚の付け根のあたりに、白い光がにじむように浮いた。

　背後から、一撃。

　手応えは、一体目とはまるで違った。同じ場所へ同じ力で入れたはずなのに、粒子になるまでが一呼吸だった。正面から刺すのと、相手が気づいていない背中から刺すのとでは、こうも違うらしい。

```
『Lv9に上がりました』
獲得ポイント　自動:20　割り振り可能:20
```

　落ちた素材を拾い上げる。指先ほどの大きさの、半透明の袋のようなものだった。

```
霞蜘蛛の霧腺(むせん)
```

　握ると、内側で液体が揺れる感触がある。あの霧の元だ。

　冬夜はそれを目の高さに掲げて、しばらく眺めた。

　――これ、丸めれば投げられるんじゃないか。

　思いついた瞬間に、指先が勝手に段取りを組み始めていた。

　三体目は、探すのに少し時間がかかった。

　見つけてから、冬夜は仕掛ける前に足元の石を一つ拾った。道に転がっている石ころに、許可はいらない。借りて、指ではじけるくらいの小さな塊に整える。

　それを、蜘蛛から見て反対側の茂みへ投げた。

　葉が鳴った。蜘蛛の口元が収縮し、白い霧が――誰もいないほうへ広がった。

　その間に、冬夜は背後を取っていた。

　霧が晴れるより早く、狙いはもう定まっていた。一撃で終わった。

```
『Lv10に上がりました』
獲得ポイント　自動:20　割り振り可能:20
```

　冬夜は短剣を鞘に戻して、息をついた。

　一度の依頼で二段階上がったのは、苔纏いの大熊のとき以来だ。中層の中でも、この蜘蛛はよほど格が高い扱いらしい。

　拾い集めた素材を確かめる。霧腺が三つ、硬毛が二つ。

　そして、それとは別に、持って帰るものがもう一つあった。

　あの蜘蛛がやっていたことは、突き詰めれば一つしかない。相手から見えなくして、それから近づく。

　毒でもなければ、特別に強い一撃でもない。順番の話だ。

　――これは、借りられる。

　冬夜は自分の右手の甲を見下ろした。藍と紫の混じった紋章が、ゆっくりと明滅している。

　人の武器を借りて形を変えるのがこの力の使い方だと思っていたが、借りられるのは物だけではないらしい。相手の狩り方そのものを、そっくり持って帰ってもいい。

　人気のない木陰で、冬夜は割り振りを済ませることにした。

　Lv9の分の二十点は、AGIへ。避ける速さと、動き出しの速さが上がる。

　Lv10の分の二十点は、DEXへ。狙ったところへ、狙った通りに届かせる精度が上がる。

　これまでは十点ずつ半々に配ってきたから、均して見れば同じ結果になる。それでも今日は、一つずつ選びたかった。

　VITの欄は、九のまま指を止めずに通り過ぎた。

　大熊に殴られてからずっと、耐久に振るべきではないかという考えは頭の隅に残っていた。今日、その答えが出た。

　この外套は、防御を捨てる代わりに見つからなくなる装備だ。それを着ると決めた以上、耐久に少し振ったところで、避けきれもせず耐えきれもしない中途半端な体になるだけだろう。

　だったら、当たらないほうに賭け切る。

　足りない分は数字で埋めない。冬夜はインベントリの中の硬毛を思い浮かべた。埋めるなら、装備と工夫のほうで埋める。

```
冬夜
Lv10
職業:暗器使い
ソウルクレスト:彼は誰(かはたれ)

HP 122/122
MP 100/100
魂力(SP) 98/98
STR 36
AGI 156
DEX 153
INT 16
VIT 9
LUK 37

スキル:投擲、隠密行動、暗器生成、毒の調合、急所看破、会心の一撃、精密投擲

所持金:1350Y
```

　九という数字だけが、最初からずっと動いていない。並んだ数字の中でそこだけが取り残されて見えるが、冬夜はもう気にならなかった。

　動かさないと決めたものが一つあるというのは、たぶん悪いことではない。



　街へ戻り、依頼達成報告の窓口で霞蜘蛛の討伐を報告した。報酬の四百ユンが手元に入る。

　続いて素材買取の窓口で、道中に溜まった灰色狼の牙と毛皮をまとめて売った。しめて百五十ユン。

「そちらの霧腺と硬毛も、お買い取りできますが」

「いえ、これは残します」

　冬夜は袋の口を閉じた。売れば手っ取り早いのは分かっているが、これには今日の稼ぎより価値のある使い道がある。

　所持金は千九百ユンになっていた。

　人通りの少ない裏道へ入り、冬夜はしゃがみ込んで道具を広げた。すり鉢と布切れを使うのは、初めて毒を作った日以来だ。

　霧腺の膜を破らないよう気をつけながら、布切れで包んで丸めていく。あのときは指先が言うことを聞かず、一度目は薄すぎる毒液を作って苦笑したものだった。

　今日は、そういうことが起きなかった。指が勝手に力加減を覚えている。DEXという数字が何をしているのか、こういうときに一番よく分かる。

```
『目眩し玉を作成しました』
```

　同じものが三つ、手のひらの上に並んだ。握り拳より一回り小さい、頼りない玉だ。

　冬夜は裏道の奥に誰もいないことを確かめてから、一つを地面へ叩きつけた。

　ぱん、と乾いた音がして、白い霧が一気に膨れ上がる。二歩先の壁が、まるごと消えた。

　数を数える。十五を過ぎたあたりで輪郭が戻り始め、二十で完全に晴れた。

　自分の体には何も起きていない。痛くもなければ、痺れもしない。

　ただ二十数えるあいだ、何も見えない。それきりのことだった。

　――これ単体では、何も起きない。

　冬夜は残った二つを、丁寧にインベントリの奥へしまった。

　これは武器ではない。相手がどちらへ動いても不利になる、そういう形を作るための一手だ。使う相手は、まだいない。



　最後に向かったのは、武具屋の隣の防具屋だった。

　軽装の上着を買った店だ。店先には相変わらず革の匂いが漂っていて、奥のカウンターで店主が金具を磨いている。

　冬夜が硬毛を二つカウンターに置くと、店主は手を止めて指でつまみ上げた。

「霞蜘蛛だな。薄く編めば当て革になる。ステータスの数字には出ないが、急所を庇うくらいはしてくれる」

「それを、お願いしたいんです。ここで加工していただけますか」

「できる。持ち込みなら、完成品を買うよりずっと安く上がるぞ。加工賃は百。日数は三日もらう」

「お願いします」

　話がまとまったところで、店主が顔を上げた。

「で、上に何を着る」

「……上に、ですか」

「当て革ってのは、単体で着るもんじゃない。上に何を羽織るかで、当てる位置も厚みも変わる。現物を出せ。合わせる相手を見ないと、ぴったりのものは作れん」

　冬夜の指が、外套の裾のあたりで止まった。

　裾の内側には、灰狼の紋様によく似た刻印が小さく打たれている。刻紋銘の刻印だ。刻紋種を倒さなければ手に入らない代物で、市場に出れば値がつきすぎる。噂の出所を辿られるという意味でも、カウンターの上に広げていいものではなかった。

　店の中には、他に客が二人いた。棚の前で防具を吟味しているだけの、なんでもない客だ。

　なんでもない客が二人いる。それだけのことが、今の自分には無理だった。

「……すみません。現物は、お見せできません」

「なんだそりゃ」

「寸法だけ、お伝えします。それでお願いできますか」

　店主はしばらく冬夜の顔を見ていた。値踏みというより、面倒事の匂いを嗅いでいる目だった。

「訳ありは珍しくない。この商売、いちいち詮索してたらきりがないからな」

　店主は磨いていた布を置いて、木の物差しを引き寄せた。

「ただし、聞いた寸法通りに作る。合わなくても直しはもう一回分の金をもらうぞ。それでいいなら受ける」

「はい。それで構いません」

　冬夜は自分の肩幅を指で測り、襟の高さと丈を言葉にした。上に着るのは布か革かと訊かれて、「布です」とだけ答えた。

　薄手なのか厚手なのか、裏地はあるのか、そういうことは何一つ言えなかった。店主は聞いた分だけを紙に書きつけて、それ以上は何も訊かなかった。

　百ユンを払うと、手元は千八百ユンになった。三日後に取りに来ればいい。

　店を出ると、通りはもう暮れかけていた。薬屋の軒先を覗くと、明かりはとうに落ちている。傷薬の買い足しは、当て革を受け取る日に回すしかなさそうだった。

　店を出て、冬夜は一度だけ振り返った。

　命が危ないわけでもなければ、誰かに追われているわけでもない。ただ、当て革を一枚頼むのに、まっすぐ「これに合わせてください」と言えない。

　秘密を抱えて暮らすというのは、こういうことらしかった。想像していたよりもずっと地味で、そのぶん、逃げ場がない。

　――次にログインしたら、まず薬屋だ。

　冬夜は頭の中の順番をそう決めて、歩き出した。傷薬を買い足して、三日後に当て革を受け取って、それから目眩し玉の使いどころを考える。

　現実では、明日何をするのかさえ決まっていない。

　なのにこちらでは、三日後に何を取りに行くかまで決まっている。

　見えなくする側に回ること。今日この森で覚えたのは、結局それだけだった。

　その、それだけのことに、冬夜は現実の自分よりずいぶん真剣になっていた。
