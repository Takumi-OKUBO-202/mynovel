# 第二十話　誘い

　路地の口を背にして、男は壁に肩を預けたまま立っていた。傾いた日が入り口の側から差していて、顔は影の中にある。

　ウィンは柄に手をかけて、茜音の前へ半歩出た。踵が石段の角に当たる。

「いつから、いたんですか」

　声が掠れた。

「んー、途中から。面白そうな話だったから」

　声は張っていない。それでも路地の奥まで届く。

「ペットの話!」

　茜音の声が裏返った。息を吸う音がそのまま続いて、うまく吐けていない。右手は、背中に回したきりだった。

「うちの子の話をしてただけだから。ね?」

「……はい。ペットです」

　男が笑って、壁から肩を離した。歩幅は広いのに、速くない。石段の下、三歩ぶん手前で止まる。

　そのぶん、姿がはっきりした。上背がある。明るい色の癖のある髪を、整えもせずに流している。

　上着は薄手で、腰にも背にも、武器らしいものは何も提げていない。

　目元が少し笑っている。ウィンと目が合っても、外さない。

「ペットの話ね。それでいいや」

　言うなり、男はウィンに背を向けた。横の壁に顔を寄せて、彫られた溝を指でなぞる。

　柄を握ったままだと気づくのは、背を向けられてからだ。

「それより君たち、今日はもう狩りは終わり?」

「終わりだよ。もう帰るとこだったの」

　答える茜音の声は、少し高いままだ。それでも茜音は首を伸ばす。

「そっちは? こんな時間から、どこか行くの」

「僕は森。刻紋種を狩りに行くんだ」

　茜音が口を開ける。閉じて、もう一度開けて、それからウィンのほうを見た。

　ウィンは、あの森の奥を思い出した。素直には頷けなかった。

「……今から、ですか」

「行くのは明日の朝。今日はぶらぶらしてるだけ」

　茜音が石段を一段下りかけて、止まって、それでも下りた。

　ウィンはその背中の位置から動かない。

「誰か、他にも行くんですか」

「今のところ僕だけ。募集も出してないし」

「夜会も明日出るって聞いたけど。かち合わないの?」

「らしいね。広いから、会わないと思うよ」

　茜音が息を吸う音がした。この人は本当に、ただ面白がっているだけなのか。

「あの。陽だまりの四人、入り口でやられてます。奥まで行けてもいないんです」

「聞いたよ」

　男は溝の上を、指でゆっくり下ろしていく。

「大丈夫。僕、わりと強いから」

　ウィンは次の言葉を待った。男は溝から指を離して、掌の埃を払う。

　茜音がもう一段下りて、男の顔を見上げた。

「今日ね、どこ行ってもその話ばっかりだったの。みんな怒ってるみたいな顔してた。……怖くないの?」

「まだ会ってないからね」

　男は困った顔をして、それから笑った。

「会ってから考えるよ」

　落書きの最後まで指を下ろして、壁から手を離す。

「君たちも来る?」

　握った柄が、掌の中で滑った。

　断る言葉なら、いくつも出てくるはずだった。四人でやられている。

　あの子がいる。連れていけない――それも含めて、喉の手前で止まった。代わりに出てこようとしたのは、行きたい、のほうだった。

　声を出すより早く、茜音が言った。

「わたしたち?」

　男は頷きもせず、ウィンと茜音を順に見て、待っている。

「わたしたち、そんなに強くないよ。ほんとに、ぜんぜんだよ」

「うん、そう見える」

　茜音が吹き出して、慌てて口を押さえた。口を押さえたまま、息が漏れている。

「なんで、俺たちなんですか」

　男が少し首を傾ける。

「んー。面白そうだったから、かな」

「……名前は、教えてもらえるんですか」

「ん? ああ——僕はミナモト」

　名前だけは、あっさり返ってきた。それで済んだという顔で片手だけ上げて、路地の口のほうへ歩き出す。二歩行ったところで、振り返らずに続ける。

「明日の朝、南門の外にいるよ。気が向いたら来て」

　そのまま路地の口を抜けて、明るい髪が人の流れに紛れた。

　角の向こうの声だけが、さっきと同じ調子で続いている。

　茜音が長く息を吐いて、胸に手を当てた。

「……びっくりした」

　言ってから、もう一度吐く。二度目のほうが長かった。

「心臓に悪いよ、あの人」

　壁から杖を取って、両手で抱える。


　　　　◇


　広場へ出た。ギルドの石段では、座り込んだ連中が、扉から出てくる者を捕まえては仲間に引き込もうとしている。その中の一人が、出てきた男に声をかけた。

「討伐、受けたのか」

「受けたよ。受けとくだけ受けとけって話だろ」

　笑い声が、石段の上で弾けた。二人は輪の外側を通って、噴水まで歩いた。

「ミナモトさん、かあ。聞いたことある?」

「ないです」

「わたしも。……フレンド、申請してこなかったね。来るかどうかも聞かないで行っちゃったし」

　茜音が噴水の縁に指を入れて、水を弾いた。指先の雫が石畳に落ちる。

「わたしね、断らなかったよ。さっき」

「聞いてました」

「ウィンくんも断らなかったじゃん」

　ウィンは口を開いて、そのまま閉じた。

　茜音が左手で、右手の甲を押さえる。

「森のこと、うちの子と関係あるのかなって、あれからずっと考えてるんだよね」

　茜音が水を弾いた指を、そのまま縁に置いた。

「あの人が行くなら、ついていけば、この目で見られるのかなって」

　噴水を回って、二人は南門まで歩いた。門の外へ延びる道は、まだ装備の音で埋まっている。

　茜音がその道の先を見ている。ウィンも見た。

　あの男が、二人の話をどこから聞いていたのかは、分からないままだ。

　自分の右手を見ると、まだ柄を握っていた。指を一本ずつ開いていくと、掌に革の巻き目が残っている。

　その手を、腰から離した。
