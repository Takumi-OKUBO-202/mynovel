# 第二十一話　本人ですけど

　三日ぶりに、朝から予定のない日が来た。

　当て革を頼んだ日から、書店のシフトが二日続いた。夜に少しだけ潜って、勝手を知った狩場で狼を数頭狩って、風呂に入って寝る。それだけで一日が終わっていた。

　午前九時過ぎ。冬夜は麦茶のグラスを机の端に置いて、ノートパソコンを開いた。

　掲示板はゲームの中からは覗けない。見るならログインする前か、脱いだ後のこの時間しかない。二日とも寝る前に一通り巡回したが、どこも代わり映えはしなかった。

　灰狼の森のまとめスレッドを開いて、冬夜は指を止めた。

　昨夜は四百二十番台で終わっていたはずの書き込みが、朝のうちに十ほど伸びている。


　それきり、四百二十三番は現れていない。あとに続いているのは、いつも通りの真偽論と、飽きた者たちの茶々だけだった。

　冬夜は椅子の背から体を起こして、もう一度、上から読み直した。

　二度目を読み終える頃には、指先が冷たくなっていた。

　まず、書かれている三つのうち、どれ一つとして掲示板には出ていない。

　冬夜は別のタブで過去ログを開き、あの目撃談を頭から確かめた。三百五十二番が書いたのは、狼がやられていたこと、白い虎が一撃で凍らせたこと。

　狼のほうにだけ刻紋種の表示が出ていたこと、そばにローブの背の低い子が立っていたこと。

　それだけだ。霜の話も、紋様の話も、膝の話も、どこにもない。

　次に、あの目撃者は遠くにいた。茜音は木立の隙間から見られていたと言っていた。

　あの距離で、草の葉先が白く縁取られたことが見えるだろうか。霜の降りる音が聞こえるだろうか。どれも、そばにいなければ拾えない細部だ。

　そして、片膝の一行だった。三百五十二番の書き込みは「狼のほうがやられてた」から始まっている。呼び出す場面から見ていたのなら、そこから書くはずだ。

　四百二十三番は、その誰も書かなかったところから書き始め、「立っていられなくなったからです」と理由まで添えてある。外から眺めているだけなら、ただ座り込んだようにしか見えないはずのものに。

　冬夜は画面から目を離して、天井を見上げた。騙りなら、こうはならない。

　過去ログを読んで面白がっている誰かに書けるのは、言い換えまでだ。書いた者は、遠くから眺めていたのではない。

　それに、と冬夜は思う。あの目撃者には、要が「これ以上書かないよう頼んだ」と言っていたはずだ。

　止められた人間が、こんな書き方で戻ってくるとは思えない。

　もう一つ引っかかっていた。書き込みの主が、自分のことを「わたし」と書いている。茜音の口調ではない。

　誰の声で読めばいいのか分からないまま、文字だけが頭の中に残った。

　冬夜はメモ帳を開き、四百二十三番の書き込みを一字ずつ写した。掲示板はゲームの中へ持ち込めない。伝えるには、こちらが覚えていくしかない。

　書き写しながら、腹の底が重くなっていくのが分かった。

　これまでは、噂の話だった。自分たちについて誰かが勝手に喋っている、という話だ。

　今日からは違う。誰かが、わざわざこちらに読ませるために書いている。



　ログインしたゲームの中は、雲の多い午前だった。

　冬夜はまずフレンド一覧を開いた。茜音の名前は、今日も灰色に沈んだままだった。

```
冬夜:話したいことがある。時間ができたら、一言でいいから返事をくれ
```

　送っても、既読も返事もつかない。分かっていて、それでも指が止まらなかった。

　別れた日の夜に「旅行になっちゃった」と一言届いたきり、続きは何もない。どこへ行ったのかも、いつ戻るのかも聞いていなかった。

　返事はもう期待していない。それでも、今日のうちに済ませておくべき用事が二つあった。

　冬夜は大通りを東へ折れて、武具屋の隣の防具屋へ向かった。

　店先の革の匂いも、奥のカウンターで金具を磨いている店主も、三日前と変わらない。冬夜が顔を出すと、店主は顎で棚のほうを示した。

「当て革だな。できてるぞ」

　差し出されたのは、薄く編んだ黒っぽい革の板が数枚、細い紐で繋がったものだった。手に取ると、思っていたより軽い。

「胸と脇腹、それと肩だ。急所だけ庇えばいい、という寸法で組んである。合わなけりゃ持ってこい」

　冬夜は外套の前を開けて、上着の上から当ててみた。脇腹の位置が指一本分だけ高い気もしたが、肩の可動は妨げられていない。合わせる相手の現物を見せられなかったのだから、この程度で済んだのは上出来だった。

「これで十分です。助かりました」

「そうか」

　店主はそれきり顔を上げず、また金具を磨き始めた。詮索はしない、と言ったのは本当らしい。

　次に、通りを一本戻って薬屋の扉をくぐる。

　棚に並んだ小瓶を眺めて、冬夜は少し迷ってから口を開いた。

「傷薬の小を、四本お願いします」

「四本ですね。百ユンになります」

　店員が手際よく小瓶を布に包んでいく。千八百から百を引いて、千七百。手持ちと合わせて五本になる。

　包みを受け取りながら、冬夜は思う。これは、備えができたという安心とは少し違う。

　何が来るのか、こっちには分かっていない。分かっていないから、増やせるものを増やしておくしかない。そういう買い方だった。



　打てる手は、思ったよりも少なかった。掲示板に書き返せば、本物がこれを読んでいると教えるだけになる。

　運営に訴えるにも、本当のことを話さない限り筋が立たない。相手の正体を探るあても、名無しの番号ひとつでは掴みようがなかった。

　残るのは、これまで決めてきたことを、これまでより厳密に守ることだけだ。

　白虎は出さない。深部には近づかない。人の多いところで身の上話をしない。

　自分で言っておいて、あまりに何もしていないな、と冬夜は思った。それでも、今はこれしかなかった。

　茜音なら、こういうときに何の根拠もなく「ちゃんと備えてるじゃん」と言うのだろう。根拠がないと分かっていても、言われれば少しは軽くなる類の言葉だ。

　その軽さが、今はない。

　冬夜は外套の襟を整え、当て革の紐を締め直した。買ったばかりの傷薬が、腰のあたりで小さく鳴った。

　備えたところで、何に備えているのかが分からない。
