# 第二十二話　いないはずの虎

　四日が過ぎた。

　その間、掲示板は静かだった。虎の話は雑談スレの底に沈み、灰狼の森のまとめスレも、深部には近づくなという注意書きを繰り返すだけになっている。

　冬夜は毎朝ノートパソコンを開いては、何も起きていないことを確かめて閉じた。何も起きていない、というのがこれほど落ち着かないものだとは思わなかった。

　書店のシフトを二日こなし、夜は森の手前で狼を数頭狩って、外套の使い方を体に馴染ませた。目眩し玉は二つとも手をつけずに残してある。使いどころが来ないまま終わってくれれば、それが一番よかった。

　五日目の朝、それが終わった。

```
【灰狼の森】エリア情報まとめスレ

488: 名無しの冒険者
また出たらしいぞ、あの白いやつ

489: 名無しの冒険者
まーた始まった。どうせガセだろ

490: 名無しの冒険者
自信あるなら見てこいよ。俺は行かんけど

491: 名無しの冒険者
そういうの見に行きたがるやつ、絶対いるよな
```

　冬夜は画面の前で動けなくなった。

　白虎を呼び出せる人間は、この世界に一人しかいない。そしてその一人は、四日前からログインしていない。

　冬夜はフレンド一覧を思い浮かべた。茜音の名前は、この四日間ずっと灰色に沈んだままだ。

　なのに、虎が出たと書かれている。

　可能性は三つ、と冬夜は数えた。書いた者の見間違い。ただの嘘。あるいは——虎に見える何かが、本当にあそこにいる。

　どれであってほしいかと言われれば、二番目だった。だが、二番目を選ぶ理由が一つもない。



　その日の夜、掲示板の様子が変わった。

```
【灰狼の森】エリア情報まとめスレ

512: 名無しの冒険者
昼に虎見に行くって言ってたやつら、戻ってこないんだが

513: 名無しの冒険者
ほらな、ガセじゃねえか
死んだ死んだ言っといて結局本人が一番元気とかいうオチだろ

514: 名無しの冒険者
いや知り合いに一人いるけど、マジで三日ログインできないって騒いでた

515: 名無しの冒険者
それただの自演だろ
八人も雁首揃えて同じ嘘つくか?

516: 名無しの冒険者
つくやつはつくだろ、注目浴びたいだけで
```

　冬夜は椅子の背にもたれて、天井を見上げた。

　ガセだ本当だと言い合っているだけで、何が起きたのかは誰も書いていない。それが、かえって落ち着かなかった。

　八人が本当に落とされたのなら、夏休みの三日をまるごと取り上げられたことになる。

　その八人を深部へ向かわせたのは、四百八十八番の書き込みだった。そして、その書き込みが出てくるきっかけを作ったのは、自分たちだ。

　冬夜はしばらく、その事実を動かせずにいた。書き込むな、と言うことはできない。虎の話をするな、とも言えない。言えば、なぜそんなことを言うのかと訊かれる。

　止める方法がないまま、止めるべきものだけが増えていく。



　茜音の名前は、まだ灰色のままだった。

　四日前、こんなDMが届いていた。

```
茜音:『ごめん、明日から旅行になっちゃった。何日か入れないと思う』
```

　あのとき冬夜は、行ってこい、とだけ返した。楽しんでこい、と付け足すかどうかを少し迷って、結局そのまま送った。

　それきり、返事は来ていない。旅行先から毎日ログインするほうがおかしいのだから、そこは何もおかしくはない。

　考えても仕方がないので、冬夜はヘッドギアを手に取った。



　視界が開けた瞬間、通知が視界の隅で明滅した。

　フレンド以外からのメッセージだ。パーティの勧誘か、素材の買い取りの申し出か。そういうものは時々届く。

　冬夜はなんとなく開いて、そのまま息を止めた。

```
差出人:  ▯▯▯▯▯

話したいことがある
あの洞窟に一人で来い
```

　名前の欄が、名前になっていない。

　文字の形をした何かが五つ並んでいるだけで、読むことも、読み上げることもできなかった。

　冬夜はメニューを閉じて、もう一度開いた。同じものが同じ場所にある。受信の一覧を遡ってみても、そこには何も残っていない。今しがた開いたはずのものが、履歴のどこにもなかった。

　もう一度閉じて、開く。やはりある。指で触れられるほどはっきりそこにあるのに、記録にだけ存在しない。

　名前は必ず表示される。それがこの世界の仕組みのはずだった。

　壊れている、と冬夜は思おうとした。だが、こういう壊れ方をするシステムを、冬夜は一つも思いつけなかった。

　そして文面は、こちらが行く場所を知っている前提で書かれている。

　あの洞窟。

　白虎が鎖に繋がれていた場所だ。あそこに二人で入ったことを知っている人間は、この世界に自分と茜音しかいない。



　冬夜は広場の隅で立ち止まって、順番に考えた。

　罠だ。それは疑いようがない。

　名前を隠して、場所を指定して、一人で来いと書く。この三つが揃っていて罠でないものは、この世にない。

　行かない、という選択肢もあった。無視して、街から出ないでいれば、少なくとも今日は何も起きない。

　だが、本当だった場合の重さが違いすぎる。八人が三日間取り上げられているとしたら、それを見過ごしていい理由にはならない。

　そして、次に誰かが同じ書き込みを見て、同じように向かうまでの時間は、たぶんそう長くない。

　冬夜は自分の持ち物を頭の中で数えた。傷薬が五本。目眩し玉が二つ。当て革は上着の下に入れてある。外套。短剣が二本と、投擲ナイフ。

　足りているとは思わない。だが、この五日で揃えられるものは揃えた。あの日、霞蜘蛛の霧の中で何もできずに突っ立っていた自分とは、少しだけ違う。

　やられたところで、失うのは三日だ。八人が今まさに払っているのと、同じ三日。

　もう一つ、決定的なことがあった。

　茜音がいない。

　狙われているのが彼女のクレストである以上、これは行くべき日だった。旅行から戻ってきてしまえば、次に同じ文面が届いたとき、一人で行く理由を説明しなければならなくなる。

　説明すれば、たぶん止められる。止められれば、二人で行くことになる。

　それだけは避けたかった。

　冬夜はメニューを開き、灰色に沈んだままの名前を選んだ。

```
冬夜:『ちょっと森まで行ってくる。戻ったら連絡する』
```

　送信して、それきり閉じた。

　嘘は書いていない。詳しく書いていないだけだ。そう自分に言い聞かせて、冬夜はメニューを消した。

　返事は来ない。相手はログインしていないのだから、当たり前だった。



　街の南門を抜けて、丘を越える。

　外套のおかげで、自分の足音はもう聞こえない。乾いた下生えを踏んでいるはずなのに、耳に届くのは風の音だけだった。

　灰狼の森の入り口で、冬夜は一度だけ立ち止まった。

　手前の縄張りには、いつもの灰色狼がいる。遠巻きにこちらを窺うだけで、襲ってはこない。何も変わっていない、いつもの森だ。

　だが、奥から吹いてくる風の匂いだけが、少し違う気がした。

　冬夜は投擲ナイフの位置を確かめて、木立の間へ入っていった。
