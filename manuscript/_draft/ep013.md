# 第十三話　苔纏いの番人

　残っていた角兎は、思いのほかあっけなく片が付いた。跳びかかってきた一匹の額を、冬夜は最短の一撃で捉える。獣は光の粒子になって消え、残るは猪型一体だけになった。

「よし、これで最後!」

　茜音が声を弾ませる。突進してくる猪型に、冬夜は短剣を槍状に変形させて迎え撃った。急所看破で見えた白く際立つ一点に、迷いなく切っ先を突き立てる。

　猪は一声だけ短く鳴き、粒子となって消えていった。

「討伐目標、たぶんこれで全部だよね」

「ですね。猪型三体、角兎五体……ちょうど揃いました」

　二人は顔を見合わせ、どちらからともなく息をついた。ここまで大きな怪我もなく来られたことに、密かな安堵がある。

　依頼としてはこれで十分なはずだった。だが茜音は振り返る様子もなく、木々の隙間に目を向けたままだった。

「もうちょい奥、行ってみない?」

「奥、ですか」

　冬夜は少し身構えた。投擲ナイフを買った日に見た依頼票の注意書きを思い出したからだ。――森のさらに奥は強力なモンスターが出現するため、単独での深追いは危険。

　苔むした石段や崩れた古い柱が眠っているという、あの噂の場所だ。トレジャーハンター気取りのプレイヤーや、歴史探究クランが度々調査に入っているらしいが、正体はいまだ分かっていないと聞いている。

「あんまり奥は良くないかもしれないです。前に依頼票で見たんですけど、この先は強いモンスターが出るからって」

「そうなんだ……」

　初めて聞いたというように、茜音は目を丸くした。それから、少し困ったような顔で自分の耳のあたりに手をやる。

「じゃあ、戻りましょう。俺たちにはまだ早いと思います」

　冬夜がそう言いかけたところで、茜音がふいに足を止めた。

「待って。……なんか、聞こえる」

「聞こえる? 何がですか」

「わかんない。声、みたいな……誰かが何か読んでるみたいな」

　茜音自身、戸惑っているのが見て取れた。眉を寄せ、耳を澄ますような仕草をしながら、木々の奥へじっと目を凝らしている。

「俺には何も聞こえませんけど」

「うん、わたしにも変な感じなんだけど……なんか、行かなきゃいけない気がする」

　冗談を言っているふうではなかった。いつもの朗らかな声とは違う、真剣な響きがある。

「……行きたい、ってことですか」

「うん。ごめん、勝手言ってるのわかってるけど」

　珍しく歯切れの悪い声で、それでも茜音はまっすぐに冬夜を見た。冬夜はしばらく黙り込む。

　危険だと分かっている場所に、根拠のはっきりしない「声」を頼りに踏み込む――普段の自分なら、迷わず断っていたはずだった。だが、この人がここまで言うのなら。

「……分かりました。少しだけ、様子を見に行きましょう」

　声のする方へ、茜音が先に立って歩き出す。下草はいつの間にか薄くなり、地面には苔むした石畳の名残らしきものが覗いていた。崩れかけた柱が、等間隔にいくつも倒れている。

　人の手が入ったことを示す痕跡は、周囲の自然な木々とは明らかに異質だった。少し進むと、切り立った岩肌に黒々とした穴が口を開けている。誰かが踏み荒らした形跡もない、手つかずの雰囲気を纏った洞窟だった。

「ここから聞こえてくる……気がする」

　茜音が洞窟を指差したその時、入り口の脇に積もっていた苔の山が、ゆっくりと動いた。

　最初は岩塊だとばかり思っていた。だがそれは、鎌首をもたげるように頭を持ち上げ、二人へと双眸を向けてくる。全身を分厚い苔が覆い、石像のように見紛う巨体だった。

　体高は冬夜の背丈の二倍近くあり、四肢は太い岩柱を思わせる。低く唸る声だけで、地面がびりびりと震えた。

　これまで相手にしてきた灰色狼や猪型とは、明らかに格が違う。冬夜は思わず息を呑み、半歩後ろへ下がった。

「……なんですか、あれ」

「わかんない、けど……すごい、圧」

　茜音の声も強張っている。長くこの洞窟の入り口に居座っていたのだろう、苔纏いの大熊とでも呼ぶべきその姿は、まさに門番そのものだった。

　冬夜は一度、茜音の肩を押さえて距離を取らせた。

「戻りましょう。今の俺たちじゃ、たぶん相手になりません」

「……うん、それはわかる」

　茜音は素直に頷いた。だが、その視線は洞窟から離れない。

「でも、あの奥から聞こえてる気がするんだよね。行きたい」

「危ないですよ、本当に」

「わかってる。無理にとは言わない。でも……行きたい」

　繰り返す声には、いつもの軽さの中に、譲らない芯があった。冬夜はしばらく黙り、大熊と茜音の顔を交互に見比べる。

　無理強いはしたくない。かといって、頷いた自分がこの人を危険にさらすことにもなりかねない。

「……仕方ありません。やるだけ、やってみましょう」

　まず状況の整理から始めた。

「あの図体だと、正面から力比べしても勝ち目は薄いです。急所を見極めて、確実に一撃を通す形にします」

「わたしは……ライトウォールで守りつつ、隙があったらライトバレット撃つね」

「詠唱中は無防備になるので、そこは俺が引きつけます。危ないと思ったらすぐ下がってください」

「うん。頼りにしてる」

　二人は短く頷き合い、それぞれの得物に手をかけた。



　冬夜が先に仕掛けた。投擲ナイフを続けざまに投げ、大熊の注意を引く。だが刃は苔の層に阻まれ、浅く突き刺さっただけで弾かれた。

　硬く分厚い苔そのものが、天然の鎧のように働いているらしい。大熊が唸り、太い前脚を振り上げる。

　冬夜は横に跳んでかわしたが、空を切った一撃だけで足元の土がえぐれた。もらえば、ただでは済まない一撃だ。

　急所看破で狙いを定めようとするが、白く浮かび上がるはずの一点がなかなか定まらない。分厚い苔に阻まれ、急所そのものが見えにくくなっているようだった。

　これまでの相手なら一瞬で見えていたものが、今回は容易に掴めない。それだけで、格の違いがはっきりと分かった。

　冬夜は近くに転がっていた崩れた柱の欠片に目を留める。持ち主のいない、ただの瓦礫だ。断りを入れる必要もなく、意識するだけですぐに形が変わり始めた。

　厚みのある盾状に変えたそれを構え、二撃目の爪撃を受け止める。重い衝撃が腕まで響いたが、なんとか踏みとどまった。

「ライトウォール!」

　茜音の声とともに、薄い光の膜が二人を包む。完全には防ぎきれないが、そのわずかな一枚が、致命傷を紙一重で防いでくれた。

　大熊が苦し紛れに大きく吼えた瞬間、開いた口の奥、喉元の苔がわずかに薄くなっている場所が目に留まる。急所看破の光が、そこだけ白く際立った。

「そこ……!」

「わかった、援護する。ライトバレット!」

　溜めを経て放たれた光弾が、大熊の顔面を掠める。ひるんだ隙に、冬夜は毒を塗った投擲ナイフを喉元目掛けて投げつけた。

　刃は薄くなった苔を貫き、皮膚に食い込む。すぐには倒れないまでも、大熊の動きにわずかな鈍りが見え始めた。毒がじわりと効き始めている証拠だ。

　だが好機と見て踏み込んだ瞬間、振り向きざまの一撃をまともに浴びてしまう。吹き飛ばされ、地面を転がりながら、脇腹に鈍い痛みが走った。

「冬夜くん!」

　駆け寄ろうとする茜音を、冬夜は手で制した。

「大丈夫です、まだ動けます」

　懐から傷薬を取り出し、一気に呷る。傷口の痛みが和らぐと同時に、茜音の淡い光がそっと体を包み込んだ。

「無理しないで、ちゃんと言ってね」

「はい……もう一回、いけます」

　毒に蝕まれた大熊の動きは、明らかに精彩を欠いていた。大きく体勢を崩した隙を、冬夜は見逃さない。

　短剣を意識するだけで、これまでにないほど鋭く長い穂先に変える。喉元の薄くなった一点だけを見据え、地を蹴った。

　振り絞るような一撃が、狙い違わず突き刺さる。これまでで一番重い手応えが腕を伝った。

　大熊は大きくのけ反り、二度、三度と痙攣するように震えたあと、光の粒子となって消えていった。

　辺りに静寂が戻る。二人はしばらく、荒い息をついたまま動けずにいた。


```
『Lv8に上がりました』
獲得ポイント　自動:20　割り振り可能:20
```

　一気に二段階も上がった実感に、冬夜は思わず声を漏らす。

「二つも……そんなに上がるものなんですね」

　角兎や猪型を狩っていた分もまとめて入ったのだろうが、それだけでは説明のつかない伸び方だった。あの一体がどれだけ格上だったか、数字が何より雄弁に語っている。

　自由に振れる分をどう使うか、いつも通り素早さと器用さに――そう決めかけて、冬夜はふと手を止めた。今日のような一撃をまともに浴びた感触が、まだ脇腹に残っている。

　どう配分するかは、落ち着いてから改めて考えることにした。

　大熊が消えた場所には、苔の下から掘り出したような、灰色がかった大きな爪が一つ残っていた。冬夜はそれを拾い、インベントリに収める。

　顔を上げると、洞窟の入り口が、何事もなかったかのように静かな口を開けていた。声の主は、まだこの奥にいるのだろうか。

　冬夜は乱れた息を整えながら、じっとその暗がりを見据えた。
