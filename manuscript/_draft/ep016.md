# 第十六話　先に置く

　南門の脇で待っていると、茜音が小走りでやってきた。

「ごめんね。今日、行けなくなっちゃった」

　開口一番だった。昨日断った友達から、それなら今日はどうかと誘い直されたのだという。

「二回続けて断るのは、さすがに」

「そうですよね」

「怒らないの?」

「約束を先にしてたのは、向こうですし」

　茜音は少しだけ肩の力を抜いて、それから手の甲を持ち上げた。星の意匠の紋章が、淡い蒼を帯びている。

「それで、ちょっとだけ時間もらってもいい? あの子、出しておきたくて」

　門を出て、街道から離れた木立の陰まで歩いた。人の目が届かないところまで来てから、茜音が紋章に意識を向ける。光の粒が集まって、腕の中に白い仔虎が現れた。

『……ようやくか』

　しゃがれた年寄りの声が、頭の中に直接響く。両手に乗る大きさの獣から出てくる声だとは、何度聞いても思えない。

「ごめんね。今日はお昼から別の子と行くから、そのあいだは出せないの」

『なぜじゃ』

「んー……その子には、ユキのこと話してないから」

『わしは黙っておるぞ』

「黙ってても、いるのは見えるでしょ」

　白虎はしばらく黙ってから、茜音の腕を蹴って地面に降りた。木立のあいだを一周して、下生えの匂いを一通り嗅いで、また戻ってくる。

「これで我慢して」

『足りぬ』

「知ってる」

　茜音は白い頭をひと撫でして、光の粒に戻した。

「ウィンくんは、今日どうするの」

「一人で行きます。前に、足元に何も落ちてなくて一頭逃したことがあって」

「あー。あったね、そういうの」

「あれを、どうにかできないかと思って」

「そっか」

　茜音は一度うなずいてから、思い出したように付け足した。

「無理しないでね。わたし、今日は治せないから」

　それだけ言って、門の内側へ戻っていった。


　　　　◇


　ギルドの石造りの建物に入ると、中はいつもどおり混み合っていた。装備を担いだプレイヤーが受付に列を作り、依頼の掲示の前にも人だかりができている。

　順番を待つあいだ、周りの話し声が耳に入った。白い虎の話をしている者はいない。昨日の騒ぎは、少なくともこの建物の中までは届いていなかった。

　掲示の前に立つ。灰色狼の間引きは、一頭あたりで数える形の依頼だった。今日はひとまず一頭ぶんの紙を剥がして、受付へ持っていく。

「灰色狼ですね。承りました」

　受付の女性が紙に印を押してから、顔を上げた。

「お気をつけください。このところ、浅いところで見かけたという報告が増えていまして」

「浅いところ、ですか」

「森の入り口に近いあたりです。普段はもっと奥にいる群れですから、少し妙だという話は出ています」

　紙の下のほうに、細かい字が添えられていた。獣道沿いに出没、とある。


　　　　◇


　南門を出て丘を越え、森の入り口まで歩いた。

　木立に入ってしばらく行くと、倒木と岩壁に挟まれた細い道に出た。人ひとりがようやく通れる幅で、抜けた先が沢へ下りている。水を汲むときはいつもここを通る。

　獣道を見つけるのに、時間はかからなかった。下生えが左右に分かれ、土がむき出しになった筋が森の奥へ伸びている。

　ウィンは腰の袋から縄を取り出した。

　自分の力でできるのは、物の形を変えることだ。変えるときには手が届いていないといけないが、一度変えてしまえば、意識を向けている限り形はそのまま保つ。投げた石が刃のまま飛んでいくのは、それができるからだった。

　ただし、変えられるのは一度に一つだけ。二つ目に手を出せば、一つ目は元に戻る。

　これまでは、相手が現れてから足元の物を拾って変えていた。石を刃に、枝を槍に。

　だがそのやり方では、使える物がそこに落ちているかどうかで手が決まる。前に一頭逃したのも、下草しかない斜面だった。

　先に置いておけばいい、と考えたのは昨日の夜だった。置くだけなら魂力は減らない。場所も長さも、こちらの都合で選べる。

　地面すれすれの高さに縄を渡して、両端を下生えに絡めた。端に手が届くところまで下がって、脇の茂みに身を伏せる。

　隠密行動を使って、息を殺した。葉の擦れる音と、遠くの沢の音。そこへ、下生えを踏む音が混じった。

　二頭だった。

　灰色狼が獣道を歩いてくる。どちらも痩せていて、脇腹の毛が泥で汚れていた。

　この辺りで見かける個体は、もっと毛並みが整っている。受付の言っていたのは、この群れのことだろうか。

　先頭の一頭が、縄の上に前脚を置いた。

　ウィンは縄の端に意識を通す。

　まっすぐだった縄が、手元から先へ向かって膨れ上がった。表面が裂けて棘が起き上がり、張っていた線が弓なりに撓む。次の瞬間、跳ね上がった縄が狼の前脚に巻きついて、ギチ、と締まった。

　狼が声を上げて、体をよじる。

　ウィンは茂みから半身を起こし、ナイフを投げた。喉を狙ったが、暴れる動きに合わせきれずに肩へ入る。浅かった。

　二本目を抜こうとしたところで、背後の下生えが鳴った。

　二頭目は獣道を通っていない。藪を斜めに突っ切って、伏せているこちら側へ回り込んでいた。

　足元に石が転がっている。刃に変えて投げれば、届く。

　だができない。棘を保っている限り、二つ目には手を出せない。

　解けば、一頭目が来る。

　迷いは、たぶん二つ数えるあいだだった。ウィンは石に意識を通した。

　棘が縄に戻る音と、石が刃に変わる感触が、ほとんど同時だった。投げた刃は二頭目の鼻面をかすめて、そのまま藪へ飛んでいく。

　肩の後ろに衝撃が走った。視界が横へ流れて、地面を転がる。

　起き上がったときには、二頭が並んでこちらを見ていた。喉の奥が低く鳴り、肩の毛が持ち上がる。一頭目の肩には、さっきのナイフが刺さったままだった。

　ウィンは短剣を抜いて後ろへ下がった。二頭を同時に相手にする形は、はじめから考えに入れていない。

　足元の枝を拾って刃に変え、正面へ投げた。当たらなくてもいい。二頭が同時に身を引いた隙に、木立の奥へ走る。

　背後で下生えの鳴る音がしばらく続き、やがて聞こえなくなった。


　　　　◇


　沢のそばまで来て、ようやく足を止めた。

　肩の後ろに手を回すと、指先に血がついた。傷薬の瓶を歯で開けて、届く範囲に振りかける。染みるような熱さのあと、痛みが薄れていった。

　空になった瓶を袋へ戻す。

　しばらく待ってから、獣道まで戻った。縄は下生えに絡んだまま残っている。棘の形は解けて、ただの縄に戻っていた。

　回収しながら、さっきの数秒を思い返す。

　罠を保っているあいだ、自分には短剣しか残らない。石も枝も、拾っても意味がない。一つしか変えられないというのは、そういうことだった。

　だとしたら、保ち続けるのが間違いだ。締めたらすぐ解いて、次の手に移ればいい。

　そのためには、締めた一瞬で片がつく形が要る。二頭に前後から来られない場所が。

　ウィンは、来る途中で抜けた細い道を思い出した。


　　　　◇


　細道の真ん中に縄を渡した。片側は倒木の根元に、もう片側は岩の割れ目に挟み込む。端に手が届く位置、道の出口に立って待った。

　後ろは岩壁で、回り込まれる隙間はない。

　沢へ下りる道はここだけだ。水を飲みに来るなら、この道を通る。

　日が傾きはじめたころ、道の向こうに影が動いた。

　肩にナイフが刺さったままの、あの個体だった。傷のせいか、歩き方が重い。

　途中で足が止まった。目が縄を見ている。自分が掛かった物を、この個体は覚えていた。

　ウィンは動かなかった。ここで下がれば、狼も下がる。

　狼が体を低くして、縄をまたぎにかかった。前脚が越え、胴が越える。

　後ろ脚が、縄に触れた。

　ウィンは意識を通す。

　バチンと縄が跳ね上がり、棘が後ろ脚に巻きついた。前へ出ようとしていた勢いのまま、狼の体が横倒しになる。

　二つ数えて、意識を切った。

　棘が縄に戻る。狼が脚を引き抜いて起き上がろうとしたときには、ウィンは短剣に意識を通していた。刃が伸びて、切っ先が厚くなる。

　喉に、深く入った。

　狼が一度だけ大きく震えて、動かなくなる。輪郭がほどけ、光の粒になって消えた。あとに残ったのは、灰色の毛皮と牙が二本、それから肩に刺さっていたナイフだった。

```
『Lv9に上がりました』
```

　ナイフを拾って鞘に戻しながら、ウィンは自分の手を見た。

　さっき短剣を握り直したとき、刃を伸ばしてから突き出すまでが、思っていたより短かった。狙った場所へ、狙ったとおりに切っ先が入っている。

　スキルの欄は、前に見たときから変わっていない。それでも、指先だけが少し違うものになっていた。


　　　　◇


　沢沿いを下って帰る途中だった。

　ぬかるみに、足跡があった。

　灰色狼のものではない。しゃがみ込んで覗き込むと、泥に残った輪郭ははっきりしていて、爪の跡が四つ、指先の側に並んでいる。

　そのうちの、右端の一本だけが深かった。

　同じ重さで踏んだなら、四本とも同じくらいの深さになるはずだ。体重が片側に寄っている。脚を痛めているのか、それとも歩き方の癖なのか。

　ウィンは指を広げて、足跡の縁に沿わせた。人差し指から小指まで伸ばして、それでも届かない。この大きさの獣は、この森では見たことがなかった。

　茜音に見せたかった、と思う。今日はもう、あちらも別の相手といる時間だった。

　沢の水が石のあいだを鳴らしている。

　顔を上げたのは、風の向きが変わったからだ。

　木立のほうへ目をやって、何もいないのを確かめてから、視線を戻した。

　足跡が、増えていた。

　最初の一つの隣、こちら側へ半歩ぶん近い場所に、同じ形の凹みができている。爪の跡は四つで、右端の一本だけが深かった。
