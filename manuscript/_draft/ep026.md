# 第二十六話　覚醒者

　スマートフォンの画面には、十三時過ぎという表示が出ていた。

　冬夜はベッドに転がったまま、メッセージアプリを開いた。連絡先を上から辿ると、四番目に「浩二おじさん」が並んでいる。

　文面はさんざん迷った末、当たり障りのないものに落ち着いた。

「最近ハマってるゲームのことで、ちょっと聞きたいことがあるんだけど」

　これ以上のことは書かなかった。あの仮面が浩二の名前を出したことも、どこまで知っていて機材を送ってきたのかも、文字にしてしまえば重すぎる。

　送信ボタンを押してから、冬夜はしばらく画面を眺めていた。既読はすぐについたが、返事は来ない。

　シャワーを浴び、昼食を済ませ、また部屋に戻ってようやく通知が鳴ったのは、十八時を回った頃だった。

「今度な」

　それだけだった。何を聞きたいのか、いつが今度なのか、一切書かれていない。

　拍子抜けするほど短い一言に、冬夜は少しの間、返す言葉を探した。結局、「了解」とだけ打って送信した。



　夕食まで少し間があったので、冬夜はブラウザを開き、いつものプレイヤー掲示板を覗いた。

　トップに並んでいたのは、灰狼の森でも、マレイアの話でもなかった。

```
【総合】今日のソウルクレスト・オンライン雑談スレ

612: 名無しの冒険者
セルフィナでやべえのあったらしいぞ
都市級の刻紋種が街の近くまで来て暴れたって

613: 名無しの冒険者
蒼海の盟ってクランが抑えたんだと
波紋の輪とは別のとこらしい

614: 名無しの冒険者
それより聞けよ、そこのクランの一人が覚醒者になったって話
オルガ=レント以来、あの国で二人目だって

615: 名無しの冒険者
は? マジで
覚醒者って第三段階だろ、Lv400超えて何十時間もかかるってやつ

616: 名無しの冒険者
条件も非公開なんだろ
レベルだけ届いても覚醒者になれるとは限らないってどっかで見た

617: 名無しの冒険者
紋章の色まで変わって見えるらしいな
遠目に見ただけで「格が違う」って分かったって書き込みあった

618: 名無しの冒険者
成長ポイントの伸び方も桁が変わるってさ
うらやましいとかいうレベルじゃない
```

　冬夜はスクロールする指を止めた。

　都市級。地域級よりさらに上の等級だ。街ひとつの機能が止まるほどの被害を出す規模だと、いつか誰かの書き込みで読んだ覚えがある。

　それを一クランが単独で抑え、なおかつ一人が覚醒者に届いた。

　自分の右手の甲に浮かぶ紋章を、冬夜は無意識に見下ろした。Lv11。今のところ、これがすべてだ。

　覚醒者は四百を超えたその先にいる。四百という数字がどれほどの隔たりなのか、実感として掴めるものではない。掴めないという事実そのものが、答えのようなものだった。

　――あの試験体のことだろうか。

　仮面の人型は、手を加えている個体を近く別の国へ移すと言っていた。都市級まで育つほどの相手なら、あの言葉と無関係ではない気もする。

　だが確かめる手立てはどこにもない。名前も出ていなければ、正体を裏付けるものも一つもない。冬夜はスレッドをそれ以上遡ることをやめ、画面を閉じた。



　夕食を終えてヘッドギアを装着し、いつも通りログインする。

　喧騒の残るセイレスの通りを抜けながら、冬夜はフレンド一覧を開いた。茜音の名前は、今日も明るく灯っている。

　声をかけようとして、指が止まった。洞窟の話をしてから、まだ何日も経っていない。あの路地の空気は、まだ完全には晴れていない。

　結局、何も送らないまま一覧を閉じた。

　夏休みも、もう後半か。

　通りを歩きながら、冬夜はふとそんなことを思った。始まったばかりのつもりでいたのに、気づけば残りを数えられる時期に入っている。

　覚醒者という遠い場所を見たばかりだからこそ、今できることは一つしかない。

　しばらく一人で動くか。

　冬夜は南門のほうへ足を向けた。
