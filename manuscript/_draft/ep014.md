# 第十四話　誰そ彼刻

　乱れた息が収まるまで、冬夜たちはしばらくその場を動かなかった。

　脇腹の痛みはだいぶ引いていたが、まだ足に力が入りきらない。傷薬を使ったばかりだというのに、これほど消耗したのは初めてだった。

「ねえ、座ろっか。わたしも膝ガクガクだよ」

　茜音が近くの石段に腰を下ろす。冬夜もその隣に座り込み、ようやく人心地がついた。

　落ち着いたところで、冬夜はステータス画面を開いた。大熊を倒した直後に二段階分のレベルアップ通知は見ていたが、自由に振れる分の使い道は、あの時は決めきれずに保留にしていた。

　いつもなら迷わず素早さと器用さに均等投資するところだ。だが今日は勝手が違った。避けきれずに吹き飛ばされた一撃の感触が、まだ体の芯に残っている。

　もし茜音の光の膜がなければ、あの一撃をまともに受けていた。そう考えると背筋が冷えた。避けて、当てて、決める――それだけを磨いてきたやり方に、初めて疑いを持った。

　少しでいい。簡単には倒れない体も欲しい。冬夜は自由配分の一部を、初めて耐久力(VIT)に回すことに決めた。残りは、決め手を早めるためにSTRへ注ぐ。

```
冬夜
Lv8
職業:暗器使い
ソウルクレスト:彼は誰(かはたれ)

HP 102/102
MP 80/80
魂力(SP) 78/78
STR 52
AGI 102
DEX 99
INT 14
VIT 29
LUK 31

スキル:投擲、隠密行動、暗器生成、毒の調合、急所看破、会心の一撃、精密投擲

所持金:435Y
```

「うわ、増え方えぐいね」

　横から覗き込んだ茜音が声を上げる。

「今回は少し、守りにも回してみました」

「へえ。冬夜くんも懲りるんだ」

「……前から懲りてはいますよ、色々と」



　立ち上がり、二人は洞窟の中へ足を踏み入れた。

　入り口の暗さに反して、奥へ進むほど壁や天井に淡く光る苔が増えていく。まるで最初から誰かに見せるためのように、道筋だけがぼんやりと浮かび上がっていた。

　崩れかけた石段が奥まで続き、ところどころに倒れた柱が転がっている。かつては何か立派な建物だったのだろう痕跡が、苔と根に覆われながらもかろうじて残っていた。

　人の手が入った形跡はどこにもない。踏み荒らされた土も、置き去りにされた道具の類も見当たらなかった。噂には聞いていたが、本当に手つかずの遺跡なのだと、冬夜は改めて実感する。

「なんか……静かだね」

「森の中とは違う静けさですね」

　声を潜め合いながら、二人は奥へ進んだ。石段を上りきったところで、天井の高い円形の広間に出る。

　中央に横たわる白い影に、二人は思わず足を止めた。全身を真っ白な毛で覆われた、巨大な虎だった。体高だけなら大熊に匹敵するほどの巨躯でありながら、毛並みのそこかしこに深い傷が刻まれ、力なく地に伏せている。

　視界の隅に、見慣れない表示が浮かんだ。

```
刻紋種
氷牙の白虎(ひょうがのびゃっこ)
```

　冬夜は息を呑む。刻紋種――ゲームを始める前に読んだガイドで名前だけは知っていた。紋章を刻まれたような、通常個体とは一線を画す特殊な存在。ギルドで小耳に挟んだ噂の中にも、その名前は出てきていた。

　だが、実物を目にするのはこれが初めてだった。ただそこに横たわっているだけなのに、これまで相対してきたどんなモンスターとも違う気配がある。

　勝てるか負けるかという物差しが、そもそも意味を成さないような圧力が、肌を通して伝わってくる。冬夜は反射的に半歩後ろへ下がった。武器を借りる、変える、そういう算段よりも先に、体が竦んで動けなかった。

「……待って、これ」

　茜音が、冬夜より先に足を踏み出していた。

「危ないですよ、茜音さん」

　止めようと伸ばした手は、空を掴んだだけだった。茜音は武器の一つも持たず、ゆっくりと、それでいてまっすぐに虎へと近づいていく。

　止めるべきか、冬夜は一瞬迷った。だが横顔を見て思い直す。そこにあったのは、これまでの依頼で見せてきた無鉄砲さとは違う、真剣な、けれど少しも怖がっていない表情だった。

　虎もまた唸り声一つ上げない。伏せたまま、ただ弱々しく茜音を見つめている。敵意のようなものは、そこにひとつも感じられなかった。

　冬夜は追いつくように、それでも警戒だけは解かずについていく。

　茜音は虎のそばに膝をつき、傷だらけの体にそっと手をかざした。手のひらから、淡い光がこぼれる。討伐の合間に何度も見てきた、いつもの優しい光だった。

　だが、傷は塞がらなかった。ほんのわずかに滲んでいた血が止まった程度で、目に見える変化はそれ以上進まない。

「……あれ? おかしいな」

　茜音が首をかしげる。困惑した表情には、いつもの余裕がなかった。

　じっと耳を澄ますような間があって、茜音がハッと顔を上げた。

「違うんだって。傷のせいじゃない……喉のところ」

「喉、ですか」

　言われて目を凝らすと、虎の喉元の毛に埋もれるようにして、小さな宝石のようなものが覗いていた。禍々しいというより、場違いに人工的な輝きだった。表面には、細かな紋様のようなものが刻まれている。

「これが、苦しめてる原因……らしい」

　茜音の声は確信めいていた。誰かに教えられたように、けれど誰の姿も見えないまま。

　茜音は両手を宝石にかざし、目を閉じる。先ほどより深く、集中するような様子だった。

　手のひらの光が一段と強くなり、虎を包み込んでいく。しばらくして、かちり、と硬い音を立てて宝石が毛の間から浮き上がり、地面に転がり落ちた。

　虎が長く息を吐く。伏せていた体がわずかに緩み、鼻先を茜音の手に擦り寄せた。感謝を示すような、その仕草に嘘は感じられなかった。

　直後、光が二人と虎を包むように膨れ上がる。眩しさに冬夜は思わず目を細めた。

```
固有スキル──『誰そ彼刻(たそがれどき)』
```

「誰そ彼刻……!」

　光の中心で、茜音が叫ぶように声を上げた。意識してのことではないらしい、驚いたように自分の口元を押さえている。たそがれどき、と読むのだと、冬夜はその響きだけで理解した。

　視界にもう一つ、通知が浮かぶ。

```
『使役に成功しました』
```

　使役――言葉の響きだけで、冬夜にもおおよその意味は掴めた。モンスターを一方的に倒すのではなく、仲間として迎え入れる力らしい。噂には聞いたことがあったが、実際に目にするのはこれが初めてだった。

「わ、わたしの星、変わってる……!」

　茜音が慌てて自分の右手を見る。手の甲に浮かぶ、星の意匠を持つ紋章――以前見せてもらった時は、灰色の星が三つ並んでいるだけだった。

　そのうちの一つが今、淡い蒼白い光を帯びて色づいている。

　光が収まると、虎の巨躯もまた縮んでいった。見上げるほどだった体は、両手に抱えられるくらいの、ぬいぐるみのように愛らしい姿に変わっている。

　声にならない声のようなものが、頭の中に直接響いた。

『そばにいる。戦う時は、力を貸そう』

　小さくなった虎は、丸い目で茜音を見上げている。

「必要な時だけ呼べばいいみたい……普段は見えないところにいてくれるって」

　茜音がぽつりと呟く。冬夜にも、なんとなくその感覚は伝わってきた。契約でも結んだような、確かな繋がりの気配だった。

「……誰そ彼刻」

　冬夜は今しがた耳にした名を、もう一度小さく呟いた。国語の授業でうろ覚えに聞いた、あの古い言葉と同じ響きだった。

「誰そ彼――黄昏時、薄闇で相手の顔がよく見えなくて、誰そこの人は、って問いかける言葉です」

「へえ、そんな意味が」

「俺のクレストの名前、『彼は誰』って言うんです。似た意味の言葉ですけど、こっちは明け方の薄闇の方で」

　言ってから、冬夜は自分の言葉にはっとした。誰そ彼と、彼は誰。夕暮れと、夜明け。同じ問いを、互いに逆の時間から発している。

「……対になってる、ってこと?」

「偶然にしては、できすぎてる気がします」

　二人はしばらく黙り込んだ。刻紋種を、傷つけずに仲間にできる力。それだけでも十分に規格外だ。そこに、互いのクレストが対をなしているという事実まで加われば――

「これ、ちょっと……知られたらまずいやつじゃない?」

　茜音の声から、いつもの軽さが少し引いていた。

「はい。悪目立ちしすぎます、多分」

「じゃあ、しばらく内緒にしとく? 二人だけの」

「そうしましょう。慌てて動くよりは、少しずつ情報だけ集めていく方がいいと思います」

　茜音は頷き、小さくなった虎をそっと抱き上げた。腕の中に収まったそれは、心地よさそうに目を細めている。



　セイレスへ戻る頃には、日はだいぶ傾いていた。ギルドの受付で討伐依頼の完了を告げると、受付嬢は淡々と用紙に印を押す。

「猪型三体、角兎五体……確認できました。報酬六百ユンになります」

　所持金は四百三十五ユンから、千三十五ユンに増えた。

「今日はほんと、色々あったね」

　茜音がのびをしながら言う。門番の大熊、初めての刻紋種、そして誰にも言えない秘密。一日に詰め込むには、いくらなんでも濃すぎる出来事だった。

「……本当に」

　冬夜は短く同意する。ふと隣を見ると、茜音の腕の中で、小さな虎がすやすやと眠っていた。



　二人が立ち去った後、洞窟の奥にはただ静けさだけが残っていた。

　誰のものとも知れない声が、暗がりの中でひとりごちる。

「……手応えが良すぎたかな。せっかく仕込んだのに、抵抗されるとはね」

　くすり、と笑うような気配が続く。

「まさか、こんな形でクレストが開くとは思わなかった。面白い」

「……それに」

　声はそこで一度、言葉を切った。

「あの子も、あそこに居合わせていたとはね」

　それきり、声は闇に溶けて消えていった。
