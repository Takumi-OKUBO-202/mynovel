# 第二十一話　本人ですけど

　三日ぶりに、朝から予定のない日が来た。

　当て革を頼んだ日から、書店のシフトが二日続いた。夜に少しだけ潜って、勝手を知った狩場で狼を数頭刈って、風呂に入って寝る。それだけで一日が終わっていた。

　午前九時過ぎ。冬夜は麦茶のグラスを机の端に置いて、ノートパソコンを開いた。

　掲示板はゲームの中からは覗けない。見るならログインする前か、脱いだ後のこの時間しかない。二日とも寝る前に一通り巡回したが、どこも代わり映えはしなかった。

　灰狼の森のまとめスレッドを開いて、冬夜は指を止めた。

　昨夜は四百二十番台で終わっていたはずの書き込みが、朝のうちに三十ほど伸びている。


　それきり、四百二十三番は現れていない。あとに続いているのは、いつも通りの真偽論と、飽きた者たちの茶々だけだった。

　冬夜は椅子の背から体を起こして、もう一度、上から読み直した。

　二度目を読み終える頃には、指先が冷たくなっていた。

　まず、書かれている三つのうち、どれ一つとして掲示板には出ていない。

　冬夜は別のタブで過去ログを開き、あの目撃談を頭から確かめた。三百五十二番が書いたのは、狼がやられていたこと、白い虎が一撃で凍らせたこと、狼のほうにだけ刻紋種の表示が出ていたこと、そばにローブの背の低い子が立っていたこと。

　それだけだ。霜の話も、紋様の話も、膝の話も、どこにもない。

　次に、あの目撃者は遠くにいた。

　茜音は木立の隙間から見られていたと言っていた。枝の鳴る音で気づいて、声をかける間もなく逃げられた、と。

　あの距離で、草の葉先が白く縁取られたことが見えるだろうか。霜の降りる音が聞こえるだろうか。獣の額から背へ紋様がどう走っていたかを、走っている最中の相手から読み取れるだろうか。

　どれも、そばにいなければ拾えない細部だ。

　そして、片膝の一行だった。

　三百五十二番の書き込みは「狼のほうがやられてた」から始まっている。呼び出す場面から見ていたのなら、そこから書くはずだ。白い山のようなものが草地に現れる瞬間ほど、真っ先に書きたくなる場面もない。

　四百二十三番は、その、誰も書かなかったところから書き始めていた。

　しかも「立っていられなくなったからです」と理由まで添えてある。外から眺めているだけなら、ただ座り込んだようにしか見えないはずのものに。

　冬夜は画面から目を離して、天井を見上げた。

　騙りなら、こうはならない。過去ログを読んで面白がっている誰かに書けるのは、過去ログに書いてあることの言い換えまでだ。

　書いた者は、あの場を近くで見ている。しかも、目撃者が逃げ帰るより前から、たぶんずっと。

　もう一つ、冬夜には引っかかっていることがあった。書き込みの主が、自分のことを「わたし」と書いている。

　茜音の口調ではない。かといって、掲示板でよく見る書き癖とも違う。誰の声で読めばいいのか分からないまま、文字だけが頭の中に残った。

　冬夜はメモ帳を開き、四百二十三番の書き込みを一字ずつ写した。掲示板はゲームの中へ持ち込めない。伝えるには、こちらが覚えていくしかない。

　書き写しながら、腹の底が重くなっていくのが分かった。

　これまでは、噂の話だった。自分たちについて誰かが勝手に喋っている、という話だ。

　今日からは違う。自分たちを近くで見ていた者がいて、そのことを、わざわざ書いて寄越している。



　ログインしたゲームの中は、雲の多い午前だった。

　冬夜はまずフレンド一覧を開いた。茜音の名前は明るく灯っている。

```
冬夜:話したいことがある。今日、時間あるか
茜音:『あるよー。でも今ちょっと手が離せないから、
　　　一時間後でもいい?』
冬夜:大丈夫。いつもの路地で
```

　返事を待つあいだに、頭の中の順番を組み直す。ちょうど今日は、済ませておくべき用事が二つあった。

　冬夜は大通りを東へ折れて、武具屋の隣の防具屋へ向かった。

　店先の革の匂いも、奥のカウンターで金具を磨いている店主も、三日前と変わらない。冬夜が顔を出すと、店主は顎で棚のほうを示した。

「当て革だな。できてるぞ」

　差し出されたのは、薄く編んだ黒っぽい革の板が数枚、細い紐で繋がったものだった。手に取ると、思っていたより軽い。

「胸と脇腹、それと肩だ。急所だけ庇えばいい、という寸法で組んである。合わなけりゃ持ってこい」

　店主が奥の棚へ向き直ったのを見てから、冬夜は外套の前を開けて、上着の上から当ててみた。脇腹の位置が指一本分だけ高い気もしたが、肩の可動は妨げられていない。

　合わせる相手の現物を見せられなかったのだから、この程度で済んだのは上出来だった。

「これで十分です。助かりました」

「そうか」

　店主はそれきり顔を上げず、また金具を磨き始めた。詮索はしない、と言ったのは本当らしい。

　次に、通りを一本戻って薬屋の扉をくぐる。

　棚に並んだ小瓶を眺めて、冬夜は少し迷ってから口を開いた。

「傷薬の小を、四本お願いします」

「四本ですね。百ユンになります」

　店員が手際よく小瓶を布に包んでいく。冬夜は財布の中身を思い浮かべた。千八百から百を引いて、千七百。

　手持ちと合わせて五本になる。一本しかない前提で組む、とこの数日ずっと自分に言い聞かせていたのが、ようやく終わった。

　包みを受け取りながら、冬夜は思う。これは、備えができたという安心とは少し違う。

　――何が来るのか、こっちには分かっていない。

　分かっていないから、増やせるものを増やしておくしかない。そういう買い方だった。



　ギルド裏手の路地は、あの日と同じように樽と木箱が積み上がっていた。

　人通りは少ないが、見上げれば洗濯物の紐が渡してあって、生活の音だけは近い。この街で二人が落ち着いて話せる場所は、結局ここしかなかった。

「おまたせー。どうしたの、めずらしいね」

　路地の入り口から、白に近い髪が覗いた。前もこの入り方だったな、と冬夜は思う。

「掲示板に、変な書き込みが出た」

　前置きは省いた。伝わりやすい順番を考えている余裕がなかった。

「わたし、まだ何もしてないよ」

「うん。茜音の話じゃない」

　冬夜は木箱に腰を下ろして、覚えてきた文面を読み上げた。本人ですけど、というたった一行から順に、そのまま。

　最初のうち、茜音はきょとんとしていた。

「え、誰それ。わたしのふりしてるってこと?」

「そう名乗ってる。でも、そこは大した問題じゃないんだ」

「大した問題じゃなくないよ。わたしだよ」

　茜音がむっとして木箱を叩く。冬夜は首を振って、続きを読み上げた。

　虎を出した直後、その場に片膝をついた。立っていられなくなったから。

　そこまで言ったところで、茜音の表情が止まった。

「……それ」

「掲示板には、一行も出てない」

　冬夜は自分の膝の上で指を組んだ。

「あの目撃者が書いたのは、狼がやられたところからだ。呼び出す場面のことは何も書いてない。膝をついたことも、その理由も、どこにもない」

「……わたし、言ってないよね。掲示板にも、誰にも」

「言ってない。知ってるのは、茜音と俺だけだ」

　茜音が自分の腕をさすった。見えないものを払い落とそうとするような、無意識の動きだった。

「……あとの二つも読むぞ」

　冬夜は続けた。狼の紋様が、額から背にかけて走っていたこと。歩くたびに、明るくなったり暗くなったりしていたこと。

「……走ってた」

「虎が息を吸ったとき、先に空気のほうが凍った、とも書いてある。草の葉の先が白くなって、地面に霜が降りる音がした、と」

　言い終えて、冬夜は顔を上げた。

「なあ。実際に、そうだったのか」

　茜音は数秒黙ってから、こくりと頷いた。

「……なった。葉っぱの先が、ぱきぱきって」

　そこで、茜音の目が見開かれた。

「待って。なんで冬夜くんがそれ知ってるの。わたし、そこまで話してないよね」

「知らなかった。今、書いてあったから読み上げただけだ」

　路地の空気が、一段静かになった気がした。

　冬夜自身が知らなかった、というのが答えだった。あの日の草地の内側にあった事実を、本人と、書き込んだ者だけが知っていて、冬夜は今日まで知らなかった。

「……近くにいた、ってことだよね」

　茜音の声が、少し低くなった。

「木の向こうで見てた人じゃなくて。もっと、ずっと近く」

「そう考えるしかない」

　言葉を柔らかくしても意味がない、と冬夜は判断した。

「あの日、わたし、ちゃんと見たんだよ」

　茜音が両手を広げて、ぐるりと一周する仕草をした。

「一周して、誰もいないの確かめて、それから出したの。そこは、間違ってないと思ってたのに」

「間違ってない。前にも言ったけど、見て誰もいなかったっていうのは、その瞬間、目に入る範囲にいなかったってだけだ」

　言いながら、冬夜は自分の言葉に自分で嫌な気分になった。

　あのとき自分が想定していたのは、木立の陰や、あとから歩いてくる人間だ。誰にも見えない場所から、逃げも隠れもせずに見ている者のことは、想定していなかった。



「……ねえ。どうしよっか」

　茜音が隣に腰を下ろした。声はいつもの調子に戻そうとしていたが、足はぶらぶらしていなかった。

「打てる手を、順番に潰していこう」

　冬夜は指を一本立てた。

「まず、掲示板に書き返すのはなしだ」

「あれはわたしじゃありません、って?」

「うん。それを書いた時点で、本物がこの掲示板を読んでますって宣言することになる」

　しかも、否定すればするほど話は伸びる。噂に一番よく効く燃料は、当事者の反応だ。この数日でようやく「どうせ夜会の誰かだろう」で落ち着きかけているものを、こちらから掘り返す理由はない。

「じゃあ、運営に言うのは?」

「考えた。けど、何を言えばいいと思う」

　茜音が口を開きかけて、そのまま閉じた。

「嘘の書き込みがあります、って言うためには、本当のほうを説明しないといけないんだ」

　あの草地で本当は何が起きたのか。それを話せる相手が、この世界に一人もいない。それが二人の置かれている状況だった。

「三つ目。相手を探す」

「できないの?」

「名無しの番号が一つあるだけだ。名前もない。誰がどこから書いたのかも分からない」

　あの書き込みからたどれるものは、一つもない。向こうはこちらの顔も、髪の色も、声も知っていて、こちらは向こうを何も知らない。

　その差が、どうやっても埋まらなかった。

「じゃあ……あの森に行かない、とか」

「もう行かない取り決めになってる。それに」

　冬夜はそこで少しだけ言いよどんだ。

「見られたのは、あの森にいたからじゃないと思う。俺たちだから見られたんだ。場所を避けても、たぶん意味がない」

　茜音は膝を抱えて、しばらく黙っていた。

「……結局、なんにもできないってこと?」

「できない」

　冬夜ははっきり言った。慰めを混ぜたら、この人はすぐ気づく。

「相手が誰かも分からない。何がしたいのかも分からない。分からないうちに動くと、こっちの居場所だけが増えていく」

　だから、できるのは一つきりだ。

　白虎は出さない。深部には近づかない。人の多いところで身の上話をしない。そして、いつも通りに過ごす。

　――要するに、これまで決めてきたことを、これまでより本気で守るだけだ。

　自分で言っておいて、あまりに何もしていないな、と冬夜は思った。

「警戒するしかない、ってことだね」

「……そうだ」

「うん」

　茜音は意外なほどあっさり頷いて、それから立ち上がった。膝についた埃を払って、いつもの顔でこちらを見下ろす。

「わかった。じゃあ、そうする」

「怖くないのか」

「怖いよ。すごく」

　あっけらかんと言われて、冬夜のほうが返事に詰まった。

「でもね。怖いのと、やめるのは別だと思ってるから」

　妙に据わった言い方だった。冬夜はその据わりの正体を、まだ知らない。

「あ、でも一個だけ約束して」

　茜音が人差し指を立てる。

「わたしに黙って、ひとりで考えないでね。冬夜くん、たぶん一人で全部背負うタイプだから」

「……分かった」

「ほんとに?」

「本当に」

　茜音は満足そうに頷いて、路地の外へ歩き出した。石畳を蹴る足音が、いつもより少しだけ大きく響く。

　冬夜はその場に残って、灰色の空を見上げた。

　掲示板の噂は、いずれ飽きられて流れていく。そういうものだと、この数日で分かった。

　だが、あの草地を近くから見ていた者は、流れていかない。今もどこかで、この街のどこかを歩いているのだろう。

　冬夜は外套の襟を整え、当て革の紐を締め直した。買ったばかりの傷薬が、腰のあたりで小さく鳴った。

　備えたところで、何に備えているのかが分からない。

　それでも冬夜は、しばらくそこを動かなかった。
