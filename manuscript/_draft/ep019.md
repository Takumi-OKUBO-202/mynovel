# 第十九話　見えなくする側

　乾杯の音頭が終わって最初に届いたのは、汗をかいたジョッキが並ぶ音だった。

　駅前の居酒屋の座敷に、大学の顔ぶれが十四人。夏休みの中日に、誰かが思いつきで声をかけて集まった、名前のない飲み会だった。

　注文を取りに来た店員が、卓を一周しながら年齢を確認していく。冬夜のところで手が止まった。

「一年です。十八なので、ウーロン茶でお願いします」

　冬夜がそう言うと、店員は慣れた様子で頷いて次へ移った。ほどなく運ばれてきたグラスは、周りのどれよりも背が低くて、色だけが濃かった。

「じゃ、乾杯だけな」

　斜め向かいの先輩がジョッキを差し出してくる。ガラスとガラスがぶつかる音は、中身が何であろうと同じだった。

　三十分もすると、卓の空気が目に見えて変わった。

　顔が赤くなる人がいて、まったく変わらない人がいて、声だけが二段階大きくなる人がいる。話は枝分かれしていく一方で、どの枝も元の話に戻ってこない。

　同じ話を二度している先輩がいた。誰もそれを指摘せず、二度目のほうがよく笑われていた。

　冬夜はウーロン茶を舐めながら、その様子を眺めていた。

　楽しそうではある。それは間違いなく分かる。ただ、その楽しさの中身がどういう手触りをしているのかは、こちらからは見えなかった。

　――お酒を飲むというのは、こういう感じなのか。

　正確には違う、と自分で思い直す。分かるのはせいぜい、飲んでいる人たちを外から見ているのはこういう感じなのか、というところまでだ。

　あと二年もすれば、たぶん自分もあちら側の卓に座っている。そう考えても、待ち遠しいという気持ちにはならなかった。

「冬夜、サークルどこ入ったんだっけ」

　話の枝が一本、こちらへ伸びてきた。

「入っていません」

「まじで? じゃあ夏休み何してんの」

「バイトです。近所の書店で、週に何回か」

「へえ。将来そっち系?」

「いえ、特には」

　三往復で枝は枯れて、話は別のほうへ流れていった。冬夜は自分でも、もう少し何か言えたはずだと思ったが、その何かが出てこない。

　いつもこうだ。答えを持っていないわけではなく、答えるほどのものを持っていない。

　卓の向こうでは、就職の話と、去年の合宿の話と、誰かの失恋の話が同時に進んでいた。その音の中で、冬夜の頭はいつのまにか別のことを転がしていた。

　――報告番号、一一四。

　前脚を鎖で繋がれた刻紋種。首に、紋章の入った石。他に例がなく、信頼性は低いものとして参考記録に回されていた一枚。

　あの綴りの紙の質感まで思い出せるのに、目の前の話は三秒前の内容が抜け落ちている。

「おい、寝てんのか」

　肩を小突かれて、冬夜は顔を上げた。

　いつのまにか隣に座り直していたのは、二年の西尾だった。学部の集まりで何度か顔を合わせている、気さくで、それでいて距離を詰めすぎない先輩だ。

「起きています。すみません」

「顔が完全に別のとこ行ってたぞ」

　西尾は笑って、自分のジョッキと冬夜のグラスを見比べた。それから店員を呼んで、勝手にウーロン茶のおかわりを頼んだ。

「飲めない席ってつまんねえだろ。俺も一年のとき、これで二時間耐えた」

「……そうでもないです。見ているだけでも、そこそこ面白いです」

「なにその観察日記みたいな感想」

　言いながら、西尾は大きくあくびをした。目の下がうっすら暗い。

「昨日、夜中までゲームやってたんだよな。寝てない」

「何をやっているんですか」

「ソウルクレスト。知ってる?」

　冬夜の手が、グラスの半ばで止まった。

「……俺も、やっています」

「まじで」

　西尾の姿勢が変わった。座り方が三センチほど前に出た、という程度の変化だったが、はっきり分かった。

　そこから先は速かった。どこの狩場が旨いとか、あの依頼は報酬が渋いとか、そういう話が交互に飛び交う。

「クレスト何出た?」

「地味なやつです。派手なことは、何もできません」

「奇遇だな、俺のも地味」

　西尾は自分のクレストの名前を言わなかったし、冬夜も訊かなかった。互いにそこは触れない、という呼吸だけが、なぜか一発で合った。

「ソロ?」

「……たまに、組む人がいます」

　言ってから、冬夜はグラスに口をつけた。それ以上は続けなかった。

　白い虎の話も、資料館の話も、塀の影で笑っていた人の話も、この卓には一つも置けない。持ってきてはいけない類の荷物だ。

「じゃあさ、今度一緒に行こうぜ。俺、北のほうの湿地なら案内できる」

「北の湿地、ですか」

　冬夜は首を傾げた。セイレスから北へ出たことはあるが、湿地という話は聞いた覚えがない。

「あれ。お前どこの国?」

「アルディアです」

「あー」

　西尾が天井を仰いだ。心底残念そうな、間の抜けた声だった。

「俺、ヴァルドレア」

　その一言で、話が終わってしまったのが分かった。

「登録したときの経路で、最初の国が決まるんですよね」

「そうそう。俺は高校の友達に誘われて入ったから、そいつと同じ国。お前は?」

「叔父です」

「はい終了。国またぐには、実際に自分の足で国境越えるしかないからな。途中の道が、俺らのレベルだとまず無理」

　知識としては知っていた。始める前に読んだガイドにも、ゲーム内の国情報の案内にも、同じことが書いてあった。

　ただ、そこに書かれていた一文が、こういう形で目の前に現れるとは思っていなかった。同じ夜に、同じ世界に、同じようにログインしていて、それでも会えない。

「いつか行けるようになったら、連絡します」

「おう。そのときは案内するわ」

　西尾はあっさりそう言って、枝豆に手を伸ばした。落胆を引きずらないところが、この人らしかった。

「そういやアルディアだろ。そっちの新しい王様、めっちゃ有能らしいじゃん」

「……王様」

「知らねえの?」

　知らなかった。冬夜はセイレスの城のほうへ足を向けたことすら一度もない。

「うちの掲示板で言われてんだよ。アルディアは当たりを引いたって。前の王様が亡くなって、息子が継いだんだろ? それが評判いいらしくて」

　西尾は指を折りながら、又聞きらしい話を並べた。街道の警備が増えたとか、通行の手数料が下がったとか、その程度のことだ。

「隣の国のことって、逆によく見えるんだよな。自分とこの悪いところは見えないくせに」

「……そういうものですか」

「そういうもんだろ」

　それきり話は屋台の値段に流れて、王様の話は二度と戻ってこなかった。

　自分の国の話を、他の国のプレイヤーから聞かされた。冬夜が持ち帰ったのは、その据わりの悪さだけだった。

　世界は、自分が見ている範囲よりずいぶん外側で、勝手に動いているらしい。

　九時前にお開きになって、駅の改札前で解散になった。

「じゃあな。また飲もう」

「俺、ウーロン茶ですけど」

「じゃあまたウーロン茶飲もうな」

　西尾はひらひらと手を振って、反対側のホームへ降りていった。

　電車を待つあいだ、冬夜はさっきの自分を思い返していた。

　サークルは、と訊かれて三語で終わった。将来は、と訊かれて「特には」で終わった。

　なのに、ゲームの話になった途端、訊かれてもいないことまで喋っていた。西尾が姿勢を前に出したのと同じくらい、こちらも前に出ていたはずだ。

　現実で「これがやりたい」と言えたことは、たぶん一度もない。



　家に着いたのは十時過ぎだった。

　母はもう寝ていて、台所の明かりだけが点けたままになっている。冬夜はそれを消して、自分の部屋に上がった。

　ヘッドギアを手に取る前に、机のノートパソコンを開く。掲示板はゲームの中からは覗けないから、調べ物はどうしてもこの時間になる。

　灰狼の森のまとめスレッドは、まだ虎の話で緩く回っていた。ただ、新しい事実は一つも出ていない。「どうせ夜会の誰かだろ」で片付けたがる流れが、この数日で完全に固まっている。

　安心すべきなのだろうな、と冬夜は思った。思っただけで、肩の力は抜けなかった。

　冬夜はメモ帳を新しく開いて、分かっていることだけを四行に並べてみた。

```
・白い虎は、脚を鎖で繋がれていた
・森閉ざしの灰狼は、群れを完璧に統べていたのに、
　侵入者にだけ度を越して執拗だった
・報告番号 一一四。前脚を鎖、首に紋章入りの石。
　他に例がなく、信頼性は低いものとして参考記録
・夜会が刻紋種を狩る理由は、報酬でも名声でもない
```

　共通しているのは、全部が刻紋種の話だということ。それだけだ。

　鎖の話が二件ある。だが片方は自分の目で見たもので、もう片方は「信頼性は低い」と注記された紙一枚だ。並べれば同じ形に見えるというだけで、同じだと言い切れる根拠はどこにもない。

　誰かが刻紋種に何かをしている――そういう形になりそうで、あと一歩のところでならない。

　線を引こうとすると、点と点のあいだが、いつも指一本分だけ足りなかった。

　冬夜はメモを保存して、ついでに「アルディア　新王」と打ち込んでみた。出てきたのは西尾が言っていたのとほとんど同じ、当たり障りのない好意的な書き込みばかりだった。

　ゲームの話をしているはずなのに、書いてある内容だけを見ると現実の記事と区別がつかない。それが少しだけ、おかしかった。

　時計は十時半を回っていた。冬夜はパソコンを閉じて、ヘッドギアを手に取った。



　ゲームの中は、よく晴れた午後だった。

　現実とゲームで時間の流れが噛み合っていないことには、もう慣れた。夜に潜って昼に立つ、というのが最近の常態になっている。

　フレンド一覧を開くと、茜音の名前は灰色に沈んでいた。ログアウト中ということだ。

　冬夜は短い文だけ送っておくことにした。

```
冬夜:今日は一人で、外套の性能を確かめてくる。
　　　中層までしか行かない
```

　深部には近づかない、という取り決めは自分にも等しくかかっている。書いてから、これはあの人に対する報告というより、自分への念押しだなと思った。

　セイレスのギルドは、いつも通り人で溢れていた。冬夜は掲示板の前を端から端まで眺めて、一枚の依頼票の前で足を止める。

```
討伐依頼(Eランク)

霞蜘蛛(かすみぐも)の間引き 三体
場所:灰狼の森・奥側(中層)
報酬:400Y

備考:糸を張らないため、巣を目印に探すことが
できません。口から霧状の分泌物を吐き、獲物の
視界を奪ってから仕留めます。動かずに待ち伏せる
性質のため、遭遇に気づくのが遅れがちです。
```

　受付のカウンターへ持っていくと、職員は依頼票に目を落として、少しだけ眉を上げた。

「霞蜘蛛は初めてですか」

「はい、初めてです」

「でしたら一つだけ。あれの霧は毒ではありません。吸っても体は何ともないので、そこは心配なさらなくて結構です」

「では、何が困るんですか」

「見えなくなります。それだけです」

　職員はあっさりそう言って、依頼票に受理の印を押した。

「見えないだけで、人は驚くほど動けなくなります。落ち着いて、まず霧から出てください」

「……分かりました。ありがとうございます」

　ギルドを出る前に、冬夜はインベントリを開いて中身を確かめた。

　投擲ナイフ五本。自作の投げ道具が数本。短剣は腰に二本。毒の小瓶。そして傷薬(小)が、一本。

　薬屋に寄るべきだ、というのはすぐに分かった。ただ、これから防具の加工を頼むつもりでいて、その相場をまだ知らない。財布の組み直しは、今日の稼ぎを受け取ってからにしたかった。

　――一本しかない前提で組む。

　冬夜は自分にそう言い聞かせた。霧に巻かれて姿勢が崩れたら、そこで一度退く。深追いをしない。それが今日の条件だ。

　条件を先に決めてしまえば、あとは守るだけでいい。



　灰狼の森の手前側は、いつもの顔ぶれだった。

　冬夜はまず、勝手を知った灰色狼で外套を試すことにした。深い灰色をした薄手の外套は、羽織っていることを忘れるほど軽い。

　下生えを踏まないよう気をつけながら、一頭の背後へゆっくり近づいていく。

　いつもなら、十歩ほど手前で耳がぴくりと動く。今日はそれが起こらなかった。

　八歩。六歩。五歩。

　狼が振り向いたのは、四歩まで詰めたところだった。そこからは急所看破の白い点を刺すだけで、こちらの一方的な仕事になった。

　冬夜は同じことを、相手を変えて何度か繰り返した。分かったことは三つある。

　一つ、消えるのは音と気配だけで、姿は消えない。正面から視界に入れば、当たり前のように見つかる。

　二つ、ゆっくり動いているあいだはほとんど無音だが、走ると足音がわずかに戻る。全力で駆ければ、効果は半分もない。

　三つ――これが一番はっきりした――防御力は、本当に何もない。

　四頭目の爪先が肩をかすめたとき、外套の生地は裂けもしなかったが、衝撃だけがそっくり素通りしてきた。下に着ている軽装の上着が受け止めていなければ、かすり傷では済まなかったはずだ。

　布一枚を余分に羽織っている、という以上の意味はない。そういう装備だ。

　冬夜は肩を回して、痛みが引くのを待った。この穴をどうにかしないことには、この外套は「見つからないまま死ねる装備」でしかない。



　中層に入ると、木が太くなり、下生えが減った。

　霞蜘蛛を最初に見つけたのは、見つけたというより、見つけられたと言うほうが正しかった。

　太い幹の根元で、樹皮の色をした塊が動いた。

　大型犬ほどの胴に、長く折れ曲がった脚が六本。灰白色の体には樹皮そっくりの斑が浮いていて、口元だけが不自然に膨らんでいる。

　こちらの足音は消えていた。それでも意味がなかった。相手は探していたのではなく、ただそこで待っていたのだ。

　膨らんだ口元が、収縮した。

　視界が、白くなった。

　三歩先の幹が消えた。自分の手が、肘から先だけ見えない。冷たくもなければ、息苦しくもない。ただ何も見えないというだけのことが、これほど足を止めるとは思わなかった。

　急所看破の白い点は、どこにも浮かばない。見えているものにしか働かない技なのだと、冬夜はこのとき初めて理解した。

　投げるのも無理だ。的が見えなければ、精密投擲も何の役にも立たない。

　霧の中で、かさ、と脚の音が回り込んだ。

　冬夜は反射的に後ろへ下がって、背中を幹に当てた。心臓が耳の裏で鳴っている。

　そこで、音が止まった。

　蜘蛛が、止まっている。こちらを探している。

　――向こうも、見えていない。

　当たり前のことに、冬夜はようやく気づいた。自分で吐いた霧の中では、あの蜘蛛も目が使えない。だから音と気配で探す。

　そして今、こちらは音も気配も薄い。

　互いに見えない状況で、見つからないことにかけては、こちらのほうが上手だった。

　冬夜は息を殺し、幹に沿って横へ五歩ずれた。霧の切れ目から、灰白色の背中が覗く。

　白い点が、一つだけ浮かんだ。

　投擲ナイフが吸い込まれるように刺さり、蜘蛛が跳ねた。だが落ちない。素の火力の低さは、こういうときに正直に出る。

　跳ねた勢いのまま、脚の一本が横薙ぎに来た。冬夜は身を捻ったが、肩をまた掠られる。衝撃が素通りする感覚は、さっきと同じだった。

　距離を取りながら、腰の短剣を握る。自分の持ち物だから、断りを入れる必要はない。意識を通すだけで、刃はぬるりと伸びて槍の形になった。

　霧が薄れ、白い点がもう一度浮かぶ。冬夜は踏み込んで、そこへ突き込んだ。

　蜘蛛の体が光の粒子になって散った。

　息が上がっていた。冬夜は膝に手をついて、ようやく気づく。

　見えなくなった時点で、自分は何もできなくなっていた。急所看破も、精密投擲も、会心の一撃も、全部「見えている」ことを前提にした技だ。

　その前提を、あの蜘蛛は一息で外してきた。

　冬夜はしばらく、その場から動かなかった。



　二体目は、こちらが先に見つけた。

　樹皮に紛れた塊が、風が吹いても揺れなかった。周りの葉が全部動いているのに、そこだけが動かない。不自然さのほうが、色より先に目についた。

　冬夜は迷わず、正面から一歩踏み込んだ。

　口元が収縮し、白い霧が広がる。今度は自分から、その中へ入った。

　視界は同じように塞がれる。だが今度は、それでいい。

　霧の中では、蜘蛛も目を使えない。使えるのは音と気配で、そこはこちらが消してある。つまりこの霧は、蜘蛛が自分の得意な狩り場を作ったつもりで、こちらの得意な狩り場を作ってくれたのと同じことだ。

　冬夜は爪先から静かに体重を移して、大きく回り込んだ。

　霧が薄れ始める。灰白色の胴の、脚の付け根のあたりに、白い点が浮かんだ。

　背後から、一撃。

　手応えは、一体目とはまるで違った。同じ場所へ同じ力で入れたはずなのに、粒子になるまでが一呼吸だった。正面から刺すのと、相手が気づいていない背中から刺すのとでは、こうも違うらしい。

```
『Lv9に上がりました』
獲得ポイント　自動:20　割り振り可能:20
```

　落ちた素材を拾い上げる。指先ほどの大きさの、半透明の袋のようなものだった。

```
霞蜘蛛の霧腺(むせん)
```

　握ると、内側で液体が揺れる感触がある。あの霧の元だ。

　冬夜はそれを目の高さに掲げて、しばらく眺めた。

　――これ、丸めれば投げられるんじゃないか。

　思いついた瞬間に、指先が勝手に段取りを組み始めていた。



　三体目は、探すのに少し時間がかかった。

　見つけてから、冬夜は仕掛ける前に足元の石を一つ拾った。無主物だから、断りは要らない。借りて、指ではじけるくらいの小さな塊に整える。

　それを、蜘蛛から見て反対側の茂みへ投げた。

　葉が鳴った。蜘蛛の口元が収縮し、白い霧が――誰もいないほうへ広がった。

　その間に、冬夜は背後を取っていた。

　霧が薄れるより早く、白い点が浮かぶ。一撃で終わった。

```
『Lv10に上がりました』
獲得ポイント　自動:20　割り振り可能:20
```

　冬夜は短剣を鞘に戻して、息をついた。

　一度の依頼で二段階上がったのは、苔纏いの大熊のとき以来だ。中層の中でも、この蜘蛛はよほど格が高い扱いらしい。

　拾い集めた素材を確かめる。霧腺が三つ、硬毛が二つ。

　そして、それとは別に、持って帰るものがもう一つあった。

　あの蜘蛛がやっていたことは、突き詰めれば一つしかない。相手から見えなくして、それから近づく。

　毒でもなければ、特別に強い一撃でもない。順番の話だ。

　――これは、借りられる。

　冬夜は自分の右手の甲を見下ろした。藍と紫の混じった紋章が、ゆっくりと明滅している。

　人の武器を借りて形を変えるのがこの力の使い方だと思っていたが、借りられるのは物だけではないらしい。相手の狩り方そのものを、そっくり持って帰ってもいい。



　人気のない木陰で、冬夜は割り振りを済ませることにした。

　Lv9の分の二十点は、AGIへ。避ける速さと、動き出しの速さが上がる。

　Lv10の分の二十点は、DEXへ。狙ったところへ、狙った通りに届かせる精度が上がる。

　これまでは十点ずつ半々に配ってきたから、均して見れば同じ結果になる。それでも今日は、一つずつ選びたかった。

　VITの欄は、九のまま指を止めずに通り過ぎた。

　大熊に殴られてからずっと、耐久に振るべきではないかという考えは頭の隅に残っていた。今日、その答えが出た。

　この外套は、防御を捨てる代わりに見つからなくなる装備だ。それを着ると決めた以上、耐久に少し振ったところで、避けきれもせず耐えきれもしない中途半端な体になるだけだろう。

　だったら、当たらないほうに賭け切る。

　足りない分は数字で埋めない。冬夜はインベントリの中の硬毛を思い浮かべた。埋めるなら、装備と工夫のほうで埋める。

```
冬夜
Lv10
職業:暗器使い
ソウルクレスト:彼は誰(かはたれ)

HP 122/122
MP 100/100
魂力(SP) 98/98
STR 36
AGI 156
DEX 153

VIT 9
LUK 37

スキル:投擲、隠密行動、暗器生成、毒の調合、急所看破、会心の一撃、精密投擲

所持金:1350Y
```

　九という数字だけが、最初からずっと動いていない。並んだ数字の中でそこだけが取り残されて見えるが、冬夜はもう気にならなかった。

　動かさないと決めたものが一つあるというのは、たぶん悪いことではない。



　街へ戻り、依頼達成報告の窓口で霞蜘蛛の討伐を報告した。報酬の四百ユンが手元に入る。

　続いて素材買取の窓口で、道中に溜まった灰色狼の牙と毛皮をまとめて売った。しめて百五十ユン。

「そちらの霧腺と硬毛も、お買い取りできますが」

「いえ、これは残します」

　冬夜は袋の口を閉じた。売れば手っ取り早いのは分かっているが、これには今日の稼ぎより価値のある使い道がある。

　所持金は千九百ユンになっていた。

　人通りの少ない裏道へ入り、冬夜はしゃがみ込んで道具を広げた。すり鉢と布切れを使うのは、初めて毒を作った日以来だ。

　霧腺の膜を破らないよう気をつけながら、布切れで包んで丸めていく。あのときは指先が言うことを聞かず、一度目は薄すぎる毒液を作って苦笑したものだった。

　今日は、そういうことが起きなかった。指が勝手に力加減を覚えている。DEXという数字が何をしているのか、こういうときに一番よく分かる。

```
『目眩し玉を作成しました』
```

　同じものが三つ、手のひらの上に並んだ。握り拳より一回り小さい、頼りない玉だ。

　冬夜は裏道の奥に誰もいないことを確かめてから、一つを地面へ叩きつけた。

　ぱん、と乾いた音がして、白い霧が一気に膨れ上がる。二歩先の壁が、まるごと消えた。

　数を数える。十五を過ぎたあたりで輪郭が戻り始め、二十で完全に晴れた。

　自分の体には何も起きていない。痛くもなければ、痺れもしない。ただ二十数えるあいだ、何も見えなかった。それだけだ。

　――これ単体では、何も起きない。

　冬夜は残った二つを、丁寧にインベントリの奥へしまった。

　これは武器ではない。相手がどちらへ動いても不利になる、そういう形を作るための一手だ。使う相手は、まだいない。



　最後に向かったのは、武具屋の隣の防具屋だった。

　軽装の上着を買った店だ。店先には相変わらず革の匂いが漂っていて、奥のカウンターで店主が金具を磨いている。

　冬夜が硬毛を二つカウンターに置くと、店主は手を止めて指でつまみ上げた。

「霞蜘蛛だな。薄く編めば当て革になる。ステータスの数字には出ないが、急所を庇うくらいはしてくれる」

「それを、お願いしたいんです。ここで加工していただけますか」

「できる。持ち込みなら、完成品を買うよりずっと安く上がるぞ。加工賃は百。日数は三日もらう」

「お願いします」

　話がまとまったところで、店主が顔を上げた。

「で、上に何を着る」

「……上に、ですか」

「当て革ってのは、単体で着るもんじゃない。上に何を羽織るかで、当てる位置も厚みも変わる。現物を出せ。合わせる相手を見ないと、ぴったりのものは作れん」

　冬夜の指が、外套の裾のあたりで止まった。

　裾の内側には、灰狼の紋様によく似た刻印が小さく打たれている。刻紋銘の刻印だ。刻紋種を倒さなければ手に入らない代物で、市場に出れば値がつきすぎるという意味でも、噂の出所を辿られるという意味でも、カウンターの上に広げていいものではなかった。

　店の中には、他に客が二人いた。棚の前で防具を吟味しているだけの、なんでもない客だ。

　なんでもない客が二人いる。それだけのことが、今の自分には無理だった。

「……すみません。現物は、お見せできません」

「なんだそりゃ」

「寸法だけ、お伝えします。それでお願いできますか」

　店主はしばらく冬夜の顔を見ていた。値踏みというより、面倒事の匂いを嗅いでいる目だった。

「訳ありは珍しくない。この商売、いちいち詮索してたらきりがないからな」

　店主は磨いていた布を置いて、木の物差しを引き寄せた。

「ただし、聞いた寸法通りに作る。合わなくても直しはもう一回分の金をもらうぞ。それでいいなら受ける」

「はい。それで構いません」

　冬夜は自分の肩幅を指で測り、襟の高さと丈を言葉にした。上に着るのは布か革かと訊かれて、「布です」とだけ答えた。

　薄手なのか厚手なのか、裏地はあるのか、そういうことは何一つ言えなかった。店主は聞いた分だけを紙に書きつけて、それ以上は何も訊かなかった。

　百ユンを払うと、手元は千八百ユンになった。三日後に取りに来ればいい。

　店を出ると、通りはもう暮れかけていた。薬屋の軒先を覗くと、明かりはとうに落ちている。傷薬の買い足しは、当て革を受け取る日に回すしかなさそうだった。

　店を出て、冬夜は一度だけ振り返った。

　命が危ないわけでもなければ、誰かに追われているわけでもない。ただ、当て革を一枚頼むのに、まっすぐ「これに合わせてください」と言えない。

　秘密を抱えて暮らすというのは、こういうことらしかった。想像していたよりもずっと地味で、そのぶん、逃げ場がない。

　――次にログインしたら、まず薬屋だ。

　冬夜は頭の中の順番をそう決めて、歩き出した。傷薬を買い足して、三日後に当て革を受け取って、それから目眩し玉の使いどころを考える。

　現実では、サークルはどこかと訊かれて三語で終わったばかりだ。将来どうするのかも、まだ何一つ決めていない。

　なのにこちらでは、三日後に何を取りに行くかまで決まっている。

　見えなくする側に回ること。今日この森で覚えたのは、結局それだけだった。

　その、それだけのことに、冬夜は現実の自分よりずいぶん真剣になっていた。
