# 第二十八話　夏の終わりが見えてくる

　素材買取の窓口に、深部で溜めた牙と毛皮をまとめて出した。

　差し出された袋は、思っていたより軽い。数をこなした実感と、返ってくるものの重さは、どうやら比例しないらしい。

　それでも足りなければ、依頼の報酬を足すしかない。冬夜はギルドを出て、広場脇の武具屋へ向かった。

　台に並べた二本の短剣を、店主はひっくり返して刃元を覗き込んだ。

「よく使ったな。ここまで毟れてると、研いでも戻らん」

「無茶な使い方をしました」

「何をどうしたらこうなる。……まあいい」

　店主は奥の棚から布に巻いた一組を持ってきて、台の上で開いた。

　同じ形をしている。同じ長さで、同じ反りだ。それなのに、置かれた瞬間の音が違った。

「一つ上がると、鋼から違う。値も違うがな」

　冬夜は袋の中身と、値札を交互に見た。手が届くかどうかの瀬戸際で、届かせるには依頼の報酬を全部積むしかない。

　貯めておく理由を探そうとして、一つも見つからなかった。

「これ、ください」

　防具屋には、肩の裂けた上着を持ち込んだ。縫い直すより作り直したほうが早いと言われ、素直に頷く。

　あわせて、霞蜘蛛の硬毛を袋ごと預けた。以前より厚く、肩から鎖骨のあたりまで当て革を入れてほしい、と頼む。

「三日もらうよ」

　三日待つのは構わない。薬屋で傷薬を、武具屋で投擲ナイフを買い足して、その日は街を出なかった。

　宿に戻って霧腺を潰し、目眩し玉を丸め直す。手の中で転がる感触は、もうすっかり見慣れたものになっていた。

　インベントリの隅の手甲は、今日も出さなかった。誰かに見せれば正体が分かるのかもしれないが、刻紋銘を人前に置く気にはならない。

　店を出るころには、財布はほとんど残っていない。

　その代わり、腰の重さが違う。街の外れで新しい刃を抜き、試しに槍状へ伸ばしてみた。

　前の短剣で同じことをすると、突いた瞬間にわずかな撓みがあった。形は槍でも、中身は初心者向けの鋼のままだったからだ。

　借りたものは、形だけが変わって、素材はそのまま残る。自分の得物でも同じことだった。

　新しい刃は、撓まない。

　――なるほど。

　装備で埋める、というのはこういうことかと、冬夜はようやく腑に落ちた。




　三日後に受け取った上着は、肩の内側が明らかに硬くなっていた。

　腕を回しても引っかからない。動きを殺さない範囲で、ぎりぎりまで詰めてくれたのだと分かる。

　その足でギルドへ寄り、深部の依頼を三枚まとめて報告した。受付は書類を確認してから、いったん奥へ引っ込んだ。

　戻ってきた手には、見覚えのあるギルド証があった。刻まれた文字が、Eから一つ変わっている。

「Dです。おめでとうございます」

「……あの、何かの間違いでは」

「深部の分だけでも数が揃っていますし、ここ最近の頻度が異常なんですよ」

　受付は淡々と続けた。ランクが上がると、受けられる依頼が「そのランク以下」から一段広がる。遠出のもの、危険度の高いもの、これまで掲示板の上のほうに貼られていて手が出せなかったものが、まとめて選べるようになるらしい。

　冬夜はギルド証を受け取り、掲示板の前に立ち直す。

　見える紙の枚数が、まるで違っていた。

　そこからは、狩場を移した。

　東の街道沿いに出る依頼を受け、荷馬車を襲う獣を間引く。北へ二日歩いた岩場では、灰狼より二回り大きい四足の獣が群れを作っていた。

　どれも、森の深部より一段上だ。まともに受ければ立っていられない。

　だから受けない。岩の裂け目に誘い、目眩し玉で視界を潰し、風下から一頭ずつ抜く。街道では倒木を借りて楔に変え、逃げ道を狭めてから仕留める。

　やっていることは、深部にいた頃と何も変わらなかった。相手が大きくなったぶん、詰みを組む手数が増えただけだ。

『Lv18に上がりました』

　伸び方が、また変わった。深部ではひとつ上がるのに何日もかかっていたのに、格上を相手にし始めた途端、間隔が縮んでいる。

　同じ時間を使うなら、上を殴ったほうが早い。それは分かっていて、これまでは受けられなかっただけの話だった。

　書店のシフトは、その週から減らしてもらった。

　店長は「学生は夏くらい遊べ」と笑っていた。空いた時間は全部、向こう側に流れ込んでいく。

　フレンド一覧の茜音の名前は、灰色に沈んだままの日が増えた。冬夜のほうも、灯っているのを見かけて、用のない文を送ることはしなくなっていた。

『Lv24に上がりました』

　岩場の主のような個体を、丸一日かけて崖の上へ追い上げた日もある。落ちてくるところを待って、喉に刃を入れた。

　依頼を報告して、素材を売って、傷薬を買い足して、また掲示板の前に立つ。

　その繰り返しの果てに、通知が出た。

『Lv30に上がりました』

　冬夜は岩場の縁に腰を下ろして、久しぶりにステータス画面を開いた。

```
冬夜
Lv30
職業:暗器使い
ソウルクレスト:彼は誰(かはたれ)

スキル:投擲、隠密行動、暗器生成、毒の調合、急所看破、会心の一撃、精密投擲
```

　スキルの欄は、Lv9のあの日から一つも増えていない。

　増えたのは、この七つで何ができるかという心当たりのほうだ。

　数字だけが二桁の後半まで来ている。それを見ても、強くなったという言葉は、まだ自分から出てこなかった。




　書店のレジに西尾が現れたのは、夕方の六時を回った頃だった。

　参考書を二冊、無造作にカウンターへ置く。顔を上げた冬夜と、そこで初めて目が合った。

「あ。お前ここだったのか」

「西尾さん。……いらっしゃいませ」

「いらっしゃいませって」

　西尾は笑って、財布を出しながらカウンターに肘をついた。

「後期の必修、これ買っとけって言われてさ。もうすぐ夏休み終わるだろ」

　手が止まりかけて、冬夜はバーコードを読み直した。

「……もう、ですか」

「もうだよ。履修登録は?」

「まだです」

「一年は締切に気をつけろよ。あれ落とすと後がだるい」

　袋に入れて渡すと、西尾は受け取って、思い出したように付け足した。

「そういやゲーム、続けてる?」

「続けてます」

「俺は最近ちょっと落ちてんだよな。二十そこそこで止まってる。そっちは?」

　冬夜は少し迷ってから、正直に答えた。

「三十です」

　西尾の眉が上がった。袋を持ったまま、しばらく黙っている。

「……夏の間だけでそれか」

「時間はありましたから」

「時間はみんなあるんだよ」

　西尾はそう言って、また来る、と軽く手を上げて出ていった。自動ドアが閉まって、店内の音が戻ってくる。

　閉店まではまだ間がある。冬夜はレジ横の棚を直しながら、さっきのやり取りを頭の中で巻き戻していた。

　帰り道の空は、まだ完全には暗くなっていない。少し前まで、この時間はもう夜だった。

　夏休みの残りは、指で数えられるところまで来ている。

　この夏、現実で決めたことが一つでもあるかと考えて、冬夜は何も思い出せなかった。履修も、サークルも、来年の話も、一つ残らず先送りにしてある。西尾に訊かれるまで、締切があることすら忘れていた。

　その一方で、向こうでは毎日何かを決めていた。どの依頼を受けるか、どこへ誘い込むか、どちらの刃を先に投げるか。夜中まで考えて、翌日に試して、うまくいかなければ組み直す。

　本気になれない、という自覚は昔から持っていた。ここへ来て変わったのは、本気になれる場所が一つだけ見つかってしまったことだ。

　そしてそれは、この世界のどこにもない。

　情けないことなのかどうか、冬夜には判断がつかなかった。ただ、シフトを減らしたときに何のためらいもなかったことだけは、はっきり覚えている。




　夕食を済ませてログインすると、セイレスの広場には昼の光が落ちていた。

　視界の端で、小さな表示が明滅している。

　フレンド一覧の名前が、灰色から明るい色へ変わっていた。

『冬夜くん、久しぶり! ちょっと相談があるんだけど、いま平気?』

　終わりが見えてきた、と思ったばかりだった。

　その終わりの手前に、まだ予定が入るらしい。
