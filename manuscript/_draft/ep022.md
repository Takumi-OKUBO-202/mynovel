# 第二十二話　一人で来い

　午前八時半。冬夜は寝間着のまま机に向かい、ノートパソコンを開いた。

　昨日はゲームから上がったのが遅く、パソコンを開かずに寝てしまった。掲示板を見ないまま一日を終えたのは、久しぶりのことだった。

　灰狼の森のまとめスレッドを開いて、冬夜は画面を上へ戻す。昨日の朝は四百三十番台で止まっていたはずの書き込みが、見たことのない伸び方をしていた。

```
【灰狼の森】エリア情報まとめスレ

461: 名無しの冒険者
虎の件、結局どこの話だったんだ
深部っていっても広いだろ

462: 名無しの冒険者
たぶんだけどおれ、そのあとにそこ通ったわ
北の沢を渡って、崩れた木の橋の先の草地
一面まだ霜が残ってて、木も幹の半分まで白かった
あんな場所ほかにないからすぐわかる

463: 名無しの冒険者
特定されてるじゃん

464: 名無しの冒険者
行くわ

465: 名無しの冒険者
ボスもう倒されてるんだろ
じゃあ今が一番安全な時期ってことじゃね

466: 名無しの冒険者
刻紋銘が落ちた場所だぞ
湧き直す可能性を考えるなら早いもん勝ち

467: 名無しの冒険者
灰狼の森って初心者エリアだし
ちょっと見に行くだけなら平気っしょ
```

　冬夜はマウスから指を離した。

　四百六十二番は、たぶん何も企んでいない。霜の残った珍しい場所を見つけて、道順を思い出したまま書いただけだ。

　三百五十二番も、四百二十三番も、場所だけは書かなかった。それを、無関係な誰かが善意で埋めた。

　冬夜はそのまま画面を送った。指が止まらないまま、書き込みの番号だけが五百を越えていく。

```
502: 名無しの冒険者
昨日の夜あそこ行った人、無事?

503: 名無しの冒険者
無理だった
草地までは着いたよ。霜も見た。そこまではよかった

504: 503
帰り道で狼に見つかってから、ずっと追われた
沢を渡っても来る。振り切ったと思っても回り込んでくる
最後は四方から同時だった。示し合わせたみたいに

505: 名無しの冒険者
うちも全滅。四人まとめて

506: 名無しの冒険者
ボスもういないのに動きが変わってないのおかしいだろ
むしろ前より揃ってる

507: 名無しの冒険者
経験値どれくらい持ってかれた?
おれレベル一個下がったんだけど

508: 名無しの冒険者
それより三日入れないのがきつい
夏休みなんだが

509: 名無しの冒険者
一昨日始めたばっかりの友達連れてった
そいつも一緒にやられた
初日でデスペナは可哀想すぎる。おれのせいだ

510: 名無しの冒険者
何人やられたか数えるのやめたほうがいい
夜通し人が入ってた
```

　やられたときにどうなるかは、始める前に読んだガイドにも書いてあった。経験値をいくらか持っていかれて、そのあとしばらくログインできなくなる。

　文字で読んでいる間は、それだけの話だった。冬夜自身、まだ一度もやられていない。

　三日、と書き込みにはあった。

　夏休みの三日だ。友達と時間を合わせて、その日のために始めた人間から、三日をまるごと取り上げる。

　冬夜は五百九番の書き込みをもう一度読んだ。連れていったのは自分だ、と書いてある。書いた本人も、たぶん同じだけ入れなくなっている。

　順番に並べれば、線は一本きりだった。

　茜音が白虎を出した。遠くから見ていた誰かが書いた。近くで見ていた者が、書かれていない細部を足した。話が本物らしくなって、無関係な誰かが道順を書き添えた。そして、人が集まった。

　どこを切り取っても、始まりは自分たちだ。

　階下から母の声が上がってきた。ごはんは食べるのか、という問いに、冬夜はあとでと返した。喉を通る気がしなかった。



　ログインしたセイレスは、白っぽく曇った朝だった。

　この世界の空は現実と噛み合っていない。それでも今日は、たまたま外と同じ色をしていた。

　ギルドの前を通りかかったとき、三人組が石段に腰かけて話しているのが耳に入った。

「今日、四人目どうする」

「あいつ木曜まで入れないってさ」

「昨日誘ったの、おれなんだよな」

　冬夜は足を止めずに通り過ぎた。掲示板の外にも、同じ話が同じ数だけ転がっている。

　ギルド裏手の路地には、先に茜音が来ていた。樽に腰かけて、足はぶらぶらしていない。

「……聞いた?」

　顔を上げた茜音の第一声が、それだった。

「掲示板で読んだ」

「わたしは、さっきそこで聞いた。何人もやられたって」

　冬夜は木箱に腰を下ろして、読んできたものを順に伝えた。場所が書かれてしまったこと。ボスがいないから安全だと思われたこと。夜通し人が入り続けたこと。

　狼が縄張りを越えて追いかけてきたことを話したとき、茜音の指が杖の柄を握った。

「あの子たち、ずっとあのままなんだ」

「そうらしい。深部の狼がおかしいっていうのは、前から書かれてた」

　王様はもういない。いないのに、群れの動きだけが変わっていない。

「……わたしが」

　茜音の声が、途中で沈んだ。

「わたしが試したりしなければ、誰も来なかったんだよね」

　来たな、と冬夜は思った。この人がそこへ行くことは、パソコンを閉じたときから分かっていた。

「違う」

　冬夜は言葉を選ばずに言った。選んでいる時間のほうが、この人には効かない。

「茜音があの子を出したところまでは、ただの目撃談だった。あれだけなら、飽きられて流れて終わってる」

「でも」

「その先を決めたのは俺だ」

　茜音が顔を上げた。

「書き返さない、運営にも言わない、探さない、いつも通りに過ごす。昨日、そう決めたのは俺だろ」

　打てる手を順番に潰して、最後に何も残らなかった。あのとき冬夜は、何もしないことを一番安全な手だと思った。

　そのあいだに、噂は場所を手に入れて、人を集めた。

「あれは、俺の判断だ。茜音のせいにできるところが一つもない」

「……冬夜くん、そういうの、ずるいと思う」

　茜音が唇を尖らせた。目の縁が赤い。

「自分のせいにすると、わたしが何も言えなくなるじゃん」

「じゃあ、二人のせいでいい」

　冬夜は膝の上で指を組んだ。

「そのかわり、落ち込むのは今日の分だけにしよう。止められることを探すほうが先だ」

　茜音はしばらく黙って、それから小さく頷いた。頷いてから、無理やり口の端を持ち上げた。



　その日は二人とも狩りに出る気になれず、いったん別れることにした。

　ギルドで話を聞いてくると言って、茜音が先に路地を出ていく。冬夜は樽の並びに背を預けたまま、しばらくそこに残った。

　視界の端に、小さな表示が浮かんだのは、そのときだった。

```
メッセージを受信しました

差出人:

話したいことがある。あの洞窟に一人で来い
```

　冬夜は二度読んで、それから差出人の欄をもう一度見た。

　空白だった。

　フレンドでない相手からでも、短いメッセージを受け取ること自体はできる。パーティに誘いたい、取引を持ちかけたい、という用があるからだ。

　ただし、その場合でも送り主の名前は必ず出る。名乗らずに送る方法は、そもそも用意されていない。

　冬夜はメニューからメッセージの履歴を開いた。

```
メッセージ履歴(直近)

茜音:『すぐ行くねー』
茜音:『あるよー。でも今ちょっと手が離せないから、
　　　一時間後でもいい?』
```

　一番新しい行は、昨日の茜音のものだった。

　たった今読んだ文面が、どこにもない。届いたはずのものが、届いた記録ごと存在していない。

　冬夜は続けて、周囲のプレイヤーを検索する機能を呼び出した。通りを歩く名前がいくつか並ぶだけで、当たり前だが、空白の名前は出てこなかった。

　不具合の報告窓口を開き、差出人の名前が表示されないメッセージが届いた、とだけ書いて送った。返ってきたのは、数分後の定型文だった。

```
【運営サポート】お問い合わせへの自動返信

ご報告いただいた時刻の前後において、
お客様のアカウントに該当する受信記録は確認できませんでした。
表示に不審な点が続く場合は、改めてご連絡ください。
```

　冬夜は窓を閉じて、路地の壁に後頭部を預けた。

　壊れているのなら、もっと単純な壊れ方をするはずだ。文字が崩れるとか、同じものが二度届くとか、そういう壊れ方を。

　名前だけがきれいに抜け落ちて、記録だけがきれいに残らない。そんな不具合は、冬夜には思いつかなかった。

　要の顔が一瞬だけ浮かんで、すぐに消えた。あの人は所属まで開示して名乗ってから来た。今さら名前を隠す理由がない。

　冬夜が長く息を吐いたのは、もう一つのほうに気づいたからだった。

　あの洞窟、と書いてある。それだけで、冬夜には場所が分かってしまった。

　森の奥の、苔むした石段の先。大熊を倒してようやく入れた、あの手つかずの洞窟。掲示板に一行も書いていない場所だ。

　草地を近くで見ていた者が、あの洞窟のことも知っている。

　行くか、と冬夜は考えた。

　考えるより先に、茜音に伝えるかどうかを考えている自分に気づいた。伝えれば止められる。止められるのが分かっていて伝えるのは、面倒なだけだ。

　――わたしに黙って、ひとりで考えないでね。

　昨日、この路地で指を立てて言われたばかりだった。冬夜はメニューを開いて、短い文を送った。

```
冬夜:さっきの場所に戻れるか
茜音:『すぐ行く』
```



「行かないよね」

　文面を聞き終えた茜音の第一声が、それだった。

「行く」

「行かないよねって聞いてるんだけど」

「行く」

　茜音が樽から降りて、正面に立った。背の低い相手に見上げられているのに、押し返される感じがある。

「わたしのせいなのに、なんで冬夜くんが一人で行くの」

「二人のせいだって、さっき決めただろ」

「そういうことじゃなくて!」

　路地の空気が、びりっと鳴った気がした。茜音がこの声を出すのを、冬夜は初めて聞いた。

「見られてたのはわたしだよ。書かれてたのも、ぜんぶわたしのことだったじゃん。片膝ついたとか、そういうの」

「そうだ」

　冬夜は頷いた。ここを否定するつもりはなかった。

「だから行かせない」

「……え」

「あの書き込みは、全部茜音を見た者の目で書かれてる。膝も、紋様も、霜も。あれを近くで見ていたやつが、興味を持ってるのは茜音のほうだ」

　冬夜は指を一本立てた。

「一人で来いって指定されてる。二人で行けば、会えないまま終わるかもしれない」

　もう一本、指を立てる。

「それと、狙われてるのが茜音なら、俺は茜音を連れていかない。理由はそれだけだ」

　茜音は口を開きかけて、閉じた。それから、絞り出すように言った。

「じゃあ、あの子を連れてって」

「連れていけない。あの子を出せるのは茜音だけだ」

　言われて気づいた顔で、茜音が黙る。契約しているのは彼女で、呼び出せるのも彼女だけだ。白虎だけを貸すという手は、最初から存在しない。

「……死んだりしないよね」

「しない」

　このゲームで死ぬことはない。最悪でも、経験値を持っていかれて、しばらく入れなくなるだけだ。

　その「だけ」の重さを、今朝いやというほど読んできたところだった。

「じゃあ、条件つける」

　茜音が指を立てた。さっき冬夜がやったのと同じ立て方だった。

「一つ。現実の時計で一時間。入る時間を先に教えて。終わったら『終わった』って一言送る。それだけでいいから」

「分かった」

「二つ。危ないと思ったら、話の途中でも落ちて。相手が何か言ってる最中でもいいから、落ちて」

「落ちる」

「ほんとに? 冬夜くん、そういうとき粘るでしょ」

「粘らない。話が通じない相手だと分かった時点で落ちる」

　茜音はしばらく冬夜の顔を見てから、三本目の指を立てた。

「三つ。わたしは街で待つ。でも、あの子はいつでも出せるようにしておく。魂力も満タンにしておく」

　そして、と茜音は続けた。

「一時間過ぎて連絡がなかったら、わたしは好きにするから。止めても行くからね」

「それでいい」

　即答すると、茜音は少し面食らった顔をした。冬夜としては、それが一番現実的な線だと思っただけだ。

　止められるつもりで隠すより、期限を決めて渡しておくほうが、この人には効く。

「持ち物、言ってみて」

「傷薬の小が五本。目眩し玉が二つ。当て革は着てる。外套も」

「短剣は?」

「二本ある。投げるほうも持ってる」

　茜音は指を折りながら数えて、それから小さく頷いた。

「……足りてはいるんだよね。悔しいけど」

「十一時十分に入る」

　冬夜は現実の時計を思い浮かべながら言った。ゲームの中の空はあてにならない。時間を約束するなら、外の時計で数えるしかない。

「十二時十分までに何も来なかったら、茜音の好きにしていい」

「うん」

　茜音は返事をしてから、まっすぐ冬夜を見上げた。

「言っとくけど、納得してないからね」

「知ってる」

「ぜんぜん、してないから」

　念を押すように、もう一度言われた。冬夜はそれに、頷くことしかできなかった。



　灰狼の森の手前側は、いつもと変わらなかった。

　灰色狼が数匹、木立の向こうからこちらを窺っている。深部の話がどれだけ騒がれても、この辺りの狼はいつも通り、間合いを測るだけで襲ってこない。

　冬夜は外套の襟を立て、獣道を東へ折れた。深部とは反対側だ。苔むした石段が眠る一帯へは、こちらから登っていく。

　崩れた柱の列を抜けると、記憶にある景色が現れた。大熊がいた広場は、あの日のまま静かだった。

　その奥に、洞窟の口が開いている。

　冬夜は足を止めて、視界の隅に時刻を呼び出した。十一時九分。約束の一分前だった。

　腰の袋から目眩し玉を一つ取り出し、握り直してから、また戻す。まだ使うときではない。

　洞窟の中は、入り口から三歩先で暗くなっていた。奥までは見通せない。

　冬夜は一つ息を吸って、その暗がりへ足を踏み入れた。
