# mynovel

VRMMOジャンルのウェブ小説プロジェクト。「小説家になろう」「カクヨム」への同時掲載を想定し、執筆から書籍化・収益化までを見据えたリポジトリ構成になっている。

詳細な運用ルール・ディレクトリの役割・執筆フローは [CLAUDE.md](./CLAUDE.md) を参照。

## 構成の概要

- `manuscript/` — 本文
- `bible/` — 世界観・設定資料(整合性チェックの参照元)
- `plot/` — プロット・伏線トラッカー
- `research/` — 市場リサーチ・競合分析
- `publishing/` — マーケティング戦略・応募履歴・PV/ブクマなどの実績ログ
- `.claude/agents/` — 執筆支援エージェント(市場リサーチ・整合性編集・下書き・校正・マーケティング)
- `.claude/skills/` — ワークフロー(新話執筆・読者視点レビュー・トレンド調査・マーケティング戦略・応募準備)
