# 応募・書籍化打診 準備ワークフロー

## 手順

1. 応募先(新人賞名、または打診先出版社)の応募規定をユーザーに確認する。不明な場合は`marketing-editor`エージェントにWebSearchで確認させる
2. `publishing/metrics.md` の実績(PV・ブックマーク・評価ポイント推移)を確認し、アピールできる実績値を整理する
3. `marketing-editor` エージェントに依頼し、応募規定に沿ったあらすじ・作品紹介文を作成する
4. `plot/outline.md` を参照し、応募時点で未完結の場合は結末までの展望(プロット概要)もまとめる
5. 応募規定のチェックリスト(文字数上限、既発表作品の可否、二重投稿の可否など)を確認し、問題がないか確認する
6. 応募内容・提出日・結果を `publishing/submission-log.md` に記録する

## 注意

- 応募規定は賞・出版社ごとに大きく異なるため、必ず最新の公式情報を確認してから進める
- なろう/カクヨムでの二重投稿禁止規定や、コンテスト応募中の投稿継続可否など、プラットフォーム側の規約も確認する
